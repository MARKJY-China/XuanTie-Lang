# 离线文档

玄铁文档同时提供**离线包**，便于无网络环境查阅、或放进自己的笔记库/内网。

| 包 | 内容 | 适合 |
|----|------|------|
| **纯 Markdown** | 全部文档的 Markdown 源文（语言参考手册、12 篇编程指南、10 篇手册章节、关键字速查、UI 状态系统与选项键）+ 版本日志 | VS Code / Typora / Obsidian / 语雀等任意 Markdown 工具；也方便全文检索与二次整理 |
| **Web 站点** | 本节文档站的完整静态站点（含搜索、侧栏、语法高亮） | 双击离线浏览或放到内网/对象存储静态托管 |

下载：

*   [玄铁文档 · 纯 Markdown(zip)](https://xuantie-community.cn-nb1.rains3.com/img/docs/xuantie-docs-md.zip)
*   [玄铁文档 · Web 站点(zip)](https://xuantie-community.cn-nb1.rains3.com/img/docs/xuantie-docs-web.zip)

## Web 包使用说明

Web 包是静态站点产物，**需经 HTTP 访问**：

* 直接双击 `index.html`（file:// 方式）能看到首页，但站内跳转会受浏览器限制而失效；
* 推荐：解压后放进任意静态服务器 / 对象存储的 HTTP 地址下访问；本地预览可执行 `python -m http.server 8080` 后访问 `http://127.0.0.1:8080/`。

## 版本对应

离线包与文档站同一内容源（仓库 `GUIDE/`），随文档更新重新打包；包内 `README` 标注生成日期。
