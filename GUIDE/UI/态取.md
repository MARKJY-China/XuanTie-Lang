# UI.态取

**读取状态键的值；构建期内读取会自动登记依赖。**

```text
设 计数 = UI.态取(状态, "计数")
```

## 你可以……

- **在构建函数里读值渲染**——界面随状态变化自动更新：

```text
UI.文本("当前: " & 字(UI.态取(s, "计数")), {"字号": 20})
```

- **驱动条件与动画目标**——配合若表达式或 `UI.动值`：

```text
UI.图片("x.png", {"不透明度": UI.动值("钮", 若 UI.态取(s, "框").字符数 > 0 { 100 } 否 { 0 })})
```

## 注意

- 键不存在时返回 `空`（不会报错）；做空值兜底：`设 v = UI.态取(s, "框") 若 v == 空 { v = "" }`。
- 读取的若是数组/字典，拿到的是**引用**——原地修改后框架感知不到，需 `UI.标脏` 或改用 `UI.态设` 写回。
