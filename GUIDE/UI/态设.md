# UI.态设

**写状态键的值；值变化时通知订阅者并标脏（驱动重绘）。**

```text
UI.态设(状态, "计数", UI.态取(状态, "计数") + 1)
```

## 你可以……

- **在事件回调里改状态**——界面下一帧自动跟上：

```text
UI.按钮("点我 +1", {"点击": 函() { UI.态设(s, "计数", UI.态取(s, "计数") + 1) }})
```

- **从异步任务里更新界面**——其他线程的 `态设` 会在下一个轮询周期（≤8ms）唤醒重绘：

```text
设 t = 异步 {
    时.睡(1000)
    UI.态设(状态, "倒计时", "到点了")
}
```

## 注意

- 新旧值相等（`==` 比较）时直接跳过——不通知、不标脏，频繁重设同值零代价。
- 标脏是重绘的唯一扳机：原地改数组/字典（如 `列表.追加(x)`）框架感知不到，要么写回 `态设(状态, "列表", 列表)`，要么 `UI.标脏`。
