# UI.态快照

**取状态容器当前的整棵值字典——不登记依赖。**

```text
设 当前 = UI.态快照(状态)
```

## 你可以……

- **把状态整体导出**——存盘、打印、发网络：

```text
设 存档文本 = 化(UI.态快照(状态))
```

- **在非构建代码里随手读值**——不想惊动依赖追踪时：

```text
设 现值 = UI.态快照(状态)["计数"]
```

## 注意

- 返回的是**值字典本体的引用**，不是深拷贝——改它等于改状态，但框架感知不到（要生效请走 `UI.态设`）。
- 与 `UI.态取` 的区别：态取在构建期内会登记依赖（供框架内部使用），快照永远不登记。
