# UI.造状态

**创建响应式状态容器——声明式 UI 的唯一数据源。**

```text
设 状态 = UI.造状态({"计数": 0, "名字": ""})
```

## 你可以……

- **用初始字典一次装入多个键**——键名自取，值可以是数字、字符串、布尔、数组、字典：

```text
设 状态 = UI.造状态({"计数": 0, "选中": "无", "列表": []})
```

- **把它交给 `UI.应用` / `UI.刷新`**——之后构建函数每帧拿着它产出界面（View = f(State)）：

```text
UI.应用(状态, 函(s) { 返 UI.列([UI.文本("计数: " & 字(UI.态取(s, "计数")))], {}) })
```

## 注意

- 界面只跟随状态走：想改界面就 `UI.态设`，绝不要直接改界面节点（下一帧整棵树会被重建）。
- 容器是个普通字典对象，但内部以 `_` 开头的字段（`_值`/`_监听`/`_脏`/`_依赖`）归框架管，别手写。
