# 字色

**文字颜色；对未设底色的矩形则是填充色。**

```text
UI.文本("你好，玄铁", {"字色": UI.色16("#E5E7EB")})
```

## 你可以……

- **用别名 `颜色`**——与 `字色` 完全同义，写入同一个内部字段：

```text
UI.文本("别名也一样", {"颜色": UI.色(255, 255, 255, 255)})
```

- **给矩形当填充色用**——底色透明时，矩形拿字色填充：

```text
UI.矩形({"宽": 40, "高": 40, "字色": UI.色16("#F59E0B")})
```

## 注意

- 矩形一旦设了 底色，填充就归底色管，字色恢复"只管文字"。
- 悬浮/按住/禁用三态字色各有专键：悬字色、按字色、禁字色。
