# 行数限制

**换行文本最多显示几行；超出部分在末行补 `…`。默认 0 = 不限。**

```text
UI.文本("这是一段很长的会话预览文本可能包含很多信息", {
  "宽": 160, "换行": 真, "行数限制": 2
})
```

## 你可以……

- **两行预览 + 省略号**——列表里最常见的形态：

```text
UI.文本(项["预览"], {"宽": 200, "换行": 真, "行数限制": 2, "字色": UI.色彩["浅灰"]})
```

## 注意

- 只在 `换行` 为真时生效；单行文本请用 `截断`。
- 超出行数时末行自动补 `…`（即使没写 `截断`）。
- 行数按实际排版算，不按 `\n` 算；文本里的 `\n` 不参与断行。
