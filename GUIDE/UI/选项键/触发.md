# 触发

**点击回调的触发时机：`"点击"`（默认）/ `"按下"` / `"按住"`。**

```text
UI.按钮("即发", {"触发": "按下", "点击": 函() { UI.态设(s, "n", UI.态取(s, "n") + 1) }})
```

## 你可以……

- **`"点击"`（默认）**——按下后在钮内松开才触发，可拖出取消。
- **`"按下"`**——指针一落即触发，不等松开：

```text
{"触发": "按下", "点击": 函() { UI.态设(s, "n", UI.态取(s, "n") + 1) }}
```

- **`"按住"`**——按住不动则按 连发间隔 持续连发：

```text
UI.按钮("连加", {"触发": "按住", "点击": 函() { UI.态设(s, "n", UI.态取(s, "n") + 1) }})
```

## 注意

- 三种模式共用同一个 点击 回调，差别只在何时调用。
- `"按住"` 模式配 首按延迟 与 连发间隔 调手感。
