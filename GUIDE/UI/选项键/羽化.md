# 羽化

**边缘羽化像素：1 仅抗锯齿，大于 1 产生柔边。**

```text
UI.矩形({"宽": 120, "高": 60, "底色": UI.色16("#3B82F6"), "羽化": 8})
```

## 你可以……

- **只要顺滑边缘**——写 1（默认），仅做抗锯齿：

```text
{"宽": 120, "高": 60, "底色": UI.色16("#10B981"), "羽化": 1}
```

- **做柔边/光晕感**——加大像素，边缘渐隐：

```text
{"宽": 120, "高": 60, "底色": UI.色16("#8B5CF6"), "圆角": 12, "羽化": 16}
```

## 注意

- 羽化大于 1 时走渐变纹理通路渲染，开销高于纯色填充。
- 羽化只参与渲染：节点占位仍由 宽/高 决定，布局不受影响。
