# 平移y

**纵向偏移像素（可负）：渲染与命中间步偏移，不影响兄弟布局。**

```text
UI.矩形({"宽": 60, "高": 60, "底色": UI.色16("#3B82F6"), "平移y": -8})
```

## 你可以……

- **悬浮微浮起**——状态覆写里改平移，低成本微交互：

```text
UI.按钮("浮起", {"悬浮": {"平移y": -2}})
```

- **用 `UI.动值` 做纵向滑入**——目标值一变即平滑补间：

```text
UI.列([UI.文本("抽屉")], {"平移y": UI.动值("抽屉y", 目标y)})
```

## 注意

- 偏移作用于整棵子树：子项与命中区域同源偏移，渲染和点击始终对得上。
- 不占布局：兄弟不会因平移让位；与 y 不同，平移y 在任何容器里都可用。
