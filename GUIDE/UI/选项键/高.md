# 高

**固定高度像素；不写则由内容撑开。**

```text
UI.矩形({"宽": 240, "高": 80, "底色": UI.色16("#374151")})
```

## 你可以……

- **定高工具条/标题栏**——行容器配定高最常见：

```text
UI.行([UI.文本("标题栏")], {"高": 40, "内边距": 8})
```

- **配合 裁剪 做收起动画**——高用动值收缩，内容不外溢：

```text
UI.列([UI.文本("内容")], {"高": UI.动值("面板高", 目标高), "裁剪": 真})
```

## 注意

- 不写高时由内容撑开：文本看字号，容器看子项与 内边距。
- 高是布局属性：改它会引发重排；只想视觉偏移请用 平移y。
