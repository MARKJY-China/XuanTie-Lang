# 边框宽

**边框厚度像素，默认 0（不画边框）。**

```text
UI.按钮("描边按钮", {"边框宽": 2, "边框色": UI.色16("#3B82F6")})
```

## 你可以……

- **只描边不填底**——不设底色 + 边框宽，空心样式：

```text
UI.按钮("空心", {"边框宽": 1, "边框色": UI.色16("#9CA3AF")})
```

## 注意

- 0 即关闭：边框色存在也不绘制。
- 边框颜色由 边框色 定；悬浮/按住/禁用三态边色见 边框色 专页。
