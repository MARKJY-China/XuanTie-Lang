# 主轴对齐

**子项在主轴上的排布方式（列的主轴是纵向，行是横向）。**

```text
UI.列([UI.文本("甲"), UI.文本("乙")], {"高": 200, "主轴对齐": UI.对齐中})
```

## 你可以……

- **六个常量任选**——`UI.对齐始`（默认）、`UI.对齐中`、`UI.对齐末`、`UI.对齐间`、`UI.对齐均`、`UI.对齐均等`：

```text
UI.行([UI.按钮("A", {}), UI.按钮("B", {})], {"宽": 400, "主轴对齐": UI.对齐间})
```

- **对齐间做两端分布**——第一个贴头、最后一个贴尾，中间均分空隙：

```text
{"主轴对齐": UI.对齐间}
```

## 注意

- 主轴方向由容器定：列=竖、行=横，别与 叉轴对齐 搞混。
- 只在有剩余空间时可见差别；子项被 弹性 撑满后它对结果无影响。
