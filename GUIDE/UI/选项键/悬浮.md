# 悬浮

**状态覆写子字典：悬浮状态下覆写任意选项键。**

```text
UI.矩形({"宽": 100, "高": 40, "底色": UI.色16("#374151"),
    "悬浮": {"底色": UI.色16("#4B5563"), "圆角": 8}})
```

## 你可以……

- **覆写颜色**——子字典里颜色键固定叫 底色/字色/边色：

```text
{"悬浮": {"底色": UI.色16("#1F2937"), "字色": UI.色16("#FFFFFF")}}
```

- **覆写任意键**——宽、圆角、不透明度等都能进子字典：

```text
{"悬浮": {"宽": 120, "不透明度": 80}}
```

## 注意

- 颜色三键与平面键（悬底色/悬字色/悬边色）等价，两套写法可混写。
- 解析优先级：禁用 > 按下 > 悬浮 > 常态——同键多处覆写时高优先级赢。
