# 外边距

**节点与兄弟之间的留白，写法同内边距。**

```text
UI.列([
    UI.按钮("上", {}),
    UI.按钮("下", {"外边距": UI.四边(8, 0, 0, 0)})
], {})
```

## 你可以……

- **裸数字 / `UI.全边` / `UI.四边`**——三种写法与 内边距 一致：

```text
{"外边距": 8}
{"外边距": UI.四边(4, 8, 4, 8)}
```

## 注意

- 外边距是节点自己的"护城河"：影响与兄弟的间隔，参与布局占位。
- 统一间隙优先用父容器的 间距；外边距留给个别子项的特殊偏移。
