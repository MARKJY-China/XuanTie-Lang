# 按下

**状态覆写子字典：按住状态下覆写任意选项键。**

```text
UI.按钮("按住变化", {"按下": {"底色": UI.色16("#1D4ED8"), "圆角": 10}})
```

## 你可以……

- **覆写颜色**——子字典里颜色键固定叫 底色/字色/边色：

```text
{"按下": {"底色": UI.色16("#B91C1C"), "字色": UI.色16("#FEE2E2")}}
```

- **覆写任意键**——尺寸、圆角、平移等皆可在按住时改写：

```text
{"按下": {"平移y": 1, "圆角": 6}}
```

## 注意

- 颜色三键与平面键（按底色/按字色/按边色）等价，两套写法可混写。
- 解析优先级：禁用 > 按下 > 悬浮 > 常态。
