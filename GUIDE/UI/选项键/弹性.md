# 弹性

**flex-grow 系数：按比例挤占父容器的剩余空间。**

```text
UI.行([UI.文本("左"), UI.弹性(1, {}), UI.文本("右")], {})
```

## 你可以……

- **当占位弹簧用**——`UI.弹性(1, {})` 把两侧内容顶开：

```text
UI.行([UI.按钮("返回", {}), UI.弹性(1, {}), UI.按钮("下一步", {})], {})
```

- **给普通节点配系数**——选项键 `"弹性"` 写比例，剩余空间按系数切分：

```text
UI.行([
    UI.矩形({"弹性": 2, "高": 40, "底色": UI.色16("#3B82F6")}),
    UI.矩形({"弹性": 1, "高": 40, "底色": UI.色16("#10B981")})
], {})
```

## 注意

- 弹性分的是"剩余空间"：内容自身尺寸先满足，多出来的才按系数分配。
- 弹性为 0（默认）即不参与分配，节点保持自身尺寸。
