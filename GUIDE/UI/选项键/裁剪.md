# 裁剪

**容器选项：子树超出节点边界即裁掉，界外部分不渲染也不响应悬浮/点击。**

```text
UI.列([
    UI.矩形({"宽": 400, "高": 40, "底色": UI.色16("#3B82F6")})
], {"宽": 200, "高": 100, "裁剪": 真})
```

## 你可以……

- **做收起动画**——高度用动值收缩，配裁剪防止内容外溢（收起动画必备）：

```text
UI.列([UI.文本("内容")], {"高": UI.动值("面板高", 目标高), "裁剪": 真})
```

## 注意

- 裁剪同时裁渲染与命中：界外部分既画不出来，也点不到。
- 滚动容器自带裁剪行为；普通容器需要时才显式开。
