# 可视

**`可视: 假` 时整棵子树不渲染、不响应交互，也不参与布局。**

```text
UI.文本("藏起来", {"可视": 假})
```

## 你可以……

- **绑状态做显隐**——构建函数每帧重算，假即整块消失：

```text
UI.列([UI.文本("详细内容")], {"可视": UI.态取(s, "展开")})
```

## 注意

- 与 不透明度 0 的差别：不透明度 0 仍占布局位（不可见、不响应）；可视 假 直接整树跳过，连布局位都不占。
- 与 禁用 不同：禁用看得见但点不动；可视 假 是彻底不存在。
