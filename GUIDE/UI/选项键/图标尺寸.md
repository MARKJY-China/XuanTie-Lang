# 图标尺寸

**图标绘制尺寸（像素）；0 = 自动（图标按钮取净区最大边，`UI.图标` 默认 24）。**

```text
UI.图标("search", {"图标尺寸": 20})
UI.图标按钮("settings", {"图标尺寸": 18})
```

## 你可以……

- **同一图标配不同字号**——列表项 16、工具栏 20、空态 40：

```text
UI.图标("inbox", {"图标尺寸": 40, "图标色": UI.色彩["浅灰"]})
```

- **不写尺寸**——`UI.图标` 用 24×24；`图标按钮` 按按钮净区自动取最大边：

```text
UI.图标按钮("more-horizontal", {"宽": 30, "高": 30})
```

## 注意

- 光栅化尺寸取整后缓存（名字@尺寸）；频繁换尺寸会多占纹理内存。
- 图标是矢量 SVG 光栅化，放大不会糊到糊成块，但过小（<12px）细节会丢，属于正常。
- `UI.图标` 的宽/高优先决定盒子；`图标尺寸` 决定图标在盒内绘制的大小并居中。
