# 边框样式

**边框画法：`"实线"`（默认）或 `"虚线"`；需配合 `边框宽` > 0 才可见。**

```text
UI.矩形({"宽": 300, "高": 1, "边框色": UI.色16("#444444"), "边框宽": 1, "边框样式": "虚线"})
```

## 你可以……

- **列表分割线/空态边框**——虚线比实线轻，适合弱分隔：

```text
UI.文本("暂无消息", {"宽": 200, "字对齐": UI.对齐中,
  "边框宽": 1, "边框色": UI.色16("#555555"), "边框样式": "虚线"})
```

- **粗实线边框**——`边框宽` 现在按真实厚度绘制（v1.6.0 修复）：

```text
UI.矩形({"宽": 120, "高": 60, "边框宽": 3, "边框色": UI.色彩["蓝"]})
```

## 注意

- 虚线只支持**直角**矩形：`圆角` > 0 时仍按实线画。
- 虚线节距固定 6px 实 + 4px 空，线宽 = `边框宽`。
- 状态边色（悬边色/按边色/禁边色）对两种样式都生效。
