# 宽

**固定宽度像素；不写则由内容撑开。**

```text
UI.矩形({"宽": 240, "高": 80, "底色": UI.色16("#374151")})
```

## 你可以……

- **定宽布局**——文本、按钮、容器都吃这一键：

```text
UI.按钮("定宽按钮", {"宽": 160})
```

- **用状态覆写改宽**——`悬浮`/`按下`/`禁用` 子字典可覆写任意键，宽也在内：

```text
UI.矩形({"宽": 100, "高": 40, "底色": UI.色16("#3B82F6"),
    "悬浮": {"宽": 120}})
```

## 注意

- 不设宽时由内容撑开：文本看文字，容器看子项与 内边距。
- 宽是布局属性：改它会推动兄弟与父容器重排，不像 平移x 那样"独善其身"。
