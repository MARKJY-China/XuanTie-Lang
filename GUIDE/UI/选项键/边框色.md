# 边框色

**边框颜色；需 边框宽 大于 0 才会绘制。**

```text
UI.矩形({"宽": 120, "高": 60, "边框色": UI.色16("#3B82F6"), "边框宽": 2})
```

## 你可以……

- **三态边色**——悬浮/按住/禁用各有平面专键：

```text
UI.按钮("描边", {"边框宽": 1, "边框色": UI.色16("#6B7280"),
    "悬边色": UI.色16("#3B82F6")})
```

- **用状态覆写子字典**——`悬浮: {"边色": ...}` 等价（见 悬浮）：

```text
{"悬浮": {"边色": UI.色16("#3B82F6")}}
```

## 注意

- 边框宽为 0（默认）时，边框色写得再漂亮也不画。
- 三态平面键叫 悬边色/按边色/禁边色；状态子字典里固定叫 `"边色"`。
