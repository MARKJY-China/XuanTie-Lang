# 按字色

**按住鼠标时的文字色；默认透明，即沿用常态字色。**

```text
UI.按钮("发射", {"字色": UI.色16("#FFFFFF"), "按字色": UI.色16("#FCA5A5")})
```

## 你可以……

- **给按压瞬间一个色差**——配合 按底色，按下去立刻有"确认感"：

```text
{"按底色": UI.色16("#1D4ED8"), "按字色": UI.色16("#DBEAFE")}
```

## 注意

- 透明即"未设置"：按住时沿用常态字色。
- 等价写法：`按下: {"字色": ...}`（见 按下）；同一键多处覆写时优先级低于禁用态。
