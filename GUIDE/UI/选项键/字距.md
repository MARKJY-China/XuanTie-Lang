# 字距

**字符间距像素，默认 1。**

```text
UI.文本("稀疏的标题", {"字号": 20, "字距": 4})
```

## 你可以……

- **标题拉开字距**——大字配大间距更精神：

```text
UI.文本("设置", {"字号": 24, "字距": 6})
```

- **正文收紧**——写 0 让字与字贴住：

```text
UI.文本("紧凑正文", {"字距": 0})
```

## 注意

- 字距单位是像素，与 字号 各自独立，改字号时记得顺手评估字距。
- 只影响文本渲染；子项之间的间隙是另一键——间距。
