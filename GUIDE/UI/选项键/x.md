# x

**子项相对 `UI.绝对` 容器内容区左上角的 x 坐标（像素）。**

```text
UI.绝对([UI.按钮("钉住", {"x": 20, "y": 30})], {"宽": 300, "高": 200})
```

## 你可以……

- **自由摆位**——绝对容器内每个子项用 x/y 精确定位：

```text
UI.绝对([
    UI.矩形({"x": 0, "y": 0, "宽": 60, "高": 60, "底色": UI.色16("#3B82F6")}),
    UI.文本("角标", {"x": 70, "y": 20})
], {"宽": 300, "高": 200})
```

## 注意

- 只在 `UI.绝对` 容器内生效；写在行/列的子项上不起作用。
- x 是布局定位，决定节点落点；只想在渲染上偏移请用 平移x。
