# y

**子项相对 `UI.绝对` 容器内容区左上角的 y 坐标（像素）。**

```text
UI.绝对([UI.按钮("钉住", {"x": 20, "y": 30})], {"宽": 300, "高": 200})
```

## 你可以……

- **与 x 配对定位**——绝对容器内每个子项各管各的落点：

```text
UI.绝对([
    UI.文本("顶栏", {"x": 0, "y": 0}),
    UI.文本("底栏", {"x": 0, "y": 180})
], {"宽": 300, "高": 200})
```

## 注意

- 只在 `UI.绝对` 容器内生效；写在行/列的子项上不起作用。
- y 是布局定位，决定节点落点；只想在渲染上偏移请用 平移y。
