# 首按延迟

**按住多久（毫秒）后开始连发，默认 0。**

```text
UI.按钮("两用", {"首按延迟": 400, "连发间隔": 60, "点击": 函() { UI.态设(s, "n", UI.态取(s, "n") + 1) }})
```

## 你可以……

- **单击/长按两用**——点击模式下设了它：延迟内松开算单击，按住超时进连发：

```text
UI.按钮("点按两用", {"首按延迟": 350, "点击": 函() { UI.态设(s, "n", UI.态取(s, "n") + 1) }})
```

- **按住模式防误触**——先延迟再连发：

```text
{"触发": "按住", "首按延迟": 300, "连发间隔": 50}
```

## 注意

- 默认 0：按住模式下一按住立刻开始连发。
- 延迟期间松开仍算一次普通点击——这正是"两用"写法的依据。
