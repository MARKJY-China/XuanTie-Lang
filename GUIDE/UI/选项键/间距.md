# 间距

**子项之间的间隙像素。**

```text
UI.列([UI.文本("一"), UI.文本("二"), UI.文本("三")], {"间距": 12})
```

## 你可以……

- **行/列通用**——凡是排子项的容器都吃这一键：

```text
UI.行([UI.按钮("甲", {}), UI.按钮("乙", {})], {"间距": 8})
```

## 注意

- 间距只加在相邻子项之间，不会在首尾两端凭空留白——两端留白用 内边距。
- 与 字距 是两回事：一个管子项间隙，一个管字符间隙。
