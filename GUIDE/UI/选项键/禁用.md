# 禁用

**禁用开关，双形态：布尔纯禁用；字典则禁用态覆写（隐含禁用）。**

```text
UI.按钮("提交", {"禁用": 真, "禁底色": UI.色16("#D1D5DB")})
```

## 你可以……

- **布尔形态**——`禁用: 真` 即不响应交互，配三态禁色改外观：

```text
{"禁用": 真, "禁底色": UI.色16("#E5E7EB"), "禁字色": UI.色16("#9CA3AF")}
```

- **字典形态**——覆写子字典，写谁谁变，且隐含禁用：

```text
UI.按钮("提交", {"禁用": {"底色": UI.色16("#E5E7EB"), "字色": UI.色16("#9CA3AF")}})
```

- **绑状态动态切换**——构建函数每帧重算，禁用跟着状态走：

```text
UI.按钮("提交", {"禁用": UI.态取(s, "锁定")})
```

## 注意

- 字典形态里颜色子键固定叫 底色/字色/边色，与 悬浮/按下 子字典同一套约定。
- 禁用态优先级最高：同一键被禁用、按下、悬浮同时覆写时，禁用赢。
