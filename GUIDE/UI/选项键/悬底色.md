# 悬底色

**鼠标悬浮时的背景色；默认透明，即不覆盖常态底色。**

```text
UI.按钮("保存", {"底色": UI.色16("#3B82F6"), "悬底色": UI.色16("#2563EB")})
```

## 你可以……

- **给按钮做悬浮反馈**——常态色照旧，只补一笔悬浮色：

```text
{"底色": UI.色16("#374151"), "悬底色": UI.色16("#4B5563")}
```

- **给整行/整列做悬浮反馈**（v1.6.0 起所有节点可用）——列表项不必再用按钮模拟：

```text
UI.行([UI.文本("妈妈"), UI.文本("17:22")], {
  "内边距": UI.全边(12),
  "底色": UI.色16("#3a3a3a"),
  "悬底色": UI.色16("#4a4a4a"),
  "点击": 函() { }
})
```

- **改用状态覆写子字典**——`悬浮: {"底色": ...}` 与平面键等价，可与非颜色键混写（见 悬浮）。

## 注意

- 透明表示"未设置"，不是"变透明"：悬底色为透明时沿用常态底色。
- v1.6.0 起 `行` / `列` / `绝对` / `文本` / `矩形` / `滚动容器` 等都会读取此键；此前只有按钮/图标按钮生效。
- 按钮三态切换由框架用动值补间，颜色过渡自动丝滑，无需手写动画。
