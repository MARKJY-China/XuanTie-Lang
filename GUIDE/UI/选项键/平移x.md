# 平移x

**横向偏移像素（可负）：渲染与命中间步偏移，不影响兄弟布局。**

```text
UI.矩形({"宽": 60, "高": 60, "底色": UI.色16("#3B82F6"), "平移x": 20})
```

## 你可以……

- **做 CSS transform 式位移**——布局照原样，只是画（和点）偏过去：

```text
{"宽": 60, "高": 60, "底色": UI.色16("#10B981"), "平移x": -12}
```

- **用 `UI.动值` 做滑入滑出**——目标值一变即平滑补间：

```text
UI.矩形({"宽": 160, "高": 300, "底色": UI.色16("#1F2937"),
    "平移x": UI.动值("抽屉x", 目标x)})
```

## 注意

- 偏移作用于整棵子树：子项与命中区域同源偏移，渲染和点击始终对得上。
- 不占布局：兄弟不会因平移让位；与 x 不同，平移x 在任何容器里都可用。
