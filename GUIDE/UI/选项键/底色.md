# 底色

**节点的背景色，默认透明。**

```text
UI.矩形({"宽": 120, "高": 60, "底色": UI.色16("#3B82F6")})
```

## 你可以……

- **用 `UI.色(r, g, b, a)` 逐通道配色**——四通道 0~255，a 为不透明度：

```text
UI.按钮("确定", {"底色": UI.色(59, 130, 246, 255)})
```

- **用 `UI.色16` 写十六进制**——支持 `"#RRGGBB"`、`"RRGGBB"`、`"#RRGGBBAA"`：

```text
UI.列([UI.文本("深色面板")], {"底色": UI.色16("#1E1E1ECC")})
```

## 注意

- 矩形不设底色时并非"无色"：它改用字色填充（见 字色）。
- 与 底色2 同设时背景变为 底色→底色2 的渐变，方向由 渐变向 定。
