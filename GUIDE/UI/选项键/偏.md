# 偏

**锚点的像素偏移:`{"左": px, "上": px, "右": px, "下": px}`(默认 0,可负)——在 [锚](锚.md) 比例定位的基础上做像素级微调。**

```text
// 主区:四锚拉伸,但给 220 宽侧栏和 40 高顶栏让位
"锚": {"左": 0, "上": 0, "右": 1, "下": 1},
"偏": {"左": 220, "上": 40, "下": -28}
```

## 你可以……

- **留边距**:贴右钮往内收 8px——`"锚": {"右": 1}, "偏": {"右": -8}`
- **让位布局**:双锚拉伸时用偏移切出固定区——顶栏 40px:`"偏": {"上": 40}`
- **越界探出**:偏移可负可正,允许探出父容器边界(做悬浮卡、弹出层)

## 注意

- 偏只服务于锚:`锚` 不设时 `偏` 无意义。
- 双锚轴的尺寸公式:`槽位尺寸×(远比-近比) + 远侧偏 - 近侧偏`——想让拉伸区"两头各留 10px",写 `"偏": {"左": 10, "右": -10}`。
