# 渐变向

**渐变方向：`"竖"`（默认）或 `"横"`。**

```text
UI.矩形({"宽": 200, "高": 80, "底色": UI.色16("#3B82F6"), "底色2": UI.色16("#8B5CF6"), "渐变向": "横"})
```

## 你可以……

- **竖向渐变**——默认行为，不写渐变向即可：

```text
{"底色": UI.色16("#111827"), "底色2": UI.色16("#374151")}
```

- **横向渐变**——显式写 `"横"`：

```text
{"底色": UI.色16("#F97316"), "底色2": UI.色16("#EF4444"), "渐变向": "横"}
```

## 注意

- 只有设了 底色2 才有渐变可言；单色背景下渐变向无效果。
- 取值只认 `"横"`，其余值（含缺省）一律按竖向处理。
