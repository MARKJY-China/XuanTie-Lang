# 字叉对齐

**文本控件的垂直对齐方式：贴顶（默认）、垂直居中、贴底。**

```text
UI.文本("垂直居中", {"宽": 300, "高": 80, "字叉对齐": UI.对齐中})
```

## 你可以……

- **垂直居中**——盒比文字高时，文字落在盒中线上（`UI.对齐中`）：

```text
UI.文本("欢迎使用玄铁", {"宽": 400, "高": 120, "字号": 24, "字叉对齐": UI.对齐中})
```

- **贴底**——底部对齐的状态栏、脚注（`UI.对齐末`）：

```text
UI.文本("第 1 页", {"宽": 200, "高": 40, "字叉对齐": UI.对齐末})
```

- **贴顶**——默认行为，不写就是它（也可显式写 `UI.对齐始`）。

## 注意

- 只在文本**比盒矮**时看得出效果：盒高取 `高`，不写时用固有高（`字号 × 7/5`）——默认就比字形箱（高 = `字号`）高出约一倍字号的 0.4 倍，所以居中/贴底本来就有轻微位移；想让效果明显就显式给 `高`。
- 字形箱高按 `字号` 计（与按钮文字垂直居中同一口径）；盒比文字矮时保持贴顶，不反向溢出。
- `字对齐` 管**水平**，`字叉对齐` 管**垂直**；与容器的 `主轴对齐` / `叉轴对齐` 也无关——那两个管子项在容器里怎么摆。
- 需要 UI 库 ≥ v1.5.7。
