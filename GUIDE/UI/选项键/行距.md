# 行距

**多行文本/多行编辑的额外行间距（像素）；只影响行与行之间，单行高度不变。默认 0。**

```text
UI.文本(预览, {"宽": 200, "换行": 真, "行距": 4})
UI.多行编辑(状态, "源码", {"行距": 3, "行号": 假})
```

## 你可以……

- **让多行文字松一点**——换行文本按 `行高 = 字号 × 7/5 + 行距` 逐行排；固有高 = 单行高 +（行数−1）× 行步：

```text
UI.文本(消息, {"宽": 220, "换行": 真, "行距": 6})
```

- **代码编辑器行距**——`多行编辑` 的滚动、光标定位、点击行列换算都会跟着行距走：

```text
UI.多行编辑(状态, "源码", {"高": 300, "行距": 2, "高亮": "玄铁"})
```

## 注意

- 行距只对"多行"生效：单行 `文本` 的高度仍是 `字号 × 7/5`。
- 负值会被夹回 0（行高不低于单行高）。
- 文本换行需要显式 `宽`；不换行的文本即使写 `行距` 也没有行可距。
