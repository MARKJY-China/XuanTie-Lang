# 悬字色

**鼠标悬浮时的文字色；默认透明，即沿用常态字色。**

```text
UI.按钮("菜单", {"字色": UI.色16("#D1D5DB"), "悬字色": UI.色16("#FFFFFF")})
```

## 你可以……

- **悬浮时提亮文字**——只动字色，底色不变也有反馈：

```text
{"字色": UI.色16("#9CA3AF"), "悬字色": UI.色16("#F9FAFB")}
```

- **与悬底色成对设计**——底变深、字变亮，对比度立刻出来：

```text
{"悬底色": UI.色16("#1F2937"), "悬字色": UI.色16("#FFFFFF")}
```

## 注意

- 透明是"未设置"的意思：悬浮字色透明时沿用常态字色，不会把字变没。
- 等价写法：`悬浮: {"字色": ...}`（见 悬浮）。
