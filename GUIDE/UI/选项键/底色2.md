# 底色2

**渐变第二色：设置后背景由单色变为 底色→底色2 的渐变。**

```text
UI.矩形({"宽": 200, "高": 80, "底色": UI.色16("#3B82F6"), "底色2": UI.色16("#8B5CF6")})
```

## 你可以……

- **竖向渐变**——默认方向，不写 渐变向 即可：

```text
{"底色": UI.色16("#111827"), "底色2": UI.色16("#374151")}
```

- **横向渐变**——配 渐变向 写 `"横"`：

```text
{"底色": UI.色16("#0EA5E9"), "底色2": UI.色16("#6366F1"), "渐变向": "横"}
```

## 注意

- 底色2 必须与 底色 配对：只写底色2 不构成渐变。
- 不设底色2 就是纯色背景，此时 渐变向 无意义。
