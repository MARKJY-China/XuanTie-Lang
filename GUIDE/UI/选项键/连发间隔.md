# 连发间隔

**"按住"模式下连发的间隔毫秒，默认 50；0 表示每帧一次。**

```text
UI.按钮("连加", {"触发": "按住", "连发间隔": 100, "点击": 函() { UI.态设(s, "n", UI.态取(s, "n") + 1) }})
```

## 你可以……

- **调连发速度**——数字越小发得越快：

```text
{"触发": "按住", "连发间隔": 30}
```

- **拉满帧率**——写 0，每帧触发一次：

```text
{"触发": "按住", "连发间隔": 0}
```

## 注意

- 只在 触发 为 `"按住"`（或经 首按延迟 进入连发）时有意义。
- 0 即每帧：回调跟着渲染帧走，重活别往里塞。
