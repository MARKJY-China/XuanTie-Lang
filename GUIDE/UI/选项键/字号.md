# 字号

**文字字号，默认 16。**

```text
UI.文本("标题", {"字号": 24})
```

## 你可以……

- **分级排版**——标题大、正文默认、辅助文字小：

```text
UI.列([
    UI.文本("标题", {"字号": 24}),
    UI.文本("正文保持默认即可"),
    UI.文本("注释", {"字号": 12, "字色": UI.色16("#9CA3AF")})
], {})
```

## 注意

- 不写即默认 16。
- 字号影响文本撑开尺寸：改大字号会把父容器顶高，除非父容器定了 高。
