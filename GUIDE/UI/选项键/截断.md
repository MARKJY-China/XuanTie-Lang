# 截断

**单行文本超宽时，末尾用 `…` 截断；默认关闭（超宽直接画到盒外）。**

```text
UI.文本("这是一段很长的单行文本会被省略号截断", {"宽": 120, "截断": 真})
```

## 你可以……

- **列表副标题/会话预览**——固定宽度，长文本自动收尾：

```text
UI.文本(项["预览"], {"宽": 180, "截断": 真, "字号": 12, "字色": UI.色彩["灰"]})
```

- **多行截断**——需要换行时改用 `换行` + `行数限制`（见 行数限制）。

## 注意

- 只在给了 `宽` 且文字比盒宽时才有省略号；盒比文字宽时原样输出。
- 从尾部逐字裁，直到 `文字 + …` 放得下；一个字符都放不下时只留 `…`。
- 只对 `文本` 控件生效，且不改变布局尺寸（盒宽仍由 `宽` 定）。
