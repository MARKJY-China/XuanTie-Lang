# 换行

**文本按 `宽` 自动折行；默认关闭（单行，超宽画到盒外）。**

```text
UI.文本("这是一段很长的会话预览文本，超过宽度会自动折行", {"宽": 200, "换行": 真})
```

## 你可以……

- **多行说明/会话预览**——给 `宽` 和 `换行`，行数由内容决定：

```text
UI.文本(消息内容, {"宽": 220, "换行": 真, "字号": 14})
```

- **限制显示行数**——再配 `行数限制`，超出部分自动补 `…`（见 行数限制）：

```text
UI.文本(预览, {"宽": 200, "换行": 真, "行数限制": 2})
```

## 注意

- **必须显式给 `宽`**：没有折行宽度就按单行算（固有宽 = 实测文字宽）。
- 换行后固有高 = 行数 × 行高（行高 = `字号 × 7/5`），行/列容器据此占位。
- 断行按字符宽度逐字累加，不做英文单词不断行的处理。
- 只对 `文本` 控件生效；输入栏/多行编辑有各自的滚动与换行逻辑。
