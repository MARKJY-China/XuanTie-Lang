# 禁字色

**禁用态的文字色；默认透明，即沿用常态字色。**

```text
UI.按钮("提交", {"禁用": 真, "禁字色": UI.色16("#6B7280")})
```

## 你可以……

- **与禁底色成套使用**——禁用按钮一眼可读：

```text
{"禁用": 真, "禁底色": UI.色16("#E5E7EB"), "禁字色": UI.色16("#9CA3AF")}
```

## 注意

- 需 禁用 为真（或 禁用 字典形态隐含禁用）才显现，否则永不生效。
- 只设禁字色不设禁底色也能用——"字变灰"，但通常成套更明确。
