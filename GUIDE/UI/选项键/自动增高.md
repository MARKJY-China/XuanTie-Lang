# 自动增高

**`多行编辑` 按内容行数自动算高，夹在 `最小高` / `最大高` 之间；做 IM 输入框、日志输入行用。**

```text
UI.多行编辑(状态, "草稿", {
    "自动增高": 真, "最小高": 40, "最大高": 160, "行号": 假
})
```

## 你可以……

- **微信式输入框**——初始一行高，换行越多越高，到上限后内部滚动：

```text
UI.多行编辑(状态, "草稿", {
    "自动增高": 真, "最小高": 40, "最大高": 140,
    "行号": 假, "行距": 2, "占位": "输入消息…"
})
```

- **显式 `高` 优先**——同时写 `高` 时不再自动增高（以 `高` 为准）。

## 注意

- 自动增高只改**固有高**；放进 `行` / `锚` 等显式给高的槽位时，槽位尺寸优先。
- 高度 = 行数 × 行高 + 上下内边距 + 2，行高 = `字号 × 7/5 + 行距`。
- 换行数按状态里的 `\n` 计；长行不折行（多行编辑横向不滚动、超长行裁剪）。
