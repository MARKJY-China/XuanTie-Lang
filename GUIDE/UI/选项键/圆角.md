# 圆角

**圆角像素；0 为直角。内部按 min(宽, 高)/2 封顶换算成百分比。**

```text
UI.按钮("圆角按钮", {"圆角": 8})
```

## 你可以……

- **圆角卡片**——矩形、按钮、容器通用：

```text
UI.矩形({"宽": 160, "高": 80, "底色": UI.色16("#FFFFFF"), "圆角": 12})
```

- **正圆/胶囊**——圆角给到短边一半即满圆：

```text
UI.矩形({"宽": 40, "高": 40, "底色": UI.色16("#EF4444"), "圆角": 20})
```

## 注意

- 圆角再大也不会超过短边一半：内部按 min(宽, 高)/2 封顶。
- 圆角只影响背景与边框的绘制，不裁子项——子树出界要配 裁剪。
