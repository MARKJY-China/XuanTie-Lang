# 点击

**点击回调：值为无参函数，触发时机由 触发 键决定。**

```text
UI.按钮("点我", {"点击": 函() { UI.态设(s, "计数", UI.态取(s, "计数") + 1) }})
```

## 你可以……

- **在回调里改状态**——界面下一帧自动跟上（View = f(State)）：

```text
{"点击": 函() { UI.态设(状态, "页", "设置") }}
```

- **换触发时机**——默认"按下在钮内松开才触发"，可配 触发 改：

```text
UI.按钮("即发", {"触发": "按下", "点击": 函() { UI.态设(s, "n", UI.态取(s, "n") + 1) }})
```

## 注意

- 默认模式下，按下后把指针拖出按钮再松开不算点击。
- 回调里直接改界面节点没用——下一帧整树重建，只能改状态。
