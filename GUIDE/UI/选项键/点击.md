# 点击

**点击回调：值为无参函数，触发时机由 触发 键决定。**

```text
UI.按钮("点我", {"点击": 函() { UI.态设(s, "计数", UI.态取(s, "计数") + 1) }})
```

## 你可以……

- **在回调里改状态**——界面下一帧自动跟上（View = f(State)）：

```text
{"点击": 函() { UI.态设(状态, "页", "设置") }}
```

- **整行/整列可点**——`行` / `列` / `绝对` / `文本` / `矩形` 等任意节点都能挂 `点击`，
  配合 `悬底色` / `按底色` 就是列表项（v1.6.0 起三态色对所有节点生效）：

```text
UI.行([UI.文本("妈妈"), UI.文本("17:22")], {
  "内边距": UI.全边(12),
  "悬底色": UI.色16("#4a4a4a"),
  "按底色": UI.色16("#333333"),
  "点击": 函() { UI.态设(状态, "当前会话", "妈妈") }
})
```

- **换触发时机**——默认"按下在钮内松开才触发"，可配 触发 改：

```text
UI.按钮("即发", {"触发": "按下", "点击": 函() { UI.态设(s, "n", UI.态取(s, "n") + 1) }})
```

## 注意

- 默认模式下，按下后把指针拖出按钮再松开不算点击。
- 回调里直接改界面节点没用——下一帧整树重建，只能改状态。
- 带 `点击` 的节点会消费命中：行内子控件没自己的点击回调时，点哪里都算整行。
