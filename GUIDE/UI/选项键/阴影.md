# 阴影

**外阴影字典：颜色、模糊、偏移；默认关闭。**

```text
UI.矩形({"宽": 160, "高": 80, "底色": UI.色16("#FFFFFF"),
    "阴影": {"颜色": UI.色(0, 0, 0, 80), "模糊": 12, "x": 0, "y": 2}})
```

## 你可以……

- **只写需要的子键**——`"颜色"`、`"模糊"`、`"x"`、`"y"` 都可省略，缺省走默认：

```text
{"阴影": {"颜色": UI.色(0, 0, 0, 60), "模糊": 8}}
```

## 注意

- 阴影颜色的 alpha 为 0（默认透明）即整体关闭——想关阴影，把颜色写透明即可。
- 阴影沿节点边缘逐圈向外扩散，模糊越大圈数越多，开销随之上涨。
