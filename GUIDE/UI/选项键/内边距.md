# 内边距

**节点内容区与边缘的距离，三种写法等价。**

```text
UI.列([UI.文本("内容")], {"内边距": 20})
```

## 你可以……

- **裸数字**——自动转成四边相同：

```text
{"内边距": 20}
```

- **`UI.全边` / `UI.四边`**——全边统一；四边按 上、右、下、左 分别指定：

```text
{"内边距": UI.全边(20)}
{"内边距": UI.四边(8, 16, 8, 16)}
```

## 注意

- 内边距把内容往里挤：内容撑开的节点尺寸 = 内容 + 内边距。
- 节点定了 宽/高 时，内边距占的是内部空间——别把内容区算漏。
