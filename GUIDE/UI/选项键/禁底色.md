# 禁底色

**禁用态的背景色；默认透明，即不覆盖常态底色。**

```text
UI.按钮("提交", {"禁用": 真, "底色": UI.色16("#3B82F6"), "禁底色": UI.色16("#9CA3AF")})
```

## 你可以……

- **给禁用按钮一个"灰掉"的外观**——配合 禁用 开关一起写：

```text
{"禁用": 真, "禁底色": UI.色16("#D1D5DB"), "禁字色": UI.色16("#6B7280")}
```

- **用 禁用 的字典形态一步写完**——覆写子字典隐含禁用（见 禁用）：

```text
UI.按钮("提交", {"禁用": {"底色": UI.色16("#D1D5DB")}})
```

## 注意

- 不设 禁用（或其为假）时禁底色永远不显现——它只是覆写，不是开关。
- 禁用后节点不响应交互，颜色是唯一的外观提示，禁底色通常与 禁字色 成套。
