# 按底色

**按住鼠标时的背景色；默认透明，即不覆盖常态底色。**

```text
UI.按钮("删除", {"底色": UI.色16("#EF4444"), "按底色": UI.色16("#B91C1C")})
```

## 你可以……

- **给按压一个"沉下去"的反馈**——按态比常态深一档最直观：

```text
{"底色": UI.色16("#3B82F6"), "悬底色": UI.色16("#2563EB"), "按底色": UI.色16("#1D4ED8")}
```

- **用状态覆写子字典表达**——`按下: {"底色": ...}` 等价（见 按下）。

## 注意

- 只有真正按住（左键尚未松开）才进入按态；松开后回到悬浮或常态。
- 透明即"沿用常态"，别把"想要更深"误写成透明。
