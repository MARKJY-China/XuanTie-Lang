# 图标色

**图标着色（tint）；默认白色，实际颜色 = 图标色 × 图标像素。**

```text
UI.图标("heart", {"图标色": UI.色彩["红"], "图标尺寸": 20})
UI.图标按钮("trash-2", {"图标色": UI.色16("#EF4444")})
```

## 你可以……

- **跟着文字色走**——工具条图标与文字同色最稳：

```text
UI.图标("settings", {"图标色": UI.色彩["浅灰"]})
```

- **三态变色**——图标是节点，照样吃 `悬/按/禁` 状态色（v1.6.0 起所有节点可用）：

```text
UI.图标("star", {
  "图标色": UI.色彩["灰"],
  "悬字色": UI.色彩["黄"],
  "点击": 函() { }
})
```

## 注意

- 内置图标集的 SVG 已把 `currentColor` 换成白色，因此 tint 能精确上色；自定义彩色 SVG 会被整张乘色。
- 透明色会让图标消失（alpha 参与相乘）。
- 禁用状态下图标透明度自动 ×0.4（与按钮一致）。
