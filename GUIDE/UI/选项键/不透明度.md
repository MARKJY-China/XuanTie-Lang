# 不透明度

**整棵子树的不透明度（0~100），沿树逐层连乘。**

```text
UI.列([UI.文本("整体半透明")], {"不透明度": 60})
```

## 你可以……

- **让一组控件一起变淡**——父写 60、子写 50，子实际 30（连乘）：

```text
UI.列([UI.按钮("淡", {"不透明度": 50})], {"不透明度": 60})
```

- **用 `UI.动值` 做浮现/淡出**——目标值变化当帧起平滑补间：

```text
UI.矩形({"宽": 100, "高": 40, "底色": UI.色16("#3B82F6"),
    "不透明度": UI.动值("面板透明度", 目标透明度)})
```

## 注意

- 0 表示不可见且不响应命中——点击直接穿透到下层。
- 与 可视： 假 不同：不透明度 0 仍占布局位，只是看不见、点不到。
