# 提交

**回车回调。`输入栏` 回车触发；`多行编辑` 有提交回调时 Enter 发送、Shift+Enter 换行。**

```text
UI.输入栏(状态, "名字", {"提交": 函(值) { 示("提交: " & 值) }})

UI.多行编辑(状态, "草稿", {
    "提交": 函(值) {
        发送(值)
        UI.态设(状态, "草稿", "")
    }
})
```

## 你可以……

- **单行回车提交**——`输入栏` 回车即回调，值已去掉换行。
- **IM 发送键语义**——`多行编辑` 设了 `提交` 后：Enter 发送（不插入换行）、Shift+Enter 换行；没设 `提交` 时 Enter 仍是换行。

## 注意

- 回调参数是**字符串当前值**（多行保留 `\n`），回调里自行清空状态即可清空输入框。
- 只读模式下不触发提交。
- `多行编辑` 的 `提交` 是 v1.8.0 新增；旧版本只认 `输入栏`。
