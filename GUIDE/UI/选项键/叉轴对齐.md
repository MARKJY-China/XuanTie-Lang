# 叉轴对齐

**子项在叉轴上的对齐（列的叉轴是横向，行是纵向），默认拉伸填满。**

```text
UI.列([UI.按钮("短", {})], {"叉轴对齐": UI.叉中})
```

## 你可以……

- **四个常量任选**——`UI.叉始`、`UI.叉中`、`UI.叉末`、`UI.叉撑`：

```text
UI.行([UI.文本("靠下")], {"高": 80, "叉轴对齐": UI.叉末})
```

- **默认 `UI.叉撑`**——子项在叉轴方向拉伸填满容器；想保持自身尺寸就改用其他三值。

## 注意

- 叉撑会覆盖子项在叉轴方向上的尺寸——列里的子项写了 宽 也会被横向拉满。
- 叉轴方向由容器定：列=横、行=纵，与 主轴对齐 互为垂直。
