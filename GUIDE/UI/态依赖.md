# UI.态依赖

**取上一次构建期内被 `UI.态取` 读过的键列表。**

```text
设 用到的键 = UI.态依赖(状态)
```

## 你可以……

- **调试界面到底读了哪些状态**——排查"为什么这个控件不更新"：

```text
示("本帧依赖: " & 化(UI.态依赖(状态)))
```

## 注意

- 这是框架内部依赖追踪的读出端，清单在**每次构建开始时重置**——读到的是上一帧构建函数的完整取键记录。
- 普通业务代码基本用不到；它服务于框架自身与调试工具。
