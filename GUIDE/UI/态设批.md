# UI.态设批

**批量写多个键——变更表逐键展开成 `UI.态设`。**

```text
UI.态设批(状态, {"计数": 0, "选中": "无", "搜索": ""})
```

## 你可以……

- **一键复位表单**：

```text
UI.按钮("重置", {"点击": 函() { UI.态设批(s, {"名字": "", "邮箱": "", "备注": ""}) }})
```

- **从字典整体灌入状态**——比如读取配置后一次性铺进界面状态：

```text
设 配置 = {"主题": "暗", "字号": 16}
UI.态设批(状态, 配置)
```

## 注意

- 等价于对变更表逐键调用 `态设`——每个键独立走"相等跳过/通知/标脏"规则。
- 没有"整体原子"语义：中间键的订阅回调会按字典遍历序逐个触发。
