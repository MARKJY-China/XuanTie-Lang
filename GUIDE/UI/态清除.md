# UI.态清除

**清空状态的订阅、依赖记录与脏标志。**

```text
UI.态清除(状态)
```

## 你可以……

- **复用状态容器重开一局**——比如换页/重载场景时把监听与追踪归零：

```text
UI.态清除(状态)
UI.态设批(状态, {"页": "首页", "选中": "无"})
```

## 注意

- 只清 `_监听`/`_依赖`/`_脏` 三个内部字段——**状态里的业务数据（`_值`）原样保留**。
- 清完之后原订阅不再触发，需要的话重新 `UI.态观` 注册。
