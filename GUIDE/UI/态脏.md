# UI.态脏?

**查询状态自上次构建以来是否被标脏过。**

```text
若 UI.态脏?(状态) { 示("有更新待渲染") }
```

## 你可以……

- **在手动渲染循环里做按需判断**——脏了才重建/重绘：

```text
当 非 R.窗口应关闭?() {
    若 UI.态脏?(状态) {
        UI.刷新(状态, 构建, 0, 0, 640, 420)
    }
    R.结束绘图()
}
```

## 注意

- 脏标志在**每次构建开始时被清掉**（框架内部行为），之后任何 `态设`/`标脏` 会重新置位——所以它回答的是"上一帧之后又发生了什么"。
- 一般不需要自己调它：`UI.应用` 的按需重绘内部就是用它做脏源的。
