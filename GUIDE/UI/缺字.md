# 缺字监测

**渲染文字前逐字检查当前字体有没有该字形；缺字不再只显示成方框，而是给出字符与码点。**

```text
示(UI.缺字("妈妈 ⋯"))      // 输出：⋯   （微软雅黑没有 U+22EF）
示(UI.缺字("妈妈 …"))      // 输出：（空）—— U+2026 有字形
```

## 你可以……

- **手动预检**——`UI.缺字(文本)` 返回当前字体缺字形的字符（去重、保持顺序）：

```text
设 缺 = UI.缺字(用户输入)
若 缺 != "" {
  示("这些字可能显示成方块: " & 缺)
}
```

- **拿累计缺字做告警**——`UI.缺字集()` 返回启动以来渲染遇到过的全部缺字：

```text
设 汇总 = UI.缺字集()
若 汇总 != "" { 示("界面缺字: " & 汇总) }
```

- **关掉自动检查**——超长文本/性能敏感时：

```text
UI.设缺字检查(假)
```

## 注意

- 自动检查覆盖 `UI.文本`、`UI.按钮`、`UI.输入栏`、`UI.多行编辑` 的绘制；缺字按（字体,码点）**只报一次**，格式为
  `[UI] 缺字: 「⋯」(码点 8943) 当前字体没有该字形,将显示为方块;请换字体或改用内置图标(UI.图标)`。
- 字体未加载时，`UI.缺字` 会先尝试加载默认字体（`确保默认字体`），仍失败则返回空串。
- 字形判定分两套：Windows GDI 系统字体问系统 cmap（`GetGlyphIndicesW`），raylib 字体池看烘焙字形表
  （字体里有但没参与烘焙的字符也算缺字——这类字本身也画不出来）。
- 缺字不会改变布局宽度，只是把“为什么是方框”查出来；符号类建议直接换 `UI.图标`（内置 Lucide）。
