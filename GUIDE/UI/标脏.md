# UI.标脏

**手动把状态标脏——告诉框架"内容变了，该重绘了"。**

```text
设 列表 = UI.态取(状态, "列表")
列表.追加("新条目")
UI.标脏(状态)
```

## 你可以……

- **原地改了数组/字典之后补一声**——框架只认 `态设`/`标脏` 两个扳机：

```text
设 配置 = UI.态取(状态, "配置")
配置["字号"] = 18
UI.标脏(状态)
```

## 注意

- 只置脏标志，不通知 `态观` 订阅者——要触发订阅请用 `UI.态设` 写回。
- 能写回就别标脏：`UI.态设(状态, "列表", 列表)` 语义更清晰（引用不变但走完整更新流程）。
