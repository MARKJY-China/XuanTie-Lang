# 图标

**内置图标集：2359 个 Lucide 图标（v1.73.0，ISC 许可），数据内嵌在 UI 库里，编译进程序、运行期不依赖任何外部文件。**

```text
UI.图标("search", {"图标尺寸": 20})
UI.图标("more-horizontal", {"图标色": UI.色彩["浅灰"], "图标尺寸": 20})
```

## 你可以……

- **用内置名字画图标**——`UI.图标(名字, 选项)`，默认 24×24，按 `图标色` 着色：

```text
UI.行([
  UI.图标("message-circle", {"图标尺寸": 18, "图标色": UI.色彩["浅灰"]}),
  UI.文本("消息", {"字号": 14})
], {"间距": 8, "叉轴对齐": UI.叉中})
```

- **图标按钮**——`UI.图标按钮` 的源同样认内置名字（不再需要自己准备 SVG）：

```text
UI.图标按钮("settings", {"宽": 30, "高": 30, "点击": 函() { }})
UI.图标按钮("more-horizontal", {"点击": 函() { }})
```

- **查有哪些名字**——`UI.图标名()` 返回全部图标名数组：

```text
示("图标数: " & UI.图标名().长度)
```

- **自定义图标**——源写 `.svg` / `.png` 路径时仍走原来的文件加载：

```text
UI.图标("./assets/logo.svg", {"宽": 32, "高": 32})
```

## 常用名字

`search` `menu` `more-horizontal` `more-vertical` `settings` `x` `plus` `minus` `check` `chevron-down`
`chevron-right` `arrow-left` `arrow-right` `trash-2` `edit` `copy` `refresh-cw` `send` `user`
`users` `message-circle` `bell` `home` `folder` `file` `download` `upload` `play` `pause` `star` `heart`

完整清单即 Lucide 图标名（kebab-case）；`UI.图标名()` 可直接打印。

## 注意

- 图标数据编译进程序：**不需要**把任何图标文件放到程序旁边，也不会因为换工作目录而丢图。
- 图标按光栅尺寸缓存（名字@尺寸），同一尺寸只栅格化一次；`图标尺寸` 换尺寸才会重新生成纹理。
- 名字写错时渲染一次后会在 stderr 打「图标未找到」提示（只提示一次），不会每帧刷屏。
- 许可：Lucide 图标为 ISC 许可，见 `lib/UI/assets/icons/LICENSE-lucide.txt`；可商用、需保留许可声明。
