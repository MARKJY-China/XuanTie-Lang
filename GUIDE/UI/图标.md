# 图标

**内置图标集：2359 个 Lucide 图标（v1.73.0，ISC 许可），数据内嵌在 UI 库里，编译进程序、运行期不依赖任何外部文件。每个图标都有唯一中文名，英文 ID 与中文名可以混用。**

```text
UI.图标("search", {"图标尺寸": 20})          // 英文 ID
UI.图标("搜索", {"图标尺寸": 20})            // 中文名（等价）
UI.图标("more-horizontal", {"图标色": UI.色彩["浅灰"], "图标尺寸": 20})
```

> 全部 2359 个中英文对照见 [图标映射表](图标映射表.md)（按常用度排列）。

## 你可以……

- **用内置名字画图标**——`UI.图标(名字, 选项)`，默认 24×24，按 `图标色` 着色：

```text
UI.行([
  UI.图标("消息", {"图标尺寸": 18, "图标色": UI.色彩["浅灰"]}),
  UI.文本("消息", {"字号": 14})
], {"间距": 8, "叉轴对齐": UI.叉中})
```

- **图标按钮**——`UI.图标按钮` 的源同样认内置名字（中文/英文皆可）：

```text
UI.图标按钮("设置", {"宽": 30, "高": 30, "点击": 函() { }})
UI.图标按钮("更多·横向", {"点击": 函() { }})
```

- **查有哪些名字**——`UI.图标名()` 返回英文 ID；`UI.图标中文名列表()` 返回中文名（均非排序保证，映射表里按常用度排好了）：

```text
示("图标数: " & UI.图标名().长度)
示(UI.图标中文名("search"))     // 搜索
示(UI.图标英文名("搜索"))       // search
```

- **自定义图标**——源写 `.svg` / `.png` 路径时仍走原来的文件加载：

```text
UI.图标("./assets/logo.svg", {"宽": 32, "高": 32})
```

## 注意

- 图标数据编译进程序：**不需要**把任何图标文件放到程序旁边，也不会因为换工作目录而丢图。
- 图标按光栅尺寸缓存（名字@尺寸），同一尺寸只栅格化一次；`图标尺寸` 换尺寸才会重新生成纹理。
- 中文名与英文 ID 等价：`UI.图标("搜索")` 和 `UI.图标("search")` 画的是同一个图标；中文名全局唯一。
- 名字写错时渲染一次后会在 stderr 打「图标未找到」提示（只提示一次），不会每帧刷屏。
- 许可：Lucide 图标为 ISC 许可，见 `lib/UI/assets/icons/LICENSE-lucide.txt`；可商用、需保留许可声明。
