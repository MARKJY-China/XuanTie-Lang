# 文本库编程指南

> **对标版本**：文本库 v1.0.1（`lib/文本/`）。安装：`tiepm az 文本`；仓库内开发可直接 `引 "../lib/文本/文本.xt" 予 T`。
> API 速查：[文本 API 参考](API/文本) ｜ 例程：[日志切分](例程/日志切分)

---

## 为什么需要它

语言内置的字符串方法（`截取`/`替换`/`分割`/`去首尾空格` 等）只覆盖最基础的操作。真正写业务时反复要的是：**在对齐时补空格、超长时截断、统计出现次数、按命名风格转换、套模板**——这些每次手写既啰嗦又容易在中文/空串/边界上出错。

文本库把这些固化成 29 个纯函数：不修改入参，不依赖 C 运行时新函数，宽度一律按**字符**计。

## 安装与引入

```text
引 "文本" 予 T
```

仓库内（未安装铁铺包时）：

```text
引 "../lib/文本/文本.xt" 予 T
```

## 函数分组

| 分组 | 函数 | 说明 |
|------|------|------|
| 填充对齐 | `填充左` `填充右` `居中` | 补到目标字符宽度；填充串可多字符 |
| 截断 | `截断` | 超长才截，宽度含省略号 |
| 统计 | `计数` `行数` `取行` `词数` | 计数不重叠；`取行` 兼容 CRLF |
| 前后缀 | `去前缀` `去后缀` | 只去一次，不命中原样返回 |
| 切分 | `切分首` `切分尾` | 返回 `[前段, 后段]` 两元素数组 |
| 命名风格 | `首字大写` `首字小写` `到驼峰` `到蛇形` `到中划线` `到标题` | 只做 ASCII 大小写与分隔符折叠 |
| 变换 | `反转` `字符数组` `去全部空白` `压缩空白` `缩进` `去缩进` | 均返回新串 |
| 模板 | `模板` | `{键}` 占位；`{{` `}}` 转义；未知键原样保留 |
| 判定 | `空白?` `数字?` `回文?` `包含任一?` | 返回布尔 |

## 快速开始

```text
引 "文本" 予 T

示(T.填充左("玄铁", 6, "—"))              // ————玄铁
示(T.截断("玄铁编程语言", 5, "…"))          // 玄铁编程…
示(T.计数("a,b,,c,,", ","))                // 5
示(T.到蛇形("userName"))                   // user_name
示(T.模板("你好，{名字}！", {"名字": "玄铁"}))  // 你好，玄铁！
```

## 典型场景

### 1. 对齐一列文本

```text
示(T.填充右("级别", 8, " ") & "消息")
示(T.填充右("WARN", 8, " ") & "缓存未命中")
```

注意：宽度按**字符**计，中文在终端里通常占两列宽，中文列对齐需要按显示宽度自行补偿（例如给中文文本多留一半的填充量）。库不做终端列宽推算。

### 2. 解析“键=值”形式的行

```text
设 行 = "port=8080"
设 段 = T.切分首(行, "=")
若 段[0] != "port" { 示("未知键: " & 段[0]) }
示("端口: " & 段[1])        // 端口: 8080
```

`切分首` 命中**第一个**分隔符，`切分尾` 命中**最后一个**；找不到时分别返回 `[文本, ""]` 与 `["", 文本]`，不会返回空数组。

### 3. 生成命名

```text
示(T.到驼峰("user_login_count"))   // userLoginCount
示(T.到蛇形("userLoginCount"))     // user_login_count
示(T.到中划线("userLoginCount"))   // user-login-count
示(T.到标题("hello WORLD"))        // Hello World
```

`到蛇形`/`到中划线` 只在小写字母或数字后出现大写时断开，连续大写整体转小写（`HTTPServer` → `httpserver`）；不做英文词典级的分词。

### 4. 模板化输出

```text
设 模板串 = "构建 {版本}：{成功} 通过，{失败} 失败"
示(T.模板(模板串, {"版本": "v1.0.0", "成功": 12, "失败": 0}))
```

- 值用 `字()` 转文本，支持 整/小数/字/布尔；数组/字典会得到占位描述，别这么用。
- 字典中不存在的键保留原样 `{键}`，便于发现漏填。
- 字面花括号写 `{{` / `}}`。

### 5. 多行文本缩进

```text
设 代码 = "若 x > 0 {\n示(\"正\")\n}"

示(T.缩进(代码, "    "))
示(T.去缩进("    甲\n    乙\n      丙"))
```

`去缩进` 只统计**半角空格**的公共前缀，制表符不参与；空行与全空白行不计入最小值。

## 边界规则（很重要）

| 情形 | 行为 |
|------|------|
| 空串 / 负宽度 | 填充类原样返回；`截断(x, 0, …)` 返回 `""` |
| 省略号比最大宽度还长 | 返回省略号的前 `最大` 个字符 |
| 空子串作 `计数` 参数 | 返回 `0`（不视为无限次出现） |
| `行数("")` | `0` |
| `取行("")` | `[""]`（1 个空行） |
| 空分隔符 | 切分类返回 `[文本, ""]` / `["", 文本]` |
| 空白判定 | ASCII 空格、`\t`、`\n`、`\r` 与全角空格 `　` |
| `数字?` | 以 `整()`/`小数()` 的严格解析为准；`"12abc"`、`""` 为假 |

## 性能提示

库内用 `&` 逐字符拼接构造结果（如 `反转`、`压缩空白`、`模板`），对 KB 级文本足够快；对 MB 级文本请改用 `字节` 集或先分块处理。字符串拼接是 O(n²) 的，这一点与语言内置 `&` 的语义一致。
