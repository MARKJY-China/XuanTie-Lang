# 概述与记法

> 对标版本：XTC v1.0-rc.6-dev.9。

本参考手册描述玄铁语言的语法和核心语义。这里的“必须”“不得”“应当”是规范性要求；“实现可以”表示当前编译器允许、但不构成跨版本保证的行为。

## 文档范围

本参考覆盖：

- 源代码的编码、词法与记号；
- 数据模型、类型、ARC 生命周期与弱引用；
- 程序结构、执行入口、异步与调度；
- 模块、导入、可见性与铁铺包；
- 表达式、简单语句、复合语句；
- 顶层组件与完整语法。

标准库、渲染库、UI 库、网络与文件 API 属于库参考，见 [API 参考](../../GUIDE/API/README.md)；本参考只在语义需要时引用它们。

## 规范性记法

语法用扩展巴科斯范式（EBNF）描述：

```text
产生式  = 备选1 | 备选2 ;
可选    = [ 元素 ] ;
重复    = { 元素 } ;
分组    = ( 元素1 元素2 ) ;
```

约定：

- `中文词` 表示关键字或终结符；`小写名` 表示非终结符。
- `/* ... */` 是说明性注释，不属于语法。
- 省略号 `…` 只出现在说明性示例中，不用于正式产生式。
- “当前实现”指仓库中的 XTC 自举编译器；GSC 种子编译器在语言子集上可能先于或滞后于 XTC。

## 源文件

- 源文件必须是 UTF-8；允许 UTF-8 BOM，词法阶段跳过 BOM。
- 非 UTF-8 源文件在词法阶段报错，不做静默转码。
- 换行可以是 LF 或 CRLF；两者在词法上等价。
- 字符串中未经转义的控制字符由词法阶段处理，未知转义序列直接报错。

## 版本标注

只有在某条规则、关键字或行为确实存在版本差异时，才在标题后用引用块标注：

```markdown
## 某特性
> 在 v1.0-rc.6-dev.5 版本加入。
```

标题中不写版本号。此约定与仓库 `AGENTS.md` 的「版本标注规范」一致。
