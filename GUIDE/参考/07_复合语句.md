# 复合语句

> 对标版本：XTC v1.0-rc.6-dev.9。

本章规定包含子语句或构成新执行单元的语句与表达式级块结构：条件分支 `若`/`抑`/`否`、条件循环 `当`、无限循环 `循`、迭代循环 `遍历`、模式匹配 `匹配`、函数定义 `函`、类型与接口定义 `型`/`口`（含 `造`/`承`/`覆`）、异步与并发 `异步`/`等待`/`并行`/`道`/`选`。

## 复合语句与作用域

```text
复合语句 = 若语句 | 当语句 | 循语句 | 遍历语句 | 匹配语句
         | 函数定义 | 型定义 | 口定义 | 外部函数定义 ;
块       = "{" { 语句 } "}" ;
```

通则：

- 复合语句的每个 `{}` 块**引入一个新作用域**：块内声明的名字块外不可见，块结束时块内活项被释放。
- 块必须**显式写出**，没有单语句省略形式（没有 `若 x 示(1)` 这种写法）。
- 复合语句不是表达式，不能出现在表达式位置。唯一的例外是 `异步`、`并行`、`等待`、`若`（值形态）、`尝试`（值形态），它们本身是表达式前缀。
- 循环内可以使用 `断`/`续`（见 [简单语句](./06_简单语句.md)）。

## 若、抑、否

### 语句形态

```text
若语句 = "若" 表达式 块 { "抑" 表达式 块 } [ "否" 块 ] ;
```

规则：

- 条件是**裸表达式**，不套圆括号（`若 (x > 0)` 也合法，因为括号本身是表达式的一部分，但没有必要）。
- 从上到下依次求值：第一个为真的分支执行，其余分支**不求值也不执行**。
- `抑` 可有零到多个；`否` 至多一个，且必须在最后。
- 写多个 `否` 时只有第一个生效，后续每个发警告 `W004`（多个否分支），被解析但丢弃：

  ```text
  警告 [W004]：第 1 行、第 25 列
    类别: 逻辑语法（多个否分支）
    若/抑/否 逻辑中出现了多个 '否' 分支，只有第一个 '否' 会生效，后续 '否' 将被忽略
    上下文: 多余的 '否' 分支始于此处
    此警告在当前严格度 [默认] 下不会中断编译。
  ```

- 缺少 `{}` 时报明确的语法错误，不猜测续行：

  ```text
  [示例.xt 行:2, 列:1] 若 的条件后面缺少 { } 代码块(玄铁要求显式大括号)
  ```

- 分支内的类型细化不泄漏到兄弟分支与汇合点之后。

```xuantie
若 分数 >= 90 {
    示("优秀")
} 抑 分数 >= 60 {
    示("及格")
} 否 {
    示("重修")
}
```

### 值形态（若表达式）

```text
若表达式 = "若" 表达式 "{" 表达式 "}" { "抑" 表达式 "{" 表达式 "}" } "否" "{" 表达式 "}" ;
```

规则：

- 只出现在**表达式位置**（初值、实参、返回值、容器元素等）。
- 每个分支体是**恰好一个表达式**，不是语句序列。
- **`否` 分支必须存在**。缺失时报（消息自身还带一个 `[行:列]` 前导）：

  ```text
  [2:7] 若表达式必须包含 否 分支,否则条件不成立时无值可求
  ```

- 求值规则与语句形态一致：命中第一个为真的条件，该分支表达式即为整个 `若` 的值。

```xuantie
设 级别 = 若 分数 >= 90 { "优" } 抑 分数 >= 60 { "良" } 否 { "差" }
设 配置 = {"仓库": 若 有镜像 { "镜像地址" } 否 { "默认地址" }}
```

## 条件的真值

规范上条件应当是 `布尔`。当前实现**不做类型检查**，按值的运行时表征判定：

| 值的表征 | 判定 | 例 |
|----------|------|----|
| 布尔（裸 i1） | 直接取该值 | `若 真` / `若 假` / `若 布尔变量` |
| 整数字面量（裸整数表征） | 非零为真 | `若 1` 为真，`若 0` 为假 |
| 裸浮点 | 非零为真 | `若 1.5` 为真 |
| 其他一切装箱值（字符串、数组、字典、实例、`空`） | 与 `真` 比较，只有 `真` 为真 | `若 "s"` 为假 |
| **整型变量** | 槽位存的是带标记表征，与 `真` 比较 → **恒为假** | `设 n = 1` 后 `若 n` 为假 |

最后一行是必须知道的坑：整数字面量在条件位走裸整数路径（非零为真），但同一个 `1` 存进变量后走标记路径（恒假）。**不要把整数当布尔用**；条件要么是布尔表达式，要么显式比较（`若 n != 0`）。

## 当

```text
当语句 = "当" 表达式 块 ;
```

规则：

- 条件在**每轮开头**重新求值；条件为假时一次都不执行。
- 条件真值判定同上一节。
- 块必须写 `{}`。缺块头时报的是通用错误（`不支持的前缀类型: …` 与 `期望当前标记为 右花括号，但得到 空`），不像 `若` 有专门提示。
- `续` 跳到条件重新求值处，因此推进条件变量的语句必须写在 `续` 之前。

```xuantie
设 i = 0
当 i < 3 {
    示(i)
    i = i + 1
}
```

## 循

```text
循语句 = "循" 块 ;
```

规则：

- 无条件循环，与 `当` 的唯一语义差别是**没有条件**（不是“条件恒真”的语法糖——`当 真` 每轮仍求值一次）。
- 只能靠 `断`、`返`、`终` 或异常退出。块内没有可达出口时循环永不结束。
- `续` 跳到循环体开头。

```xuantie
循 {
    设 指令 = 输("> ")
    若 指令 == "退出" { 断 }
}
```

## 遍历

```text
遍历语句 = "遍历" 标识符 [ "," 标识符 ] "于" 表达式 块 ;
```

规则：

- `于` 必写（漏写报 `期望当前标记为 于，但得到 …`）。
- 第一个名字是**迭代变量**，取到元素（字典取到**键**）。
- 第二个名字（逗号分隔）是**索引变量**，取到 0 起的 `整`。两个名字都在循环体内可见，都受遮蔽规则约束。
- 迭代目标是任意表达式，求值一次。

支持的目标类型：

| 目标 | 迭代变量取到 | 索引 |
|------|--------------|------|
| 数组 | 元素 | 0 起下标 |
| 范围 `起..止` | 逐个整数，左闭右开 | 0 起序号 |
| 字典 | 键 | 0 起遍历序号（不是哈希值） |
| 字 | 单个逻辑字符（单字符字符串） | 0 起字符序号 |

`范围` 表达式求值为一个**整数数组**（`1..4` 得到 `[1,2,3]`，长度 3），因此遍历区间与遍历数组是同一机制：

```xuantie
遍历 i 于 1..4 { 示(i) }      // 1 2 3
```

```xuantie
设 xs = ["a", "b", "c"]
遍历 值, 序号 于 xs {
    示(字(序号) & ":" & 值)      // 0:a  1:b  2:c
}

设 映射 = {"名": "玄铁"}
遍历 键 于 映射 {
    示(键 & "=" & 映射[键])
}
```

ARC 规则：

- 每轮开始时保留一次本轮元素，并在写入迭代变量**之前**释放上一轮持有的元素。因此循环体内不会积累引用，迭代变量在循环结束后仍持有末轮元素。
- 索引变量写入的是带标记的整数，不持有对象引用。

**其他目标类型不受支持**：整数、实例等目标不会报错，但运行时会解引用非对象指针（实测 `遍历 v 于 5` 以访问违例 0xC0000005 终止）。见「当前实现限制」。

## 匹配

```text
匹配语句 = "匹配" 表达式 "{" { 模式 "->" 分支体 } "}" ;
模式     = "_" | "是" 类型名 | 表达式 ;
分支体   = 块 | 语句 ;
```

规则：

- 匹配目标求值一次。
- 分支自上而下判定，**命中第一个即结束**，没有 fallthrough，也不需要 `断`。
- 全部分支都不命中时，直接继续执行 `匹配` 之后的语句（无 `否` 兜底要求，但通常应写 `_` 兜底）。
- 分支体可以是块，也可以是**单条语句**。
- 分支体是否有返回值不影响 `匹配`（`匹配` 是语句，不是表达式）。

三类模式：

| 模式 | 语义 |
|------|------|
| `_` | 匹配一切（必须放最后，写 `_` 即无条件跳入该分支） |
| `是 类型名` | 按运行时类型判定 |
| 表达式 | 与目标值做相等比较 |

`是 类型` 目前认识这些类型名：

| 类型名 | 命中 |
|--------|------|
| `整` | 整数 |
| `小数` | 浮点 |
| `字` | 字符串 |
| `布尔` | 布尔 |
| `数组` | 数组 |
| `字典` | 字典 |
| `实例` | 任意 `型` 的实例 |
| `结果` | `结果` 容器 |

不在表内的类型名（如 `是 字节`、`是 任务`、`是 道`）**不报错**，而是映射为“无匹配类型”（ID 0）：除目标是 `空` 之外永不命中——实测 `匹配 空 { 是 字节 -> … }` 会命中该分支。写 `是 字节` 无法达到“判断是不是字节集”的目的。

```xuantie
匹配 值 {
    是 整 -> 示("整数")
    是 字 -> 示("字符串")
    _    -> 示("其他")
}
```

## 函数定义 函

```text
函数定义   = [ 可见性 ] "函" 标识符 [ "<" 泛型参数列表 ">" ] "(" [ 参数列表 ] ")" [ ":" 类型 ] [ "为" 字符串 ] 块 ;
参数列表   = 参数 { "," 参数 } ;
参数       = 标识符 [ ":" 类型 ] ;
匿名函数   = "函" "(" [ 参数列表 ] ")" [ ":" 类型 ] 块 ;
泛型参数列表 = 类型名 { "," 类型名 } ;
```

### 参数

- 参数只有“名字 + 可选类型注解”两种成分。**没有默认值**（`函 f(a: 整 = 1)` 报 `期望当前标记为 右圆括号，但得到 等于`），**没有可变参数**（`函 f(...xs)` 报 `期望当前标记为 右圆括号，但得到 范围`）。
- 参数类型注解是**运行时契约**，不是编译期检查：调用时若实参类型不符，抛运行时错误，由**调用方**语句级轮询接住（因此把调用包在 `尝试` 里可接住），未被接住则打印诊断并以退出码 1 终止：

  ```text
  [主.xt:1:1] 参数类型不匹配——形参注解为 '整',但传入的是其他类型(如字符串/对象)
    提示: 请检查调用处实参类型;若确需混用,去掉形参的类型注解或先显式转换(整()/字())。
  ```

- 实例方法的第一个参数由编译器注入 `此`，源码中不要写。
- 参数名不得是保留字。

### 返回类型

- `: 类型` 在参数表之后。省略注解当前**不告警**：`W002`/`W003` 已在警告表中登记，但实现从不发出。
- **返回类型注解不做校验**：函数体返回与注解不符的值不会报错（实测 `函 f(): 整 { 返 "abc" }` 编译通过，返回值被当整数使用得到垃圾数值）。

### 泛型

- 泛型参数写在函数名后 `<T, U>`；调用时用 `f<整>(…)` 显式给出实参类型。
- 泛型当前是**语法层**能力：编译器做类型擦除，所有类型参数在底层都是 `i64`；不强制检查泛型实参，也没有泛型约束（`<T 承 口>` 未支持）。见 [泛型编程指南](../03_泛型编程指南.md)。

### C ABI 导出名

```xuantie
公 函 加(甲: 整, 乙: 整): 整 为 "xt_add" { 返 甲 + 乙 }
```

`为 "名字"` 给函数指定导出符号名，供 C 侧按该名链接。导出名必须写成**字符串字面量**，否则报 `导出名必须是非空 ASCII 标识符字符串,例如 为 "xt_add"`。该检查只校验“是字符串字面量”：内容不做校验，非 ASCII 名与空串都能编过（实测），能否被 C 侧正确链接由使用者负责。

### 嵌套函数

函数体内可以定义具名函数：

```xuantie
函 外层(): 整 {
    函 内层(): 整 { 返 2 }
    返 内层() + 1
}
```

嵌套函数是独立的 LLVM 函数，写在同一模块里；它对**局部变量**的访问按闭包规则捕获（值快照），对全局变量按名直接引用。

### 匿名函数与尾随闭包

- `函(参数) [: 类型] { … }` 是表达式，可赋给变量、作实参、作返回值。
- **尾随闭包**：调用表达式 `f(实参…)` 之后，**同一行**紧跟一个 `函(...) { … }`，该匿名函数被追加为最后一个实参：

  ```xuantie
  示(应用(3) 函(n) { 返 n * 2 })      // 等价于 应用(3, 函(n){…})
  ```

  同行是硬条件：换行后再写 `函` 不被视为尾随闭包，会报 `期望当前标记为 右圆括号，但得到 函数定义`。泛型调用 `f<T>(…)` 同样支持尾随闭包。

- 闭包捕获规则：外层**局部**变量按创建时刻的值快照进闭包环境，闭包内修改不回传；全局变量直接按名引用。循环体内创建的闭包逐迭代快照（否则全部读到末轮终值）。

## 型、口

### 型定义

```text
型定义 = [ 可见性 ] "型" 标识符 [ "<" 泛型参数列表 ">" ] [ "承" 限定名 ] "{" { 型成员 } "}" ;
型成员 = [ 可见性 ] ( "设" 声明目标 [ ":" 类型 ] [ "=" 表达式 ]
                    | "弱" "设" 声明目标 [ ":" 类型 ] [ "=" 表达式 ]
                    | 具名函数
                    | "覆" 具名函数 ) ;
具名函数 = "函" 标识符 [ "<" 泛型参数列表 ">" ] "(" [ 参数列表 ] ")" [ ":" 类型 ] 块 ;
限定名 = 标识符 { "." 标识符 } ;
```

`声明目标` 的定义见 [简单语句](./06_简单语句.md#变量声明-设)；`参数列表` 见本章「函数定义」。

规则：

- 型体只接受成员声明：`设`、`弱 设`、`函`、`覆 函`（均可带 `公`/`私`/`护`）。**其他内容被静默跳过**——写进型体的普通语句不会执行，也不会报错。见「当前实现限制」。
- 成员默认 `公`。
- 字段可以有类型注解与初值；实例化时未赋值的字段取声明处的初值。字段注解**不支持泛型实参**：`设 子: 数组<整>` 不报错，但 `<整>` 被型体当作未知记号跳过，注解实际只剩 `数组`。
- 构造方法固定名为 `造`：`函 造(参数…) { … }`。它不是普通方法，`造 型名(实参…)` 会调用它。
- **子类定义了自己的 `造` 后，父类的 `造` 不会被自动调用**（实测：父类构造里写的字段赋值不生效）。
- `承 父类` 建立单继承；父类须已定义，否则报 `未定义的父类 'X'`。父类名可带模块限定（`承 库.基类`）。
- `覆 函` 标记重写。**当前实现不校验**被重写的父类方法是否存在，也**不要求**重写必须写 `覆`：同名方法一律按名字覆盖父类方法。`覆` 只是标记。
- 可见性检查对成员生效（`私` 只在定义型内、`护` 在定义型及子类内），详见 [模块与导入](./04_模块与导入.md#可见性公私护)。

```xuantie
型 计数器 {
    私 设 次数 = 0
    公 函 加一(): 整 { 此.次数 = 此.次数 + 1  返 此.次数 }
}
设 c = 造 计数器()
示(c.加一())
```

### 构造与实例化

```text
实例化表达式 = "造" 限定名 [ "<" 泛型实参列表 ">" ] "(" [ 实参列表 ] ")" ;
```

> 在 v1.0-rc.6-dev.5 版本变更：型未定义构造器时，`造 型(实参…)` 带实参从“静默丢弃实参”改为编译期报错（issue #149）。

规则：

- 无构造器时可用 `造 型()` 实例化（字段取初值）；**带实参则报错**：

  ```text
  型 '配置' 未定义构造器，不接受实例化参数
    提示: 要接受参数请在该型中定义 造(...);只建字段默认值请写 造 配置()
  ```

- 有构造器时，实参个数必须与声明一致，否则报 `构造函数 'X.造' 声明需要 N 个参数,但这里传了 M 个`。

### 口定义

```text
口定义 = "口" 标识符 [ "<" 泛型参数列表 ">" ] "{" { 方法签名 } "}" ;
方法签名 = "函" 标识符 [ "<" 泛型参数列表 ">" ] "(" [ 参数 { "," 参数 } ] ")" [ ":" 类型 ] ;
```

规则：

- 接口方法**只有签名**，写函数体会导致解析错误（`不支持的前缀类型: 右花括号`）。
- 没有“某型实现某口”的声明语法，也没有运行期的接口表。接口是编译期约定，不生成代码；把实例赋给接口类型的注解不会做实现性检查。
- 参数注解在签名里同样不参与强制检查。

## 异步、等待、并行

```text
异步表达式 = "异步" 块 ;
等待表达式 = "等待" "(" 表达式 ")" ;
并行表达式 = "并行" 块 ;
```

三者都是**表达式**，可直接作语句。

### 异步

- `异步 { … }` 立即返回一个**任务句柄**（`任务`），块体在后台执行。
- 块内 `返` 的值是该任务的结果；没有 `返` 时结果为 `空`。
- 块内捕获的外层局部变量是**启动时刻的值副本**：外层之后再改它看不到，块内改了也不写回。要共享请走通道或全局变量。循环里批量起任务必须逐迭代捕获（先 `设 局部 = 循环变量`），否则所有任务都拿到终值。
- 执行层由编译器按**挂起点位置**自动路由：

  | 块体特征 | 路由 |
  |----------|------|
  | 语句级出现 `等待`、`收`、`发`、`选`、`时.睡`、`连`、`流.读`/`流.写` | 无栈状态机（fiber），挂起时让出调度器线程 |
  | 上述挂起点出现在**循环体内** | 整块降级为线程池任务，编译期打印提示；挂起操作按阻塞执行 |
  | 含 `求`、`执`、`输`、`进程.*`（C 侧阻塞实现） | 整块降级为线程池任务，编译期打印提示 |
  | 以上都没有 | 独立函数 → 线程池 |

  注：`文件.读`/`文件.写` 被显式排除在切分点之外，按阻塞调用执行。

- 嵌套的 `异步` 有独立的编译单元与路由决策，不继承外层的尝试块与状态机。

### 进程退出与后台任务

> 在 v1.0-rc.6-dev.5 版本变更：常驻后台任务不再阻止进程退出（issue #142）。

主脚本结束时，编译器生成的收尾会等待有限的后台任务完成（默认最多 2 秒，可用环境变量 `XT_SCHED_DRAIN_MS` 调整）；超时后不杀任务，由进程退出统一回收。

### 等待

- `等待(任务)` 阻塞直到任务完成，返回其 `返` 值；任务没有 `返` 时为 `空`。
- **任务结果只能取一次**：`等待` 消费任务句柄后会把实参标识符的槽位清零，第二次 `等待` 同一任务得到 `空`。要多次使用的结果请先存进变量。
- `等待` 会驱动调度器直到全局静止：程序里还有其他长时间睡眠的任务时，它会等那些任务一并结束才返回，这是设计而非挂死。
- 在异步状态机内部，`等待` 是切分点：位置在语句级即挂起当前 fiber，位置在循环体内则整块改走线程池。

### 并行

- `并行 { 分支 分支 … }` 把块内的**每条顶层语句**当作一个分支，各自编译为独立函数并并发执行。
- 返回一个**数组**，元素是各分支的 `返` 值，**按书写顺序**排列（不按完成先后）。
- 各分支运行在隔离环境上：符号表只复制全局符号，分支内声明的局部不跨分支，分支内对外层局部变量的修改不回传。跨分支收数据用返回数组或通道。
- 分支是普通语句，因此也可以是 `异步 { … }`（此时分支的值是一个任务句柄）。
- 空 `并行 {}` 不是有效用法。

```xuantie
设 汇总 = 并行 {
    { 时.睡(30); 返 "A" }
    { 返 "B" }
}
示(汇总[0] & 汇总[1])     // AB
```

### 异步边界

- `尝试`/`捕捉` 的异常状态按线程隔离，`异步`/`并行` 块内可以使用；不同任务互不串扰，但不要跨任务共享同一个结果变量。
- `断`/`续` 不能跨越函数边界；异步块与并行分支都是独立函数，`断`/`续` 在其中的含义只对块内的循环成立。
- `异步`/`并行` 块内不能 `返` 到外层函数；`返` 的含义是“给出本任务/本分支的值”。

## 道与选

```text
通道构造 = "道" "(" [ 表达式 { "," 表达式 } ] ")" ;
选择     = "选" "(" [ 表达式 { "," 表达式 } ] ")" ;
```

- `道(容量)` 构造一个带缓冲通道；容量取第一个实参（按整数使用），省略时为 16。
- 通道的读写是方法调用而非语句：`通道.发(值)`、`通道.收([超时毫秒])`。它们在普通代码与异步块内的阻塞语义不同，详见 [道](../关键字/道.md) 与 [多线程开发深度教程](../11_多线程开发深度教程.md)。
- `选(通道数组, 超时毫秒)` 等多个通道中第一个就绪者，返回就绪通道在数组中的下标（`整`）；超时返回 `-1`。`选` 只告诉你“哪个就绪”，不替你取数据——拿到下标后自己 `收`。
- 参数不足两个时，当前实现**静默返回 0**（不报错），见「当前实现限制」。
- `选` 是挂起点：出现在循环体内会让整个 `异步` 块走线程池（规则同 `等待`）。

```xuantie
设 数据 = 道(2)
设 控制 = 道(1)
设 下标 = 选([数据, 控制], 1000)
匹配 下标 {
    0 -> 示("数据就绪")
    1 -> 示("控制就绪")
    _ -> 示("超时")
}
```

## 控制流与作用域汇总

| 构造 | 引入新作用域 | 是 `断`/`续` 的作用目标 | 值 | 依赖真值判定 |
|------|--------------|--------------------------|----|--------------|
| `若`/`抑`/`否` 语句 | 是（每块） | 否 | 无 | 是 |
| 若表达式 | 否（分支体是表达式） | 否 | 命中分支的值 | 是 |
| `当` | 是（循环体） | 是 | 无 | 是 |
| `循` | 是（循环体） | 是 | 无 | 否 |
| `遍历` | 是（循环体） | 是 | 无 | 否 |
| `匹配` | 是（每个分支体块） | 否 | 无 | 模式比较 |
| `函` 体 | 是（函数体） | 否（用 `返`） | 有返回值 | — |
| `异步` 块 | 是（块） | 否（块内自有循环可作目标） | 任务句柄 | — |
| `并行` 块 | 是（块；每个分支独立上下文） | 否（分支内自有循环可作目标） | 结果数组 | — |
| 独立块 | 是 | 否 | 无 | — |

## 错误与诊断

| 场景 | 诊断 |
|------|------|
| `若` 缺块 | `若 的条件后面缺少 { } 代码块(玄铁要求显式大括号)` |
| 若表达式缺 `否` | `… [l:c] 若表达式必须包含 否 分支,否则条件不成立时无值可求`（消息内另带 `[行:列]` 前导） |
| 多个 `否` | 警告 `W004`（只有第一个生效） |
| `当`/`循`/`遍历` 缺块 | `不支持的前缀类型: …` + `期望当前标记为 右花括号，但得到 空` |
| `遍历` 漏 `于` | `期望当前标记为 于，但得到 …` |
| `遍历` 缺迭代变量 | `期望迭代变量名` / `期望索引变量名` |
| `匹配` 缺箭头 | `期望当前标记为 箭头，但得到 …` |
| `函` 缺函数名 | `期望函数名称` |
| `函` 参数写默认值 | `期望当前标记为 右圆括号，但得到 等于` |
| `函` 参数写变参 | `期望当前标记为 右圆括号，但得到 范围` |
| 导出名不合法 | `导出名必须是非空 ASCII 标识符字符串,例如 为 "xt_add"` |
| 父类不存在 | `未定义的父类 'X'` |
| 有构造器但实参个数不符 | `构造函数 'X.造' 声明需要 N 个参数,但这里传了 M 个` |
| 无构造器却传实参 | `型 'X' 未定义构造器，不接受实例化参数` |
| 接口方法带函数体 | `不支持的前缀类型: 右花括号` |
| 尾随闭包换行 | `期望当前标记为 右圆括号，但得到 函数定义` |
| 对象级 `覆` | `不支持的前缀类型: 重写` |
| 实参类型与形参注解不符 | 运行时：`参数类型不匹配——形参注解为 '整',但传入的是其他类型(如字符串/对象)` |
| `选` 参数不足 | 无诊断，静默返回 0 |

## 当前实现限制

- **条件不做类型检查。** 非布尔条件按表征判定；整型变量作条件**恒为假**（字面量非零为真），两类写法行为不一致。
- **返回类型注解不校验。** 返回与注解不符时不报错，传入下游按注解类型使用会得到垃圾值。
- **`覆` 不校验。** 不要求父类存在同名方法，也不要求重写必须写 `覆`；同名即覆盖。
- **型体吞掉非成员语句。** 型体内的普通语句既不执行也不报错。
- **无默认参数、无变参。** 参数表只接受“名字 + 可选类型注解”。
- **无泛型约束、无泛型实参检查。** 泛型是类型擦除的语法层能力。
- **字段注解不支持泛型实参。** `设 子: 数组<整>` 的 `<整>` 被型体静默跳过，注解只剩 `数组`。
- **无接口实现声明。** `口` 只提供签名，不参与赋值兼容性检查。
- **`遍历` 只支持数组、字典、字**（`范围` 因求值为数组而可用）。其他目标不报错，运行时会解引用非对象指针（实测 `遍历 v 于 5` 访问违例）。
- **`匹配` 的类型模式表固定。** `是 字节`/`是 任务`/`是 道` 映射为无匹配类型（只在目标为 `空` 时命中）；没有范围模式、守卫、绑定模式。
- **导出名内容不校验。** `为 "…"` 只检查是不是字符串字面量。
- **并行空块无意义。** `并行 {}` 不是有效用法。
- **`选` 参数不足静默返回 0。** 应在调用处保证两个实参都在。
- **`尝试` 不跨任务共享。** 异常状态按线程隔离，任务内使用是安全的；跨任务共享结果变量属于数据竞争。
