# 数据模型

> 对标版本：XTC v1.0-rc.6-dev.5。

本章规定玄铁程序中“值”的表示、分类、所有权与可观察行为。记法与术语见 [概述与记法](./00_概述.md)。文中“当前实现”指本仓库的 XTC 自举编译器（`xuantie_compiler/编译.xt`）与运行时（`runtime/xt_runtime.c`）；未另行注明来源的断言均可在这两处源码或 `Test/` 回归用例中找到依据。

## 规范性规则

### 值的表示

所有值在运行时是同一个机器字类型 `XTValue`（`uintptr_t`），按最低位（LSB）区分形态：

| 形态 | 编码 | 判据 |
|------|------|------|
| 整数 | `(值 << 1) \| 1` | LSB = 1 |
| 堆对象 | 对齐指针，LSB = 0 且地址 > 4096 | 实际指针 |
| `真` | `0x4` | 与 `0x4` 相等 |
| `假` | `0x2` | 与 `0x2` 相等 |
| `空` | `0x0` | 与 `0x0` 相等 |

- 整数必须落在对称域 **±(2⁶²−1)**。`−2⁶²` 在二进制上可编码，但按同一判据视为越界。
- 实现不得对越域整数装箱（左移 1 位会静默溢进符号位）；越域必须在装箱前显式失败。
- 每个堆对象必须以对象头开始：

| 字段 | 类型 | 语义 |
|------|------|------|
| `magic` | `uint32_t` | 恒为 `0x58544F42`（`'XTOB'`） |
| `ref_count` | `_Atomic uint32_t` | 引用计数；`0x7FFFFFFF` 表示长生（Arena 对象） |
| `type_id` | `uint32_t` | 运行期类型标识 |

- `type_id` 取值：`1` 整（装箱形态，极少用）、`2` 小数、`3` 字符串、`4` 布尔（保留，布尔一般用哨兵）、`5` 数组、`6` 字典、`7` 实例、`8` 结果、`9` 函数、`10` 字节、`11` 任务、`12` 通道、`13` 区域分配器、`14` 网络流、`15` 文件句柄、`16` 外部句柄、`17` 子进程句柄。
- 实现必须在 `retain`/`release` 前校验 `magic`；校验失败属运行时不变量被破坏，按硬错误终止（见“错误与诊断”）。

### 类型分类

| 类别 | 语言类型 | 底层表示 | 语义 |
|------|----------|----------|------|
| 无堆分配标量 | `整`、`布尔`、`空` | 标记值/哨兵 | 值语义 |
| 堆标量 | `小数` | `XTFloat`（堆上 `double`） | 值语义（比较与传值表现为数值） |
| 引用类型 | `字`、`字节`、`数组`、`字典`、实例、`结果`、`函数`、`任务`、`道` | 带对象头的堆对象 | 引用语义（赋值共享同一对象） |

以下事实对整章成立：

- 只有整数、布尔、空完全不需要堆分配；小数每次都分配 `XTFloat`。
- 引用类型的赋值、传参、放入容器都只复制引用并增加计数，不复制载荷。

### 标量

#### 整

- 采用标记编码，不分配堆内存；可表示域 ±(2⁶²−1)。
- 字面量越域属编译期错误（编译期直接拒绝，不发生静默失真）。
- 算术、位运算结果越域时：在活动 `尝试` 块内转为可捕异常（消息“整数溢出(超出可表示域 ±2^62-1)”）；无活动 `尝试` 块时打印诊断并以退出码 1 终止。
- 除零与求模除零：在活动 `尝试` 块内抛“除数不能为零”；**无活动 `尝试` 块时返回 `0`**，不诊断、不终止（当前实现，实测）。
- 整数除法向零截断（原生 `sdiv` 语义）；整数与小数混合算术提升为 `double`。

#### 小数

- 堆对象，载荷为 C `double`；不参与整数域检查，也不因越域被拒绝。
- 特殊值（`NaN`、`±Inf`）由 IEEE 754 运算产生，语言层不额外规定其传播与打印形态（**未定义**）。
- 与整数、布尔混合算术时统一按数值提升为 `double`。

#### 布尔

- 只有 `真`（`0x4`）与 `假`（`0x2`）两个哨兵，不是独立堆对象；比较表达式、`且`/`或`/`非` 的结果是布尔。
- **条件位置**（`若`/`抑`/`当` 的条件）的当前判据：标记值与哨兵 `0x4` 比较相等；编译期为裸位的值（整数字面量、标量形参）按“非零”；小数按“非零”。
- 因此 `若 真` 成立，而 `设 x = 1` 之后 `若 x` **不成立**——变量槽位存标记值，与 `0x4` 不相等。这是当前实现的内部不一致：条件位置不得依赖非布尔值，应写比较或逻辑表达式。

#### 空

- `空` 是值 `0x0`，不是类型错误；函数无 `返` 时结果为 `空`，缺键、正向越界读取也返回 `空`。
- 对 `空` 做成员访问、作为索引目标、或作为对象调用方法，属运行时硬错误（在同一函数的 `尝试` 块内可捕，见 [关键字/尝试](../关键字/尝试.md)）。

### 字符串

- 载荷是 UTF-8 字节序列；`length` 记录**字节数**，因此 `字节数` 与 `字符数` 不同。
- 语言层不提供原地修改字符串的操作，可观察行为等价于不可变：`+`、`&`、`示` 内插都产生新串。
- 实现可以对 `s = s + …` 的自拼接做原地追加以避免 O(n²)，但仅在左串被唯一持有时（引用计数不超过阈值）启用；存在别名时走新建路径，别名方观察不到改写（实测：`设 b = a` 后自拼接 `b`，`a` 不变）。
- `字()` 把任意值转成字符串；对容器的渲染是占位串——数组得 `"数组对象"`、字典得 `"字典对象"`，元素不展开；`结果` 得 `成功(…)`/`失败(…)`。

### 字节

- `字节` 是可增长的字节缓冲（`uint8_t*` + `length` + `capacity`），用于二进制 I/O。
- `字节(容量)` 构造；`.追加(字节值)` 追加单字节。
- 字节到字符串的转换做严格 UTF-8 校验：非法字节序列明确报错退出，不做替换或截断。

### 数组

- 载荷是 `XTValue` 指针数组 + `length`/`capacity`；容量不足时倍增扩容。
- 追加对元素 `retain`，改元素先 `release` 旧值再存入，数组销毁时逐元素 `release`。
- 引用语义：`设 b = a` 后对 `b` 的原地修改对 `a` 可见（实测两者 `长度` 同步变化）。
- 正向越界读取返回 `空`；写越界是空操作；负索引属运行时硬错误（同一函数 `尝试` 内可捕）。

### 字典

- 哈希桶 + 链地址法；负载因子超过 `0.75` 时容量倍增并重哈希。
- 键哈希：标记整数取数值、`真`/`假` 取 `4`/`2`、`空` 取 `0`、字符串用 DJB2 逐字节。
- 键相等按 `xt_eq` 判定（字符串比内容，数值比数值）。
- 缺键读取返回 `空`；`含?` 以“取到的值非空”为判据，因此**把 `空` 作为值存入后该键表现为不存在**。
- 引用语义与数组相同；实例（`型` 的对象）与字典内存布局兼容，字段即字典条目。

### 结果

- 载荷三部分：`is_success`（`1`/`0`）、`value`、`error`，三者都持有各自引用。
- `成功(值)`、`失败(原因)` 构造；`.成功`、`.值`、`.错误` 读取；`.接着(回调)`、`.否则(回调)` 为链路方法（成功/失败时以对应载荷调用回调）。
- `?` 后缀作用于 `结果`：成功取 `.值`，失败立即终止当前函数并把该 `结果` 返回上一层。`?` 作用于非 `结果` 是运行时硬错误（退出码 1）。
- 类型注解不接受 `结果` 直接赋给标量：`设 n: 整 = 整("12")` 是编译期错误，必须写 `.值`。

### 函数与闭包

- 函数对象持有底层函数指针（`func_ptr`）与捕获环境字段（`env`）。具名函数的 `env` 为 `空`；带捕获的闭包在创建时把环境字典写入 `env`，动态调用时作为隐藏的第一个实参传入。
- 裸函数名作值使用时包装为函数对象（不是裸代码地址）。
- 匿名函数/闭包在**创建时**把外层局部变量快照进环境字典（逐项 `retain`）；此后外层修改不影响闭包内看到的值，闭包内的修改也不写回外层。
- 全局（顶层 `设`/`常`）不进入快照，而是按符号直接读写同一槽位。

### 实例与字段

- 实例对象与字典内存兼容并额外持有类指针；字段以字典条目形式存储，可在运行期新增属性（实测）。
- 方法编译为独立函数，符号名形如 `型名.方法名`，第一个形参固定为 `此`。
- 成员访问优先按接收者的静态类型（`型:名`）解析；静态类型未知时退化为运行期成员查找，找不到即“调用了对象不存在的方法”硬错误。
- `私`/`护` 在编译期检查：`私` 只允许定义型内部访问，`护` 只允许定义型及其子类访问。
- **未定义**：实例的字段内存布局、字段遍历顺序、析构器/终结器语义。语言层没有析构器。

### 弱引用

- 弱引用是“不持有所有权”的引用：不 `retain` 目标，目标释放时不 `release`。
- 注册模型：局部弱引用登记一个 `XTValue*` 槽位；弱字段（字典/实例条目）登记“对象 + 键”对。目标对象释放时遍历注册链表，把槽位写为 `空`、或把该键的值写为 `空`。
- 弱引用变量重赋值不释放旧值、不持有新值，并重新登记新槽位。
- 弱引用字段的类型应当带可空修饰 `?`；缺失时给出 W005 警告（严格模式升级为错误）。
- 并发下弱引用的可见性**未定义**：注册链表由运行时全局锁保护，但语言层不提供跨线程同步保证。

### 任务

- 任务句柄有两种底层表示：
  - **fiber 句柄**：`1` 到 `65535` 的小整数（槽位下标 + 1），`0` 为非法句柄。
  - **线程池任务**：堆上的任务对象（状态 `0` 运行中 / `1` 已完成 / `2` 失败，`pool_id` 为 `-1` 表示未提交）。
- 返回值只能消费一次：`等待` 取走结果后槽位被回收复用，再次 `等待` 同一句柄得到 `空`。
- `是 任务` 对线程池任务为真、对 fiber 句柄恒为假（当前实现，实测）。
- **未定义**：把任务句柄当普通整数比较、打印或存入容器后的行为。fiber 句柄是小整数，其取值与布尔哨兵 `0x2`/`0x4` 重叠，不得依赖任何按值比较的结果。

### 值语义与引用语义

| 类型 | 赋值/传参表现 | 原地可改 |
|------|----------------|----------|
| `整`、`布尔`、`空` | 复制标记值 | 不适用 |
| `小数` | 装箱对象；比较按数值 | 否 |
| `字` | 复制引用；无原地修改语法 | 否 |
| `字节`、`数组`、`字典`、实例 | 复制引用，共享载荷 | 是 |
| `结果` | 复制引用 | 否（只读成员） |
| `函数` | 复制引用，共享捕获环境 | 否 |
| `任务` | 复制句柄（见上） | 不适用 |

- 赋值是“共享引用 + 增加计数”，不是深拷贝。
- 需要独立副本必须显式重建（例如逐元素 `追加` 到新数组）；语言层不提供通用深拷贝操作。

### 可变性与别名

- 数组、字典、实例是可变引用类型：任一别名原地修改，其余别名立即可见。
- `设 x = …` 重复声明同一名字是**覆盖写**，不是新建块级遮蔽：覆盖前先释放槽位旧值（并把槽位清零），再把新值存入。
- 块内 `设` 声明的名字在块外不可见（编译期拒绝，而非运行期读到空）。
- 字符串没有可观察的原地修改，因此别名不会因内部优化而互相污染。

### 相等与同一性

| 左侧 | 右侧 | `==` 判据（当前实现） |
|------|------|------------------------|
| 数值（整/小数/布尔） | 数值 | 按数值比较；`1 == 1.0` 为 `真` |
| 字符串 | 字符串 | 按内容逐字节比较 |
| 引用类型 | 同一对象 | 真（同一性） |
| 引用类型 | 不同对象 | 假——即使内容相同（数组/字典/实例无结构相等） |
| 布尔 | 非布尔 | 两侧静态类型都确定时是**编译期错误**；判据为“类型不可比” |

- `是` 右侧是类型名时做运行期类型判断，结果为布尔；右侧不是类型名时退化为 `==`（值等价）。
- 运行期类型判断按类型名文本匹配（`整`/`整数`、`字`/`字符串`、`道`/`通道` 等别名并列），未知类型名返回假。
- 实例可定义 `_等_` 参与 `==`/`!=` 的重载分派；已定义 `_等_` 的类型不再走内建比较。

### 类型检查与转换的边界

| 检查点 | 时机 | 结论 |
|--------|------|------|
| 字面量与注解冲突、`结果` 赋给标量、实参个数、方法存在性（静态类型已知时）、常量重赋值、块级可见性、`私`/`护` | 编译期 | 报错并中断编译 |
| 布尔与非布尔 `==`（两侧静态类型均确定） | 编译期 | 报错（逻辑运算结果与其它类型比较恒假） |
| 标量形参收到非标量实参 | 运行期 | 硬错误（有活动 `尝试` 时转为可捕） |
| 成员缺失、未知成员、索引非对象、负索引、方法缺失 | 运行期 | 同一函数 `尝试` 内可捕，否则硬退出 |
| `是 类型名` | 运行期 | 返回布尔，不改变值本身 |
| `整()`、`小数()` | 运行期 | 转换失败返回 `失败` 结果，不抛异常 |
| `字()` | 运行期 | 任何值都得到字符串；容器为占位串 |

- 类型注解只提供静态检查与标量存储形态，不改变值的运行期表示。带 `整` 注解的**形参**在函数入口脱壳为裸整数保存；带 `整` 注解的**局部量**槽位仍存标记值（因此条件位置判为假，见“标量/布尔”）。
- 泛型参数是**编译期类型擦除**的：`型 盒<T>`、`函 交换<T>` 的 `T` 不参与代码生成，不产生按类型的特化或运行期检查。

## 运行时语义

### 分配

- 所有堆对象经统一分配入口创建：设置 `magic`、初始化 `ref_count = 1`、写入 `type_id`；分配失败直接硬错误终止。
- 处于区域分配模式时，对象从区域缓冲区分配并把 `ref_count` 置为长生值，`release` 不再释放；区域自身按引用计数回收。

### 引用计数

- `retain`：对非整数、非小常量的真实对象原子递增；长生对象直接跳过。使用松弛内存序。
- `release`：原子递减，旧值为 `1` 时转入析构；使用顺序一致内存序，保证析构前所有写入对本线程可见。
- 析构按类型执行：字符串释放字符缓冲（区域分配的除外）；数组/字典/实例逐元素 `release`；结果释放 `value` 与 `error`；通道销毁锁与条件变量并释放缓冲元素；文件/网络/子进程/外部句柄执行关闭或析构钩子。
- 长生对象永不析构。

### 作用域释放

- 编译器把每个作用域内的堆值槽位登记为“活项”。作用域结束时逐项 `release`，并把槽位写回 `0`——再遇同一槽位时释放的是空操作，从机制上避免二次释放。
- 函数 `返` 路径释放**整条作用域链**上的活项；块末只释放该层并弹出。
- 标量槽位不入活项登记（内容不是对象指针，释放会当作指针解引用）。
- 参数在函数入口 `retain`，因此形参与局部量走同一套释放纪律；调用方保留自己的引用。

### 参数与返回值所有权

- 调用方传参是**借用**：实参引用不被调用方消耗。
- 被调函数入口对每个装箱参数 `retain` 一次，作用域退出时 `release`。
- `返` 的表达式结果自带 `+1` 引用并移交调用方；调用方负责在作用域结束时释放。

### 容器所有权

- 数组追加/改元素、字典插入/改值都会 `retain` 新值并 `release` 被替换的旧值；容器析构时释放全部元素。
- 因此把值放进容器后，调用方仍须释放自己那份引用；容器持有的是独立的一份。

### 弱引用归零

连锁路径：最后一个强引用被 `release` → 计数归零 → 析构 → 遍历弱引用注册链表 → 把槽位写 `空`（或把字段值写 `空`）→ 摘除该条注册。

- 局部弱引用的槽位是栈上 alloca，弱引用声明时该槽位从作用域活项中移除，避免块末把它当强引用释放。
- 弱字段归零走“字典弱写”，不 `release` 旧值。

### 循环引用

- 引用计数无法回收互相强引用的对象组：两个实例互相持有强引用时，计数永不归零，内存泄漏。
- 当前实现**不做**环检测：编译流程中的 W401 检测趟被显式跳过（编译器只保留警告表条目，不发射该警告）。因此 `Test/24_循环引用检测.xt` 只能验证类型定义可编译，不能验证告警。
- 破环的唯一手段是弱引用（见 [04_弱引用编程指南](../04_弱引用编程指南.md)）。

## 错误与诊断

| 场景 | 诊断形态 | 能否 `捕捉` |
|------|----------|--------------|
| 整数字面量越域 | 编译期错误，中断编译 | 不适用 |
| 整数运算越域 | 有 `尝试`：可捕异常；否则 stderr 诊断 + 退出码 1 | 同函数 `尝试` 内可捕 |
| 整数/小数除零、求模除零 | 有 `尝试`：可捕异常“除数不能为零”；否则返回 `0`/`0.0` | 同函数 `尝试` 内可捕 |
| 堆损坏或非法指针（`magic` 不符） | stderr 诊断（含地址与栈回溯）+ 退出码 `255`（`exit(-1)`） | 不可捕 |
| 标量形参收到非标量 | 有 `尝试`：可捕；否则 stderr 诊断 + 退出码 1 | 同函数 `尝试` 内可捕 |
| 对 `空`/标量访问成员、索引非对象、负索引、方法缺失 | 有活动 `尝试`（同一函数）：可捕；否则 stderr 诊断 + 退出码 1 | 见注 |
| 对非 `结果` 调用 `.接着`/`.否则` | 运行时守卫诊断（“该值不是 结果 对象”）+ 退出码 1 | 不可捕 |
| 正向越界读、缺键读 | 返回 `空` | 不适用（不是故障） |

注：成员/索引/方法类硬错误只在**同一函数的 `尝试` 块内**转为可捕异常；跨函数时不转异常，按硬退出处理。完整清单见 [关键字/尝试](../关键字/尝试.md)。

## 当前实现限制

- 整数域只有 ±(2⁶²−1)；需要更大整数时必须走字符串或字节集，语言层无大整数类型。
- 条件位置对非布尔值的判定不一致（标记值与哨兵 `4` 比较；裸整数按非零）。不得依赖 `若 x` 这种写法。
- 布尔与非布尔的 `==` 在两侧静态类型都确定时被拒绝；但运行期比较函数本身按数值统一处理布尔与数值，二者仅在编译期无法判定时才可能相遇。
- 字典以“值非空”实现 `含?`，值为 `空` 的键与不存在的键不可区分。
- 引用类型没有结构相等，也没有深拷贝；`==` 对数组/字典/实例是比较对象身份。
- 无环检测（W401 检测趟被跳过）；无 GC、无析构器；除句柄类的析构钩子外没有终结语义。
- 弱引用：重赋值时旧槽位未从注册链表摘除（清零前会校验槽位仍指向该对象，故不会误清零），闭包弱捕获（`函() [弱 此]`）尚未实现。
- `是 任务` 对 fiber 句柄恒为假；任务句柄不是可自由比较的普通值。
- 泛型是编译期类型擦除，不产生按类型特化的代码或运行期检查。
- 小数没有越域/精度诊断，特殊值（`NaN`、`±Inf`）的打印与比较细节未定义。
- 递归深度不做检查；超出原生线程栈的递归会导致进程崩溃（未定义行为）。
