# 表达式

> 对标版本：XTC v1.0-rc.6-dev.9。

本章规定玄铁的表达式语法、求值顺序与值语义。语句（声明、控制流、`示`、`返`）不在本章范围，见 [词法分析](./01_词法分析.md) 与手册的 [控制流体系](../手册/03_控制流体系.md)。

实现依据：`xuantie_compiler/语法分析.xt`（`解析表达式` / `解析中缀`）、`xuantie_compiler/抽象语法树.xt`（节点类别）、`xuantie_compiler/编译.xt`（求值落点）与 `runtime/xt_runtime.c`（运行时帮手）。文中标注"实测"的结论均在 XTC v1.0-rc.6-dev.5 自举产物上编译运行确认。

## 表达式与语句边界

- 表达式**有值**；语句**无值**（`示`、`返`、`断`、`续`、`终` 及各类声明/控制流都是语句）。
- 表达式可以独立成句，构成**表达式语句**：求值后丢弃结果。它是调用有副作用函数、写赋值的主要手段。
- 函数体/块内最后一条**表达式语句**不会自动成为函数返回值——函数返回值只由 `返` 提供。唯一的块尾取值规则在 `尝试` 的表达式形态（取块尾表达式语句的值，见 [尝试](../关键字/尝试.md)）。

```text
语句       = 声明语句 | 控制流语句 | "示" "(" 表达式 ")" | "返" [ 表达式 ]
           | "断" | "续" | "终" [ 表达式 ] | 块 | 表达式语句 ;
表达式语句 = 表达式 ;
```

本章 EBNF 沿用 [概述与记法](./00_概述.md) 的记法（`[ ]` 可选、`{ }` 重复、`;` 结束产生式）。非终结符用中文命名并出现在 `=` 左侧；终结符一律加引号。

边界规则：

- 语句之间**不需要**分隔符，换行不是语句分隔符；`;` 是空语句，可出现在语句位。
- 声明处有一条换行敏感规则：`设 x =` 后换行报 `缺少初始值表达式(= 后不允许换行,值须与 = 同行)`（实测）。其它位置换行不影响解析。
- `示` 是**语句关键字**，不是函数：`示(...)` 不能出现在表达式内部（实测 `示(假 且 示("右侧"))` 报 `不支持的前缀类型: 显示`）。需要"表达式内的输出"请先用函数封装。
- 表达式可出现在：声明初值、赋值右侧、实参、下标、条件、`返` 的返回值、字典的键与值、匹配模式、括号分组、字符串插值内。`返` 后面是否解析表达式由表达式首集判定（见下表）。

可以开始一个表达式的记号（语法层的表达式首集）：

| 类别 | 记号 |
|------|------|
| 字面量 | 数字、小数、字符串、`真`、`假`、`空` |
| 名字 | 标识符；类型词 `整` `小数` `字` `字节` `字节视图` `任务` `道` `结果` 在表达式位按名字处理（供 `整(x)` 这类转换调用） |
| 前缀运算 | `非`、`-`、`取反`、`是`（仅匹配模式里的前缀形态） |
| 容器与分组 | `(`、`[`、`{` |
| 复合形态 | `造`、`函`（匿名函数）、`若`（若表达式）、`异步`、`并行`、`等待` |
| 核心原语 | `求`、`听`、`连`、`执`、`输`、`选` |
| 模块与转换 | `引`、`化`、`解` |

`尝试` 也能开始一个表达式（解析器接受），但语法层的"表达式首集"判定 `是表达式开头` 未收录它，这导致 `返 尝试 { … } 捕捉 … { … }` 取不到该表达式的值（见「当前实现限制」）。

## 字面量表达式

| 形态 | 例子 | 值 |
|------|------|-----|
| 整数 | `42` | `整` |
| 小数 | `3.14` | `小数`（double） |
| 字符串 | `"玄铁"`、`'玄铁'`、`"""多行"""` | `字` |
| 插值字符串 | `"计数: #{n}"` | `字` |
| 布尔 | `真`、`假` | `布尔` |
| 空 | `空` | 空值 |
| 数组 | `[1, 2, 3]`、`[]` | `数组` |
| 字典 | `{"键": 1, 裸键: 2}`、`{}` | `字典` |

- 字面量的词法形式（进制、转义、插值、`?` 后缀）见 [词法分析](./01_词法分析.md)。
- 整数域为 ±(2^62−1)，越界在编译期被拒；小数为 IEEE-754 双精度。
- 负数不是字面量：`-1` 是前缀 `-` 作用于 `1`。

### 数组与字典字面量

```text
数组字面量 = "[" [ 表达式 { "," 表达式 } ] "]" ;
字典字面量 = "{" [ 键值对 { "," 键值对 } [ "," ] ] "}" ;
键值对     = 键 ":" 表达式 ;
键         = 表达式 | 标识符 ;
```

- 数组元素按书写顺序存入；**不允许**尾随逗号（实测 `[1,]` 报 `不支持的前缀类型: 右方括号`）。
- 字典**允许**尾随逗号（实测 `{"a": 1,}` 通过）。
- 字典的键有三种写法：引号字符串、裸标识符、括号表达式。
  - 裸标识符键要求"标识符紧跟冒号"，此时按**字符串字面量**处理，不当作变量求值。
  - 要用变量或表达式的**值**作键必须加括号：`{(变量): 值}`。
  - 关键字作键必须加引号：`{"选": 1}`（详情见 [字典](../关键字/字典.md)）。
- 字典是哈希表，键的类型不限（字符串、整数等均可），查找与相等判定由运行时字典实现负责。

### 字符串插值

- 形态 `#{表达式}`，可嵌在短字符串与多行字符串内；一段字符串被切成"文本段 + 表达式段"交替求值。
- 每个表达式段按对象转文本（`xt_obj_to_string`）后拼接，结果恒为新 `字`。
- 空值段的文本是 `"空"`，并给出一条编译警告（`字符串插值中包含明确的 '空' 值`）。
- `${...}` 不支持，报 `不支持的插值符号 '$'，玄铁仅支持 '#{'`。
- 插值里可以写任意表达式，包括嵌套字符串与 `若` 表达式（实测 `"嵌#{ 若 真 { "x" } 否 { "y" } }套"` → `嵌x套`）。

## 标识符

- 标识符表达式的值 = 该名字当前绑定槽位的值（读取会对引用类型计一次引用，语义上等价于"取当前值"）。
- 名字解析在编译期完成；名字未声明报 `未知标识符 'X'`（附改名建议）。
- 块内声明的名字在块外不可见；在块外使用会给出定向报错（提示把声明提到块外或把使用移进块内）。
- `此` 表示当前实例，只在 `型` 的方法体内有绑定；在其它位置按普通名字解析（通常报未知标识符）。

## 成员访问

```text
成员访问 = 表达式 "." 成员名 ;
```

规则：

- 先求值左侧，再取成员；成员名不参与名字解析，按字符串键在对象上查找。
- 可链式：`a.b.c`、`文件.读(...)`、`配置["键"].长度`。
- 成员名接受标识符，以及下列关键字记号：`字节`、`整`、`字`、`布尔`、`数组`、`字典`、`结果`、`执`、`或`、`且`、`空`。其它关键字（如 `是`）会报 `期望成员名称，但得到 是`（实测）。
- 对整数/布尔/空等非对象值取成员是**运行时错误**（不是静默得空）：

```text
运行时错误 [示例.xt:6:7]: 对非对象值(整数/布尔/空)访问成员 '值'
  提示: 成员访问(如 .成功/.值/.长度)只对对象有效;请先用类型检查或 结果 判定保护。
```

- 成员访问可作赋值目标：`对象.字段 = 值`；对 `型` 实例的字段赋值按字段（必要时按弱引用字段规则）写入。

## 函数与方法调用

```text
调用       = 表达式 "(" [ 实参 { "," 实参 } ] ")" ;
泛型调用   = 表达式 "<" 类型实参 { "," 类型实参 } ">" "(" [ 实参 { "," 实参 } ] ")" ;
实参       = 表达式 ;
```

- 实参只有**位置实参**：没有命名实参，没有默认值，没有变长参数。函数定义侧同样只接受 `名[:类型]`（见 [设](../关键字/设.md) 附近的声明规则与手册）。
- 求值顺序：先求值被调表达式，再从左到右求值实参，然后调用。
- 方法调用就是"成员访问 + 调用"：`对象.方法(实参)`。
- 实例化用关键字 `造`：`造 类型名(实参)`；也可写 `造 类型名<类型实参>(实参)`（泛型语义见 [泛型编程指南](../03_泛型编程指南.md)）。
- 泛型调用的识别靠前瞻：`<` 后必须是标识符或类型关键字，且其后紧跟 `>`、`,` 或 `?`，否则 `<` 退回比较运算符。
- **尾随闭包**：调用之后同一行紧跟 `函(参数) { … }` 时，该匿名函数作为**最后一个实参**追加（实测 `对(3) 函(v) { 返 v * 2 }` 得 `6`）。跨行不成立。
- `求` / `听` / `连` / `执` / `输` / `选` 是**核心原语**，语法上是"关键字 + 实参表"，不是普通函数值，不能当值传递；参数个数在编译期校验（如 `听` 必须 2 或 3 个、`执` 必须 1 或 2 个，越界会给出带示例的报错）。
- 参数类型注解只在部分场景做检查；不匹配时在调用链有活动 `尝试` 的情况下由调用方语句级轮询转成可捕异常（见 [尝试](../关键字/尝试.md)）。

## 下标与索引

```text
下标 = 表达式 "[" 表达式 "]" ;
```

- 统一语法：`容器[下标]`。下标表达式按最低优先级解析（可写任意表达式）。
- 语义按容器类型分派：
  - 数组：整数下标，越界读返回 `空`；**负下标是运行时错误**（可被 `尝试` 捕获）。
  - 字典：键查找，缺键返回 `空`；键不存在不会自动插入。
  - 字符串：按**字符**下标（实测 `"玄铁"[0]` 得 `玄`、`[1]` 得 `铁`）。
  - 非对象值取下标（如 `空[0]`、`1[0]`）是运行时错误。
- 下标可作赋值目标：`数组[i] = 值`、`字典[键] = 值`（写入时字典会插入新键）。

## 前缀运算符

| 运算符 | 拼写 | 语义 | 备注 |
|--------|------|------|------|
| 负号 | `-` | 数值取负 | 对小数按浮点取负 |
| 逻辑非 | `非` | 布尔取反 | 结果恒为 `布尔` |
| 按位取反 | `取反` | 整数按位取反 | 不是逻辑非 |
| 类型前缀 | `是 类型名` | 类型测试的前缀形态 | 只在 `匹配` 模式里使用；表达式位是 `a 是 T` 中缀形态 |

优先级：前缀运算符的操作数只吸收优先级**高于 7** 的运算，即只吸收后缀类（`. ? ( )`、`[ ]`）。因此：

- `-a * b` = `(-a) * b`
- `-a.b` = `-(a.b)`
- `-a[0] + 1` = `(-(a[0])) + 1`

> 当前实现限制：`!` 虽然被词法器记成 `非` 记号（字面量 `"!"`），但前缀编译只识别关键字 `非`。实测 `示(!真)`、`示(!假)` 都输出 `空`（既不取反也不报错）。**不要用 `!`**，逻辑非只写 `非`。

## 中缀运算符与优先级

优先级数值越大结合越紧（来自 `当前优先级`）：

| 级别 | 运算符 | 结合性 | 说明 |
|------|--------|--------|------|
| 9 | `.`（成员）、`?`（冒泡后缀） | 左 | 最紧 |
| 8 | `(`（调用）、`[`（下标） | 左 | 后缀类 |
| 7 | `*` `/` `%` `位与` `左移` `右移` | 左 | |
| 6 | `+` `-` `&` `位或` `异或` | 左 | `&` 是字符串拼接 |
| 5 | `<` `<=` `>` `>=` `..` | 左 | 比较与范围同级 |
| 4 | `==` `!=` `是` | 左 | |
| 3 | `=` | 右 | 右侧按最低优先级解析整段表达式 |
| 2 | `且` | 左 | 短路 |
| 1 | `或` | 左 | 短路 |

规则与陷阱：

- 同级别一律**左结合**：`2 * 3 % 4` = `2`（实测），`a - b - c` 等价于 `(a - b) - c`。
- `=` 是**右结合**的表达式：右侧按优先级 0 解析，因此 `a = b = 1` 等价于 `a = (b = 1)`；赋值本身有值，`设 b = (a = 2)` 后 `a` 与 `b` 都是 `2`（实测）。
- 赋值目标只能是变量、成员或下标（`x = v`、`o.f = v`、`a[i] = v`）。
- `..` 与比较同级、左结合；`1 .. 3 + 1` 中 `+`（6 级）比 `..`（5 级）紧，右端是 `3 + 1`。
- `|` 不是运算符，只作类型注解里的联合类型分隔符。
- `&&`、`||`、`+=`、`++`、`**` 等写法不存在（见 [词法分析](./01_词法分析.md) 的运算符表）。
- 没有三目运算符：`?` 是后缀冒泡，`:` 是定界符，`条件 ? a : b` 不成立，请用若表达式。

### 类型实参与 `<` 的歧义

`<` 既可能是比较，也可能是泛型实参的开头。判定规则：`<` 后是标识符或类型关键字，且该记号之后紧跟 `>`、`,` 或 `?` 时按泛型处理，否则按比较处理。

> 当前实现限制：连写比较会被这条前瞻规则吞掉。实测 `甲 < 乙 > 丙` 把 `< 乙 >` 当作泛型实参列表消费，随后报 `期望当前标记为 右圆括号，但得到 标识符`。需要链式比较时加括号或拆成两个条件。

## 算术、位运算与比较

### 整数

- 整数运算保持整数语义（不自动提升为小数）。`整` 采用 tagged 编码，可表示域 ±(2^62−1)。
- 除法是 **C 语义的向零截断**：`7 / 2` = `3`，`-7 / 2` = `-3`（均实测）。文档别处写作"向下取整"，负数场景以本节为准。
- 取模与除法同符号规则（C 语义）：`-7 % 2` = `-1`，`7 % -2` = `1`（实测）。
- 除零：**没有**活动 `尝试` 时整数 `/`、`%` 返回 `0`；在 `尝试` 块内抛可捕异常 `除数不能为零`。
- 越域：`+ - * / %` 与 `位与 / 位或 / 异或 / 左移 / 右移 / 取反` 的结果在运行时检查；越域时在 `尝试` 块内抛可捕异常 `整数溢出(超出可表示域 ±2^62-1)`，没有 `尝试` 则打印诊断并以退出码 1 终止（不静默回绕）。
- 位移量必须在 `0 … 62`，越界同样按"整数溢出"处理。

### 小数

- 任一侧是小数，整体提升为小数运算：`7 / 2.0` = `3.5`（实测）。
- `%` 按 `fmod` 语义：`5.5 % 2.0` = `1.5`（实测）。
- 小数除零返回 `0.0`（无 `尝试` 时），有 `尝试` 时抛可捕异常。
- 打印/转文本时整数值不带小数点：`字(2.0)` 得 `"2"`。

### 比较

- 整数与小数可混合比较，按数值判定：`1 == 1.0` 为 `真`（实测）。
- 字符串按内容比较：`"abc" == "abc"` 为 `真`（实测）；`!=` 为取反。
- 布尔与非布尔值做 `==` / `!=` 是**编译错误**，实测文案：

```text
编译错误: [示例.xt 行:1, 列:5] '==' 两侧类型不可比:左侧是布尔、右侧是整;
逻辑运算(且/或/非)返回布尔,与字符串/数字比较恒为假,分支会被静默吞掉
 | 提示: 若本意是「空或空串」,请分开写 (X == 空) 或 (X == ""),或直接用 X.字符数 == 0
```

- 比较运算符是运算符重载的入口之一：自定义 `型` 可实现 `_等_`；`==` / `!=` 仅对自定义类型启用重载，内置标量按原生比较（详见 [运算符-比较](../关键字/运算符-比较.md) 与 [10_运算符重载编程指南](../10_运算符重载编程指南.md)）。

### 位运算

| 写法 | 语义 |
|------|------|
| `a 位与 b` | 按位与 |
| `a 位或 b` | 按位或 |
| `a 异或 b` | 按位异或 |
| `a 左移 b` / `a 右移 b` | 位移，位移量 0…62 |
| `取反 a` | 按位取反（前缀） |

`&` 是字符串拼接，不是位与；`|` 不是位或。

### 运算符重载

自定义类型可按魔术方法重载算术与比较：`_加_`、`_减_`、`_乘_`、`_除_`、`_模_`、`_等_`。两侧均为标量时走原生指令，不走重载。详见 [手册 §运算符重载](../手册/01_词法与基础语法.md#运算符重载魔术方法)。

## 逻辑运算与短路

- `且`（2 级）、`或`（1 级）与前缀 `非` 构成逻辑运算，结果恒为 `布尔`（不像某些语言返回操作数本身）。
- **短路**：`且` 左侧为假时右侧不求值；`或` 左侧为真时右侧不求值。实测：`假 且 说()` 不执行 `说`，`真 或 说()` 不执行 `说`，`真 且 说()` 执行。
- 求值顺序固定为从左到右。

> 当前实现限制（真值判定）：`且`/`或` 会把操作数转换成条件。字面量整数走"非零即真"（`1 且 真` 为 `真`），但**装箱整数**与 `真` 的编码值比较，`设 n = 1` 后 `n 且 真` 得 `假`（实测）；字符串同样按编码值比较，`"x" 且 真` 得 `假`。因此逻辑运算的操作数**应当**是布尔值或比较表达式，不要依赖整数/字符串的真值转换。

## `是` 比较

`是` 有两种形态，由右侧记号的形态决定：

| 右侧 | 形态 | 语义 |
|------|------|------|
| 类型关键字（`整` `小数` `字` `布尔` `数组` `字典` `结果` `字节` `字节视图` `任务` `道` `空`） | 类型判断 | 运行时检查类型 |
| 已知类型名的字符串字面量（`"整"`、`"字符串"`、`"通道"` 等） | 类型判断 | 同上（兼容别名） |
| 其它任意表达式 | 值等价 | 与 `==` 完全同语义 |

- 类型判断可接受的名字：`整`、`整数`、`小数`、`浮点`、`字`、`字符串`、`布尔`、`逻辑`、`数组`、`字典`、`结果`、`字节`、`任务`、`道`、`通道`、`空`、`实例`、`函数`。
- 类型名写错或不存在的类型：结果为 `假`，**不报错**。
- 值等价形态会被编译期直接改写成 `==`；因此 `1 是 1.0` 为 `真`（数值比较）。
- 前缀形态 `是 类型` 只用于 `匹配` 的分支模式，不在普通表达式里单独使用。

## 字符串拼接与格式化

- 规范拼接运算符是 `&`：任一侧为字符串即按文本拼接，非字符串一侧先转文本。`"a" & 1` 得 `"a1"`（实测）。
- 空值参与拼接会被转成文本 `"空"`，并给编译警告 `字符串拼接中包含明确的 '空' 值`。
- 拼接总是产生新字符串（字符串不可变，见 [字符串](../关键字/字符串.md)）。
- 格式化没有 `printf` 风格：三种手段是 `&` 拼接、`字(x)` 显式转换、`"…#{表达式}…"` 插值。
- `%` 不能用于字符串：`"a" % 1` 是**编译错误** `字符串不支持 % 运算符`（提示改用 `&` 与 `字()`）。
- 实现细节：任一侧为字符串时 `+` 在运行时会走字符串拼接（实测 `"a" + 1` 得 `"a1"`），但 `+` 的规范语义是数值加法，字符串拼接请一律使用 `&`。
- 自拼接 `s = s + X`（`s` 的静态语言类型为 `字` 时）有原地追加的快路径，语义与 `s = s & X` 等价，只是把循环拼接从 O(n²) 降到摊销 O(1)。

## 范围表达式

```text
范围 = 表达式 ".." 表达式 ;
```

- 值是一个**整数数组**，区间为 `[起, 止)`——左闭右开。实测 `1 .. 3` 的长度是 2，`遍历 x 于 1 .. 3` 输出 `1`、`2`。
- 起点 ≥ 终点时得到空数组（不报错）。
- 两个操作数按整数解释；范围不能直接当"惰性区间"使用，它已经物化成数组。
- 优先级 5（与比较同级），常用于 `遍历`：`遍历 i 于 0 .. 列表.长度 { … }`。

## 条件表达式

条件求值可以是表达式（值形态）：

```text
若表达式 = "若" 表达式 "{" 表达式 "}" { "抑" 表达式 "{" 表达式 "}" } "否" "{" 表达式 "}" ;
```

```xuantie
设 级别 = 若 分数 >= 90 { "优" } 抑 分数 >= 60 { "良" } 否 { "差" }
```

规则：

- 分支体是**单个表达式**，不是语句块：不能在一个分支里写多条语句。
- `否` 分支**必须存在**；缺失报 `若表达式必须包含 否 分支,否则条件不成立时无值可求`（实测）。
- 值 = 被选中分支的值；分支间的类型不做统一。
- 可出现在任何表达式位：实参、返回值、字典值、插值内（实测 `示(若 真 { 1 } 否 { 2 })` → `1`）。
- 与 `若` 语句的区别：

| | `若` 语句 | 若表达式 |
|---|---|---|
| 分支体 | 语句块（可多条语句） | 单个表达式 |
| `否` 分支 | 可选 | 必须 |
| 值 | 无 | 有 |

### `匹配` 不能作表达式

玄铁只有 `匹配` **语句**，没有匹配表达式；`匹配` 也不能出现在实参/初值等表达式位。需要"按值取一个结果"时用若表达式，或把 `匹配` 写进函数再用 `返` 返回。

`匹配` 语句的分支模式有三种：`_`（兜底）、`是 类型`、以及任意表达式（与目标按运行时相等判定 `xt_eq` 比较）。分支自上而下判定，命中第一个即执行；没有命中且没有 `_` 时整个 `匹配` 静默跳过（见 [匹配](../关键字/匹配.md)）。

## 尝试表达式

> 在 v1.0-rc.6-dev.5 版本加入：`尝试` / `捕捉` 的表达式形态（issue #113）。

`尝试 { … } 捕捉 (e) { … }` 既是语句也是表达式。表达式形态的值 = **尝试块（或捕捉块）最后一条表达式语句的值**；块尾不是表达式语句时值为 `空`。

```xuantie
设 值 = 尝试 {
    设 x = 40
    x + 2
} 捕捉 (e) {
    0
}
```

- 块内的 `返` 仍然是**函数返回**，不是"提前取这个表达式的值"。
- 适合"取一个值、失败给默认值"；复杂控制流请用语句形态（详见 [尝试](../关键字/尝试.md)）。
- 当前 `返` 的表达式首集判定未收录 `尝试`，写成 `返 尝试 { … } 捕捉 … { … }` 会丢掉该值（见「当前实现限制」）。

## 闭包与匿名函数

```text
匿名函数 = "函" "(" [ 参数 { "," 参数 } ] ")" [ ":" 类型 ] 块 ;
参数     = 标识符 [ ":" 类型 ] ;
```

- 匿名函数是表达式：可赋给变量、作实参、作返回值、立即调用，也可写成尾随闭包。
- 没有捕获列表语法；捕获由编译器收集。
- 捕获语义（实测）：
  - 闭包按**值快照**捕获创建时刻的外层可见变量；函数内的局部变量在闭包内被重新赋值**不会**写回外层（实测：外层 `m = 1`，闭包里 `m = 99`，调用后外层仍为 `1`）。
  - 顶层（全局）变量是例外：闭包内对顶层 `设` 声明的变量赋值会写回全局（实测：闭包内 `n = 99` 后全局 `n` 为 `99`）。
- 匿名函数是独立的编译单元：不继承外层的 `尝试` 处理器（异常处理器是函数级的）。
- 返回类型注解可写（`函(x): 整 { … }`）；注解只被记录，不改变求值语义。

> 当前实现限制：没有默认参数、没有变长参数、没有命名参数；没有捕获列表语法。

## 异步块、等待、并行与选

这四个关键字都是**表达式**（有值），不是语句块：

| 形态 | 语法 | 值 | 说明 |
|------|------|----|------|
| 异步块 | `异步 { … }` | `任务` 句柄 | 块内 `返 值` 提供任务结果 |
| 等待 | `等待(任务表达式)` | 任务结果 | 无 `返` 的任务得到 `空` |
| 并行块 | `并行 { { … } { … } }` | `数组` | 每个分支是语句块，值按分支顺序收集 |
| 选 | `选([通道…], 超时毫秒)` | `整` | 就绪通道下标；超时 `-1` |

规则：

- `异步` 块的值是任务句柄，必须用 `等待` 取值：`示(等待(异步 { 返 41 + 1 }))` 得 `42`（实测）。
- 异步块**不**使用块尾表达式作为结果：块内没有 `返` 时，`等待` 得到 `空`（实测 `异步 { 41 + 1 }` → `等待` 得 `空`）。
- `等待` 的结果只能取一次；再次等待同一个已完成任务得到 `空`。`等待` 会驱动调度器直到全局静止（详见 [等待](../关键字/等待.md)）。
- `并行` 的每个分支是语句块，分支值来自 `返`；分支不写 `返` 时该分支为 `空`（实测 `并行 { { "A" } { "B" } }` 的两项都是 `空`）。结果数组按**书写顺序**排列，不按完成先后。
- `并行` 分支跑在隔离的环境副本上，分支内修改外层变量不会汇总回去；跨分支取数据用返回数组或通道。
- `选` 是核心原语的调用形态，**不是**块（`选 { … }` 不成立），返回就绪通道下标而不是数据本身，取数据要再 `收`（见 [选](../关键字/选.md)）。
- 执行层由编译器按挂起点位置自动路由：`等待`/`收`/`发`/`选`/`时.睡` 只在语句级 → fiber；任一出现在循环体内 → 整个异步块走线程池（详见 [异步](../关键字/异步.md)）。
- `异步` / `并行` 块内可以使用 `尝试`（异常处理器状态按线程隔离）；不要跨任务共享同一个 `尝试` 结果变量。

## 静态规则

编译期可判定的规则（违反即报错，不静默）：

1. 名字必须已声明：`未知标识符 'X'`。
2. 常量不可再赋值：`常量 'X' 不能重新赋值`（提示改用 `设`）。
3. 类型注解与字面量冲突：`类型注解冲突: 声明为 '整',但赋的值是 '字'`；赋 `结果` 容器给标量注解会给提示"成功用 `.值`、失败看 `.错误`"。
4. 浮点槽位只收数值：`类型违例: 浮点变量不可赋 '字' 值(浮点槽位为裸位存储,非数值右值会被强转为 0.0)`。
5. `%` 不接受字符串：`字符串不支持 % 运算符`。
6. 布尔与非布尔的 `==` / `!=`：`'==' 两侧类型不可比:左侧是布尔、右侧是整…`。
7. 整数字面量域检查（±(2^62−1)）。
8. 保留字不得出现在标识符位（见 [词法分析](./01_词法分析.md#保留字不可作标识符)）。
9. 核心原语的参数个数校验（`听` 2–3 个、`执` 1–2 个）。
10. `若` 语句的条件后必须紧跟 `{`，否则报 `若 的条件后面缺少 { } 代码块(玄铁要求显式大括号)`。

除此之外，玄铁的表达式**没有静态类型系统**：算术、比较、成员、下标、`是` 的判定都在运行时按值分派。这意味着多数类型错误表现为运行时错误（见下节），而不是编译错误。

## 运行时语义

- 求值顺序：二元运算先左后右；`且`/`或` 短路（见上）；调用先求被调再从左到右求实参；`?` 在其左表达式求值后立即生效。
- 值模型：`整` 是 tagged i64；`小数` 是双精度；`字` 是不可变 UTF-8 对象；`数组`/`字典`/实例是引用计数对象；布尔是独立类型；`空` 是空值。
- `?`（错误冒泡）：
  - 左值必须是**运行时类型为 `结果`** 的对象，否则打印 `运行时错误: '?' 操作符仅能作用于 '结果' 类型` 并以退出码 1 终止。
  - 成功：解包出 `.值` 作为表达式结果。
  - 失败：当前函数**立即返回**这个失败的 `结果` 给它的调用者（实测：`调用(真)` 直接把 `取数(真)` 的 `失败("坏了")` 交回，`.错误` 得 `坏了`）。
- 运行时硬错误（成员访问非对象、未知成员、下标非对象、负下标、方法缺失、参数类型不匹配）：同一函数内有活动 `尝试` 时可被 `捕捉`；没有则打印诊断并退出码 1。跨函数时按硬退出处理（错误点返回后表达式已无有效值）。
- 约定返回值（不是异常）：正向下标越界、字典缺键返回 `空`；I/O 走 `结果` 容器。
- 引用计数：读取对象值计一次引用，赋值/传参/入容器由实现维持引用平衡；用户不直接管理。

## 错误与诊断

| 情形 | 阶段 | 消息（原文） |
|------|------|--------------|
| 表达式位遇到非表达式记号 | 语法 | `不支持的前缀类型: X`（如 `右方括号`、`显示`、`小于`） |
| 表达式后出现多余记号 | 语法 | `期望当前标记为 右圆括号，但得到 标识符` |
| 名字未声明 | 编译 | `未知标识符 'X'` |
| 对常量赋值 | 编译 | `常量 'X' 不能重新赋值` |
| 注解与字面量冲突 | 编译 | `类型注解冲突: 声明为 '…',但赋的值是 '…'` |
| 成员名为不支持的关键字 | 语法 | `期望成员名称，但得到 是` |
| 若表达式缺 `否` | 语法 | `若表达式必须包含 否 分支,否则条件不成立时无值可求` |
| 字符串用 `%` | 编译 | `字符串不支持 % 运算符` |
| `?` 用于非 `结果` | 运行时 | `运行时错误: '?' 操作符仅能作用于 '结果' 类型` |
| 非对象访问成员 | 运行时 | `对非对象值(整数/布尔/空)访问成员 'X'` + 提示 |
| 除零（有 `尝试`） | 运行时 | `除数不能为零` |
| 整数越域（有 `尝试`） | 运行时 | `整数溢出(超出可表示域 ±2^62-1)` |

说明：编译期错误以退出码 1 结束且不产出二进制；运行时硬错误同样以退出码 1 终止（可捕场景除外）。行列为 1 基。

## 当前实现限制

| 限制 | 表现（已实测） |
|------|----------------|
| `!` 未实现 | `!真`、`!假` 均得 `空`；逻辑非只能写 `非` |
| 类型注解不支持泛型实参 | `设 r: 结果<整> = …`、`设 xs: 数组<整> = …` 报 `不支持的前缀类型: 小于`；当前只能写 `: 结果`、`: 数组`。数值数组用内置 `小数数组`（下标读写零装箱，但暂不支持 `遍历`/型字段） |
| `小数数组` 的跨类型使用 | 不能赋给普通 `数组` 变量、不能作型字段、不能用 `遍历`；这些位置显式报错，不会按错布局读内存 |
| `<` 泛型前瞻吞掉比较 | `甲 < 乙 > 丙` 报语法错误，无法链式比较 |
| `返` 不识别 `尝试` 为表达式 | `返 尝试 { 1 } 捕捉 (e) { 2 }` 返回 `0`（值被丢弃）；`示(尝试 {…} 捕捉(…) {…})` 才得 `1` |
| 无匹配表达式 | `匹配` 只有语句形态 |
| 无命名/默认/变长实参 | 形参与实参都只按位置匹配 |
| 成员名关键字白名单 | `x.是` 报 `期望成员名称`；只有 `字节/整/字/布尔/数组/字典/结果/执/或/且/空` 放行 |
| 非法赋值目标不报错 | `1 = 2` 编译通过、静默丢弃（应属明确错误） |
| 逻辑运算真值判定不一致 | 字面量整数按非零为真，装箱整数/字符串按编码值比较（`n 且 真` 为 `假`） |
| 数组字面量尾随逗号 | `[1,]` 报错；字典 `{"a":1,}` 允许（两者不一致） |
| 范围只支持整数 | `1 .. 3` 物化为整数数组，不是惰性区间 |
| 若表达式分支体单一 | 分支只能写一个表达式，不能写语句序列 |
