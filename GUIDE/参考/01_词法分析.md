# 词法分析

> 对标版本：XTC v1.0-rc.5。

本章规定玄铁源文件如何被切分为**记号**，以及每类记号的拼写、字符集与错误行为。词法分析不涉及类型、作用域或求值：它只把字符流变成记号流，供语法层消费（表达式语法见 [表达式](./05_表达式.md)）。

记号在本实现中的唯一生产者是 `xuantie_compiler/词法.xt` 的 `词法分析器`；语法层对记号的消费见 `xuantie_compiler/语法分析.xt`。本章规则以这两个文件与可复现测试为准。

## 记号模型

每条记号（`标记` 型）携带五个字段：

| 字段 | 含义 |
|------|------|
| 标记类型 | 内部类别名，如 `变量声明`、`右圆括号`、`标识符`；语法层与错误消息都用它 |
| 标记字面量 | 记号的源文本。关键字是原词；字符串是**已解转义**的内容；数字是数字文本 |
| 标记行 / 标记列 | 起始位置。行、列均从 1 起算 |
| 源文件 | 产生该记号的文件路径，可为空 |

位置规则：行号只在遇到 `\n` 时加一；列号从 1 起、遇 `\n` 归零后重新计数。因此一个记号的位置是它**首字符**的 1 基行列。

本章 EBNF 沿用 [概述与记法](./00_概述.md) 的记法（`[ ]` 可选、`{ }` 重复、`( )` 分组、`;` 结束产生式、`/* */` 为说明性注释）。为便于检索，本章的非终结符用中文命名：出现在 `=` 左侧的名字即非终结符，终结符一律加引号。

```text
源文件 = [ BOM ] , { 源单元 } ;
源单元 = 空白 | 注释 | 记号 ;
```

## 源文件、编码与换行

规范性要求：

- 源文件**必须**是 UTF-8。
- 允许 UTF-8 BOM（字节序列 `EF BB BF`）；词法器在构造时跳过它，BOM 不进入任何记号。
- 换行可以是 LF（`\n`）或 CRLF（`\r\n`），二者词法等价。
- 不做源码预处理：无宏、无文本包含、无编码声明。`引 "路径"` 是**语法层**的模块引入，不是文本拼接。

实现细节（已核对 `玄铁.xt` 与实测）：

- UTF-8 体检发生在**送入词法器之前**（驱动器按 `UTF8非法偏移` 扫描源文本），不是词法器内部。首个非法字节序列即报错退出，不静默转码：

```text
错误: 源文件不是 UTF-8 编码(首个非法字节偏移 0)
  提示: GBK/ANSI 编码请先另存为 UTF-8(记事本/VS Code 均可导出 UTF-8)
```

- 该体检只能识别"字节序列不是合法 UTF-8"。GBK 字节**恰好**构成合法 UTF-8 时不会被拦，会以乱码标识符报到编译层（实测：GBK 编码的 `示` 被解成 `ʾ`，报 `未知标识符 'ʾ'`）。因此"能编译"不等于"编码正确"。
- `\r` 单独出现时只按空白跳过，**不**增加行号；只有 `\n` 递增行号。

## 注释

```text
注释 = "//" , { 非换行字符 } ;
```

- 只有一种注释：`//` 到行尾（或文件尾）。注释在词法层被整体丢弃，不产生记号，也不产生警告。
- **没有块注释**。`/*` 不被识别为注释定界符：`/` 是 `除`、`*` 是 `乘`，所以 `/* x */` 会被切成 `除 乘 标识符 乘 除`，随后引发语法错误。
- 字符串字面量内部的 `//` 不是注释：字符串扫描优先于注释扫描。
- `#` 不是注释符，出现在字符串外时产生 `非法` 记号，报 `未识别的字符: #`。
- 没有独立的文档注释语法（`///` 只是 `//` 注释，内容不产生任何记号）。

## 空白

被跳过的空白字符恰为四个：

| 字符 | 码位 | 备注 |
|------|------|------|
| 空格 | U+0020 | |
| 制表符 | U+0009 | |
| 换行 | U+000A | 唯一递增行号的字符 |
| 回车 | U+000D | CRLF 的 `\r` 在此被吃掉 |

空白只用于分隔记号，缩进无意义（块结构一律用花括号）。

> 当前实现限制：其它 ASCII 控制字符（如 U+000C 换页）不在空白集内，会被当作标识符字符并入相邻标识符，产生难以定位的报错。实测：`示(1)` 之后跟一个换页符，报 `未知标识符 '示'`（提示 `是否想用『示』？`），肉眼看不见差异。

## 标识符

```text
标识符   = 标识符首 , { 标识符字 } , [ "?" ] ;
标识符首 = 字母 | "_" | 多字节字符 ;
标识符字 = 标识符首 | 数字 ;
字母     = "a" … "z" | "A" … "Z" ;
数字     = "0" … "9" ;
```

规则：

- 标识符可以包含任意多字节（非 ASCII）字符，因此中文、日文均可作名字；大小写敏感。
- 数字只能出现在**非首位**。
- 关键字匹配发生在整个标识符文本上：`设` 是关键字，`设定` 是普通标识符。
- 标识符末尾可以带**一个** `?`（见「`?` 后缀标识符」）。词法器读完标识符后，会**无条件**吞掉紧跟的一个 `?`。

> 当前实现限制（字符集）：判定"是否标识符字符"的依据是排除 ASCII 分隔符集（空白、`( ) { } [ ] . , : ; = + - * / % & < > ! " # $ ' \ ? | ^ ~ @` 与反引号）以及数字，其余字节一律算标识符字。因此 U+0000–U+0008、U+000B、U+000C、U+000E–U+001F、U+007F 等控制字符也会进入标识符。

## 关键字

关键字是固定拼写的保留词，词法器把它们识别为独立记号类型。当前实现共 64 个：

| 分组 | 关键字（标记类型） |
|------|--------------------|
| 声明与修饰 | `设`(变量声明) `常`(常) `函`(函数定义) `型`(型定义) `口`(接口定义) `外`(外部函数) `造`(实例化) `承`(继承) `覆`(重写) `弱`(弱引用) `公`(公) `私`(私) `护`(护) `引`(引) `予`(予) |
| 类型词 | `整`(整) `字`(字) `布尔`(布尔) `小数`(小数类型) `数组`(数组) `字典`(字典) `结果`(结果) `字节`(字节) `任务`(任务) `道`(道) |
| 控制流 | `若`(如果) `抑`(抑) `否`(否则) `当`(当循环) `循`(无限循环) `遍历`(遍历循环) `于`(于) `断`(中断) `续`(继续) `终`(终止) `返`(返回) `匹配`(匹配) |
| 逻辑与值 | `真`(布尔真) `假`(布尔假) `空`(空) `且`(且) `或`(或) `非`(非) `是`(是) |
| 异步与并发 | `异步`(异步) `等待`(等待) `并行`(并行) `选`(选) |
| 异常处理 | `尝试`(尝试) `捕捉`(捕捉) |
| 系统原语 | `示`(显示) `化`(化) `解`(解) `求`(求) `听`(听) `连`(连) `执`(执) `输`(输) |
| 位运算 | `位与`(位与) `位或`(位或) `异或`(异或) `左移`(左移) `右移`(右移) `取反`(取反) |

补充：

- 位运算关键字是**词**而不是符号：写 `x 位与 y`，不写 `x & y`（`&` 是字符串拼接）。
- `此`、`字符串`、`测试` **不在**词法关键字表内——它们在词法层是普通标识符，由语法层按名字保留（见下节）。
- 关键字不可作标识符，判定与文案见下节。

## 保留字不可作标识符

保留字出现在标识符位置一律报错：变量名、常量名、函数名、参数名、迭代变量名、型名、接口名都不允许。判定分两层：

1. **词法关键字**（上节 64 个）：词法层已给出专用记号类型，语法层在期望标识符处直接拒绝。
2. **按名字保留**（无专用记号，词法上仍是普通标识符）：`测试`、`字符串`、`此`。语法层用名字比对拒绝。

保留字名清单（`语法分析.xt` 的 `是保留字`，权威来源为 GSC 的同名判定）：

| 保留字 | 含义 | 保留字 | 含义 |
|--------|------|--------|------|
| `整` | 整数类型与转换函数 | `数组` | 数组类型 |
| `小数` | 小数类型与转换函数 | `字典` | 字典类型 |
| `字` | 字符串类型与转换函数 | `结果` | 结果容器类型 |
| `布尔` | 布尔类型 | `字节` | 字节串类型 |
| `字符串` | 字符串类型（别名） | `任务` | 异步任务类型 |
| `道` | 通道类型 | `测试` | 测试块关键字（XTC 侧无对应语法，仅保留名字） |

此外，表示实例自身的 `此` 同样不能用作标识符。

报错文案（编译器原文，按位置分三种）：

```text
[示例.xt 行:3, 列:5] 语法错误：'结果' 是玄铁语言的保留关键字，不能用作变量名或标识符。请换一个名字。
[示例.xt 行:3, 列:5] 语法错误：'结果' 是玄铁语言的保留关键字，不能用作函数名。请换一个名字。
[示例.xt 行:3, 列:5] 语法错误：'否' 是玄铁语言的关键字，不能用作变量名或标识符。请换一个名字(如 否值)。
```

第三条用于"词法关键字记号落到标识符位"，会附带改名建议。

规则细节：

- 只禁止"当名字"，不禁止"当关键字/类型词用"：`设 n = 整("42")`、`设 r: 结果 = ...` 合法。
- 组合名合法：词法按完整标识符切分，`结果值`、`任务列表` 都不是保留字。
- 报错定位在声明处；报错后语法层吞到本行结束或块尾再继续，避免级联噪声。

> 当前实现限制：以 `?` 结尾的整词不匹配任何关键字——`是?` 这类写法是**合法标识符**（实测 `设 是? = 1` 能编译并输出 `1`）。它与关键字视觉相近，不要使用。

## 数字字面量

```text
整数字面量 = 数字 , { 数字 } ;
小数字面量 = 数字 , { 数字 } , "." , 数字 , { 数字 } ;
```

### 整数字面量

- 只有十进制。**没有**十六进制（`0x`）、八进制、二进制前缀，**没有** `_` 分隔符，**没有**指数记法，**没有**类型后缀。
- 前导零允许：`000123` 等于 `123`。
- 字面量本身**不含符号**：`-1` 是前缀运算符 `-` 作用于字面量 `1`，不是负数字面量。
- 可表示域为 ±(2^62−1) = ±4611686018427387903（`整` 采用 tagged 编码）。字面量在编译期逐位比较判定越界，越界即报错，不产出二进制。

> 在 v1.0-rc.5 版本加入：整数字面量的编译期域检查（±(2^62-1)）。

越界错误原文（实测）：

```text
编译错误: [示例.xt 行:1, 列:3] 整数字面量超出可表示范围 ±4611686018427387903: 4611686018427387904
 | 提示: 整 采用 tagged 编码 (值<<1)|1,可表示范围为 ±(2^62-1);越过域界会静默失真,故编译期直接拒绝
```

需要超出域的大数时没有内建类型可用，请拆成多个整数、字符串或字节集通道（见 [整](../关键字/整.md)）。

### 小数字面量

- 形式固定为 `整数部分 . 小数部分`，两部分都必须是数字；`1.` 不是小数字面量（切分为 `数字 1` + `点`）。
- 运行时是 IEEE-754 双精度（`小数`）。
- 无指数记法（`1e9` 会切成 `数字 1` + 标识符 `e9`），无十六进制浮点。
- 字面量本身同样不含符号；负小数由前缀 `-` 构成。
- 打印时整数值不带小数点：`字(2.0)` 得 `"2"`（见 [小数](../关键字/小数.md)）。

### 切分规则与例子

| 源文本 | 记号序列 | 说明 |
|--------|----------|------|
| `123` | 数字 `123` | |
| `1.5` | 小数 `1.5` | `.` 后紧跟数字才归入字面量 |
| `1.` | 数字 `1`、点 | 小数部分为空，回退为整数 + 点 |
| `1..3` | 数字 `1`、范围 `..`、数字 `3` | 范围运算符的切口 |
| `1.5.2` | 小数 `1.5`、点、数字 `2` | 第二次 `.` 后是数字，但字面量已结束 |
| `0x10` | 数字 `0`、标识符 `x10` | 无十六进制前缀 |
| `1_000` | 数字 `1`、标识符 `_000` | 无数字分隔符 |

## 字符串字面量

```text
字符串字面量 = 短字符串 | 多行字符串 ;
短字符串     = 引号 , { 短串单元 } , 引号 ;
多行字符串   = 三引号 , { 多行串单元 } , 三引号 ;
引号         = '"' | "'" ;
三引号       = '"""' | "'''" ;
短串单元     = 转义序列 | 插值 | /* 除当前引号与反斜杠外的任意字符，含换行 */ ;
多行串单元   = 转义序列 | 插值 | /* 除连续三个当前引号外的任意字符 */ ;
插值         = "#{" , 表达式源文本 , "}" ;
```

规则：

- 单引号与双引号等价，都是字符串。玄铁**没有字符字面量**：`'a'` 是长度为 1 的字符串。
- 同种引号连写三个开启多行字符串，遇到连续三个同种引号结束；多行串内的单个引号是普通字符。短字符串与多行字符串都允许 `#{...}` 插值。
- 短字符串**不禁止跨行**：换行会作为字面内容保留（当前实现没有"单行字符串"检查）。
- 字符串内容在词法层完成转义；只有到文件尾仍未见到闭合引号，才判定未闭合。

### 合法转义（全集）

| 转义 | 结果 |
|------|------|
| `\\` | 反斜杠 |
| `\"` | 双引号 |
| `\'` | 单引号 |
| `\$` | 字面 `$`（兼容保留） |
| `\{` | 字面 `{`（兼容保留） |
| `\n` | 换行 U+000A |
| `\r` | 回车 U+000D |
| `\t` | 制表符 U+0009 |
| `\0` | NUL 字节 0x00（真 NUL，不是两个字符） |

- 除上表九种外，`\` + 任意字符都是**错误**，不再静默降级为"反斜杠 + 字符"两字面量。
- 不支持 `\xNN` 十六进制转义、`\uXXXX`、八进制转义。
- `\0` 产出真 NUL；字符串按长度存储，但 `示`、`==`/`!=` 等走 C 字符串语义的通道遇 NUL 会截断——二进制数据请走 `到字节集` / [字节](../关键字/字节.md)。

未知转义错误原文（实测）：

```text
词法错误 —— 示例.xt
[示例.xt 行:1, 列:10] 字符串字面量中存在未知转义序列 '\q'(合法转义: \\ \" \' \$ \{ \n \r \t \0)
```

若未知转义是 `\x`，消息追加一句 `。\xNN 十六进制转义不支持;任意二进制字节请走 到字节集(字符串) / 字节集通路`。定位指向**反斜杠后的那个字符**。

### 插值

- 拼写 `#{表达式}`，`#` 与 `{` 必须相邻，短串与多行串内均可出现。
- 词法层在括号深度 0 处识别 `#{`，随后按花括号配对扫描：内部可以嵌套任意 `{}`，也可以嵌套字符串（内部引号成对，转义引号不提前结束）。配平后把 `#{` 与 `}` 之间的源文本**原样**交给子解析器，解析为**一个**表达式。
- 因此插值里可以写任意表达式，包括嵌套字符串字面量与 `若`/`尝试` 表达式：

```xuantie
示("嵌#{ 若 真 { "x" } 否 { "y" } }套")   // 输出：嵌x套
```

- `${...}` **不支持**：词法层把它当普通文本，语法层报 `不支持的插值符号 '$'，玄铁仅支持 '#{'`。
- `#{` 之后直到文件尾都没有配平的 `}` 时，整个字符串变成 `非法` 记号（`未闭合的字符串字面量`），由语法层报错。
- 插值文本内的转义**不在**词法层这一步处理；其中的字符串字面量由子词法器重新扫描，所以插值内字符串的转义照常生效。

## `?` 后缀标识符

`?` 在玄铁里有三种角色，按**位置**区分：

| 位置 | 拼写 | 含义 | 判定层 |
|------|------|------|--------|
| 标识符末尾 | `存在?`、`空?`、`末尾?` | 名字的一部分（惯例用于返回布尔的函数/成员） | 词法：读完标识符后吞一个 `?` |
| 类型注解末尾 | `节点?` | 可空类型后缀 | 语法：`解析类型` |
| 表达式之后 | `表达式 ?` | 错误冒泡（`结果` 解包 / 失败上抛） | 语法：问号后缀节点 |

规则与陷阱：

- 名字末尾的 `?` 与名字之间不能有空白。
- 错误冒泡必须让 `?` 与左侧表达式**分开**：`设 值 = 除法(10, 2)?` 中 `?` 紧邻 `)`，不构成标识符，按冒泡解析；而 `设 值 = 包 ?` 依赖 `包` 与 `?` 之间的空白。
- `甲?.值` 会被读成标识符 `甲?` 后接 `.值`，实测报 `未知标识符 '甲?'`——这不是冒泡。
- 一个标识符只吞一个 `?`：`甲??` 读作标识符 `甲?` + 问号记号。

## 运算符与定界符

最长匹配优先：`==` 优于 `=`，`!=` 优于 `!`，`<=`/`>=` 优于 `<`/`>`，`->` 优于 `-`，`..` 优于 `.`。

| 拼写 | 标记类型 | 类别 | 备注 |
|------|----------|------|------|
| `=` | 等于 | 赋值 | 语法上是中缀表达式（右侧吃整段表达式） |
| `==` | 相等 | 比较 | |
| `!=` | 不等 | 比较 | |
| `<` `<=` `>` `>=` | 小于 / 小于等于 / 大于 / 大于等于 | 比较 | `<` 在特定后续记号下会被当作泛型实参开头 |
| `+` `-` `*` `/` `%` | 加 / 减 / 乘 / 除 / 取模 | 算术 | `-` 同时是前缀负号；`/` 后紧跟 `/` 才是注释 |
| `&` | 连接 | 拼接 | 字符串拼接，**不是**位与 |
| `!` | 非 | 前缀 | 与关键字 `非` 共用记号类型（见下） |
| `?` | 问号 | 后缀 | 错误冒泡；另见「`?` 后缀标识符」 |
| `.` | 点 | 成员 | 也是小数字面量的一部分 |
| `..` | 范围 | 区间 | |
| `->` | 箭头 | 匹配 | 仅用于 `匹配` 的模式与分支之间 |
| `\|` | 竖线 | 类型 | 仅作类型注解里的联合类型分隔符，不是逻辑或 |
| `(` `)` `{` `}` `[` `]` | 左/右 圆括号、花括号、方括号 | 定界符 | 必须配对 |
| `:` | 冒号 | 定界符 | 类型注解、字典键值分隔 |
| `;` | 分号 | 定界符 | 空语句（语法层跳过） |
| `,` | 逗号 | 定界符 | 实参、元素、键值对分隔 |

不存在的运算符（写了不会"报未实现"，而是被切成别的记号或直接报非法字符）：

| 写法 | 实际结果 |
|------|----------|
| `&&`、`\|\|` | 两个 `连接` / 两个 `竖线` 记号，随后语法错误 |
| `+=` `-=` `*=` `/=` `%=` | `加`/`减`/… + `等于`，随后语法错误 |
| `++`、`--` | 两个 `加` / 两个 `减` |
| `**` | 两个 `乘` |
| `<<`、`>>` | 两个 `小于` / 两个 `大于`（位移请写 `左移`/`右移`） |
| `~`、`^`、`#`、`` ` `` | `非法` 记号，报 `未识别的字符` |
| `$` | `非法` 记号，报 `未识别的字符: $` |
| `?:` | 不存在三目运算符；`?` 与 `:` 各自成记号 |

关于 `!`：词法器把 `!` 记成标记类型 `非`、字面量 `"!"`。但**当前实现只编译关键字 `非`**，`!x` 不会被当作逻辑非（见 [表达式 §前缀运算符](./05_表达式.md#前缀运算符)）。

## 注解记号

```text
注解 = "@" , 标识符 ;
```

- 只认两个：`@允许`（标记类型 `注解允许`）与 `@响应`（标记类型 `响应`）。其它 `@名字` 一律是 `非法` 记号，报 `未识别的字符: @未知`。
- `@允许(…)` 的括号内只接受**标识符**记号（警告码如 `W004`，或类别名），不解析字符串、不解析表达式；它只抑制紧随其后的**一条**语句的警告。
- `@响应` 之后必须跟 `设`，否则报错。

## 分隔符与标点

- 分号 `;` 是空语句：语法层在程序体与块内跳过它，因此 `;;` 是合法的空转写法，但**不要**把它当语句终止符——玄铁不要求语句以 `;` 结尾。
- 换行**不是**语句分隔符，语句边界由语法决定。唯一的换行敏感规则在声明处：`设 x =` 后面换行会报 `缺少初始值表达式(= 后不允许换行,值须与 = 同行)`（实测）。
- 冒号同时用于类型注解（`设 x: 整`）与字典键值（`{键: 值}`），由语法上下文区分。
- 箭头 `->` 只出现在 `匹配` 分支。
- 括号必须配对；未闭合属于**语法**错误（不是词法错误），报 `期望当前标记为 右圆括号/右方括号/右花括号`。
- 未闭合的**字符串**属于词法错误，但报错发生在语法层：词法器给出 `非法` 记号（字面量 `未闭合的字符串字面量`），语法层报 `未识别的字符: 未闭合的字符串字面量`。

## 字节 / 数组 / 字典字面量的词法线索

这三种复合值**没有专用字面量记号**，全部由普通记号组合而成，因此它们的"词法线索"只是括号与关键字的搭配：

| 复合字面量 | 记号形态 | 备注 |
|------------|----------|------|
| 数组 | `左方括号` … `右方括号`（`[` … `]`） | 元素以逗号分隔；**不允许**尾随逗号（实测 `[1,]` 报 `不支持的前缀类型: 右方括号`） |
| 字典 | `左花括号` … `右花括号`（`{` … `}`） | `键` `冒号` `值`；键可为字符串、裸标识符或括号表达式；允许尾随逗号（实测 `{"a": 1,}` 通过） |
| 字节 | 关键字 `字节` + `(` … `)` | 形如 `字节(容量)` 的缓冲构造，是调用形态，不是字面量 |
| 字符串的字节视图 | 普通标识符 `到字节集` / `字节到字符串` | 函数调用，不是字面量 |

- 没有十六进制字节字面量，也没有 `b"..."` 之类的字节串前缀；二进制数据一律走 `到字节集("…")` 与 `字节` 缓冲（见 [字节](../关键字/字节.md)）。
- `{` 在词法层既可能是字典字面量，也可能是块或插值的结束花括号；词法不区分，歧义由语法层按上下文消解。
- 字典的裸标识符键依赖"标识符紧跟冒号"这一**记号邻接**关系（词法只提供记号，判断在语法层）；关键字（如 `选`）作键必须加引号。

## 静态规则

本章的规范性要求汇总：

1. 源文件必须是合法 UTF-8，允许一个前导 BOM；换行 LF/CRLF 均可。
2. 只有 `//` 行注释；`#`、`/*`、`--` 都不是注释。
3. 空白集只有 空格 / `\t` / `\n` / `\r`。
4. 标识符 = 标识符首 + 标识符字 + 至多一个结尾 `?`；关键字整词优先于标识符。
5. 保留字（64 个词法关键字 + `测试`、`字符串`、`此`）不得作标识符。
6. 数字只有十进制整数与 `整数.小数` 两种形态。
7. 字符串转义只有上表九种，越界即错误。
8. 记号集封闭：不属于上文的字符产生 `非法` 记号，不会"跳过继续"。
9. 词法错误与语法错误在不同阶段报出，二者都以退出码 1 结束本次编译。

词法层不做、也不得依赖：类型检查、作用域解析、常量折叠、宏展开、缩进敏感结构。

## 运行时语义

词法分析本身不产生运行时行为；它决定字面量落到运行时的**值形态**：

| 记号 | 运行时值 | 边界 |
|------|----------|------|
| 整数字面量 | `整`（tagged i64） | ±(2^62−1)；越界在编译期被拒 |
| 小数字面量 | `小数`（IEEE-754 double） | 无指数记法；整数值打印不带小数点 |
| 字符串字面量 | 不可变 UTF-8 `字` 对象 | 按字节长度存储；含 NUL 的串在 C 字符串语义通道会截断 |
| 插值字符串 | 逐段转文本后拼接出的新 `字` | 空值转成文本 `"空"`（并给编译警告） |
| `真` / `假` | `布尔` | 布尔不是整数，`整(真)` 才得 `1` |
| `空` | 空值 | 既不是 `0` 也不是空串 |

注释与空白不产生任何运行时开销，也不进入调试信息以外的任何产物。

## 错误与诊断

| 情形 | 阶段 | 消息（原文） | 定位 |
|------|------|--------------|------|
| 源文件不是合法 UTF-8 | 驱动前置体检 | `错误: 源文件不是 UTF-8 编码(首个非法字节偏移 N)` + 提示两行 | 无行列，给字节偏移 |
| 未知转义 | 词法 | `字符串字面量中存在未知转义序列 '\q'(合法转义: …)` | 反斜杠后的字符 |
| 字符串未闭合 | 词法 → 语法 | `未识别的字符: 未闭合的字符串字面量` | 字符串起始 |
| 非法字符 | 词法 → 语法 | `未识别的字符: #` / `未识别的字符: $` / `未识别的字符: @未知` | 该字符 |
| 保留字作标识符 | 语法 | 见「保留字不可作标识符」三条文案 | 声明处 |
| `${…}` 插值 | 语法 | `不支持的插值符号 '$'，玄铁仅支持 '#{'` | 字符串起始 |
| 整数字面量越界 | 编译（语义） | `整数字面量超出可表示范围 ±4611686018427387903: …` | 字面量 |

说明：

- 行列均从 1 起。字符串相关的多个错误都定位在字符串**起始**位置（词法只记录串首），而未知转义定位在转义字符本身。
- 词法器**不自行退出**：它把发现的问题记入 `词法错误列表`，由驱动器（主文件）或模块加载处统一打印并以退出码 1 终止。这样同一次编译能一次报出多条词法错误。
- 词法错误不是警告，`--严格` / `--禁止` 与是否升级警告无关。

## 当前实现限制

| 限制 | 表现 |
|------|------|
| 标识符字符集过宽 | ASCII 控制字符（U+000C 等）被并入标识符，报错指向肉眼相同的名字 |
| 编码体检只认"非法字节序列" | GBK 恰好构成合法 UTF-8 时以乱码标识符报错（实测 `未知标识符 'ʾ'`） |
| 短字符串可跨行 | 没有单行字符串检查，少写一个引号可能"吞掉"后续整段代码 |
| 关键字可被 `?` 绕过 | `是?`、`即?` 之类是合法标识符（实测可编译） |
| 无块注释 | `/* … */` 会被切成运算符序列 |
| 无文档注释语法 | `///` 只是普通行注释 |
| `!` 与 `非` 共用记号类型 | 词法接受 `!`，但当前前缀代码只实现 `非` |
| `@允许` 参数只收标识符 | 不能写字符串形式的警告码 |
| 无字符/原始/十六进制字面量 | `'a'` 是字符串；`0x10` 切为 `0` + 标识符 |
