# 完整语法规范
> 对标版本：XTC v1.0-rc.6-dev.5。

本文给出玄铁语言**当前实现**的完整语法，组织方式对标 Python 语言参考的 grammar 附录：先词法层，再文法层，最后是优先级表与实现限制清单。所有产生式都直接来自仓库中的编译器源码，并用当前编译器实测校核；本文不描述计划中或尚未实现的语法。

## 记法与依据

语法用扩展巴科斯范式（EBNF）书写，与 [概述与记法](./00_概述.md) 保持一致：

```text
产生式  = 备选1 | 备选2 ;
可选    = [ 元素 ] ;
重复    = { 元素 } ;
分组    = ( 元素1 元素2 ) ;
```

- `中文词` 与 `"符号"` 是终结符，`小写名` 是非终结符。
- `/* ... */` 是说明性注释，不属于语法本身。
- 省略号 `…` 只用于说明性示例，不进入正式产生式。

**依据的源码**（均在仓库根目录下）：

| 范围 | 源码 | 关键位置 |
|------|------|----------|
| 词法 | `xuantie_compiler/词法.xt` | `读标记`、`读标识符`、`读数字`、`读字符串`、`是字母` |
| 语法 | `xuantie_compiler/语法分析.xt` | `解析语句`、`解析表达式`、`解析中缀`、`当前优先级`、`解析型定义`、`解析接口定义`、`解析外部函数`、`解析引入` |
| AST | `xuantie_compiler/抽象语法树.xt` | 各节点字段即语法容量 |
| 语义约束 | `xuantie_compiler/编译.xt` | `全局预扫描`、`编译问号后缀`、`编译匹配语句`、`映射类型注解`、`查找成员可见性` |

“当前实现”指仓库中的 **XTC 自举编译器**（`xuantie_compiler/*.xt`，版本常量在 `玄铁.xt` 的 `版本号`）。种子编译器 GSC（`lexer/`、`parser/`、`token/`，Go）只用于引导自举，其语法集合与 XTC 不完全相同，差异见 [与 GSC 种子编译器的差异](#与-gsc-种子编译器的差异)。

文中“限制”标注的是**源码确实如此**、但与直觉或与既有文档不一致的行为，不是待办项。

## 词法

### 源文件与空白

源文件内容以字符串交给词法器；词法器构造时剥掉开头的 UTF-8 BOM（`词法.xt` 的 `造`）。空白只有四种，**换行不结束语句、不参与缩进**：

```text
空白    = " " | "\t" | "\r" | "\n" ;
```

因为换行无语法意义，`设 x = 1 设 y = 2` 是两条合法语句（实测 `-jc` 通过）。唯一的换行相关限制是 `=` 右侧的初始值必须与 `=` 同行（见 [变量与常量声明](#变量与常量声明)）。

### 注释

只有行注释，没有块注释：

```text
注释    = "//" { 非换行字符 } ;
```

- `//` 到行尾（或文件尾）全部跳过。
- `///` 与 `//` 等价：当前实现没有文档注释语义。
- `/* ... */` 不是注释，`/` 会被当作除法记号，实际得到 `不支持的前缀类型: 除`（实测）。

### 标识符

```text
标识符    = 标识首 { 标识续 } [ "?" ] ;
标识首    = ASCII字母 | "_" | 非ASCII字符 ;
标识续    = 标识首 | 数字 ;
ASCII字母 = "a".."z" | "A".."Z" ;
数字      = "0".."9" ;
```

实现要点（`词法.xt` 的 `是字母`、`读标识符`）：

- 词法器逐字符扫描并判定：除 ASCII 运算符、数字、空白外，所有非 ASCII 字符都归入“字母”（`是字母` 用排除法近似 UTF-8）。因此中文、日文、乃至非 ASCII 标点都能出现在标识符里，编译器不做 Unicode 类别判定；错误定位的列号按字符计数。
- 末尾允许**一个** `?`（`存在?`、`尾?`）。`?` 只吸收一个，`a?b` 会被切成 `a?` 与 `b` 两个记号。
- `_` 可单独作标识符（`匹配` 的默认分支正是按名字 `_` 识别的），但 `_` 不是“丢弃”占位符。
- 保留字不得作标识符，见下节。

### 关键字

关键字由词法器整词匹配（`读标记` 中的 `匹配 字面量` 表）。下表是**全部**关键字，按用途分组：

| 分类 | 关键字 |
|------|--------|
| 声明与修饰 | `设` `常` `函` `型` `口` `外` `弱` `造` `承` `覆` `公` `私` `护` `予` |
| 控制流 | `若` `抑` `否` `当` `循` `遍历` `于` `断` `续` `终` `匹配` `尝试` `捕捉` `返` |
| 并发与异步 | `异步` `等待` `并行` `选` |
| 值与逻辑 | `真` `假` `空` `且` `或` `非` `是` |
| 类型词 | `整` `小数` `字` `布尔` `字节` `字节视图` `数组` `字典` `结果` `任务` `道` |
| 内建与原语 | `示` `化` `解` `求` `听` `连` `执` `输` |
| 位运算 | `位与` `位或` `异或` `左移` `右移` `取反` |
| 模块 | `引` |

以下词**不是** XTC 的关键字，只是普通标识符（多数是 GSC 的兼容别名或历史词）：`打印` `变量` `常量` `跳出` `继续` `函数` `返回` `引用` `整数` `逻辑` `等于` `接着` `成功` `失败` `测试` `此` `字符串`。其中 `测试`、`此`、`字符串` 属于保留字（能识别但不能当名字），其余可以自由作标识符。

### 保留字

保留字清单来自 `语法分析.xt` 的 `是保留字`（与 GSC 的 `expectPeek`/`parseFunctionStatement` 保持一致）：

| 保留字 | 含义 | 保留字 | 含义 |
|--------|------|--------|------|
| `整` | 整数类型 | `小数` | 小数类型 |
| `字` | 字符串类型 | `布尔` | 布尔类型 |
| `字节` | 字节串类型 | `数组` | 数组类型 |
| `字典` | 字典类型 | `结果` | 结果容器 |
| `任务` | 异步任务句柄 | `道` | 通道类型 |
| `字符串` | 字符串类型别名 | `测试` | 测试块（XTC 未实现，见限制） |

另外 `此`（当前实例）同样保留。

规则：保留字与关键字一律不得作**变量名、常量名、函数名、方法名、参数名、迭代变量名、型名、接口名**。唯一例外是泛型参数位置——那里按类型变量处理，允许类型词（`<整>` 合法）。两个报错文案不同：保留字走“是玄铁语言的**保留**关键字”，其余关键字走“是玄铁语言的**关键**字”。

```text
设 测试 = 1     // 解析错误：'测试' 是玄铁语言的保留关键字…
设 若 = 1       // 解析错误：'若' 是玄铁语言的关键字…
函 结果() { }   // 解析错误：…不能用作函数名
型 整 { }       // 解析错误：…不能用作变量名或标识符
设 存在? = 真   // 合法：组合名/问号标识符不受影响
```

### 整数字面量

```text
整数字面量    = 数字 { 数字 } ;
```

- 只有十进制。**不支持** `0x`、`0b`、`0o`、指数、下划线分隔、正负号。
- `0x10` 会被切成 `0` 与标识符 `x10`，得到解析错误（实测）。
- 负数是一元 `-` 运算，不是字面量。
- 整数值的表示域是标记整数（±(2^62-1)），运行时溢出进 `尝试` 可捕异常，属语义层，不在文法内。

### 小数字面量

```text
小数字面量    = 数字 { 数字 } "." 数字 { 数字 } ;
```

- 小数点两侧都必须有数字：`.5` 非法（`点` 记号开头，实测 `不支持的前缀类型: 点`），`1.` 也非法（`1` 之后是 `点`）。
- **不支持**指数（`1e3` 切成 `1` 与 `e3`，实测解析错误）、不支持类型后缀（`f`/`d`）。

### 字符串字面量

```text
字符串     = 短字符串 | 长字符串 ;
短字符串   = '"' { 串项 } '"' | "'" { 串项 } "'" ;
长字符串   = '"""' { 串项 } '"""' | "'''" { 串项 } "'''" ;
串项       = 转义 | 插值 | 普通字符 ;
转义       = "\\" 转义符 ;
转义符     = "\\" | '"' | "'" | "$" | "{" | "n" | "r" | "t" | "0" ;
插值       = "#{" 表达式 "}" ;
普通字符   = /* 除所属闭合引号与反斜杠外的任意字符，且不构成 "#{" */ ;
```

- 单引号、双引号等价；三引号是跨行字符串，两种引号都支持三引号。
- 合法转义只有 `\\` `\"` `\'` `\$` `\{` `\n` `\r` `\t` `\0`（`\0` 落成真正的 NUL 字节）。**未知转义直接报词法错误并中止编译**，例如 `\x41`、`\q`、`\#`；错误消息会列出合法集合，`\xNN` 另附字节集通路的提示。
- 文件尾仍未闭合的字符串被转成“未闭合的字符串字面量”非法记号，由解析器报错，不静默截断。
- 三引号字符串里的转义同样生效；跨行内容原样保留（含换行）。

### 字符串插值

插值语法是 `#{表达式}`，短字符串与长字符串都支持：

```text
示("你好，#{名字}! #{1 + 2}")
```

实现要点（`词法.xt` 的 `读字符串` + `语法分析.xt` 的 `解析字符串`）：

- 插值内容按 `{`/`}` 深度配对，并跟踪内部的字符串引号（`"…"`/`'…'`，支持 `\` 转义），所以 `#{f("{")}` 能正确闭合。
- 插值里的表达式交给一个**子词法器 + 子解析器**解析；子词法器的词法错误会回传主词法器。
- `${` 不是插值，报错“不支持的插值符号 '$'，玄铁仅支持 '#{'”。
- 单个 `#`（后面不是 `{`）是普通字符。
- **限制**：无法用转义写出字面量 `#{`——`\#` 属未知转义，`\{` 只得到 `{`；需要拼接（如 `"#" & "{值}"`）。

### 运算符与定界符

记号表（`词法.xt` 的 `读标记`）：

| 记号 | 拼写 | 用途 | 备注 |
|------|------|------|------|
| 等于 | `=` | 赋值/初始化 | 中缀，见优先级表 |
| 相等 | `==` | 相等比较 | 自定义型可重载 |
| 不等 | `!=` | 不等比较 | |
| 小于/大于 | `<` `>` | 比较 | `<` 也可能开启泛型实参 |
| 小于等于/大于等于 | `<=` `>=` | 比较 | |
| 加/减/乘/除/取模 | `+` `-` `*` `/` `%` | 算术 | |
| 连接 | `&` | 字符串拼接 | |
| 竖线 | `|` | 联合类型注解的分隔 | 表达式层不用 |
| 范围 | `..` | 范围表达式 | |
| 点 | `.` | 成员访问/限定名 | |
| 箭头 | `->` | 匹配分支 | |
| 问号 | `?` | 错误冒泡后缀、可空类型后缀、标识符结尾 | 见词法歧义 |
| 逗号 | `,` | 分隔 | |
| 分号 | `;` | 空语句/分隔 | |
| 冒号 | `:` | 类型注解、字典键值 | |
| 圆括号 | `(` `)` | 分组/调用/参数 | |
| 方括号 | `[` `]` | 数组、下标、解构 | |
| 花括号 | `{` `}` | 块、字典、解构 | |
| 注解 | `@允许` `@响应` | 语句修饰 | 其他 `@名` 报“未识别的字符” |
| 非 | `!` | **陷阱** | 单独 `!` 会切成 `非` 记号，但代码生成按字面量 `"非"` 判定，`!真` 求值为 `空`；不要用 `!` |
| 美元 | `$` | 非法 | 词法层产出非法记号并报错 |

不是运算符、出现在表达式里会报“未识别的字符”的字符：`~` `^` `#`（字符串外） `\`（字符串外） 等。也不存在 `+=` `-=` `++` `--` `&&` `||` `?:`，写了会得到类似 `不支持的前缀类型: 等于` 的解析错误。

### 词法错误与非法记号

- 无法归类的字符 → `非法` 记号，`解析程序` 报“未识别的字符: X”，跳过该记号继续。
- 字符串未知转义 → 记入词法器的 `词法错误列表`，由驱动统一打印并以退出码 1 终止（不静默降级为“反斜杠+字符”）。
- 未闭合字符串 → `非法` 记号（消息“未闭合的字符串字面量”）。

## 文件与顶层

```text
程序        = { 程序项 | ";" } ;
程序项      = 引入语句 | 语句 ;
```

- 一个 `.xt` 文件就是一个编译单元；没有模块声明、命名空间声明、包声明、`导出` 之类语法。
- 声明（`设`/`常`/`函`/`型`/`口`/`外 函`）与普通语句**同层**，可以任意交错，也可以出现在块内（嵌套函数、块内 `型` 都是语法允许的）。
- 引入语句：`引入语句 = "引" 字符串 [ "予" 标识符 ] ;`，详见 [引入](#引入)。

### 入口与执行

当前实现**没有**特殊入口函数名，也没有 `主` 约定（实测：文件里只写 `函 主() { … }` 不会被执行）：

- 主文件的顶层语句按书写顺序编译进 `@main` 主体；运行时先初始化运行时，再执行这些语句，最后驱动调度器收尾。
- 被引入模块的顶层语句同样会执行（实测：模块顶层 `示(...)` 先于主文件语句输出）。`-lib` 库模式不生成 `@main`，此时顶层语句不执行，只给出告警。
- 因此“入口”= 顶层语句序列本身；要封装，惯例是顶层写一行调用（如 `主()`）。

### 顶层可见性

`公`/`私`/`护` 可以写在顶层 `设`/`常`/`函`/`型` 之前，语法接受；但**当前实现不据此过滤跨模块导出**——预扫描会登记全部顶层符号。真正的访问控制只发生在**型成员**上（见 [型声明](#型声明)）。这是实现现状，不要按 C++/Java 的 `private` 语义依赖顶层修饰符。

## 声明

### 变量与常量声明

```text
变量声明    = [ 可见性 ] [ "弱" ] "设" 声明目标 [ ":" 类型 ] [ "=" 表达式 ] ;
常量声明    = [ 可见性 ] "常" 声明目标 [ ":" 类型 ] [ "=" 表达式 ] ;
可见性      = "公" | "私" | "护" ;
声明目标    = 标识符 | 数组解构 | 字典解构 ;
数组解构    = "[" [ 解构项 { "," 解构项 } ] "]" ;
解构项      = 标识符 | "..." 标识符 ;
字典解构    = "{" [ 标识符 { "," 标识符 } ] "}" ;
```

规则与实现事实：

- 省略 `= 表达式` 时值取 `空`（`设 x: 整` 合法）。
- **`=` 右侧必须与 `=` 同行**：换行会报“缺少初始值表达式(= 后不允许换行,值须与 = 同行)”，不静默续行。
- 同一作用域重复声明同名符号报错（变量/函数/型统一查重），跨层遮蔽允许。
- `弱` 只能与 `设` 组合，`弱 常` 报错；`弱` 与 `@响应` 不能叠加（`@响应` 后只接受 `设` 词法记号）。
- 弱引用建议配可空注解，缺 `?` 给 `W005` 警告（不中断编译）。
- 数组解构支持 `...名` 收集剩余；字典解构只接受标识符，不支持 `...`。
- 解构语法细节：`...` 在词法上是 `..` + `.`，解析器对以点开头的元素较宽容（`..名` 也会被当作剩余项）；按 `...名` 书写即可，不要依赖宽容路径。
- 常量被重新赋值属编译期错误（语义层，不在文法内）。

示例：

```text
设 计数 = 0
公 设 全局配置: 字典 = {}
常 最大重试 = 3
弱 设 父节点: 节点? = 空
@响应 设 标题 = ""
设 [甲, 乙, ...其余] = [1, 2, 3, 4]
设 {宽度, 高度} = {"宽度": 800, "高度": 600}
```

### 函数声明

```text
函数声明    = [ 可见性 ] "函" 函数名 [ 泛型参数 ] "(" [ 参数表 ] ")" [ ":" 类型 ] [ 导出名 ] 块 ;
函数名      = 标识符 | "造" ;
泛型参数    = "<" 类型变量 { "," 类型变量 } ">" ;
类型变量    = ( 标识符 | 基本类型词 ) [ "?" ] ;
参数表      = 参数 { "," 参数 } ;
参数        = 标识符 [ ":" 类型 ] ;
导出名      = "为" 字符串 ;
```

- `造` 可作函数名，在型体内即构造函数（`造` 在声明位置被词法切成“实例化”记号，解析器显式接受它作函数名）。
- 函数体必须写 `{ }`，空体可写 `{}`。
- 返回值用 `返`；返回类型注解可省略。
- 泛型参数可写类型关键字（`<整>` 合法，虽然作为类型变量名很怪），可带 `?`（`<T?>`）。
- `为 "ASCII名"` 是 C ABI 导出别名，只在库编译（`-lib`，配合 `--emit-header`）时有意义；名字必须是 ASCII 标识符字符串，详见 [C ABI 互操作](<../C ABI互操作.md>)。注意 `为` **不是关键字**，是只在“返回类型之后 + 字符串之前”这个位置按上下文识别的普通标识符。
- 函数声明是语句，因此可以嵌套（`函` 写在 `若`/`循`/块内）；嵌套函数在块内先登记后使用。
- 不支持：默认参数、可变参数、命名实参、函数类型语法（`(整) -> 整` 之类）。

示例：

```text
函 加(甲: 整, 乙: 整): 整 { 返 甲 + 乙 }

公 函 泛< T >(值: T): T { 返 值 }

公 函 原生加(甲: 整, 乙: 整): 整 为 "xt_add" {
    返 甲 + 乙
}
```

### 型声明

```text
型声明      = [ 可见性 ] "型" 标识符 [ "承" 限定名 ] [ 泛型参数 ] "{" { 型成员 } "}" ;
限定名      = 标识符 { "." 标识符 } ;
型成员      = [ 可见性 ] ( 字段声明 | 弱字段声明 | 方法声明 | 覆写声明 ) ;
字段声明    = "设" 标识符 [ ":" 类型 ] [ "=" 表达式 ] ;
弱字段声明  = "弱" "设" 标识符 [ ":" 类型 ] [ "=" 表达式 ] ;
方法声明    = "函" 函数名 [ 泛型参数 ] "(" [ 参数表 ] ")" [ ":" 类型 ] 块 ;
覆写声明    = "覆" "函" 函数名 [ 泛型参数 ] "(" [ 参数表 ] ")" [ ":" 类型 ] 块 ;
```

规则与实现事实：

- 成员默认可见性为 `公`；`私`/`护` 在**成员访问**处检查（`编译.xt` 的 `查找成员可见性` 与 `检查访问权限`）：`私` 只允许定义类内部访问，`护` 允许定义类及其子类访问，全局访问 `护` 成员直接报错。
- 构造函数名固定为 `造`：`函 造(...) { … }`；实例化用 `造 型名(实参)`（见 [造表达式](#造表达式)）。
- `覆` 必须后跟 `函`，且只出现在型体内；`覆` 之外不能标注重写。
- **`承` 必须写在泛型参数之前**：`型 子 承 父 { }` 合法，`型 子<T> 承 父 { }` 报错（实测“期望当前标记为 左花括号，但得到 继承”）。
- `承` 之后只接受限定名，**不支持父类泛型实参**；`型 子 承 父<整> { }` 会把 `<整>` 登记为**子类型自身**的泛型参数（能编译，但不表达“继承 `父<整>`”）。
- 型体只识别 `设`、`弱 设`、`函`、`覆 函` 四种成员。其他写法不会被当作成员：`常` 这类不含花括号的记号被**逐个跳过且不报错**（实测：型体内写 `常 k: 整 = 1` 编译通过但成员不存在）；含 `{ }` 的写法（嵌套 `型`/`口`）会在内层 `}` 处提前结束型体并报错。两种都不要用。
- `[可见性] 型` 中的修饰符会被解析但**丢弃**（`型定义节点` 无可见性字段）。

示例：

```text
型 节点 {
    设 值: 整
    弱 设 父: 节点?
    私 设 缓存: 字典
    公 函 造(值: 整) {
        此.值 = 值
        此.缓存 = {}
    }
    函 取值(): 整 { 返 此.值 }
}

型 叶 承 节点 {
    设 标记: 字
    覆 函 取值(): 整 { 返 此.值 + 1 }
}
```

### 接口声明

```text
接口声明    = "口" 标识符 [ 泛型参数 ] "{" { 方法签名 } "}" ;
方法签名    = "函" 标识符 [ 泛型参数 ] "(" [ 记号序列 ] ")" [ ":" 类型 ] ;
```

- 接口方法没有函数体，写法与函数声明相同但省略 `{ }`。
- 接口体只识别 `函`；其他记号被跳过。
- **限制**：方法签名只保留**方法名**，参数与返回类型被跳过、不参与任何校验（`解析方法签名` 返回的是名字字符串）。因此接口目前只表达“有哪些方法名”。
- 不支持在接口里写可见性修饰（`公 口` 本身也报错：“不可识别的修饰目标: 接口定义”）。

示例：

```text
口 形状 {
    函 面积(): 小数
    函 周长(): 小数
}

口 容器<T> {
    函 取(): T
}
```

### 外部函数声明

```text
外部函数声明 = "外" "函" 标识符 "(" [ 外参 { "," 外参 } ] ")" [ ":" 类型名 ] ;
外参         = 标识符 [ ":" 类型名 ] ;
```

- `外 函` 声明 C ABI 符号，没有函数体；`函` 必须紧跟 `外`，否则报“期望 '函' 关键字跟在 '外' 之后”。
- **限制**：参数类型与返回类型各只取**一个记号**（`解析外部函数` 直接读标记字面量）。`整?` 这种紧跟 `?` 的写法因为词法会并入同一记号，所以能带出；`|` 联合、`<...>` 泛型实参会被拆成独立记号并导致参数解析错位，不要写。返回类型省略时记为 `空`。
- 惯例写在顶层：预扫描只登记顶层的外部函数；嵌套写法能通过 `-jc` 检查，但其符号可见性与链接行为未核实，不要依赖。

示例：

```text
外 函 xt_add(甲: 整, 乙: 整): 整
外 函 xt_now(): 字
```

### 引入

```text
引入语句    = "引" 字符串 [ "予" 标识符 ] ;
```

- `引` 在语法上是**表达式**（`解析表达式` 有 `引` 分支），但只有**顶层**的引入语句才会被加载：`全局预扫描` 只遍历顶层语句列表并识别“表达式语句 = 引入”。写在函数体等嵌套位置的 `引` 不参与预扫描，编译期实测报“无法引入模块文件”。
- 路径约定：相对路径用 `/`（相对源文件所在目录），绝对路径用 `\`（Windows 原生）；混用给 `W006` 警告并自动规范化。
- 同一模块在一次编译中只能使用一个别名；重复引入且别名不同会报错。
- 裸包名（如 `引 "数组工具"`）按铁铺安装目录解析，未安装则报错并提示 `铁铺 安装`。
- 循环引入被检测并报错；同一文件引入自身直接报错。
- 无别名时，被引入文件的顶层符号以裸名进入命名空间（扁平命名空间）；有别名时用 `别名.名` 访问。详见 [模块系统](../手册/05_模块系统.md)。

示例：

```text
引 "./库/数学.xt"
引 "./库/文件.xt" 予 文件
引 "数组工具"
```

### 注解

```text
注解语句    = "@响应" 变量声明
            | "@允许" "(" 码列表 ")" 语句 ;
码列表      = 标识符 { "," 标识符 } ;
```

- `@允许(W001, 隐式类型)`：抑制紧随其后的**一条**语句里的指定警告码或警告类别；语句解析完即清除抑制列表。
- `@响应 设 …`：声明响应式变量，赋值触发 UI 依赖更新；后面必须是 `设`，否则报“期望 '设' 关键字跟在 '@响应' 之后”。
- 词法层只认这两个注解名，其他 `@名字` 一律报“未识别的字符”。
- `@允许` 括号内解析器只收集标识符，其他记号被跳过；按 `@允许(码, 码)` 写即可。

## 语句

```text
语句        = 声明 | 注解语句
            | 块
            | 若语句 | 当语句 | 循环语句 | 遍历语句 | 匹配语句 | 尝试语句
            | 中断语句 | 继续语句 | 返回语句 | 终止语句 | 显示语句
            | 表达式语句 ;
声明        = 变量声明 | 常量声明 | 函数声明 | 型声明 | 接口声明 | 外部函数声明 ;
```

`;` 是空语句，可单独出现也可作分隔；它不是必需的语句终结符。

### 块

```text
块          = "{" { 语句 | ";" } "}" ;
```

块引入一层新作用域（同名声明可在内层遮蔽外层）；块本身可作语句使用（`{ 示(1) }` 合法）。

### 条件分支

```text
若语句      = "若" 表达式 块 { "抑" 表达式 块 } [ "否" 块 ] ;
```

- 分支体必须是 `{ }` 块；只有**首个** `若` 分支带“缺块守卫”，会报“若 的条件后面缺少 { } 代码块”。`抑`/`否` 分支缺块时不会得到这条友好提示，而是吞到文件尾后报“期望右花括号”（限制）。
- 多余的 `否` 分支给 `W004` 警告并被忽略。
- `若` 在**语句位置**一律解析为若语句；若表达式必须出现在表达式位置（`=` 右侧、实参、`返` 后面等），见 [若表达式](#若表达式)。详见 [控制流体系](../手册/03_控制流体系.md)。

### 条件循环

```text
当语句      = "当" 表达式 块 ;
```

### 无限循环

```text
循环语句    = "循" 块 ;
```

`循` 没有条件也没有 `当` 式后缀，退出靠 `断`/`返`/`终`。

### 遍历循环

```text
遍历语句    = "遍历" 标识符 [ "," 标识符 ] "于" 表达式 块 ;
```

- 第一个标识符是元素变量，第二个（可选）是下标/键变量。
- 目标可以是任意表达式，常见是数组、字典与 `..` 范围；各容器的具体迭代语义由运行时按类型分派。
- 迭代变量名不得是保留字/关键字。

### 循环控制

```text
中断语句    = "断" ;
继续语句    = "续" ;
```

两者都不带操作数。`断`/`续` 后若紧跟表达式记号，解析器会把该表达式当作下一条语句（不报错），不要依赖这种写法。

### 跳转

```text
返回语句    = "返" [ 表达式 ] ;
终止语句    = "终" [ 表达式 ] ;
```

- `返` 的值只有当下一个记号属于“表达式开头”集合时才解析。该集合（`是表达式开头`）是：数字、小数、标识符、字符串、`整`/`小数`/`字`/`道`/`字节`/`任务`/`结果`、`真`/`假`/`空`、`非`/`-`/`取反`/`是`、`(`/`[`/`{`、`造`/`函`/`等待`/`并行`/`引`/`化`/`解`/`异步`/`求`/`听`/`连`/`执`/`输`/`选`/`若`。注意 `布尔`/`数组`/`字典` **不在**集合里。因此 `返 示(1)` 会被当作“无值返回 + 下一条 `示` 语句”，`返 布尔` 也不是返回布尔值，都不报错（限制）。
- `终` 的退出码接受任意表达式（变量、算术、调用皆可）；语义上必须是整数，给字符串/数组/字典会报“终止码必须是整数”。省略时退出码为 0。

### 匹配

```text
匹配语句    = "匹配" 表达式 "{" { 匹配分支 } "}" ;
匹配分支    = 模式 "->" ( 块 | 语句 ) ;
模式        = "_" | 表达式 ;
```

- 分支模式可以是 `_`（默认分支，按名字 `_` 识别），也可以是任意表达式（字面量、标识符、调用结果等）；`数值 ->` 按相等判定。
- 模式可写 `是 类型名` 前缀形式作**类型匹配**（`是 整`、`是 字` …），这是前缀 `是` 唯一真正生效的位置。
- 分支体可以是块，也可以是单条语句（`1 -> 示("一")` 合法）。
- 分支自上而下判定，命中即结束；空 `匹配 x { }` 语法合法。
- 详见 [匹配](../关键字/匹配.md)。

### 尝试与捕捉

```text
尝试语句    = "尝试" 块 "捕捉" [ "(" [ 标识符 ] ")" | 标识符 ] 块 ;
```

- `捕捉` 子句不可省略：`尝试` 块后没有 `捕捉` 直接报解析错误。
- 错误变量名有三种写法：`捕捉 (名) { }`、`捕捉 名 { }`、`捕捉 { }`（默认变量名 `_`）。
- `尝试` 同时是表达式（`issue #113` 的价值形态），见 [尝试表达式](#尝试表达式)。
- 语义边界（哪些错误可捕、硬退出清单）见 [尝试](../关键字/尝试.md)，不在文法范围。

### 显示

```text
显示语句    = "示" "(" 表达式 ")" ;
```

- **只接受一个**实参：`示(a, b)` 报“期望当前标记为 右圆括号，但得到 逗号”；`示()` 报“不支持的前缀类型: 右圆括号”。
- `示` 是语句，不能出现在表达式里（`设 x = 示(1)` 报“不支持的前缀类型: 显示”）。需要字符串时用 `字(...)` 或 `&` 拼接。

### 表达式语句与赋值

```text
表达式语句  = 表达式 ;
```

- 玄铁**没有独立的赋值语句**：`=` 是中缀表达式运算符（优先级 3，右侧吃整个表达式，因此 `a = b = 1` 右结合）。赋值、调用、`引`、`若表达式`、`异步`/`并行` 块等都以表达式语句的形式出现。
- 赋值目标在语义层检查；编译期对常量赋值直接报错。

## 表达式

### 优先级分层文法

下面按 `当前优先级` 的分层给出表达式文法；每一层都是“下一层 + 若干同层中缀运算符”：

```text
表达式       = 或表达式 ;
或表达式     = 且表达式 { "或" 且表达式 } ;
且表达式     = 赋值表达式 { "且" 赋值表达式 } ;
赋值表达式   = 相等表达式 [ "=" 表达式 ] ;
相等表达式   = 比较表达式 { ( "==" | "!=" | "是" 类型判断右项 ) 比较表达式 } ;
比较表达式   = 加减表达式 { ( "<" | ">" | "<=" | ">=" | ".." ) 加减表达式
                            | 泛型应用 } ;
加减表达式   = 乘除表达式 { ( "+" | "-" | "&" | "位或" | "异或" ) 乘除表达式 } ;
乘除表达式   = 前缀表达式 { ( "*" | "/" | "%" | "位与" | "左移" | "右移" ) 前缀表达式 } ;
前缀表达式   = ( "非" | "-" | "取反" ) 后缀表达式
             | "是" 类型名
             | 后缀表达式 ;
后缀表达式   = 主要表达式 { 后缀操作 } ;
后缀操作     = "(" [ 实参表 ] ")" [ 尾随闭包 ]
             | "[" 表达式 "]"
             | "." 成员名
             | "?" ;
实参表       = 表达式 { "," 表达式 } ;
类型实参     = "<" 类型变量 { "," 类型变量 } ">" ;
泛型应用     = 类型实参 "(" [ 实参表 ] ")" ;
尾随闭包     = 匿名函数 ;
类型判断右项 = 类型名 | 字符串 ;
```

要点（都由 `解析表达式`/`解析中缀`/`当前优先级` 决定）：

- 前缀运算符的操作数按优先级 **7** 解析，与 `*` 同级且不包含任何中缀运算符：`非 a == b` 是 `(非 a) == b`，`-a * b` 是 `(-a) * b`，`-a + b` 是 `(-a) + b`。
- `=` 的优先级是 3，但右操作数按优先级 0 解析，所以赋值右结合且右侧吞掉一切：`a = b 且 c` 是 `a = (b 且 c)`，`a 且 b = c` 是 `a 且 (b = c)`。
- `..` 与比较同级（5），左结合。
- 后缀操作按书写顺序左到右链接（`a.b(c)[d]?` 依次作用于左侧结果）。
- `是` 的中缀右侧不是普通表达式：见 [类型判断](#类型判断是)。
- 泛型应用写在比较层：`名<实参>(...)`；`<` 后若不像类型实参（不是标识符/类型词/`>`），退回普通比较。

### 主要表达式

```text
主要表达式  = 字面量
            | 标识符
            | "此"
            | "(" 表达式 ")"
            | 数组字面量
            | 字典字面量
            | 若表达式
            | 造表达式
            | 匿名函数
            | 异步块
            | 并行块
            | 等待表达式
            | 核心原语
            | 化表达式
            | 解表达式
            | 尝试语句
            | 引入语句 ;

字面量      = 整数字面量 | 小数字面量 | 字符串 | "真" | "假" | "空" ;
```

### 数组字面量

```text
数组字面量  = "[" [ 表达式 { "," 表达式 } ] "]" ;
```

- 空数组 `[]` 合法。
- **不支持尾随逗号**：`[1, 2,]` 会在 `]` 处报“不支持的前缀类型: 右方括号”。
- 数组元素类型不要求一致（动态数组）。

### 字典字面量

```text
字典字面量  = "{" [ 键值对 { "," 键值对 } [ "," ] ] "}" ;
键值对      = 键 ":" 表达式 ;
键          = 标识符 | 表达式 ;
```

- 空字典 `{}` 合法。
- **裸键**：标识符紧跟 `:` 时按字符串键处理（`{宽度: 800}` 等价于 `{"宽度": 800}`），不当作变量求值；需要变量作键时写括号：`{(键名): 值}`。
- 关键字作键必须加引号（`{"选": 1}`，因为 `选` 是关键字记号）。
- 字典字面量**允许**尾随逗号（与数组不同，这是解析器循环结构的自然结果）。

### 若表达式

```text
若表达式    = "若" 表达式 "{" 表达式 "}" { "抑" 表达式 "{" 表达式 "}" }
              "否" "{" 表达式 "}" ;
```

- 每个分支体是**单个表达式**（不是语句块），`否` 分支**必须存在**，否则报“若表达式必须包含 否 分支,否则条件不成立时无值可求”。
- 只在表达式位置生效；语句位置的 `若` 一律按 [若语句](#条件分支) 解析。
- 示例：`设 级别 = 若 分数 >= 90 { "优" } 抑 分数 >= 60 { "良" } 否 { "差" }`。

### 造表达式

```text
造表达式    = "造" ( 限定名 | "字节" ) [ 类型实参 ] "(" [ 实参表 ] ")" ;
```

- `造 型名(...)` 分配实例；若该型定义了名为 `造` 的方法，就调用它作为构造函数，并校验实参个数。
- **限制**：型没有定义 `造` 时，`造 型()` 只能零实参；传入实参会报“型 'X' 未定义构造器，不接受实例化参数”（不静默丢弃）。
- `造 模块.型名(...)` 支持限定名。
- `造 字节(n)` 是唯一对类型关键字开放的内建构造（生成 n 字节缓冲）；`造 数组(...)` 之类不支持（`期望型名称` 报错）。
- 泛型实例化：`造 盒<整>(1)`。

### 匿名函数（闭包）

```text
匿名函数    = "函" "(" [ 参数表 ] ")" [ ":" 类型 ] 块 ;
```

- 可作实参、可赋给变量、可被返回；体是普通块，可捕获外层变量。
- 匿名函数**不能**带泛型参数。
- 出现在语句开头时会被当成函数声明（要求名字），因此匿名函数必须写在表达式位置。

### 尾随闭包

```text
尾随闭包    = 匿名函数 ;
```

调用右括号之后，**同一行**紧跟的 `函(...) { ... }` 作为该调用的**最后一个实参**追加（不是独立语句）。跨行不再识别。实测 `高阶(1) 函(甲: 整): 整 { 返 甲 + 1 }` 等价于把闭包作为第二实参传入；参数个数不符时由语义层报“声明需要 N 个参数，但调用给了 M 个”。

### 成员访问

```text
成员名      = 标识符 | 部分关键字 ;
后缀操作 "." 成员名 ;
```

`解析中缀` 对成员名放行的记号：标识符，以及 `字节` `整` `字` `布尔` `数组` `字典` `结果` `成功` `失败` `执` `或` `且` `空`。其中 `成功`/`失败` 在 XTC 词法里本来就是标识符（白名单里属冗余项）。因此 `r.成功`、`x.空` 这类写法能通过语法。

### 调用

```text
后缀操作    = "(" [ 实参表 ] ")" [ 尾随闭包 ] ;
```

- 实参只按位置传递；**不支持**命名实参、默认值、可变参数、展开实参（`f(...xs)` 会在 `..` 处报“不支持的前缀类型: 范围”）。
- **不支持尾随逗号**：`f(1,)` 报“不支持的前缀类型: 右圆括号”。
- 参数个数在语义层校验（`函数参数数量表`）。
- 成员调用与普通调用同形：`对象.方法(实参)`。

### 下标

```text
后缀操作    = "[" 表达式 "]" ;
```

- 下标是**单个表达式**，没有切片语法。
- `..` 范围可以作为下标表达式通过语法，但**没有切片语义**（实测 `xs[0..2]` 得到首元素的值，不要使用）。
- 负索引是运行时错误（进 `尝试` 可捕），不是文法问题。

### 泛型应用

```text
泛型应用    = 类型实参 "(" [ 实参表 ] ")" ;
```

- 只在 `< ... >` 之后紧跟 `(` 时成立，例如 `取<整>(x)`、`盒1.换<字>("x")`、`造 盒<整>(1)`。
- **`<` 的判定有前瞻**：`<` 后必须是标识符/类型关键字/`>`；若是标识符还要再看下一个记号是不是 `>`/`,`/`?`，否则退回普通比较运算。所以 `a < b` 不会被误当泛型。
- 不带调用的裸泛型引用（如 `示(盒<整>)`）会被解析成左值本身，**实参被丢弃**（限制）；泛型实参只在调用/实例化位置有效。
- 泛型参数没有约束/上界语法。

### 一元与前缀

```text
前缀表达式  = ( "非" | "-" | "取反" ) 后缀表达式
            | "是" 类型名
            | 后缀表达式 ;
```

- `非`、`-`、`取反` 是前缀运算符；`!` 虽被词法识别为 `非` 记号，但代码生成按字面量 `"非"` 判等，`!真` 求值为 `空`，**不要使用 `!`**。
- `是 类型名` 前缀形式只在 `匹配` 的模式位置有实现（类型匹配）。写在普通表达式里语法能通过，但右侧按**普通标识符**编译：`是 整` 报“未知标识符 '整'”，`是 甲`（甲 是变量）求值为 `空`。它不是可用的“是不是这个类型”判断，见限制 L13。

### 二元

二元运算即上文分层文法中的中缀运算符：`或` `且` `=` `==` `!=` `是` `<` `>` `<=` `>=` `..` `+` `-` `&` `位或` `异或` `*` `/` `%` `位与` `左移` `右移`。结合性与优先级见 [运算符优先级与结合性](#运算符优先级与结合性)。

### 类型判断（是）

`是` 有两种形态：

1. **中缀类型判断**：`表达式 是 类型名`。右侧若是类型词记号（`整` `小数` `字` `布尔` `数组` `字典` `结果` `字节` `字节视图` `任务` `道` `空`），或内容是已知类型名的字符串字面量，则节点标记为类型判断；否则退化为与 `==` 同语义的值比较（与 GSC 对齐），此时右侧按优先级 4 解析（遇到同层运算符即停）。
   - 字符串形式认这些名字：`整` `整数` `小数` `浮点` `字` `字符串` `布尔` `逻辑` `数组` `字典` `结果` `字节` `字节视图` `任务` `道` `通道` `空` `实例` `函数`。
2. **前缀类型匹配**：仅用于 `匹配` 的模式，如 `是 整 -> { … }`。

### 错误冒泡（?）

```text
后缀操作    = "?" ;
```

- `?` 只能跟在返回 `结果` 的表达式之后：`设 值 = 可能失败()?`。成功解包出值，失败把错误返回给上层。
- **词法歧义**：`?` 紧跟标识符时会被吸进标识符，因此 `x?` 是名为 `x?` 的标识符（实测“未知标识符 'x?'”），`a.v?` 是成员名 `v?`（运行时取到空）。要写冒泡，前面必须是 `)`、`]`、空白等非标识符结尾：`f()?`、`xs[0]?`、`包 ?`。
- 语义上只对 `结果` 有效；作用到非 `结果` 值会在运行时崩溃（`编译问号后缀` 会先按 `%XTObject*` 解引用读类型标记，整数/布尔等标记值不是有效指针）。写之前确认左侧是 `结果`。
- 另有 `?` 的两个非运算符用途：可空类型后缀（`节点?`）与标识符结尾（`文件.存在?`）。

### 范围

```text
比较表达式  = 加减表达式 { ".." 加减表达式 } ;
```

`1..10` 是左闭右开区间（`遍历 i 于 1..3` 实测输出 1、2）。范围也可作为普通表达式参与 `遍历` 目标等位置。

### 异步块与并行块

```text
异步块      = "异步" 块 ;
并行块      = "并行" 块 ;
```

- `异步 { … }` 立即返回任务句柄，块体后台执行；`并行 { … }` 并行执行块内语句。
- 两者都是表达式，可作实参、可赋给变量、也可作表达式语句。
- 块内 `返` 是块的返回值（异步任务的结果，用 `等待` 取）。

### 等待

```text
等待表达式  = "等待" "(" 表达式 ")" ;
```

括号必需；实参是任务句柄。

### 核心原语（求/听/连/执/输/选）

```text
核心原语    = ( "求" | "听" | "连" | "执" | "输" | "选" ) "(" [ 实参表 ] ")" ;
```

- 这六个词是**关键字 + 括号实参**的原语调用形式，不走普通函数名解析，参数按各自 API 校验（如 `选([通道…], 超时毫秒)`、`执(命令[, 超时毫秒])`）。
- `求`=HTTP 请求、`听`=监听、`连`=连接、`执`=执行命令、`输`=标准输入、`选`=多路通道等待。逐个关键字见 [选](../关键字/选.md)、[求](../关键字/求.md)、[听](../关键字/听.md)、[连](../关键字/连.md)、[执](../关键字/执.md)、[输](../关键字/输.md)。

### 序列化与反序列化

```text
化表达式    = "化" "(" 表达式 [ "," 表达式 ] ")" ;
解表达式    = "解" "(" 表达式 ")" ;
```

- `化(值[, 选项])` 生成 JSON 文本；第二个实参是选项表达式（可选）。
- `解(文本)` 解析 JSON 文本，实参必须是字符串（否则运行时类型守卫失败）。

### 尝试表达式

`尝试语句` 同时可作表达式使用（`解析表达式` 的 `尝试` 分支）：值是**尝试块（或捕捉块）最后一条表达式语句的值**；块尾不是表达式语句时值为 `空`。块内的 `返` 仍是函数返回，不是取值。

```text
设 结果 = 尝试 {
    设 x = 40
    x + 2
} 捕捉 (e) {
    示("出错: " & 字(e["消息"]))
    0
}
```

## 类型与注解

```text
类型        = 类型项 { "|" 类型项 } ;
类型项      = 类型名 [ "?" ] ;
类型名      = 标识符 | 基本类型词 ;
基本类型词  = "整" | "小数" | "字" | "布尔" | "字节" | "数组" | "字典"
            | "结果" | "任务" | "道" ;
```

出现位置：变量/常量声明、参数、函数返回类型、字段、匿名函数参数与返回类型。

- 注解是**字符串**，不是完整类型表达式：`解析类型` 只取一个记号（可能已含尾部 `?`），再允许一个 `?` 与任意多个 `| 类型项`。
- **不支持泛型实参**：`设 r: 结果<整> = …` 会在 `<` 处报“不支持的前缀类型: 小于”（实测）。同理 `盒<整>`、`数组<整>`、`字典<字, 整>` 都不能写进注解。数值数组请用内置的 `小数数组`（见 [数组](../关键字/数组.md#小数数组)）。
- **不支持限定名**：`设 a: 模块.型 = …` 在 `.` 处报“不支持的前缀类型: 点”（实测）。
- `整?` 与 `整 ?` 等价（前者由词法并入标识符，后者由解析器补 `?`），注解字符串都是 `整?`。
- 语义层只对 `整`/`小数`/`布尔` 做标量映射，`小数数组` 映射为连续 double 数组形态，其余注解落到通用 `i64` 表示（`映射类型注解`）。注解还参与“字面量冲突检查”：
  - 右值是字面量时，注解必须与字面量类别**整串相等**（`整`/`小数`/`字`/`布尔`/`数组`/`字典`，或 `结果`）。
  - 因此 `设 y: 整? = 1` 报“类型注解冲突: 声明为 '整?',但赋的值是 '整'”；`设 z: 整 | 字 = 1` 同样冲突。可空/联合注解只在右值是 `空` 或非字面量表达式时才不触发该检查。
  - 右值非字面量时不做这个检查（`设 x: 未知型 = f()` 可通过）。
- 结论：联合类型与可空类型在当前实现里**只有语法、没有一致的类型语义**；把 `?`/`|` 当作文档性注解使用，并避免让右值成为相冲突的字面量。

## 运算符优先级与结合性

优先级数字越小绑定越松（`当前优先级` 的返回值）；“结合性”指同层运算符连续出现时的分组方向。

| 优先级 | 运算符 | 结合性 | 说明 |
|--------|--------|--------|------|
| 1 | `或` | 左 | 逻辑或，短路 |
| 2 | `且` | 左 | 逻辑与，短路 |
| 3 | `=` | 右 | 赋值；右操作数按优先级 0 解析，吞掉整个右侧表达式 |
| 4 | `==` `!=` `是` | 左 | `是` 右侧特殊（类型名/字符串/表达式） |
| 5 | `<` `>` `<=` `>=` `..` | 左 | `<` 兼作泛型应用入口；`..` 与比较同级 |
| 6 | `+` `-` `&` `位或` `异或` | 左 | `&` 是字符串拼接；`位或`/`异或` 与加减同级 |
| 7 | `*` `/` `%` `位与` `左移` `右移` | 左 | `位与`/移位与乘除同级 |
| 8 | `(` 调用 `)` `[` 下标 `]` | — | 后缀，按书写顺序链接 |
| 9 | `.` 成员 `?` 后缀 | — | 后缀，按书写顺序链接 |
| 前缀 | `非` `-` `取反` | 右 | 操作数按优先级 7 解析（`非 a == b` = `(非 a) == b`） |
| 前缀 | `是 类型名` | — | 仅 `匹配` 模式有实现 |

注意：

- 上表 8/9 两级在普通链式写法里不可区分（都按书写顺序左到右）；它们只影响“后缀操作内部再取操作数”的场合。
- `且`/`或` 的优先级低于 `=`，这是 `a 且 b = c` 被解析成 `a 且 (b = c)` 的原因；写复合条件时建议加括号。
- `非` 的绑定强于所有中缀运算符，`非 a 且 b` 是 `(非 a) 且 b`（不是 `非 (a 且 b)`）。

## 当前实现限制与未支持语法

以下行为均由源码与实测确认；写代码时按此规避，不要按其他语言的直觉推断。

| 编号 | 限制 | 依据/实测 |
|------|------|-----------|
| L1 | 类型注解不支持泛型实参与限定名（只取一个记号） | `解析类型`；`结果<整>`/`模块.型` 报“不支持的前缀类型” |
| L2 | 可空/联合注解与字面量冲突检查按整串比较，`整? = 1`、`A|B = 1` 报“类型注解冲突” | `编译.xt` 的 `语句.注解类型` 检查 |

| L12 | `?` 作用到非 `结果` 值会在运行时崩溃（先按对象指针读类型标记） | `编译问号后缀`；实测段错误 |
| L13 | 前缀 `是` 在普通表达式里不可用：右操作数按普通标识符编译（`是 整` 报“未知标识符 '整'”；`是 变量` 求值为 `空`）；只有 `匹配` 模式里的 `是 类型` 有实现 | `编译表达式` 前缀分支先编译右节点、兜底返回 `["0","i64"]`；实测 |
| L14 | 裸泛型引用（`盒<整>` 不带调用）语法上丢弃实参、只留左值；型名不是值，实际使用会报“未知标识符 '盒'” | `解析中缀` 的 `<` 分支 `返 左`；实测 |

| L18 | 数组字面量与调用实参不支持尾随逗号；字典字面量支持 | `解析数组字面量`/`解析调用参数`/`解析字典字面量` |
| L19 | `测试` 块未在 XTC 实现（`测试` 只是保留字，写出即“未知标识符 '测试'”） | `解析语句` 无测试分支 |

| L23 | `?` 不能转义为字面 `#{`（`\#` 是未知转义） | `读字符串` 的转义表 |
| L24 | `断`/`续`/`返` 后的“多余”记号不会报错，会被当成下一条语句或返回值被丢弃 | `解析中断语句`/`解析返回语句` 无尾随校验 |

## 与 GSC 种子编译器的差异

GSC（`lexer/lexer.go`、`parser/parser.go`、`token/token.go`）是引导自举用的 Go 种子编译器，最后一次改动早于 XTC。自举要求“同一份源码先被 GSC 编译”，所以**可移植写法必须落在两者交集**；规范以 XTC 为准。已知差异：

| 项目 | XTC（当前实现） | GSC（种子） |
|------|-----------------|-------------|
| 关键字别名 | 只认规范关键字 | 额外接受 `打印`→`示`、`变量`→`设`、`常量`→`常`、`跳出`→`断`、`继续`→`续`、`函数`→`函`、`返回`→`返`、`引用`→`引`、`整数`→`整`、`逻辑`→`布尔`、`等于`→`==` |
| `测试` 块 | 未实现（保留字） | 有 `TOKEN_TEST` 与 `parseTestStatement` |
| `!` 记号 | 切成 `非` 记号（但前缀不生效） | 单独 `!` 是非法记号 |
| `///` 注释 | 与 `//` 相同 | 产出 STRING 记号（文档注释残留实现） |
| `$` 记号 | 非法 | 有 `TOKEN_DOLLAR` |
| 赋值语句 | `=` 是表达式中缀运算符 | 另有 `AssignStatement` 语句节点 |
| 字符串转义 | 合法集固定，未知转义报错 | 另有 `\}`、`\#` 等宽松处理 |

规范写法建议：只用上表“XTC”列的关键字与语法，不写 GSC 独有别名。

## 校核方式

本文的每条产生式都对应源码里的具体分支；有争议的条目用当前编译器逐个探针验证（`build/xtc_s4.exe -jc 文件.xt` 只做词法/语法/语义检查不链接；少数运行期行为另行完整编译并运行），探针放在本地 `temp/`（临时文件，未入库）。已实测的代表性结论：

- `设 r: 结果<整>`、`设 b: 盒<整>`、`设 a: 模块.型` → 解析错误（L1）；`设 y: 整? = 1`、`设 z: 整 | 字 = 1` → 类型注解冲突（L2）。
- 型体内 `常 k: 整 = 1` → 编译通过（静默忽略，L3）；嵌套 `型` → 内层 `}` 处提前结束型体并报“不支持的前缀类型: 右花括号”（L3）；`公 口` → “不可识别的修饰目标”（L4）。
- `型 A<T> 承 B` → “期望当前标记为 左花括号，但得到 继承”；`型 A 承 B<整>` → 编译通过（L7）。
- 函数体内 `引` → “无法引入模块文件”（L8）；`当 真 示(1)`、`循 示(1)`、`遍历 x 于 [1] 示(x)`、`若 真 { 示(1) } 否 示(2)` → 文件尾“期望右花括号”（L9）。
- `示(!真)` 输出 `空`、`示(非 真)` 输出 `假`（L10）；`示(是 整)` → “未知标识符 '整'”，`设 甲 = 1` 后 `示(是 甲)` 输出 `空`（L13）；`示(x?)` → “未知标识符 'x?'”，`a.v?` 取到空（L11）；`a.取()?`（左值为整数）运行时崩溃（L12）。
- `示(盒<整>)` 语法通过（`<整>` 被丢弃）但随后报“未知标识符 '盒'”——型名不是值（L14）；`造 数组(3)` → “期望型名称”（造表达式只开放 `字节`）；`示(1, 2)` → “期望当前标记为 右圆括号，但得到 逗号”（L17）；`示([1, 2,])` 报错、`示({a: 1,})` 通过（L18）。
- `测试 "名字" { }` → “未知标识符 '测试'”（L19）；只写 `函 主() { 示("x") }` 运行无输出（L20）。
- 正例：泛型函数/型/接口、`造 盒<整>(1)`、`覆 函`、`弱 设`、`@响应`/`@允许`、解构（含 `...`）、`匹配`（含 `是 整`）、`尝试`语句与表达式形态、`异步`/`并行`/`等待`、`选`、`化`/`解`、`求`/`听`/`连`/`执`/`输`、尾随闭包、三引号字符串、`#{…}` 插值、`1..3` 遍历，均以 `-jc` 通过。
