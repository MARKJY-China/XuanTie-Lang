## 版本标注约定

本参考手册只在**确有版本差异**的条目上标注版本。标注一律放在标题之后、正文之前的引用块中，例如：

```markdown
## 惰性导入
> 在 v1.0-rc.5 版本加入。
```

标题本身不写版本号；这样标题保持稳定，便于搜索、链接与版本对照。
