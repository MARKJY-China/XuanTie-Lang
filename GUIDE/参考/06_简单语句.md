# 简单语句

> 对标版本：XTC v1.0-rc.6-dev.9。

本章规定不包含子语句的语句：表达式语句、变量与常量声明、解构声明、赋值、`返`、`终`、`断`、`续`、`示`、`尝试`/`捕捉`，以及空语句与独立块语句。复合语句（`若`、`当`、`循`、`遍历`、`匹配`、`函`、`型`、`口`、`异步`、`等待`、`并行`）见 [复合语句](./07_复合语句.md)。

## 语句序列

```text
程序     = { 语句 } ;
块       = "{" { 语句 } "}" ;
语句     = 空语句
         | 块语句
         | 表达式语句
         | 变量声明
         | 常量声明
         | 返回语句
         | 终止语句
         | 中断语句
         | 继续语句
         | 显示语句
         | 尝试语句
         | 复合语句 ;
空语句   = ";" ;
块语句   = 块 ;
```

规范：

- 语句之间**不需要也不使用**分隔符；换行与空白在语法上不承担分隔作用。
- `;` 只在语句序列中被当作可跳过的空语句（程序顶层与 `{}` 块内都允许），它不构成语句边界。
- 每条语句由首个记号唯一决定其种类，分发如下：

| 首个记号 | 语句 |
|----------|------|
| `设` / `常` / `弱` / `@响应` | 变量声明 / 常量声明 |
| `公` / `私` / `护` | 带可见性修饰的声明（`设`、`常`、`弱 设`、`函`、`型`） |
| `返` / `终` / `断` / `续` / `示` | 对应简单语句 |
| `尝试` | 尝试语句 |
| `@允许` | 语句级警告抑制注解，本身不产生语句，只修饰紧跟的一条语句 |
| `{` | 块语句 |
| 其他表达式起始记号 | 表达式语句（含赋值、调用、`引`、`异步`、`并行`、`选` 等） |

## 表达式语句

```text
表达式语句 = 表达式 ;
```

规则：

- 表达式被完整求值，**结果丢弃**；结果持有的临时对象引用由编译器插入释放，不泄漏。
- 任何表达式都可以作语句，包括纯算术（`a + b`）与函数调用。
- 下列构造**不是**表达式，不能出现在表达式语句的表达式中：`示`（显示语句）、`设`/`常`（声明）、`返`/`终`/`断`/`续`、`公`/`私`/`护`。
- 赋值是表达式前缀 `=` 的形态，但**不得作为值使用**（见「赋值」）。

```xuantie
1 + 1                     // 合法，无副作用
示("ok")                  // 显示语句
引 "./库/文本.xt" 予 文本  // 引入是表达式语句形态
异步 { 示("后台") }        // 异步块是表达式，此处作语句
```

## 变量声明 设

```text
变量声明   = [ 可见性 ] [ "弱" ] "设" 声明目标 [ ":" 类型 ] [ "=" 表达式 ] ;
可见性     = "公" | "私" | "护" ;
声明目标   = 标识符 | 数组解构 | 字典解构 ;
数组解构   = "[" [ 解构元素 { "," 解构元素 } ] "]" ;
解构元素   = 标识符 | "..." 标识符 ;
字典解构   = "{" [ 标识符 { "," 标识符 } ] "}" ;
```

规则：

- **初值可省略**：`设 x` 等价于 `设 x = 空`。
- **`=` 之后不允许换行**：值必须与 `=` 同行。跨行视为缺值，报 `缺少初始值表达式(= 后不允许换行,值须与 = 同行)`。这是刻意的——静默续行会把下一行语句吞成值。
- **同一作用域内同名重复声明**是错误：`重复声明 'x'(首次声明在第 N 行)`。例如：

  ```xuantie
  设 a = 1
  设 a = 2      // 错误：重复声明 'a'
  ```

- **跨层同名是遮蔽**，不是错误：内层 `设` 新建一个独立槽位，块结束后外层名字恢复可见。
- **声明的作用域是所在的块**。在同一函数内，块（`若`/`抑`/`否` 分支、循环体、独立块）中声明的变量**块外不可见**，引用报：

  ```text
  变量 '局' 是在代码块(若/否/循环等)内声明的,块外不可见
    提示: 请把声明提到代码块之外(先 设 局 = 初始值),或把对它的使用移进块内
  ```

  例外：**顶层**（任何 `函` 之外）的 `设` 一律注册为全局变量，即使写在顶层 `若` 块内，块外同样可见。见「当前实现限制」。

- **类型注解**语法上只取一个类型名，可带 `?` 可空后缀，也可用 `|` 并列多个候选名。注解与字面量明显冲突时编译期报错：

  ```text
  类型注解冲突: 声明为 '整',但赋的值是 '字'
  ```

  该检查只比对字面量类别（`整数`/`小数`/`字符串`/`布尔`/`数组`/`字典`），以及“值是 `结果` 容器”这一情形；右侧是复杂表达式时不做检查。

  注意比较是**按注解整串**与类别名做的，因此带 `?` 或 `|` 的注解搭配字面量初值会被误判为冲突（实测 `设 x: 整? = 1`、`设 x: 整|字 = 1` 均报冲突）。带 `?` 的注解请配合 `空` 初值或不写初值使用（`设 x: 整? = 空` 合法）。

- **注解不支持泛型实参**：`设 xs: 数组<整> = [1]` 在 `<` 处中断，报 `不支持的前缀类型: 小于`。型字段里写 `设 子: 数组<整>` 不报错，但 `<整>` 被型体跳过，注解实际只剩 `数组`（见 [复合语句](./07_复合语句.md#型口)）。
- **`小数数组`**：内置连续 double 缓冲的数值数组，注解写 `设 xs: 小数数组 = []`；下标读写由编译器直接 `load`/`store double`，元素不进装箱/ARC。只收数值，追加字符串等会在编译期报错；暂不支持 `遍历`、作为型字段、赋给普通 `数组` 变量。详见 [数组](../关键字/数组.md#小数数组)。

- **`弱` 前缀**声明弱引用变量：变量不持有对象所有权，被引用对象归零时自动变 `空`。`弱 设` 应搭配可空注解（`弱 设 父: 节点?`），否则发 `W005`。弱引用变量的槽位不参与作用域释放。
- **`@响应` 前缀**等价于 `公 设` 并额外标记为响应式（赋值触发 UI 依赖更新）：`@响应 设 计数 = 0`。
- **保留字不得作声明名**：`结果`、`任务`、`道`、`测试`、`字符串`、`整`、`小数`、`布尔`、`数组`、`字典`、`字节`、`字节视图`、`此` 报 `语法错误：'X' 是玄铁语言的保留关键字，不能用作变量名或标识符。请换一个名字。`；`若`/`否`/`抑` 这类关键字记号落到命名位置时报同类提示并建议改名。
- **省略注解当前不告警。** 警告码 `W001`/`W002`/`W003`（隐式类型）已在警告表中登记，但当前实现从不发出，`--严格`/`--禁止` 下也不会因此报错。

## 常量声明 常

```text
常量声明 = [ 可见性 ] "常" 声明目标 [ ":" 类型 ] [ "=" 表达式 ] ;
```

规则：

- `常` 的初始化只允许发生一次。之后对同名标识符的任何赋值都是**编译期错误**：

  ```text
  常量 'N' 不能重新赋值
    提示: 常 声明只允许初始化一次;要可变请改用 设
  ```

- `常` **不是编译期常量表达式**：它没有常量折叠语义，不能用在需要编译期常量的位置（如数组长度），只是“禁止再赋值的变量”。
- `常` 允许省略初值（此时值恒为 `空`），也允许解构形式；但**解构形式声明的名字不进入常量保护集合**，对它们赋值不会被拦截。见「当前实现限制」。

## 解构声明

```text
数组解构 = "[" 元素 { "," 元素 } "]" ;
元素     = 标识符 | "..." 标识符 ;
字典解构 = "{" 标识符 { "," 标识符 } "}" ;
```

语义：

| 形式 | 取值方式 | 不足时 |
|------|----------|--------|
| `设 [a, b] = 数组` | 按位置取下标 0、1… | 缺位元素得 `空` |
| `设 [a, ...rest] = 数组` | 前若干位按位置取；`...rest` 收剩余部分为数组 | 剩余为空数组 |
| `设 {甲, 乙} = 字典` | 以元素名作键取值 | 键不存在得 `空` |

规则与限制：

- 解构只发生在**声明位置**。右侧必须是数组或字典；取出的每个元素各自成为独立变量。
- 变量名必须与键名一致（字典解构没有 `键: 变量` 改名语法）；关键字作键需改用索引 `字典["键"]`。
- `...`（剩余）**只支持数组解构**，字典解构写 `{...rest}` 报 `解构字典期望标识符或逗号`。
- 元素个数少于数组长度不报错，多余元素被忽略。
- 解构声明的变量同样受块作用域约束，也参与 ARC 释放。

```xuantie
设 xs = [1, 2, 3]
设 [甲, 乙, ...其余] = xs
示(甲)        // 1
示(乙)        // 2

设 配置 = {"主机": "localhost", "端口": 8080}
设 {主机, 端口} = 配置
示(主机 & ":" & 字(端口))   // localhost:8080
```

## 赋值

```text
赋值     = 赋值目标 "=" 表达式 ;
赋值目标 = 标识符 | 索引表达式 | 成员访问 ;
```

语言**没有独立的赋值语句**：`=` 是中缀运算符，赋值以表达式语句的形式出现（优先级与结合性见 [完整语法规范](./09_完整语法规范.md)）。下面只规定目标形态与语义。

规则：

- 只有 `=` 一种赋值形式。**复合赋值未支持**：没有 `+=`、`-=`、`*=` 等记号，写 `x += 1` 会被解析成 `x + (= 1)`，报 `不支持的前缀类型: 等于`。
- **多目标赋值与解构赋值未支持**：`甲, 乙 = 3, 4` 报解析错误；`[a] = [2]` 这类写法能通过解析，但目标形态不受处理，实测运行时访问违例（元素写成索引表达式时直接报解析错误）。批量赋值只能用声明形式（`设 [a, b] = …`）或逐条赋值。
- 赋值目标必须是上面三种之一。当前实现对**其他形态不报错**：`(a) = 3` 编译通过但完全无效果（连未声明的 `a` 也不报错）。这属实现缺陷，一律不要这样写。
- 赋值在语法上是 `=` 中缀形态，但**语言层面不作为可用的值**：不要嵌进表达式，也不要链式书写。`x = y = 3` 能通过解析，但结果不正确（实测 `x` 得到的是带标记的中间表示），禁止使用。
- **左值标识符必须已声明**：对未声明的名字赋值，读取左值时即报 `未知标识符 '名'`。
- **索引赋值**对数组与字典统一处理：目标按类型分派，索引表达式求值一次，值的所有权移交给容器。
- **成员赋值**挂到对象的成员表上。允许对实例**动态挂载**未在型中声明的成员（之后按同名字段读取）；访问控制按接收者的静态类型检查。
- **覆盖写**遵守 ARC 规则：写入新值前释放槽位旧值，非标量新值由槽位持有一次引用，表达式侧的临时引用随即释放。
- **常量不可赋值**（见「常量声明」）。
- **弱引用变量**的赋值走弱引用初始化，只记录指向，不持有所有权。

## 返回语句 返

```text
返回语句 = "返" [ 表达式 ] ;
```

规则：

- `返` 立即结束**当前函数调用**，把值交给调用方。省略值时返回 `空`。
- 值是任意表达式，但**只有当紧随其后的记号属于“表达式开头”集合时才解析**：`返 示(1)` 会被当作“无值返回 + 下一条 `示` 语句”，不报错。不要依赖这种写法。
- 值不要求与返回类型注解一致（当前不做返回类型检查，见「当前实现限制」）。
- `返` 之前会释放当前帧所有作用域活项（含内层块），随后返回。
- 在 `异步` 块内，`返` 的含义是**写入该任务的结果槽**并以完成态结束，`等待(任务)` 取到的就是它。任务没有 `返` 时结果为 `空`。
- 在**顶层**（任何 `函` 之外）写 `返` 当前实现不报错，语义等价于结束主程序（实测退出码 0，其后语句不执行）。这不是受保证的写法。

```xuantie
函 符号(n: 整): 整 {
    若 n < 0 { 返 -1 }
    返 1
}
```

## 终止语句 终

```text
终止语句 = "终" [ 表达式 ] ;
```

规则：

- `终` 是**进程级**退出：无论陷在多深的函数或循环，都不会再执行其后的任何语句。
- 退出码是任意表达式，**应当是整型**。静态可知为 `字`/`数组`/`字典` 时编译期报错：

  ```text
  终止码必须是整数,得到 字
    提示: 写 终 3,或 终 退出码变量(整)
  ```

- 省略退出码等价于 `终 0`。
- `终` 之后的语句是死代码，编译器不再为其生成可达指令。
- 可恢复的错误不要用 `终`，用 `结果` 容器显式返回。

## 中断语句 断 与继续语句 续

```text
中断语句 = "断" ;
继续语句 = "续" ;
```

规则：

- 两者**只能出现在循环体内**（`当`、`循`、`遍历` 的循环体，含其内部嵌套的块）。否则编译期报：

  ```text
  '断' 只能在循环中使用
  '续' 只能在循环中使用
  ```

- `断` 跳到最内层循环的结束标签；`续` 跳到最内层循环的下一轮推进点（`当` 的条件判定、`遍历` 的步进）。嵌套循环中只作用于最内层。
- 两者在跳转前释放**循环体及其内层块**的有效引用（回填槽位为空操作，避免二次释放），但保留静态作用域帧供各块末尾正常弹出。
- 放在 `尝试` 块内跳出属未受保证的边界（能工作，但官方文档列为未覆盖），不建议依赖。

## 显示语句 示

```text
显示语句 = "示" "(" 表达式 ")" ;
```

规则：

- 恰好一个参数，圆括号必写：`示 1` 报 `期望当前标记为 左圆括号，但得到 数字`；`示("甲","乙")` 报 `期望当前标记为 右圆括号，但得到 逗号`。
- 语义是“把值转成文本，追加换行后写到标准输出”。多项输出用 `&` 先拼接。
- 数组、字典、实例打印为占位描述（`数组对象`、`字典对象`、`实例对象`），要看内容用 `化` 转 JSON。
- 整数值的小数打印不带小数点（`示(2.0)` 输出 `2`）。
- `示` 是语句，**不能作表达式**：`设 x = 示(1)` 报 `不支持的前缀类型: 显示`。

## 尝试语句

```text
尝试语句 = "尝试" 块 "捕捉" [ 错误变量 ] 块 ;
错误变量 = 标识符 | "(" 标识符 ")" ;
```

`捕捉` 必写；错误变量三种写法等价（省略则内部名为 `_`）：

```xuantie
尝试 { 危险() } 捕捉 (错误) { 示(错误["消息"]) }
尝试 { 危险() } 捕捉 错误   { 示(错误["消息"]) }
尝试 { 危险() } 捕捉        { 示("已兜底") }
```

### 语句形态与表达式形态

- **语句形态**：结果丢弃。
- **表达式形态**：`尝试` 可作为表达式前缀出现（`设 r = 尝试 { … } 捕捉 { … }`）。值取**尝试块或捕捉块最后一条表达式语句**的值；块尾不是表达式语句时值为 `空`。表达式形态里 `返` 仍是函数返回，不是“取该值”。

```xuantie
设 结果值 = 尝试 {
    设 x = 40
    x + 2          // 该块的值
} 捕捉 (e) {
    示("出错: " & 字(e["消息"]))
    0              // 该块的值
}
```

### 错误对象

`捕捉` 的变量是一个**字典**，当前只有 `消息` 一个键（`错误["消息"]` 或 `错误.消息`）。被接住的运行时错误，消息里带 `[文件:行:列]` 定位前缀；位置不可得时退化为 `运行时错误: …`。

### 捕获模型

实现是**轮询式**：进入 `尝试` 块后登记异常深度，块内每条语句执行完都轮询一次异常状态；命中即跳到 `捕捉` 块。同函数内还有若干硬错误守卫点会直接分支到本层捕捉块。因此：

- 故障语句会**先执行完**（可能已经打印或算出一个占位值）再进 `捕捉`。
- 只有**同一函数**内包住出错语句的 `尝试` 才能接住成员/索引/方法类硬错误；跨函数（错误在被调函数里、`尝试` 在调用方）按硬退出处理。
- `异步`/`并行` 块内可以使用 `尝试`：异常深度、挂起标志与消息按线程隔离；不要跨任务共享同一个 `尝试` 结果变量（并发写入按语言常规数据竞争处理）。

### 可捕与不可捕

| 类别 | 例子 | `捕捉` 是否接得住 |
|------|------|-------------------|
| 运行时计算故障 | 整数/小数除零、求模除零、整数溢出、负索引、索引非对象 | 是 |
| 类型/成员故障 | 注解参数类型不匹配、成员访问空值、未知成员、方法缺失 | 是（同一函数内） |
| 运行时不变量 | 堆损坏、非法指针、解码类型守卫失败 | 否，打印诊断后以退出码 1 终止 |
| 约定返回值 | 正向索引越界、字典缺键、`文件.读` 等 I/O | 否，返回 `空` 或 `结果` 容器 |

## 空语句与块语句

```text
空语句 = ";" ;
块语句 = "{" { 语句 } "}" ;
```

- 空语句不产生任何代码，只用于占位或分隔书写。
- 独立的块语句是合法语句，它**引入一个新的作用域**：块内 `设`/`常` 声明的变量在块外不可见，块结束后其持有的引用被释放。

```xuantie
{
    设 临时 = []
    临时.追加("x")
}   // 出块：临时 被释放，名字不再可见
```

## 作用域与 ARC 释放规则

玄铁没有 `free`/`delete`，对象生命周期由引用计数在编译期插入的保留/释放调用管理。语句层面的规则是完整的：

| 时机 | 释放行为 |
|------|----------|
| 块正常结束（函数体、分支块、循环体、独立块） | 释放该块作用域内声明的全部活项，然后弹出该层；该层新声明的名字从符号表移除 |
| `返` | 释放当前帧**所有层**的作用域活项（不清栈，供其余静态终结路径使用），返回后不再发射 |
| `终` | 不逐层释放，直接交还进程 |
| `断` / `续` | 释放从当前层到循环入口层的活项（不弹栈，仅回填槽位为空），然后跳转 |
| 覆盖写（再次使用同名标识符赋值） | 先释放槽位旧值，再存新值；新值非标量时槽位持有一次引用 |
| 表达式语句求值完毕 | 释放该表达式的临时结果引用 |
| 遍历每一轮 | 释放迭代变量上一轮持有的元素，再写入本轮元素（元素先保留一次） |
| `匹配` 结束 | 匹配目标值由作用域机制统一释放（不单独释放） |
| 弱引用变量 | 不持有所有权，**不参与**作用域释放 |

三条配套规范：

1. 释放后槽位一律回填为空值，使后续路径的重复释放成为空操作。
2. 标量槽位（裸整数/裸布尔/裸浮点位）不参与保留释放；只有对象引用才计数。
3. 循环体内声明的变量被闭包捕获时按**创建时刻的值**快照，逐迭代独立；否则所有闭包都会读到末轮终值。

## 错误与诊断

| 场景 | 诊断 |
|------|------|
| 同层重复声明 | `重复声明 'x'(首次声明在第 N 行)` |
| `=` 后换行 | `缺少初始值表达式(= 后不允许换行,值须与 = 同行)` |
| 注解与字面量冲突 | `类型注解冲突: 声明为 '整',但赋的值是 '字'` |
| 保留字作名字 | `语法错误：'结果' 是玄铁语言的保留关键字，不能用作变量名或标识符。请换一个名字。` |
| 关键字作名字 | `语法错误：'否' 是玄铁语言的关键字，不能用作变量名或标识符。请换一个名字(如 否值)。` |
| 解构元素非法 | `解构数组期望标识符或逗号` / `解构字典期望标识符或逗号` |
| 常量被赋值 | `常量 'N' 不能重新赋值` |
| 未声明左值 | `未知标识符 '名'` |
| 块外引用块内声明 | `变量 '名' 是在代码块(若/否/循环等)内声明的,块外不可见` |
| 复合赋值 | `不支持的前缀类型: 等于` |
| 多目标赋值 | `不支持的前缀类型: 逗号` |
| `断`/`续` 不在循环内 | `'断' 只能在循环中使用` / `'续' 只能在循环中使用` |
| `返` 于顶层 | 不报错，等价结束主程序 |
| `终` 非整退出码 | `终止码必须是整数,得到 字` |
| `示` 缺括号 / 多参数 | `期望当前标记为 左圆括号，但得到 …` / `期望当前标记为 右圆括号，但得到 逗号` |
| `尝试` 缺 `捕捉` | `期望当前标记为 捕捉，但得到 …` |

## 当前实现限制

- **无复合赋值。** `+=`、`-=` 等一律不支持。
- **无多目标/解构赋值。** 只有声明位能做解构。
- **非 lvalue 赋值目标不诊断。** `(a) = 3` 编译通过且无任何效果。
- **链式赋值结果错误。** `x = y = 3` 可通过解析，但 `x` 得到的不是 `3`。
- **常量不保护解构声明。** `常 [a, b] = …` 之后对 `a` 赋值不会报错。
- **`常` 不是编译期常量。** 无常量折叠，不能用于需要编译期值的场合。
- **返回类型注解不校验。** 返回值的类型与 `: 类型` 注解不一致不会报错（「变量声明」里的注解冲突检查只覆盖变量声明的字面量初值，不覆盖返回）。
- **顶层退化为全局作用域。** 顶层（`函` 外）的块不产生块级作用域：顶层 `若`/循环块内 `设` 的名字注册为全局，块外可见。
- **`返` 于顶层不报错。** 语义上等价结束主程序，不属受保证的写法。
- **`尝试` 的边界有限。** 只覆盖轮询点与同函数内的守卫点；跨函数的硬错误不保证可捕；异步/并行任务内的故障由该任务自己的 `尝试` 按线程局部状态捕获；`断`/`续` 从 `尝试` 内跳出属未覆盖边界。
