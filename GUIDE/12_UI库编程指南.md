## 玄铁声明式 UI 库编程指南

UI 库是基于渲染库的**声明式界面框架**：界面 = 状态的函数（View = f(State)）。你只描述"状态长这样时界面长什么样"，框架负责布局、绘制与事件分发。

```text
引 "UI" 予 UI        // 铁铺安装后裸包名引用(推荐)
引 "渲染" 予 R
```

> 本地项目内也可以相对路径引用：`引 "./lib/UI/UI.xt" 予 UI`。UI 库内部会再引渲染库，菱形引入是安全的（见 [05_模块系统.md](./05_模块系统.md) 3.2 节）。

---

### 1. 五分钟上手：计数器

```text
引 "UI" 予 UI
引 "渲染" 予 R

设 状态 = UI.造状态({"计数": 0})

UI.应用(状态, 函(s) {
    返 UI.列([
        UI.文本("计数器演示", {"字号": 28}),
        UI.文本("当前: " & UI.态取(s, "计数"), {"字号": 20}),
        UI.按钮("点我 +1", {"点击": 函() {
            UI.态设(s, "计数", UI.态取(s, "计数") + 1)
        }})
    ], {"内边距": 20, "间距": 12})
}, {"宽": 640, "高": 420, "标题": "我的应用"})
```

点按钮，数字会真实递增。这就是全部：没有手动事件循环、没有手动重绘、**没有字体配置**（内置鸿蒙字体自动加载，见第 4 节）。

**工作原理（了解即可）**：`应用` 每帧执行一次你的构建函数，用返回的控件树完成 FlexBox 布局、悬浮/点击处理和绘制。状态变了，下一帧界面自然就是新的。

### 2. 状态系统

| API | 说明 |
|-----|------|
| `UI.造状态(初始字典)` | 创建响应式状态容器 |
| `UI.态取(状态, "键")` | 读取状态（渲染期内自动登记依赖） |
| `UI.态设(状态, "键", 新值)` | 写状态；值变化时通知订阅者并标脏 |
| `UI.态观(状态, "键", 回调)` | 订阅某键的变化 |
| `UI.态设批(状态, 变更表)` | 批量设置多键 |

### 3. 控件一览

| 函数 | 说明 |
|------|------|
| `UI.列(子列表, 选项)` | 竖排容器（主轴竖向） |
| `UI.行(子列表, 选项)` | 横排容器（主轴横向） |
| `UI.叠(子列表, 选项)` | 层叠容器 |
| `UI.绝对(子列表, 选项)` | 绝对布局容器：子项按 `x`/`y` 坐标直摆，不做 flex 计算 |
| `UI.文本("内容", 选项)` | 文本 |
| `UI.按钮("标签", 选项)` | 按钮，`选项["点击"]` 传回调函数 |
| `UI.矩形(选项)` | 色块 |
| `UI.空白(选项)` | 占位 |
| `UI.弹性(弹值, 选项)` | 弹性占位（挤占剩余空间） |

**通用选项键**：所有控件/容器的第二个参数是选项字典，键都是中文。按用途分组如下。

**颜色·背景三态**（颜色值用 `UI.色(r,g,b,a)` 或 `UI.色16("#RRGGBB")`):

| 键 | 含义 |
|----|------|
| `底色` | 控件常态下的背景颜色 |
| `悬底色` | 在控件处于**被鼠标悬浮**的情况下触发的背景色（鼠标移入即生效，移出恢复 `底色`) |
| `按底色` | 在控件处于**被按住不放**的情况下触发的背景色 |
| `禁底色` | 控件被**禁用**时的背景色（禁用后不再响应悬浮与点击) |

**颜色·文字三态**:

| 键 | 含义 |
|----|------|
| `字色` | 控件上文字的常态颜色（`颜色` 是它的别名,同义) |
| `悬字色` | 鼠标悬浮时文字的颜色 |
| `按字色` | 按住不放时文字的颜色 |
| `禁字色` | 禁用时文字的颜色 |

**尺寸与布局**:

| 键 | 含义 |
|----|------|
| `宽` / `高` | 控件固定宽度/高度(像素);不写则由内容撑开 |
| `弹性` | 弹性系数:父容器剩余空间按比例分配给它(类似 flex-grow) |
| `主轴对齐` | 子项在主轴方向的排布:`对齐始/对齐中/对齐末/对齐间/对齐均/对齐均等` |
| `叉轴对齐` | 子项在叉轴方向的对齐:`叉始/叉中/叉末/叉撑` |
| `间距` | 容器内相邻子项之间的空隙(像素) |
| `内边距` | 控件内容与其边框之间的空隙,见下方"边距写法三选一" |
| `外边距` | 控件与外部兄弟之间的空隙 |
| `x` / `y` | **仅绝对容器内有效**:子项相对容器内容区左上角的坐标(像素);不写默认 (0,0) |

**文字与形状**:

| 键 | 含义 |
|----|------|
| `字号` | 文字大小(像素,默认 16) |
| `圆角` | 背景矩形的圆角半径(像素,0=直角) |
| `边框色` / `边框宽` | 描边颜色与线宽(像素);`边框宽` 为 0 时不描边 |

**交互**:

| 键 | 含义 |
|----|------|
| `点击` | 回调函数,触发时执行:`{"点击": 函() { ... }}` |
| `触发` | 触发模式三选一:`"点击"`(默认,按下并在按钮内松开才触发)、`"按下"`(按下瞬间立即触发)、`"按住"`(按住期间连续触发) |
| `连发间隔` | `"按住"` 模式下连续触发的间隔毫秒数(默认 50;设 0 = 每帧都触发) |
| `首按延迟` | 首次触发前的延迟毫秒数(默认 0 = 按下即发)。按住模式:按住超过此时长才开始连发;点击模式设了它:按住超时自动进入连发,延迟内松开仍是单击——一个按钮同时支持单击与长按连发 |
| `禁用` | `真` 时控件禁用:不吃悬浮/点击,并显示为 `禁底色`/`禁字色`(默认灰) |
| `可视` | `假` 时控件不渲染也不参与交互 |


**边距写法三选一**（裸数字会自动转 全边，推荐显式写 全边/四边）：

```text
{"内边距": 20}                      // 裸数字 = 四边同为 20(自动转 全边)
{"内边距": UI.全边(20)}             // 显式四边同值
{"内边距": UI.四边(8, 16, 8, 16)}   // 上右下左分别指定
```

**对齐常量**：主轴 `UI.对齐始/对齐中/对齐末/对齐间/对齐均/对齐均等`；叉轴 `UI.叉始/叉中/叉末/叉撑`。

**绝对布局（`UI.绝对`)**：子项带 `x`/`y` 选项即按坐标直接摆放（相对容器内容区左上角），完全跳过 flex 测量与排布；容器自身仍是正常控件——在 列/行 里参与 flex（可 `弹性`、`宽/高`)，可带 `底色`/`圆角`/`内边距`。

```text
UI.绝对([
    UI.文本("左上角", {"x": 16, "y": 12}),
    UI.按钮("确定", {"x": 220, "y": 110, "点击": 函() { ... }}),
], {"弹性": 1, "底色": UI.色16("#1E2430"), "圆角": 10})
```

适用场景：精确摆位（表单、画布类界面、游戏 HUD)。**两个注意**：一是绝对容器**不裁剪**——坐标越界的子项会画出容器外；二是子项位置不随窗口尺寸自动调整（无锚点，窗口缩放后不会重排），需要自适应的场景请用 行/列 + 弹性。

**颜色**：`UI.色彩["白"/"黑"/"红"/"绿"/"蓝"/"黄"/"灰"/"深灰"/"浅灰"/"透明"/"主题"/"强调"]`，或 `UI.色(r, g, b, a)` 自定义。

### 4. 中文字体（默认零配置）

UI 库**内置鸿蒙字体（HarmonyOS Sans）**：不显式指定任何字体时，框架会自动查找并加载内置字体——**不写任何字体代码，中文即开即显**。查找顺序：铁铺已安装包内 assets → 程序自身目录 assets → 当前目录 assets → 仓库 assets；全部未命中则回退 raylib 默认字体（仅 ASCII，中文会显示为方块）并打印一行提示。

```text
UI.应用(状态, 构建函, {"宽": 640, "高": 420, "标题": "我的应用"})
// 无需 "字体" 选项,中文自动正常
```

**显式指定**（覆盖默认）：`应用` 选项传 `"字体": "你的.ttf"`，手动渲染循环里用 `UI.设字体(路径, 字库字号)`(**必须在窗口初始化之后**调用，加载字形纹理需要 GL 上下文）。

- `字库字号`：栅格化字号（默认 32)，越大越清晰、纹理越大。
- 全 CJK 字体纹理较大（数千字形），首次加载约 1-2 秒；框架会先画一帧背景再加载，避免白窗无响应感。

### 5. 手动渲染循环（嵌入自定义绘制）

不用 `应用` 的主循环时，用 `刷新` 把 UI 嵌入你自己的帧循环：

```text
引 "UI" 予 UI
引 "渲染" 予 R

R.初始化窗口(640, 420, "手动循环")
UI.设字体("HarmonyOS_Sans_SC_Regular.ttf", 32)
设 状态 = UI.造状态({})

当 非 R.窗口应关闭?() {
    R.开始绘图()
    R.清背景(40, 40, 50, 255)
    // 你自己的绘制...
    UI.刷新(状态, 函(s) { 返 UI.列([UI.文本("嵌入UI", {})], {}) }, 0, 0, 640, 420)
    R.结束绘图()
}
R.关闭窗口()
```

### 6. 使用禁区与常见错误

| 错误用法 | 后果 | 正确做法 |
|----------|------|----------|
| `引 "UI" 予 UI` 后又 `引 "UI" 予 界面` | **编译报错**：同一模块只能用一个别名 | 统一别名 |
| 对 `空` 或数字做索引（如拿错类型的选项值） | **运行时明确报错**退出（索引守卫） | 按上表写选项；读取返回值前判空 |
| 在窗口初始化前 `UI.设字体` | 字体加载失败（无 GL 上下文） | 用 `应用` 的 `"字体"` 选项，或在 `初始化窗口` 之后调用 |
| 回调里直接改界面节点 | 无效——下一帧整棵树会被重建 | 只改状态（`态设`），界面跟着状态走 |
| `返 [w, h]` 这类直接返回字面量 | 旧版编译器会**静默返回空**；已修复 | 请升级到最新版编译器 |

---

### 7. 当前能力边界（诚实清单）

- 控件集：文本/按钮/矩形/容器/空白/弹性。**尚无**输入框、滑块、复选框、滚动容器（排期中）。
- 每帧整树重建，简单直接；大型界面（上千控件）的增量更新是后续优化方向。
- 圆角矩形已支持（`圆角` 选项）；文本无复杂排版（无富文本/多字体混排）。
- 已知问题与修复进度见项目仓库 issue/更新日志。
