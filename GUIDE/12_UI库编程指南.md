## 玄铁声明式 UI 库编程指南

UI 库是基于渲染库的**声明式界面框架**：界面 = 状态的函数（View = f(State)）。你只描述"状态长这样时界面长什么样"，框架负责布局、绘制与事件分发。

```text
引 "UI" 予 UI        // 铁铺安装后裸包名引用(推荐)
引 "渲染" 予 R
```

> 本地项目内也可以相对路径引用：`引 "./lib/UI/UI.xt" 予 UI`。UI 库内部会再引渲染库，菱形引入是安全的（见 [05_模块系统.md](./05_模块系统.md) 3.2 节）。

---

### 1. 五分钟上手：计数器

```text
引 "UI" 予 UI
引 "渲染" 予 R

设 状态 = UI.造状态({"计数": 0})

UI.应用(状态, 函(s) {
    返 UI.列([
        UI.文本("计数器演示", {"字号": 28}),
        UI.文本("当前: " & UI.态取(s, "计数"), {"字号": 20}),
        UI.按钮("点我 +1", {"点击": 函() {
            UI.态设(s, "计数", UI.态取(s, "计数") + 1)
        }})
    ], {"内边距": 20, "间距": 12})
}, {"宽": 640, "高": 420, "标题": "我的应用"})
```

点按钮，数字会真实递增。这就是全部：没有手动事件循环、没有手动重绘、**没有字体配置**（内置鸿蒙字体自动加载，见第 4 节）。

**工作原理（了解即可）**：`应用` 每帧执行一次你的构建函数，用返回的控件树完成 FlexBox 布局、悬浮/点击处理和绘制。状态变了，下一帧界面自然就是新的。

### 2. 状态系统

| API | 说明 |
|-----|------|
| `UI.造状态(初始字典)` | 创建响应式状态容器 |
| `UI.态取(状态, "键")` | 读取状态（渲染期内自动登记依赖） |
| `UI.态设(状态, "键", 新值)` | 写状态；值变化时通知订阅者并标脏 |
| `UI.态观(状态, "键", 回调)` | 订阅某键的变化 |
| `UI.态设批(状态, 变更表)` | 批量设置多键 |

---

### 3. 控件详解

每个控件/容器都是 `UI.XX(...)` 构造的节点,末参为选项字典(通用键见 3.11)。本节逐控件给出参数、专属选项与示例。

#### 3.1 列(竖排容器)

`UI.列(子列表, 选项)` —— 子项自上而下排列,是最常用的布局根。

```text
UI.列([
    UI.文本("标题", {"字号": 22}),
    UI.按钮("确定", {"点击": 函() { ... }}),
], {"内边距": UI.全边(16), "间距": 12})
```

要点:`间距` 控制子项间隙;`弹性` 子项会瓜分剩余高度;自身可带 `底色`/`圆角`/`内边距`。

#### 3.2 行(横排容器)

`UI.行(子列表, 选项)` —— 子项自左而右排列。选项与 列 相同(主轴换成横向)。

```text
UI.行([
    UI.文本("名字:", {}),
    UI.输入栏(s, "名字", {"弹性": 1}),
], {"间距": 8, "叉轴对齐": UI.叉中})
```

#### 3.3 叠(层叠容器)

`UI.叠(子列表, 选项)` —— 子项在同一区域层叠(后画的盖先画的),用于背景+前景、角标等。

```text
UI.叠([
    UI.矩形({"底色": UI.色16("#1E2430"), "圆角": 10}),
    UI.文本("盖在最上层", {"x": 0, "y": 0}),
], {"宽": 200, "高": 80})
```

#### 3.4 绝对(绝对布局容器)

`UI.绝对(子列表, 选项)` —— 子项带 `x`/`y` 选项按坐标直摆(相对容器内容区左上角),完全跳过 flex 测量。

```text
UI.绝对([
    UI.文本("左上角", {"x": 16, "y": 12}),
    UI.按钮("确定", {"x": 220, "y": 110, "点击": 函() { ... }}),
], {"弹性": 1, "底色": UI.色16("#1E2430"), "圆角": 10})
```

**两个注意**:① 绝对容器**不裁剪**——越界子项会画出容器外;② 位置不随窗口缩放自适应(无锚点),要自适应请用 行/列+弹性。

#### 3.5 文本

`UI.文本("内容", 选项)` —— 静态文字。常用键:`字号`(默认 16)、`字色`。

```text
UI.文本("计数: " & UI.态取(s, "计数"), {"字号": 18, "字色": UI.色彩["黄"]})
```

#### 3.6 按钮

`UI.按钮("标签", 选项)` —— 点击按钮。专属键:

| 键 | 含义 |
|----|------|
| `点击` | 回调:`{"点击": 函() { ... }}` |
| `触发` | `"点击"`(默认,按下并在钮内松开才触发)/`"按下"`(按下即发)/`"按住"`(按住连发) |
| `连发间隔` | 按住模式连发间隔毫秒(默认 50;0=每帧) |
| `首按延迟` | 按住超时开始连发的延迟(默认 0)。点击模式设了它:按住超时进连发、延迟内松开仍单击——单击/长按两用 |
| `禁用` | 真 时不响应交互并显示禁用色 |
| 三态色 | `悬底色`/`按底色`/`禁底色` + `悬字色`/`按字色`/`禁字色` |

```text
UI.按钮("点我 +1", {"点击": 函() { UI.态设(s, "计数", UI.态取(s, "计数") + 1) }})
UI.按钮("按住连发", {"触发": "按住", "首按延迟": 300, "连发间隔": 100, "点击": 函() { ... }})
```

#### 3.7 矩形

`UI.矩形(选项)` —— 色块。常用键:`宽`/`高`/`底色`/`圆角`。

```text
UI.矩形({"宽": 120, "高": 64, "底色": UI.色16("#3B82F6"), "圆角": 8})
```

#### 3.8 空白 / 弹性

`UI.空白(选项)` 占位(默认 弹性1);`UI.弹性(弹值, 选项)` 按系数挤占剩余空间。

```text
UI.行([UI.文本("左", {}), UI.弹性(1, {}), UI.文本("右", {})])   // 两端贴边
```

#### 3.9 输入栏(v1.1.0 新增)

`UI.输入栏(状态, 键, 选项)` —— 单行文本输入框。值直接绑定 `状态[键]`(读写双向),无需回调。

| 参数 | 含义 |
|------|------|
| `状态` | `UI.造状态` 的容器 |
| `键` | 绑定到状态容器的键名(字符串) |

**专属选项键**:

| 键 | 含义 |
|----|------|
| `占位` | 空值时灰色显示的提示文本 |
| `只读` | 真 时不可编辑(仅展示/可选中复制) |
| `提交` | 回车回调:`{"提交": 函(值) { ... }}` |
| `焦框色` | 获焦时边框高亮色(默认亮蓝) |
| 通用 | `宽`(默认 240)/`高`/`字号`/`底色`/`字色`/`框色`/`圆角`/`内边距` |

**交互全集**(免配置开箱即用):

- 鼠标:点击获焦(按点击处定位光标)、按住拖动框选、点外/ESC 失焦
- 键盘:字符输入(**中文 IME 上屏正常,候选窗跟随光标**)、退格(按住连删)、左右方向键(按住连移)、上=到首/下=到尾、回车=提交
- 组合键:Ctrl+A 全选、Ctrl+C 复制、Ctrl+X 剪切、Ctrl+V 粘贴(自动去换行)
- 光标闪烁;内容超宽时横向滚动保持光标可见

```text
设 状态 = UI.造状态({"名字": ""})
UI.输入栏(状态, "名字", {"占位": "请输入名字(支持中文)...", "提交": 函(v) { 示("提交了: " & v) }})
```

**注意**:单行性——粘贴内容会被去掉换行;暂不支持多行编辑、Home/End、Shift 选择。

#### 3.10 通用选项键速查

所有控件/容器的选项字典通用键(颜色值用 `UI.色(r,g,b,a)` 或 `UI.色16("#RRGGBB")`):

**颜色·背景三态**:`底色`/`悬底色`(悬浮)/`按底色`(按住)/`禁底色`(禁用)
**颜色·文字三态**:`字色`(`颜色` 同义)/`悬字色`/`按字色`/`禁字色`
**尺寸布局**:`宽`/`高`(不写由内容撑开)、`弹性`(flex-grow)、`主轴对齐`/`叉轴对齐`、`间距`、`内边距`/`外边距`、`x`/`y`(仅绝对容器内)
**文字形状**:`字号`、`圆角`、`边框色`/`边框宽`
**交互**:`点击`、`触发`、`连发间隔`、`首按延迟`、`禁用`、`可视`

**边距写法三选一**:`{"内边距": 20}`(裸数字自动转全边)、`UI.全边(20)`、`UI.四边(8,16,8,16)`。
**对齐常量**:主轴 `UI.对齐始/对齐中/对齐末/对齐间/对齐均/对齐均等`;叉轴 `UI.叉始/叉中/叉末/叉撑`。
**颜色常量**:`UI.色彩["白"/"黑"/"红"/"绿"/"蓝"/"黄"/"灰"/"深灰"/"浅灰"/"透明"/"主题"/"强调"]`。

### 4. 中文字体（默认零配置）

UI 库默认字体**优先走 GDI 系统字体（微软雅黑）**:Windows 系统级灰阶抗锯齿(与记事本同质感)、按需栅格化零启动成本、生僻字由系统字体引擎自动回落——**不写任何字体代码，中文即开即显且免字体文件**。

GDI 不可用时的回退链：内置鸿蒙字体(HarmonyOS Sans,按 铁铺已安装包 assets → `XUANTIE_HOME` 安装目录 → 程序自身目录 assets 查找)→ raylib 默认字体(仅 ASCII,中文会显示为方块并打印一行提示)。

```text
UI.应用(状态, 构建函, {"宽": 640, "高": 420, "标题": "我的应用"})
// 无需 "字体" 选项,中文自动正常
```

**显式指定**（覆盖默认）：`应用` 选项传 `"字体": "你的.ttf"`，手动渲染循环里用 `UI.设字体(路径, 字库字号)`(**必须在窗口初始化之后**调用，加载字形纹理需要 GL 上下文）；或直接 `UI.设字体` 传 `R.加载系统字体("微软雅黑", 32)` 的句柄指定其他系统字体(如 "宋体"/"Consolas")。

- `字库字号`：栅格化字号（默认 32)，越大越清晰、纹理越大。
- ttf 路径的全 CJK 字体纹理较大（数千字形），首次加载约 1-2 秒；框架会先画一帧背景再加载，避免白窗无响应感。

### 5. 手动渲染循环（嵌入自定义绘制）

不用 `应用` 的主循环时，用 `刷新` 把 UI 嵌入你自己的帧循环：

```text
引 "UI" 予 UI
引 "渲染" 予 R

R.初始化窗口(640, 420, "手动循环")
UI.设字体("HarmonyOS_Sans_SC_Regular.ttf", 32)
设 状态 = UI.造状态({})

当 非 R.窗口应关闭?() {
    R.开始绘图()
    R.清背景(40, 40, 50, 255)
    // 你自己的绘制...
    UI.刷新(状态, 函(s) { 返 UI.列([UI.文本("嵌入UI", {})], {}) }, 0, 0, 640, 420)
    R.结束绘图()
}
R.关闭窗口()
```

### 6. 使用禁区与常见错误

| 错误用法 | 后果 | 正确做法 |
|----------|------|----------|
| `引 "UI" 予 UI` 后又 `引 "UI" 予 界面` | **编译报错**：同一模块只能用一个别名 | 统一别名 |
| 对 `空` 或数字做索引（如拿错类型的选项值） | **运行时明确报错**退出（索引守卫） | 按上表写选项；读取返回值前判空 |
| 在窗口初始化前 `UI.设字体` | 字体加载失败（无 GL 上下文） | 用 `应用` 的 `"字体"` 选项，或在 `初始化窗口` 之后调用 |
| 回调里直接改界面节点 | 无效——下一帧整棵树会被重建 | 只改状态（`态设`），界面跟着状态走 |
| `返 [w, h]` 这类直接返回字面量 | 旧版编译器会**静默返回空**；已修复 | 请升级到最新版编译器 |

---

### 7. 当前能力边界（诚实清单）

- 控件集：文本/按钮/矩形/容器/空白/弹性/**输入栏**(v1.1.0 新增)。**尚无**滑块、复选框、滚动容器、多行编辑(排期中)。
- 输入栏为单行:不支持多行、Home/End、Shift 选择;IME 候选窗跟随光标已支持(Windows)。
- 每帧整树重建，简单直接；大型界面（上千控件）的增量更新是后续优化方向。
- 圆角矩形已支持（`圆角` 选项）；文本无复杂排版（无富文本/多字体混排）。
- 已知问题与修复进度见项目仓库 issue/更新日志。
