# 玄铁发布前人工冒烟清单

自动化回归（`Test/` 单元 + 环境混沌脚本）覆盖不了需要**真人交互**的场景。每次发行包发布前，按本清单逐项人工验证。发现任何一项异常，先修后发。

## 1. 窗口与渲染（渲染库）

- [ ] 运行 `examples/旋转球体.xt` 编译产物：球体正常旋转、无闪烁、无黑屏
- [ ] 窗口可拖拽、可缩放（如支持）、点右上角 X 能正常关闭退出
- [ ] 中文标题/文字显示正常（无问号乱码，鸿蒙字体生效）
- [ ] 连续运行 3 分钟，任务管理器观察内存**无持续增长**（z13 类泄漏的肉眼防线）

## 2. UI 库交互

- [ ] 编译运行计数器示例（`引 "UI"` + 按钮）：点击按钮，数字**每次都正确 +1**
- [ ] 连续快速点击 50 次：不卡死、不崩、计数不错乱
- [ ] 文本/按钮中文显示正常，字号/间距渲染无错位
- [ ] 鼠标悬浮在按钮上有悬浮态反馈（如有设计）
- [ ] 程序运行期间内存平稳（参照 ui_counter 95-96MB 平台期先例）

## 3. 中文输入（如程序含输入框）

- [ ] 用系统中文输入法在输入框打字：候选框正常、上屏正常、不吞字
- [ ] 退格/方向键在中文串上行为正常（不乱码不断字）

> 已知限制：raylib 无系统 IME 集成，输入框中文支持取决于库层方案；若该项失败且属已知限制，在发行注记中写明。

## 4. 编译器与铁铺

- [ ] 在**任意目录**（非项目根）用 PATH 里的 `xtc.exe tie xxx.xt` 编译引渲染/UI 的程序：成功
- [ ] `tiepm list` / `tiepm search 渲染` 正常输出
- [ ] 全新目录下 `tiepm install 渲染` → 编译引渲染程序 → 运行出窗口（端到端走一遍用户视角）
- [ ] `xtc.exe tie` 一个含语法错误的文件：报错信息定位准确、无编译器自身崩溃

## 5. 多线程（并发类程序）

- [ ] 裸 `异步{...}` spawn 后主线立即结束的程序：**任务必执行**（drain 修复的防线，连跑 10 次全要有输出）
- [ ] `等待`/`发`/`收`/`选` 组合的小 demo 连跑 10 次：无失语、无挂死、无重复打印

## 6. 发行包本身

- [ ] 发行包解压到**无 raylib、无 LLVM、无 GCC 环境**的干净机器（或虚拟机）：`xtc tie` 基础程序成功
- [ ] 干净机器上 `tiepm install 渲染` + 编译引渲染程序成功（验证包内 libraylib.a 定位）
- [ ] 发行包内 GUIDE 手册随包可查，版本号与 `versionLog.md` 一致
