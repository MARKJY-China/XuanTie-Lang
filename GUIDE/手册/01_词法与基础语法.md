## 1.2 运算符

*   **算术**：`+`, `-`, `*`, `/`, `%`
    *   整数间运算保持整数语义（`7 / 2 = 3`）；任一侧为小数即提升为小数运算（`7 / 2.0 = 3.5`)
    *   小数支持 `%`（按 fmod 语义，如 `5.5 % 2.0 = 1.5`)
    *   除零约定：整数与小数均返回 `0`（不报错；与 GSC 解释器的报错行为有意分歧，移植代码时注意）
    *   小数字面量打印规则：整数值小数打印不带小数点（`字(2.0)` 得 `"2"`)
*   **比较**：`==`, `!=`, `<`, `>`, `<=`, `>=`
    *   整数与小数可混合比较，按数值判定（`1.0 == 1` 为 `真`)
*   **逻辑**：`且` (AND), `或` (OR), `非` (NOT), `是` (IS)
*   **位运算**：`位与`, `位或`, `异或`, `左移`, `右移`, `取反`
*   **其他**：
    *   赋值：`=`
    *   成员访问：`.`
    *   箭头：`->`（匹配语句中模式与分支之间的分隔符：`模式 -> 块`）
    *   **错误冒泡后缀操作符**：`?`（跟在返回 `结果` 类型的表达式之后，用于快速解包或向上传递错误，如 `设 值 = 可能出错的操作()?`）

## 1.2.1 运算符重载（魔术方法）

玄铁支持通过**魔术方法**重载算术和比较运算符，使自定义类型（`型`）可使用原生运算符语法：

| 运算符 | 魔术方法 | 示例 |
|--------|---------|------|
| `+` | `_加_` | `v1 + v2` |
| `-` | `_减_` | `v1 - v2` |
| `*` | `_乘_` | `v1 * 2` |
| `/` | `_除_` | `v1 / v2` |
| `%` | `_模_` | `v1 % 3` |
| `==` | `_等_` | `v1 == v2` |
| `!=` | `_等_`（取反） | `v1 != v2` |

**注意**：`==` 和 `!=` 仅对自定义类型（类型声明含 `型:` 前缀）启用重载；弱引用、整型、字符串等内置类型直接走指针/值比较，不触发 `_等_`。

## 1.3 字面量与标识符特性

*   **布尔值**：`真` (true), `假` (false)
*   **空值**：`空` (null)
*   **数字**：支持标准的十进制整数与浮点数（小数）
*   **字符串**：支持双引号 `""` 或单引号 `''`
*   **问号标识符**：标识符支持以 `?` 结尾，常用于返回布尔值的函数或变量命名（例如 `文件.存在?`、`队列.空?`），这让代码读起来更像自然语言的提问。
