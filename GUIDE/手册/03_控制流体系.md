# 3. 控制流体系

玄铁的控制流设计贴合中文语境，主要包含以下几种结构：

## 3.1 条件分支
使用 `若`、`抑` (else if)、`否` (else) 进行逻辑判断：
```text
若 条件A {
    // ...
} 抑 条件B {
    // ...
} 否 {
    // ...
}
```

**若表达式**：条件判断也可以直接作为表达式求值，分支体为单个表达式，`否` 分支必须存在：
```text
设 级别 = 若 分数 >= 90 { "优" } 抑 分数 >= 60 { "良" } 否 { "差" }
设 配置 = {"仓库": 若 有镜像 { "镜像地址" } 否 { "默认地址" }}
示(若  x > 0 { "正" } 否 { "非正" })   // 亦可作实参/返回值
```

## 3.2 循环结构
*   **条件循环** (`当`)：
    ```text
    当 条件 { ... }
    ```
*   **无限循环** (`循`)：
    ```text
    循 { 
        若 退出条件 { 断 } 
    }
    ```
*   **迭代循环** (`遍历`)：搭配 `于` (in) 关键字使用，常用于遍历数组或字典：
    ```text
    遍历 元素 于 集合 { ... }
    ```
*   **循环控制**：`断` (break) 退出循环；`续` (continue) 跳过本次循环。
