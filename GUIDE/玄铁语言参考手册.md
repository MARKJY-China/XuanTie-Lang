# 玄铁语言参考手册

> **对标版本**：XTC v1.0-rc（版本变更记录见根目录 [versionLog.md](../versionLog.md)，手册内不再逐条标注新增版本）

欢迎来到玄铁的官方文档。**玄铁是一门全中文关键字、编译到原生机器码的系统级编程语言**：自举编译器（编译器本身由玄铁写成）、静态类型、ARC 内存管理，并附带桌面 2D 渲染与声明式 UI 官方库。

本页只给你一张玄铁的模糊画像和文档地图；每个特性与功能的细节都放在独立的章节里，按需点入。

```text
设 问候 = "你好，世界"
示(问候)

函 斐波(n) {
    若 n < 2 { 返 n }
    返 斐波(n - 1) + 斐波(n - 2)
}
示("斐波(20) = " & 字(斐波(20)))
```

## 设计理念

-   **全中文语法**：关键字即自然语言词汇；返回布尔的函数可以以 `?` 结尾（`文件.存在?`），代码读起来像提问。
-   **宁可报错，也不静默**：明确的编程错误，编译期能拦则拦；运行期拦不住就带定位信息退出，绝不静默跳过。
-   **错误处理显式化**：可能失败的操作返回 `结果` 容器，`?` 后缀把错误向上冒泡，控制流一眼可见。
-   **一个源文件到一个原生 exe**：无虚拟机、无外部运行时依赖，拷走即跑。
