# 路径库编程指南

> **对标版本**：路径库 v1.0.1（`lib/路径/`）。安装：`tiepm az 路径`；仓库内开发可直接 `引 "../lib/路径/路径.xt" 予 P`。
> API 速查：[路径 API 参考](API/路径) ｜ 例程：[文件清单](例程/文件清单)

---

## 这个库做什么、不做什么

**做**：把路径当字符串来算——拼接、折叠 `.`/`..`、取目录/文件名/扩展名、算相对路径、检查文件名合法性。

**不做**：任何文件系统操作。读、写、删、建目录、取尺寸、列目录都仍走语言内置的 [`文件`](关键字/文件) 模块（列目录目前没有内建，需要自己用 `执` 或原生桥）。

## 安装与引入

```text
引 "路径" 予 P
```

分隔符由**运行平台**决定：Windows 为 `\`，Linux/macOS 为 `/`。所有函数同时接受 `/` 与 `\` 作为输入，不必先手工统一。

## 快速开始

```text
引 "路径" 予 P

示(P.拼接("src", "main.xt"))          // src\main.xt（Windows）
示(P.规范化("src/./工具/../工具/文本.xt"))  // src\工具\文本.xt
示(P.换扩展名("src/工具/文本.xt", "md"))   // src/工具/文本.md
示(P.相对("C:/项目/src/工具/文本.xt", "C:/项目/docs"))  // ..\src\工具\文本.xt
```

注意最后两行的差别：`换扩展名` 只做字符串截取，**目录部分保持你传入的写法**；`规范化`/`拼接`/`相对` 才会按平台重写分隔符。

## 函数分组

| 分组 | 函数 | 说明 |
|------|------|------|
| 分隔符 | `分隔符` `规范化分隔符` `转斜杠` `转反斜杠` | 跨平台输入输出 |
| 拼接 | `拼接` `连接` | 自动补分隔符；子段为绝对路径时重新起算 |
| 判定 | `绝对?` `根` `同名?` | `同名?` 在 Windows 上大小写不敏感 |
| 取件 | `目录` `文件名` `扩展名` `主名` `去扩展名` `换扩展名` `拆分` | 均不访问磁盘 |
| 规范化 | `规范化` | 折叠 `.`/`..`/重复分隔符 |
| 定位 | `绝对` `相对` | `绝对` 基于 `xt_cwd()` |
| 系统目录 | `临时目录` `家目录` | 只给出路径字符串 |
| 文件名规则 | `非法字符` `合法名?` | Windows 非法字符与保留设备名 |

## 规则细节

### 拼接 vs 规范化

`拼接` 只保证“不多不少一个分隔符”，不处理 `.` 与 `..`：

```text
P.拼接("a", "../b")        // a\..\b
P.规范化("a/../b")         // b
```

需要干净路径时：`P.规范化(P.拼接(基, 子))`。

`连接` 接受数组，空串段被忽略，遇到绝对路径段时从该段重新起算：

```text
P.连接(["项目", "", "src", "main.xt"])   // 项目\src\main.xt
P.连接(["项目", "C:/绝对", "x"])          // C:\绝对\x
```

### 取件的边界

| 输入 | `目录` | `文件名` | `扩展名` | `主名` |
|------|--------|----------|----------|--------|
| `a/b.txt` | `a` | `b.txt` | `.txt` | `b` |
| `a/b.tar.gz` | `a` | `b.tar.gz` | `.gz` | `b.tar` |
| `.gitignore` | `""` | `.gitignore` | `""` | `.gitignore` |
| `a.` | `""` | `a.` | `""` | `a.` |
| `/a` | `/`（平台分隔符） | `a` | `""` | `a` |
| `a/b/` | `a/b` | `""` | `""` | `""` |

隐藏文件（点开头）没有扩展名，这是有意的 Unix 语义。

### 规范化

- 折叠 `.` 与重复分隔符；
- `..` 弹出上一段；相对路径开头的 `..` 保留（`a/../../b` → `..\b`）；
- 绝对路径上越过根的 `..` 被忽略（`/../a` → `\a`）；
- 空串返回空串；`.` 返回 `.`；
- 不解析符号链接，也不判断路径是否真的存在。

### 相对路径

`相对(目标, 基准)` 的第二个参数必须是**目录**（如果手上是文件路径，先 `P.目录(...)`）：

```text
P.相对("C:/项目/src/a.xt", "C:/项目/docs")   // ..\src\a.xt
P.相对("C:/项目", "C:/项目")                // .
P.相对("D:/x", "C:/y")                      // D:\x（根不同，退回规范化目标）
```

### 文件名合法性

`合法名?` 的规则：

- 非空，且不是 `.` / `..`；
- 不含 `\ / : * ? " < > |` 与控制字符；
- 不以空格或点结尾；
- 不是 Windows 保留设备名（`CON` `PRN` `AUX` `NUL` `COM1`-`COM9` `LPT1`-`LPT9`，大小写不敏感，带扩展名的也拦）。

`非法字符(名)` 返回命中的字符数组，便于直接展示给用户。

## 与 文件 内建配合

```text
引 "路径" 予 P

设 根 = P.拼接(P.绝对("."), "输出")
设 建 = 文件.建目录(根)
若 非 建.成功 { 示("建目录失败: " & 建.错误) ; 终 1 }
设 路径 = P.拼接(根, "报告.txt")
设 写 = 文件.写(路径, "内容")
若 非 写.成功 { 示("写入失败: " & 写.错误) }
```

注意 `文件` 的错误一律走 `结果` 容器，不要假设成功。
