 

# 字典

**哈希表引用类型，键到值的映射。**

```text
设 配置: 字典 = {"名称": "玄铁", 版本: 1}
示(配置["名称"])
```

## 你可以……

- **三种键写法混用**——引号字符串、裸标识符、括号表达式：

```text
设 后缀 = "版"
设 典 = {"名称": "玄铁", 版本: 1, ("动态" & 后缀): 真}
```

- **下标读写，配 `删` 与 `长度` 管理条目**：

```text
配置["版本"] = 2
配置.删("名称")
示(配置.长度)
```

- **用方法查询**——`设置`/`获取`/`包含?`/`键集`：

```text
若 配置.包含?("版本") { 示(配置.获取("版本")) }
```

## 注意

- 要用变量或表达式的值作键必须加括号：`{(变量): 值}`——不加括号会被当裸键字面量。
- 关键字作键仍需引号：`{"选": 1}`（`选` 是通道关键字），裸键仅限标识符。
