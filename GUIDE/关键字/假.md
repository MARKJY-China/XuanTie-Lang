# 假

**布尔字面量：逻辑假。**

```text
设 已登录 = 假
若 非 已登录 { 示("请先登录") }
```

## 你可以……

- **声明关闭状态**——与 `真` 配对表示开关：

```text
设 静音 = 假
```

- **从函数返回否定结论**：

```text
函 通过?(分数) { 返 分数 >= 60 }   // 不足 60 即得 假
```

- **作失败标记**——循环里置位，事后判断：

```text
设 找到 = 假
遍历 项 于 列表 {
    若 项 == 目标 {
        找到 = 真
        断
    }
}
```

## 注意

- `假` 不等于 `空`——`假 != 空` 成立。判空必须显式写 `== 空`，不能靠 `假` 兜底。
