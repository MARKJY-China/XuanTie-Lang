# 断

**立即退出当前循环。**

```text
遍历 数 于 [1, 2, 3, 4] {
    若 数 == 3 { 断 }
    示(数)
}
// 只印出 1、2
```

## 你可以……

- **找到即停**——命中目标后不再空转：

```text
设 找到 = 0
遍历 数 于 [11, 12, 13, 14] {
    若 数 > 13 {
        找到 = 数
        断
    }
}
```

- **给 循 开出口**——无限循环的常规退场方式：

```text
循 {
    设 指令 = 输("> ")
    若 指令 == "退出" { 断 }
}
```

## 注意

- 嵌套循环中 `断` 只跳出最内层，外层照常继续。
