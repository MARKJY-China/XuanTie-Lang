

# 否

**兜底分支：前面条件全不真，就执行我。**

```text
若 分数 >= 60 {
    示("及格")
} 否 {
    示("重修")
}
```

## 你可以……

- **给整条 若 链兜底**——跟在 `若`/`抑` 之后，条件全落空时执行：

```text
若 年龄 < 18 {
    示("未成年")
} 抑 年龄 < 60 {
    示("成年")
} 否 {
    示("长者")
}
```

- **在若表达式里给默认值**——此时 `否` 分支必须存在：

```text
设 配置 = {"仓库": 若 有镜像 { "镜像地址" } 否 { "默认地址" }}
```

## 注意

- `否` 不带条件；还需要判条件的兜底请用 `抑`。
- 若表达式中 `否` 不能省略——否则条件不成立时表达式无值可取。
