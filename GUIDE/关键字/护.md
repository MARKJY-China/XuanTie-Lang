# 护

**受保护可见性：仅本型及其子类可访问。**

```text
型 动物 {
    护 设 体力 = 100
}

型 猫 承 动物 {
    函 运动() { 此.体力 = 此.体力 - 10 }   // 子类中可访问
}
```

## 你可以……

- **给子类留扩展口，又不暴露给外部**——`护 函` 同理：

```text
型 动物 {
    护 函 呼吸() { 示("呼吸") }
}

型 猫 承 动物 {
    函 生活() { 此.呼吸() }
}
```

## 注意

- 在全局范围（任何型之外）访问 `护` 成员，直接编译错误。
- 继承链之外的其他型访问同样报错——只有定义类及其子类放行。
