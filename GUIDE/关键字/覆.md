# 覆

**显式标记：本方法重写父类的同名方法。**

```text
型 猫 承 动物 {
    覆 函 叫() { 示("喵") }
}
```

## 你可以……

- **重写与新增并存**——只有覆盖父类方法才标 `覆`，子类新方法不用：

```text
型 猫 承 动物 {
    覆 函 叫() { 示("喵") }      // 覆盖父类方法
    函 抓老鼠() { 示("抓！") }   // 子类新方法，不加 覆
}
```

- **重写后保持多态**——统一遍历时各走各的实现：

```text
遍历 动 于 动物们 {
    动.叫()   // 猫走猫的 叫，狗走狗的 叫
}
```

## 注意

- `覆` 后必须紧跟 `函`，否则编译报错。
- 不写 `覆` 的同名方法同样会覆盖父类实现——`覆` 是显式标记，不是控制覆盖行为的开关。
