

# 连

**建立 TCP 连接，返回结果。**

```text
设 r = 连("127.0.0.1:8000")
若 r.成功 { r.值.发("hello") }
```

## 你可以……

- **一问一答**——判 `成功` 再取用，`值` 是流：

```text
设 r = 连("127.0.0.1:8000")
若 r.成功 {
    设 流 = r.值
    流.写("你好")
    设 回 = 流.读()
    若 回 != 空 { 示("服务端说: " & 回) }
    流.关()
}
```

- **放进 `异步` 块**——`连`/`读`/`写` 变挂起点，等待期间不占线程：

```text
设 客 = 异步 {
    设 r = 连("127.0.0.1:8000")
    若 非 r.成功 { 返 空 }
    r.值.写("问")
    设 答 = r.值.读()
    示("答: " & 答)
}
等待(客)
```

## 注意

- 必须判 `成功` 再取用，失败原因在 `错误`；地址格式是 `"主机:端口"` 一个串。
- `读` 返回 `空` 只有一个含义——对端关了；别再读写，直接收尾。
- `关` 通常可以不写：ARC 引用归零自动关闭；长寿命循环里建议显式 `流.关()` 及时释放。
