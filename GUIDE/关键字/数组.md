

# 数组

**动态数组引用类型，有序、可变长。**

```text
设 列表: 数组 = [1, 2, 3]
列表.追加(4)
示(列表[0])     // 1
示(列表.长度)   // 4
```

## 你可以……

- **下标访问，配合 `遍历` 逐项处理**：

```text
遍历 项 于 列表 {
    示(项)
}
```

- **用内置方法操作**——`追加`/`删`/`插`/`找`/`含?`/`连接`：

```text
若 列表.含?(3) { 示("在") }
示(列表.连接("-"))
```

- **引入标准库用高阶方法**——`映射`/`过滤`/`归纳`/`排序`/`去重` 等：

```text
引 "../lib/数组/数组.xt" 予 A
设 偶 = A.过滤(列表, 函(x) { 返 x % 2 == 0 })
```

## 注意

*   本词是**保留字**：不能用作变量名、函数名、参数名等标识符（完整规则与清单见 [词法与基础语法](../手册/01_词法与基础语法.md#保留字不可作标识符)）。
- 高阶方法不在内置，必须 `引` 标准库数组模块后再用。
- 泛型实参当前不支持：`数组<整>` 会在 `<` 处报“不支持的前缀类型: 小于”。需要连续 `double` 存储时写 `小数数组`（见下）。

## 小数数组

> 在 v1.0-rc.6 版本加入。

`小数数组` 是内置的数值专用数组：元素以连续 `double` 存放，下标读取/写入直接 `load`/`store double`，
循环内不装箱、不对元素做 ARC。声明写法与普通数组一致，只是注解换成 `小数数组`：

```text
设 采样: 小数数组 = []
采样.追加(1.5)
采样.追加(2.5)
采样[1] = 3.5
示(采样.长度)   // 2
示(采样[0])     // 1.5
```

- 只收数值（整/小数/布尔）；追加字符串、数组、对象会在编译期报错，不会静默转成 `0.0`。
- 下标必须是整数；负索引仍按数组统一约定报错，正向越界读返回 `空`（数值语境为 `0.0`）。
- 目前最小切片支持：局部变量、函数参数、函数返回、`[]` 字面量、下标读写、`追加`、`长度`、`含?`/`找`、`删`/`插`/`弹出`、`连接`。
- 暂不支持：`遍历 小数数组`、`截取`（返回值失去静态形态）、把 `小数数组` 赋给普通 `数组` 变量、作为型字段存储；这些位置会显式报错，不会按错布局读内存。

### 无检查访问（unsafe）

热循环可用显式无检查接口，跳过 type/elem_kind 与边界检查：

```text
设 采样: 小数数组 = []
采样.追加(1.0)
示(采样.无检查取(0))
采样.无检查设(0, 2.0)
```

- `无检查取(下标)` / `无检查设(下标, 值)` 只接受 `小数数组`，不检查越界/类型；
  下标越界或接收者形态错误属于**未定义行为**，编译器不会报错。
- 仅在你已用循环条件/长度检查证明下标安全时使用；普通 `采样[i]` 仍走完整守卫。
- C 内核路径（`xt_fft4096_f64`）同样属于显式 unsafe，调用方需保证数组形态与长度。
