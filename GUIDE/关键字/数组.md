

# 数组

**动态数组引用类型，有序、可变长。**

```text
设 列表: 数组 = [1, 2, 3]
列表.追加(4)
示(列表[0])     // 1
示(列表.长度)   // 4
```

## 你可以……

- **下标访问，配合 `遍历` 逐项处理**：

```text
遍历 项 于 列表 {
    示(项)
}
```

- **用内置方法操作**——`追加`/`删`/`插`/`找`/`含?`/`连接`：

```text
若 列表.含?(3) { 示("在") }
示(列表.连接("-"))
```

- **引入标准库用高阶方法**——`映射`/`过滤`/`归纳`/`排序`/`去重` 等：

```text
引 "../lib/数组/数组.xt" 予 A
设 偶 = A.过滤(列表, 函(x) { 返 x % 2 == 0 })
```

## 注意

- 高阶方法不在内置，必须 `引` 标准库数组模块后再用。
- 泛型注解写 `数组<整>`；元素可空写 `数组<节点?>`，数组整体可空写 `数组<节点>?`。
