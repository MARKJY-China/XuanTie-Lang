# 引

**引入模块：相对路径或铁铺包名。**

```text
引 "./库/数学.xt" 予 数学
```

## 你可以……

- **按相对路径引入**——路径相对当前源文件；不带 `予` 时以文件名作访问前缀：

```text
引 "./库/数学.xt"
设 r = 数学.平方(5)
```

- **引入铁铺安装的包**——直接写裸包名：

```text
引 "渲染" 予 R
R.初始化窗口(800, 600, "示例")
```

## 注意

- 同一模块一次编译只能用一个别名：先 `予 R` 后 `予 渲染` 会直接报错。
- 循环引用会被编译器检测并报错。
- 路径分隔符有讲究：`/` 表相对路径，`\` 表绝对路径（Windows）。
