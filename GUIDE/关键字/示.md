# 示

**打印输出。把值打成文本，并换行。**

```text
示("你好，玄铁")
```

## 你可以……

- **打印任意值**——数字、布尔、空都直接打：

```text
示(42)      // 42
示(真)      // 真
示(空)      // 空
```

- **用 `&` 拼接多项一起打**：

```text
设 名字 = "玄铁"
示("语言: " & 名字 & ", 编号: " & 1)
```

## 注意

- 末尾自动换行；不想换行就自己组好串再一次打出。
- 数组、字典、实例打出来是占位描述（`数组对象`、`实例对象`），要看内容用 `化` 转 JSON。
- 整数值的小数打印不带小数点：`示(2.0)` 输出 `2`。
