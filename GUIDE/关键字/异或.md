# 异或

**按位异或：两位不同为 1，相同为 0。**

```text
示(5 异或 3)   // 6
```

## 你可以……

- **翻转指定位**——与掩码异或，掩码为 1 的位被翻转：

```text
标志 = 标志 异或 8
```

- **同一密钥异或两次还原**——异或是自身的逆运算：

```text
设 加密 = 明文 异或 密钥
设 还原 = 加密 异或 密钥   // 回到明文
```

## 注意

- 没有 `^` 运算符，按位异或只能写关键字 `异或`。
