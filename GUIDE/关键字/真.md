# 真

**布尔字面量：逻辑真。**

```text
设 已登录 = 真
若 已登录 { 示("欢迎") }
```

## 你可以……

- **声明开关状态**——布尔变量只取 `真` 或 `假`：

```text
设 静音 = 真
若 静音 { 示("已静音") }
```

- **接收比较结果**——比较与逻辑运算的产出就是 `真`/`假`：

```text
设 成年 = 年龄 >= 18
设 同值 = 1.0 == 1   // 整数与小数按数值判定,得 真
```

- **从函数返回判断结论**——约定返回布尔：

```text
函 通过?(分数) { 返 分数 >= 60 }
```
