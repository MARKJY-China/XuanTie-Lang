

# 且

**逻辑与：两侧皆真才真，左侧为假即短路。**

```text
若 年龄 >= 18 且 已购票 {
    示("允许入场")
}
```

## 你可以……

- **组合多个条件**——全部成立才进分支：

```text
若 分数 >= 60 且 出勤达标 {
    示("通过")
}
```

- **短路保护**——左侧挡住危险操作，右侧才会执行：

```text
若 列表.长度 > 0 且 列表[0] == 目标 {
    示("命中首个元素")
}
```

- **串联多个判断**——左到右依次求值：

```text
若 已登录 且 是会员 且 非 已过期 {
    示("完整权益")
}
```

## 注意

- 短路：左侧为 `假` 时右侧根本不求值——别把必须执行的副作用调用放在右侧。
- `且` 比 `或` 先结合：`a 或 b 且 c` 等价于 `a 或 (b 且 c)`；混排时建议加括号写明意图。
