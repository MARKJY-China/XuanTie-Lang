

# 匹配

**模式匹配：按值或类型分派分支。**

```text
匹配 分数 {
    100 -> { 示("满分") }
    _ -> { 示("其他") }
}
```

## 你可以……

- **按值分支**——与字面量相等即命中：

```text
匹配 指令 {
    "退" -> { 示("退出") }
    "查" -> { 示("查询") }
    _ -> { 示("未知指令") }
}
```

- **按类型分支**——用 `是` 判定类型：

```text
匹配 值 {
    是 整 -> { 示("整数") }
    是 字 -> { 示("字符串") }
    _ -> { 示("其他类型") }
}
```

## 注意

- 自上而下判定，命中第一个分支即结束（编译为条件分支链），其余分支不再看。
- `_` 匹配一切，必须放最后——放前面会把后面的分支全部屏蔽。
