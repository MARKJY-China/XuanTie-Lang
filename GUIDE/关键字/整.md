 

# 整

**64 位整数类型（i64），算术与索引的基础类型。**

```text
设 年龄: 整 = 18
示(年龄 + 2)
```

## 你可以……

- **做整数运算**——`+ - * / %` 保持整数语义，除法截断：

```text
示(7 / 2)   // 3
示(7 % 2)   // 1
```

- **与小数混合运算**——任一侧是小数即提升为小数语义：

```text
示(7 / 2.0)   // 3.5
```

- **显式转换**——`整(x)` 返回 `结果`，失败不炸、可判定：

```text
设 转 = 整("42")
若 转.成功 { 示(转.值) }
```

## 注意

- 整数除零返回 `0`，不报错（与 GSC 解释器的报错行为有意分歧）。
- `整("1.5")`、`整("12abc")`、`整("")` 均判失败——字符串必须是纯整数文本，解析小数用 `小数()`。
- 小数转整数是截断取整：`整(3.7)` 得 `3`。
