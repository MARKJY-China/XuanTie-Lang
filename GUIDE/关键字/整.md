 

# 整

**i64 存储的整数类型，算术与索引的基础类型；可表示范围为 ±(2^62-1)（约 ±4.61×10^18）。**

> v1.0-rc.5 起明确域限：`整` 用 tagged 编码 `(值 << 1) | 1` 装箱，域外值会静默失真，故编译器/运行时在入口处显式拒绝（见下「可表示范围」）。

```text
设 年龄: 整 = 18
示(年龄 + 2)
```

## 可表示范围（v1.0-rc.5，issue #150/#153）

- **可表示域**：`-4611686018427387903 … 4611686018427387903`，即 ±(2^62-1)。
- **字面量越界**：编译期直接报错「整数字面量超出可表示范围 ±4611686018427387903」，不产出二进制；`--严格` 下同样报错。
- **`解()` 越界数字**：整份解析返回 `空`，stderr 一行诊断（不静默截断）。
- **`整()` 转换越界**：返回失败 `结果` 容器（原因含「超出 整 可表示域」）。
- **注意**：加/乘等算术运算本身**尚未做溢出检查**，域内结果正常、越域仍可能回绕；需要大数请拆分为多个整数或走字符串/字节集通道。

## 你可以……

- **做整数运算**——`+ - * / %` 保持整数语义，除法截断：

```text
示(7 / 2)   // 3
示(7 % 2)   // 1
```

- **与小数混合运算**——任一侧是小数即提升为小数语义：

```text
示(7 / 2.0)   // 3.5
```

- **显式转换**——`整(x)` 返回 `结果`，失败不炸、可判定：

```text
设 转 = 整("42")
若 转.成功 { 示(转.值) }
```

## 注意

*   本词是**保留字**：不能用作变量名、函数名、参数名等标识符（完整规则与清单见 [词法与基础语法](../手册/01_词法与基础语法.md#保留字不可作标识符)）。
- 整数除零返回 `0`，不报错（与 GSC 解释器的报错行为有意分歧）。
- `整("1.5")`、`整("12abc")`、`整("")` 均判失败——字符串必须是纯整数文本，解析小数用 `小数()`。
- 小数转整数是截断取整：`整(3.7)` 得 `3`。
