

# 空

**空值字面量：引用无指向。**

```text
设 缓存 = 空
若 缓存 == 空 { 示("尚未加载") }
```

## 你可以……

- **判空**——显式与 `空` 比较：

```text
若 x == 空 { 示("无值") }
若 x != 空 { 示("有值") }
```

- **表示"暂无值"**——变量先置 `空`，就绪后再赋实值：

```text
设 配置 = 空
若 文件.存在?("cfg.json") { 配置 = 文件.读("cfg.json") }
```

- **配合可空类型标注**——类型后加 `?` 声明可空：

```text
弱 设 父: 父节点?   // 弱引用释放后自动置为 空
```

## 注意

- `空` 不等于 `0`，也不等于 `假`——`0 != 空`、`假 != 空` 均成立。判空只能写 `== 空`。
- `等待` 无 `返` 回值的任务得到的是 `空`，不是 `0`。
