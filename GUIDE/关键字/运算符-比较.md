 

# 运算符-比较

**比较两值，返回 真 或 假。**

```text
若 分数 >= 60 { 示("及格") }
```

## `==` 等于

两值相等为 `真`。

```text
若 1.0 == 1 { 示("相等") }   // 混合比较按数值判定
```

## `!=` 不等于

两值不等为 `真`。

```text
若 状态 != "完成" { 示("进行中") }
```

## `<` 小于

```text
若 i < 10 { 示("个位数") }
```

## `>` 大于

```text
若 余额 > 0 { 示("可取") }
```

## `<=` 小于等于

```text
若 库存 <= 5 { 示("补货") }
```

## `>=` 大于等于

```text
若 年龄 >= 18 { 示("成年") }
```

## 注意

- 整数与小数可混合比较，按数值判定：`1.0 == 1` 为 `真`。
- 组合多个条件用 `且`、`或`、`非`，不是 `&&`、`||`、`!`。
