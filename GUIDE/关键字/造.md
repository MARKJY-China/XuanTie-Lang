 

# 造

**实例化一个型；也是构造方法的固定名。**

```text
设 c = 造 猫("小花")
```

## 你可以……

- **在型内定义构造方法**——`函 造` 在实例化时自动调用，负责初始化字段：

```text
型 猫 {
    设 名字
    函 造(名) { 此.名字 = 名 }
}
```

- **实例化泛型类**——具体类型参数跟在类名后：

```text
设 整盒 = 造 盒子<整>(123)
设 字盒 = 造 盒子<字>("玄铁")
```

- **不写构造方法也能实例化**——字段取声明处的初始值；**但不能传参**（v1.0-rc.5 起传参会编译报错，不再静默丢弃，issue #149）：

```text
型 配置 {
    设 端口 = 8080
}
设 cfg = 造 配置()      // 正确
// 设 bad = 造 配置(1)  // 编译错误：型 '配置' 未定义构造器，不接受实例化参数
示(cfg.端口)   // 8080
```

## 注意

- 子类定义了自己的 `造` 后，父类的 `造` 不会被自动调用——实例化只执行最终（最派生）的那个构造。
