# 执

**执行系统命令（shell 命令行），返回结果（输出或错误）。**

「命令」指你在终端里敲的那种命令行，由系统的命令解释器（shell）执行：
- Linux / macOS：交给 `/bin/sh`（等价于 `sh -c "命令"`）
- Windows：直接 `CreateProcessW` 启动 `cmd.exe /d /s /c`（**不再写临时 .bat**；`/d` 关闭 AutoRun）

```text
设 r = 执("dir")              // Windows
设 r = 执("ls -l")            // Linux/macOS
若 r.成功 { 示(r.值) }
```

## 你可以……

- **取命令输出**——`值` 是完整输出文本：

```text
设 r = 执("cd")               // Windows：显示当前目录
设 r = 执("pwd")              // Linux/macOS：显示当前目录
设 目录 = r.值.替换("\r", "").替换("\n", "")
```

- **超时终止**——第二个参数是可选超时毫秒（缺省 0 = 旧行为，不超时）；超时会终止子进程树并返回失败：

```text
设 r = 执("ping 127.0.0.1 -n 60 >nul", 500)
若 非 r.成功 { 示(r.错误) }   // 执行超时…；子进程已被清理
```

- **失败处理**——非零退出码即失败，原因在 `错误`：

```text
设 r = 执(clang指令)
若 非 r.成功 { 示("编译失败: " & r.错误) }
```

- **管道与重定向**——命令字符串按 shell 语法解析，管道、重定向都可用：

```text
设 r = 执("cmd /c dir")                  // Windows
设 r = 执("ls -l | grep 玄铁")            // Linux/macOS
```

## 注意

- **这是 shell 命令，不是文件路径**：命令字符串会先被 shell 解析——`$`（变量）、`` ` ``（先执行里面的命令）、`;`（接着执行下一条）、`|`（管道）、`*`（通配）、`&` 等字符有特殊含义，不是字面量。
- **不要让用户输入直接拼进命令字符串**：用户填的内容会被 shell 当成命令的一部分执行（例如填 `报告.txt; 删除全部`，shell 看到 `;` 会真的执行「删除全部」）。这称为命令注入——先校验或转义再拼接。
- **同步阻塞**：命令跑完才返回，长命令会卡住当前线程；需要上限时用第二个超时参数（>0 毫秒）。
- **别把 `执` 当 HTTP 客户端**：`curl`/`wget` 是系统外部程序，不是所有平台都自带（Windows 10/11 默认就没有 `curl.exe` 的机器并不少见）。取网络内容请用内置 [求](求.md)（文本）或 [进程](进程.md)（需要流式/子进程时）；`xtc 升级` 自身也已改为走运行时 HTTP，不再调用系统 `curl`（issue #163）。
- **stderr 已并入输出**：命令的报错信息也在 `值` 里。
- **失败只看退出码**：命令输出了错误文本但退出码为 0，仍判成功。
- **输出上限 64 MiB**：超过上限会终止子进程并返回失败，避免异常命令耗尽内存。
- **独立进程、无窗口**：Windows 下用 `CREATE_NO_WINDOW` + 管道启动，不会弹控制台；命令是无状态的，工作目录/环境变量取当前进程，不保留 shell 上下文。
- **编码**：Windows 子进程先切 UTF-8 代码页；个别 cmd 内建命令/旧程序的输出仍可能是系统 ANSI 代码页，需要时自行转码。
