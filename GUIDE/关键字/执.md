 

# 执

**执行系统命令，返回结果（输出或错误）。**

```text
设 r = 执("cmd /c dir")
若 r.成功 { 示(r.值) }
```

## 你可以……

- **取命令输出**——`值` 是完整输出文本：

```text
设 r = 执("cmd /c cd")
设 目录 = r.值.替换("\r", "").替换("\n", "")
```

- **失败处理**——非零退出码即失败，原因在 `错误`：

```text
设 r = 执(clang指令)
若 非 r.成功 { 示("编译失败: " & r.错误) }
```

- **用 cmd 语法**——Windows 下命令经 cmd 批处理执行，重定向可用：

```text
执("cmd /c del /q \"" & 输出路径 & "\" 2>nul")
```

## 注意

- 同步阻塞：命令跑完才返回，长命令会卡住当前线程。
- stderr 已并入输出（`2>&1`），命令的报错信息也在 `值` 里。
- 失败只看退出码：命令输出了错误文本但退出码为 0，仍判成功。
