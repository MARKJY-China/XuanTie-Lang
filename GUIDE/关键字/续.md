# 续

**跳过本轮，直接进入下一轮循环。**

```text
遍历 数 于 [1, 2, 3, 4] {
    若 数 == 2 { 续 }
    示(数)
}
// 印出 1、3、4
```

## 你可以……

- **过滤不要的元素**——命中条件就跳过循环体剩余部分：

```text
设 总计 = 0
遍历 数 于 [4, 5, 6, 7, 8] {
    若 数 < 6 { 续 }
    总计 = 总计 + 数
}
示(总计)  // 21
```

## 注意

- 嵌套循环中 `续` 只作用于最内层。
- 在 `当` 循环里用 `续`，先把条件变量推进再跳，否则容易死循环。
