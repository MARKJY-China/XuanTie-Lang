# 函

**声明函数；函数也是值，可赋值可传递。**

```text
函 斐波那契(n: 整): 整 {
    若 n < 2 { 返 n }
    返 斐波那契(n - 1) + 斐波那契(n - 2)
}
```

## 你可以……

- **写匿名函作值**——赋给变量，随用随调：

```text
设 加法 = 函(a, b) { 返 a + b }
示(加法(1, 2))
```

- **作回调直接传给别的函数**：

```text
听(8000, 函(流) {
    流.写("欢迎！")
})
```

- **声明泛型函数**——类型参数写在 `<>` 里：

```text
函 交换<T>(a: T, b: T) {
    返 [b, a]
}
```

## 注意

- 省略参数与返回类型（如 `函 平方(x) { 返 x * x }`）属「隐式类型」：默认只告警，`--严格` / `--禁止` 模式下升级为错误。
