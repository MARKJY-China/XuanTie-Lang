
# 尝试

**执行可能出错的块，异常时交给 `捕捉`。**

> 对标版本：玄铁 v1.0-rc.5（issue #110 运行时错误定位、issue #113 硬错误可捕获与 尝试 表达式形态）。

```text
尝试 {
    示("正在执行危险操作...")
} 捕捉 (错误) {
    示("捕获到异常")
}
```

## 你可以……

- **把一整段危险操作包起来，出错统一善后**——善后逻辑集中写在 `捕捉` 一处：

```text
尝试 {
    设 x = 10 / 0
    示("结果: " & 字(x))
} 捕捉 (错误) {
    示("捕获到错误，改用默认配置")
}
```

- **不要错误详情就省略变量**——只写 `捕捉` 加块：

```text
尝试 {
    危险操作()
} 捕捉 {
    示("已兜底")
}
```

- **用表达式形态直接取值**（`尝试` 是语句，也是表达式）：

```text
设 结果 = 尝试 {
    设 x = 40
    x + 2
} 捕捉 (e) {
    示("出错: " & 字(e["消息"]))
    0
}
```

表达式形态的值 = **尝试块（或捕捉块）最后一条表达式语句的值**；块尾不是表达式语句时值为 `空`。
不提供 `返` 式的提前取值语义——`尝试` 块里的 `返` 仍是函数返回。该形态适合"取一个值、失败给默认值"，
复杂控制流请用语句形态。

## 哪些故障进 `捕捉`（可捕 / 硬退出清单）

**运行时可捕故障**（`捕捉` 接得住）：

| 故障 | 触发示例 |
|------|----------|
| 整数除零 / 求模除零 / 小数除零 | `1 / 0`、`7 % 0`、`1.0 / 0.0` |
| 整数溢出（超出 ±2^62-1） | `2 * 4611686018427387903` |
| 注解参数类型不匹配 | `函 严格(值: 整)` 收到字符串；在调用链上有活动 `尝试` 时由**调用方语句级轮询**接住 |
| 成员访问空值 | `空值.长度`（含 `.成功/.值` 等） |
| 未知成员 | `"abc".不存在的成员` |
| 索引非对象 | `空值[0]`、`1[0]` |
| 负索引 | `数组[-1]` |
| 方法缺失 | `字典值.不存在()` |

**硬退出**（打印诊断后以退出码 1 终止进程，`捕捉` 兜不住）：

- 堆损坏 / 非法指针（`检测到堆损坏或非法指针访问`）等运行时不变量破坏；
- `解(非字符串)` 之类的运行时类型守卫失败；
- **成员/索引/方法类硬错误发生在被调函数里、而 `尝试` 在调用方**：编译器只在**同一函数的 `尝试` 块内**
  把硬错误转成可捕异常；跨函数时按硬退出处理（错误点返回后表达式已无有效值，继续执行不安全，
  宁可报错也不静默）。需要在被调函数内部用 `尝试` 包住出错的语句；
- 无 `尝试` 保护时的上述硬错误：一律打印诊断并退出（不会静默返回）。

**不是异常**（`捕捉` 不会触发，属约定返回值）：

- 正向索引越界、字典缺键、`数组.取` 越界 → 返回 `空`；
- `文件.读` 等 I/O API → 返回 `结果` 容器，用 `.成功/.值/.错误` 判断，这才是错误处理主路。

## 错误位置（`文件:行:列`）

运行时错误带源码位置（issue #110）：

```text
运行时错误 [D:\项目\主.xt:12:5]: 对非对象值(整数/布尔/空)访问成员 '长度'
  提示: 成员访问(如 .成功/.值/.长度)只对对象有效;请先用类型检查或 结果 判定保护。
```

被 `捕捉` 接住时，位置写在错误消息里：

```text
尝试 {
    设 无 = {"x": 1}["不存在"]
    示(无.长度)
} 捕捉 (e) {
    示(e["消息"])   // [D:\项目\主.xt:3:8] 对非对象值(整数/布尔/空)访问成员 '长度'
}
```

- 覆盖：成员缺失 / 未知成员 / 索引非对象 / 方法缺失 / 注解参数类型不匹配。
- 参数类型错误的位置是**形参所在函数定义处**（跨函数调用时调用点位置不可得）。
- 负索引等"运行时内部 raise"的故障没有编译期守卫点，消息不带位置（仍可捕）。
- 位置未知时退化为旧格式：`运行时错误: ...`。

## 注意

- 语句级轮询的已知取舍：故障语句会先执行完（可能打印/计算出一个占位值）再进 `捕捉`，例如
  `尝试 { 示(数组[-1]) } 捕捉 { }` 会先输出 `空`；跳转前未使用的表达式值会被丢弃，但异常路径上的
  局部属主引用不做逐层释放（进程继续运行，属已知取舍）。
- `尝试` 块内 `返` 会补发异常处理器的深度回退；但 `断`/`续` 跳出 `尝试` 块仍属未覆盖边界，尽量别写。
- 多线程/`异步`/`并行` 块内不要用 `尝试`（处理器状态是进程级全局，跨线程不可靠）。
- `捕捉` 子句不能省略：`尝试` 块后面必须紧跟 `捕捉`，否则编译报错。
