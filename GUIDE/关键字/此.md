# 此

**当前实例的引用，相当于 this。**

```text
型 猫 {
    设 名字
    函 造(名) { 此.名字 = 名 }
}
```

## 你可以……

- **在方法里读写自己的字段**：

```text
函 改名(新名) {
    此.名字 = 新名
}
```

- **调用本实例的其他方法**：

```text
函 自我介绍() {
    示("我是 #{此.名字}")
    此.叫()
}
```

## 注意

- 访问字段必须写 `此.字段`；裸写字段名不会解析到实例字段。
- `此` 只在型的方法（含 `造`）里有效，顶层函数中没有 `此`。
