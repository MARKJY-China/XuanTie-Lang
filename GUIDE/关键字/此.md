

# 此

**当前实例的引用，相当于 this。**

```text
型 猫 {
    设 名字
    函 造(名) { 此.名字 = 名 }
}
```

## 你可以……

- **在方法里读写自己的字段**：

```text
函 改名(新名) {
    此.名字 = 新名
}
```

- **调用本实例的其他方法**：

```text
函 自我介绍() {
    示("我是 #{此.名字}")
    此.叫()
}
```

## 注意

*   本词是**保留字**：不能用作变量名、函数名、参数名等标识符（完整规则与清单见 [词法与基础语法](../手册/01_词法与基础语法.md#保留字不可作标识符)）。
- 访问字段必须写 `此.字段`；裸写字段名不会解析到实例字段。
- `此` 只在型的方法（含 `造`）里有效，顶层函数中没有 `此`。
