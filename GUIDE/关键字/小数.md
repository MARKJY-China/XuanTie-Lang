

# 小数

**双精度浮点数类型（double）。**

```text
设 比率: 小数 = 3.14
示(比率 * 2)
```

## 你可以……

- **与整数混合运算**——自动提升为小数语义：

```text
示(7 / 2.0)   // 3.5
```

- **取余**——`%` 按 fmod 语义：

```text
示(5.5 % 2.0)   // 1.5
```

- **显式转换**——`小数(x)` 返回 `结果`，可解析数字字符串：

```text
设 转 = 小数("3.14")
若 转.成功 { 示(转.值) }
```

## 注意

- 整数值的小数打印不带小数点：`字(2.0)` 得 `"2"`。
- 小数除零同样返回 `0`，不报错。
- 与整数混合比较按数值判定：`1.0 == 1` 为 `真`。
