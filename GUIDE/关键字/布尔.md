

# 布尔

**布尔类型（i1），取值只有 `真` 与 `假`。**

```text
设 已登录: 布尔 = 真
若 已登录 { 示("欢迎") }
```

## 你可以……

- **用逻辑运算符组合条件**——`且`、`或`、`非`：

```text
若 年龄 >= 18 且 已购票 { 示("允许入场") }
```

- **接收比较表达式的结果**：

```text
设 达标 = 分数 >= 60
若 达标 { 示("及格") }
```

- **转成整数**——`整(真)` 得 `1`，`整(假)` 得 `0`：

```text
示(整(真))   // 1
```

## 注意

*   本词是**保留字**：不能用作变量名、函数名、参数名等标识符（完整规则与清单见 [词法与基础语法](../手册/01_词法与基础语法.md#保留字不可作标识符)）。
- 整数与小数可混合比较，按数值判定：`1.0 == 1` 为 `真`。
