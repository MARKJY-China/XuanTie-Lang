

# 取反

**按位取反：0 变 1、1 变 0，前缀一元运算。**

```text
示(取反 0)   // -1
```

## 你可以……

- **生成清位掩码**——配合 `位与` 清掉指定低位：

```text
设 掩码 = 取反 255        // 低 8 位为 0，其余全 1
设 高位 = 数据 位与 掩码   // 清掉低 8 位
```

## 注意

- `取反` 是按位运算，`非` 是逻辑取反：`取反 0` 得 `-1`（补码），`非 真` 得 `假`，别混。
