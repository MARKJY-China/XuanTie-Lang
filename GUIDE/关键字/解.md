

# 解

**JSON 反序列化。把 JSON 文本解析成字典/数组。**

```text
设 数据 = 解("{\"名称\": \"玄铁\"}")
示(数据["名称"])   // 玄铁
```

## 你可以……

- **解析后当字典用**——键用引号串下标：

```text
设 消息 = 解(体)
若 消息.包含?("method") {
    示(消息["method"])
}
```

- **解析数组**：

```text
设 列表 = 解("[1, 2, 3]")
示(列表[1])   // 2
```

- **配 `求` 解析接口返回**：

```text
设 r = 求("http://api.example.com/data")
若 r.成功 {
    设 数据 = 解(r.值)
    若 数据 != 空 { 示(数据["名称"]) }
}
```

## 注意

- 非法 JSON、空串都解析成 `空`——取用前先判空。
- JSON 的 `null` 也解析成 `空`，与失败同值；需要区分时核对原文。
