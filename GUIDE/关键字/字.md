 

# 字

**UTF-8 字符串对象引用类型。**

```text
设 名: 字 = "玄铁"
示("你好, " & 名)
```

## 你可以……

- **单双引号皆可写字面量**：

```text
设 a = "双引号"
设 b = '单引号'
```

- **用 `&` 拼接**——非字符串先 `字()` 转文本：

```text
设 年 = 2026
示("年份: " & 字(年))
```

- **调内置方法**——`拼接`/`截取`/`替换`/`分割`/`包含?`/`获取字符`，属性有 `长度`：

```text
设 词 = "a,b,c".分割(",")    // ["a", "b", "c"]
若 "玄铁".包含?("铁") { 示("在") }
```

## 注意

- `分割` 按完整字面子串匹配并保留空段：`"a,,b".分割(",")` 得 `["a", "", "b"]`；分隔符为 `""` 时按逻辑字符逐字拆分。
- `字()` 对数组等对象只给占位描述（如 `"数组对象"`），不是逐元素序列化——要 JSON 文本请用 `化()`。
