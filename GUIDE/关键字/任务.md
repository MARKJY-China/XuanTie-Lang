# 任务

**异步任务句柄类型，`异步 {}` 的返回值。**

```text
设 t = 异步 {
    返 42
}
示(等待(t))   // 42
```

## 你可以……

- **先并发起跑，再逐个等待**——`等待(任务)` 等它完成并取回 `返` 回值：

```text
设 a = 异步 { 时.睡(2000) }
设 b = 异步 { 时.睡(1000) }
等待(a)
等待(b)
```

- **用 `并行` 一次跑多个块**——返回各块结果组成的数组：

```text
设 结果组 = 并行 { { 1 + 1 }, { 2 + 2 } }
示(结果组)
```

## 注意

- 编译器按 `异步` 块的内容自动选择 fiber 调度器或 OS 线程池执行，无需手动指定。
- fiber 任务捕获的外层局部变量是 spawn 时刻的值副本——之后外层的修改它看不到，共享数据请走通道或全局变量。
- 任务无 `返` 时，`等待` 得 `空`。
