# 系统

**系统处理命名空间。** 进程启动、剪辑板、屏幕/鼠标信息、系统信息、消息框、INI 配置项。

## 进程

| 调用 | 返回 | 说明 |
|------|------|------|
| `系统.运行(命令)` | 布尔 | 启动外部命令，**启动即返不等待**；启动失败返 `假`。要等待并拿输出/退出码请用全局的 [执](执.md) |

## 剪辑板

| 调用 | 返回 | 说明 |
|------|------|------|
| `系统.取剪辑板文本()` | 字 | 读剪辑板文本（无文本返空串） |
| `系统.置剪辑板文本(内容)` | 布尔 | 写文本进剪辑板 |
| `系统.清除剪辑板()` | 布尔 | 清空剪辑板 |

## 屏幕与鼠标

| 调用 | 返回 | 说明 |
|------|------|------|
| `系统.取屏幕宽度()` / `系统.取屏幕高度()` | 整 | 主显示器像素尺寸（非 Windows 返 0） |
| `系统.取鼠标位置()` | 字典 | `{x, y}` 屏幕坐标（非 Windows 返 `{-1, -1}`） |

## 系统信息

| 调用 | 返回 | 说明 |
|------|------|------|
| `系统.操作系统类别()` | 字 | `"windows"` / `"linux"` / `"macos"` |
| `系统.取启动时间()` | 整 | 操作系统自启动至今的毫秒数 |
| `系统.鸣叫()` | 空 | 蜂鸣提示音 |
| `系统.信息框(内容, 标题)` | 空 | 模态消息框（Windows MessageBox；非 Windows 为空操作） |

## 配置项（INI）

UTF-8 自解析实现，跨平台行为一致；文件不存在时写入会新建。

| 调用 | 返回 | 说明 |
|------|------|------|
| `系统.读配置项(文件, 节, 键, 缺省)` | 字 | 读 INI 值；键/节/文件不存在时返 `缺省` |
| `系统.写配置项(文件, 节, 键, 值)` | 结果 | 键存在则改、不存在则补、节不存在则新建 |

```text
设 写 = 系统.写配置项("设置.ini", "网络", "主机", "127.0.0.1")
若 写.成功 {
    示(系统.读配置项("设置.ini", "网络", "主机", "缺省"))   // 127.0.0.1
}
```

## 注意

*   `系统.运行` 是**即发即忘**：拿不到子进程输出与退出码；等待+捕获输出用 `执`。
*   剪辑板在非 Windows 平台取返空串、置/清除返 `假`。
*   INI 写入是**整文件重写**（先解析再重排），并发多进程写同一文件无锁——需要并发安全请自行加文件锁或改用其他存储。
