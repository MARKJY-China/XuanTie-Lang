 

# 终

**立即终止程序，可带退出状态码。**

```text
若 参数不足 {
    示("用法错误")
    终 1
}
```

## 你可以……

- **带状态码退出**——非零表示异常结束，供调用方脚本判断：

```text
若 失败数 == 0 { 示("全部通过") } 否 { 终 1 }
```

- **正常结束**——状态码 0 表示顺利收场：

```text
示("任务完成")
终 0
```

## 注意

- `终` 是进程级退出：无论陷在多深的函数或循环里，其后的语句都不再执行。
- 可恢复的错误不要用 `终`，用 `结果` 类型显式返回（见手册「结果类型与错误处理」）。
