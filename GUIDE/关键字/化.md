

# 化

**JSON 序列化。把值转成 JSON 文本。**

```text
示(化({"名称": "玄铁"}))   // {"名称": "玄铁"}
```

## 你可以……

- **序列化字典和数组**——嵌套结构递归转换：

```text
设 数据 = {"名单": ["甲", "乙"], "人数": 2}
设 文本 = 化(数据)
```

- **基本值转 JSON 字面量**：

```text
示(化(真))    // true
示(化(空))    // null
示(化(42))    // 42
```

- **配 `求` 发 JSON 请求体**：

```text
设 r = 求("http://api.example.com/items", {
    "方法": "POST",
    "头": {"Content-Type": "application/json"},
    "体": 化({"名": "玄铁"})
})
```

## 注意

- 自定义类型（`型` 实例）不在支持之列，会序列化成 `"object"` 占位串；要导出就自己组装字典。
- 字典是哈希表，输出文本的键序不保证与书写顺序一致。

- **缩进美化输出**——第二个参数传 `"缩进"`（对照 `serde_json::to_string_pretty`），
  适合配置/索引类 JSON 的人工审查与 diff：

```text
示(化({"名": "玄铁", "标签": [1, 2]}, "缩进"))
// {
//   "名": "玄铁",
//   "标签": [
//     1,
//     2
//   ]
// }
```

  第二参数只接受字符串 `"缩进"`；传其他值会运行时报错退出。
