

# 化

**JSON 序列化。把值转成 JSON 文本。**

```text
示(化({"名称": "玄铁"}))   // {"名称": "玄铁"}
```

## 你可以……

- **序列化字典和数组**——嵌套结构递归转换：

```text
设 数据 = {"名单": ["甲", "乙"], "人数": 2}
设 文本 = 化(数据)
```

- **基本值转 JSON 字面量**：

```text
示(化(真))    // true
示(化(空))    // null
示(化(42))    // 42
```

- **序列化小数**——输出合法 JSON 数字，采用最短可往返表示：

```text
示(化(3.14))        // 3.14
示(化(0.1))         // 0.1
示(化(1.0))         // 1.0（整数值的小数补 ".0"，解 回来仍是 小数）
示(化([1.5, 0.25])) // [1.5, 0.25]
```

- **配 `求` 发 JSON 请求体**：

```text
设 r = 求("http://api.example.com/items", {
    "方法": "POST",
    "头": {"Content-Type": "application/json"},
    "体": 化({"名": "玄铁"})
})
```

## 注意

- `型` 实例序列化为**纯字段快照**：保留 `__类型__` 与字段，方法（含 `造`）跳过，不再输出 `"方法名":"object"` 垃圾键（v1.0-rc.6-dev.5，#148）。反序列化只得到普通字典，实例的方法/构造需自行按 `__类型__` 重建。
- 数组元素位置的函数值会落 `null`（不能跳过数组元素）；字典里的函数值键值对整体跳过。

## v1 契约（JSON 序列化，写死）

- **小数格式**：输出合法 JSON 数字，采用最短可往返表示（有效数字上界 17 位，与 `%.17g` 同界）；整数值补 `.0` 保留「小数」类型。对任意有限 `小数 x`，`解(化(x))` 与 `x` 位级相等（不经过十进制截断）。
- **非有限值**：`NaN`、`+Inf`、`-Inf` 没有 JSON 字面量。`化()` 遇到时打印运行时错误并**退出进程**（不可捕捉），绝不输出 `NaN`/`Infinity` 这类非法 JSON。
- **键序**：同一份数据（同一个未被修改的容器）多次 `化()`，输出**字节完全一致**；键序由哈希表桶序决定，**不保证与书写/插入顺序一致**，也不承诺跨实现/跨版本一致。数组严格按索引顺序输出。
- **数字类型**：`整` 按 i64 十进制精确输出，不转 double（如 `9007199254740993` 原样保留）。

## 缩进美化输出

第二个参数传 `"缩进"`（对照 `serde_json::to_string_pretty`），适合配置/索引类 JSON 的人工审查与 diff：

```text
示(化({"名": "玄铁", "标签": [1, 2]}, "缩进"))
// {
//   "名": "玄铁",
//   "标签": [
//     1,
//     2
//   ]
// }
```

第二参数只接受字符串 `"缩进"`；传其他值会运行时报错退出。
