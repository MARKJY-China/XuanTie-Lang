 

# 运算符-符号

**赋值、成员访问、类型标注与注解符号速查。**

## `=` 赋值

`设`/`常` 声明时给初值；单独写是重新赋值。

```text
设 计数 = 0
计数 = 计数 + 1
```

## `.` 成员访问

取字段、调方法、访问模块符号。

```text
文件.写("a.txt", "内容")
```

## `:` 类型注解

标注变量、参数、返回值的类型。

```text
设 年龄: 整 = 18
函 斐波那契(n: 整): 整 { 返 n }
```

## `->` 匹配箭头

`匹配` 语句中模式与分支块之间的分隔符。

```text
匹配 v {
    42 -> { 示("四十二") }
    _ -> { 示("其他") }
}
```

## `@` 注解

语句级修饰：`@允许(码)` 抑制紧跟语句的警告；`@响应` 声明响应式变量，赋值触发 UI 依赖更新。

```text
@允许(未使用变量)
设 临时 = 0
@响应 设 计数 = 0
```

## 注意

- `@允许` 参数写警告码（`W004`）或类别名，只抑制紧跟的下一条语句；`@响应` 后必须跟 `设`，否则编译报错。
