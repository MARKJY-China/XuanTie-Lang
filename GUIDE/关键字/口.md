# 口

**定义接口：只有签名、没有实现的方法约定。**

```text
口 可叫 {
    函 叫(): 字
}
```

## 你可以……

- **声明多个方法签名**——参数与返回类型都可标注：

```text
口 形状 {
    函 面积(): 小数
    函 缩放(倍率: 小数)
}
```

- **定义泛型接口**——接口名后加 `<T>`：

```text
口 容器<T> {
    函 取(): T
}
```

- **用作成员的类型标注**——如委托模式里弱引用一个接口：

```text
型 视图 {
    弱 设 代理: 代理口?
}
```

## 注意

- 接口方法只写签名，没有函数体。
- 当前没有"某型实现某口"的显式声明语法；接口不生成运行时代码，仅作编译期约束。
