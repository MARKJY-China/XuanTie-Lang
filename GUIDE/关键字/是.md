

# 是

**判断：左侧是不是某个类型 / 某个值。**

```text
若 成绩 是 整 {
    示("是整数")
}
若 成绩 是 60 {
    示("刚好及格")
}
```

## 你可以……

- **中缀判断类型**——裸类型名或字符串形态等价：

```text
若 数据 是 数组 { 示("长度: " & 字(数据.长度)) }
若 数据 是 "字典" { 示("是字典") }
```

- **值等价**——右侧不是类型名时按值比较（同 `==`)：

```text
若 答案 是 42 { 示("命中") }
若 1 是 1.0 { 示("整数与小数按数值相等") }
```

- **在 `匹配` 里按类型分支**——自上而下首个命中即执行，`_` 兜底：

```text
匹配 值 {
    是 整 -> { 示("整数") }
    是 字 -> { 示("字符串") }
    _ -> { 示("其他类型") }
}
```

## 注意

- 可判断的类型名：`整`、`小数`、`字`、`布尔`、`数组`、`字典`、`结果`、`字节`、`任务`、`道`、`空`、`实例`、`函数`；兼容别名 `整数`/`字符串`/`逻辑`/`浮点`/`通道`。
- 类型名不存在或写错时结果为 `假`，不会报错。
- `匹配` 里没有分支命中且无 `_` 时，整个匹配块静默跳过。
