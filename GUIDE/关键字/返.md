# 返

**从函数返回一个值，并立即结束本次调用。**

```text
函 加倍(n: 整): 整 {
    返 n * 2
}
```

## 你可以……

- **提前返回**——分支里命中即退出函数：

```text
函 符号(n: 整): 整 {
    若 n < 0 { 返 -1 }
    返 1
}
```

- **直接返回任意表达式**：

```text
函 问候(名字: 字): 字 {
    返 "你好, " & 名字
}
```

## 注意

- `异步` 任务没有 `返` 时，`等待` 取回的是 `空`。
