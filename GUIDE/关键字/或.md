# 或

**逻辑或：任一侧为真即真，左侧为真即短路。**

```text
若 键 == "q" 或 键 == "Q" {
    示("退出")
}
```

## 你可以……

- **多选一条件**——任一成立即进分支：

```text
若 等级 == "vip" 或 等级 == "svip" {
    示("贵宾通道")
}
```

- **宽松校验**——多种合法形态并列：

```text
若 输入 == "y" 或 输入 == "Y" 或 输入 == "" {
    示("确认")
}
```

## 注意

- 短路：左侧为 `真` 时右侧不求值——右侧的函数调用可能不会执行。
- 结果是布尔值 `真`/`假`，不像某些语言那样返回某一个操作数本身。
- `且` 比 `或` 先结合：`a 且 b 或 c` 等价于 `(a 且 b) 或 c`。
