

# 位与

**按位与：两位都为 1，结果才为 1。**

```text
示(5 位与 3)   // 1
```

## 你可以……

- **用掩码截取低位**——`位与 255` 只留低 8 位：

```text
设 低位 = 数据 位与 255
```

- **判奇偶**——看最低位是 0 还是 1：

```text
若 n 位与 1 == 1 { 示("奇数") }
```

- **清零指定位**——与取反后的掩码相与：

```text
标志 = 标志 位与 取反 8
```

## 注意

- 位运算全是中文关键字。`&` 在玄铁是字符串拼接，不是按位与（见 [运算符-拼接与冒泡](运算符-拼接与冒泡.md)）。
