# 数学

**数学函数与常量命名空间。** 函数按需返回**整**或**装箱小数**；常量不带括号直接使用。

## 常量

| 写法 | 值 |
|------|-----|
| `数学.圆周率` | 3.14159… |
| `数学.自然常数` | 2.71828… |

> 两个常量等价于 `数学.圆周率()` / `数学.自然常数()`（带括号也认）。
> `数学.PI` / `数学.E` 是等价别名（仅自举编译器路径保留，新代码请用上面的中文名）。

## 函数

| 调用 | 返回 | 说明 |
|------|------|------|
| `数学.平方根(x)` | 小数 | 平方根 |
| `数学.幂(底, 指数)` | 小数 | 幂运算 |
| `数学.绝对值(x)` | 数值 | 绝对值 |
| `数学.正弦(x)` / `数学.余弦(x)` | 小数 | 三角函数（弧度） |
| `数学.最大值(a, b)` / `数学.最小值(a, b)` | 数值 | 取大/取小 |
| `数学.取整(x)` | 整 | 向下取整（floor） |
| `数学.进一(x)` | 整 | 向上取整（ceil） |
| `数学.四舍五入(x)` | 整 | 四舍五入 |
| `数学.随机(上限)` | 整 | 0..上限-1 的随机整数 |
| `数学.设随机种子(种子)` | 空 | 固定随机序列（可复现实验用） |

## 用法

```text
示("圆周率 = " & 字(数学.圆周率))
示("平方根(16) = " & 字(数学.平方根(16)))
示("圆面积 r=2: " & 字(2.0 * 2.0 * 数学.圆周率))
```

## 注意

*   常量支持**裸访问**（`数学.圆周率`）与**调用**（`数学.圆周率()`）两种写法，取值一致。
*   `数学.平方根` 等返回小数（装箱浮点），参与算术时按小数运算。
