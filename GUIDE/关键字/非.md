

# 非

**逻辑非：布尔取反，真变假、假变真。**

```text
若 非 已完成 {
    示("继续处理")
}
```

## 你可以……

- **反转条件**——前缀写在条件前：

```text
当 非 R.窗口应关闭?() {
    R.开始绘图()
    R.结束绘图()
}
```

- **前置校验取反**——配合返回布尔的问号方法最顺口：

```text
若 非 文件.存在?("cfg.json") {
    示("缺少配置文件")
}
```

- **配合 且/或 组合**：

```text
若 非 已过期 且 已登录 {
    示("放行")
}
```

## 注意

- `非` 是逻辑取反（布尔），按位取反是另一个关键字 `取反`——别混用。
- 结果恒为布尔值：`非 假` 得 `真`，`非 真` 得 `假`。
