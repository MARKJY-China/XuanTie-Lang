

# 于

**遍历的介词：指明迭代哪个集合。**

```text
遍历 元素 于 集合 {
    示(元素)
}
```

## 你可以……

- **于 数组**——取到元素：

```text
遍历 项 于 [10, 20] {
    示(项)
}
```

- **于 字典**——取到键：

```text
设 映射 = {"a": 1, "b": 2}
遍历 k 于 映射 {
    示(k)
}
```

## 注意

- `于` 不单独使用，只能出现在 `遍历` 语句中、循环变量之后。
