

# 输

**读标准输入。返回用户输入的一行文本。**

```text
设 名字 = 输("名字? ")
示("你好, " & 名字)
```

## 你可以……

- **读一行**——提示语原样打出，返回键入的文本（不含换行）：

```text
设 行 = 输("> ")
```

- **读数字**——配 `整` 的结果判定，失败不炸：

```text
设 转 = 整(输("请输入数字:"))
若 转.成功 {
    示("两倍 = " & 字(转.值 * 2))
} 否 {
    示("不是数字")
}
```

- **挡住程序退出**——服务端启动后把主线程留住：

```text
听(8000, 函(流) { 流.写("欢迎!\n") })
输("按回车停止...")
```

## 注意

- 返回的总是 `字`；数值判断前先用 `整()`/`小数()` 转换。
- 输入流结束（EOF）时返回空串。
