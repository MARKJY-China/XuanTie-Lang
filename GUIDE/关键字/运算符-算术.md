# 运算符-算术

**加减乘除与取模：整数守整数，遇小数全提升。**

```text
示(7 / 2)     // 3
示(7 / 2.0)   // 3.5
```

## `+` 加

两数相加。

```text
设 和 = 1 + 2   // 3
```

## `-` 减

两数相减；也可作负号前缀。

```text
设 差 = 5 - 3   // 2
设 负 = -1.5    // 负号前缀
```

## `*` 乘

两数相乘。

```text
设 积 = 4 * 3   // 12
```

## `/` 除

整数相除向下取整；任一侧是小数则按小数除。

```text
示(7 / 2.0)   // 3.5（7 / 2 得 3）
```

## `%` 模

整数取余；小数按 fmod 语义。

```text
示(5.5 % 2.0)   // 1.5（整数 7 % 2 得 1）
```

## 注意

- 除零不报错：整数与小数一律返回 `0`。
- 整数间运算保持整数语义；任一侧是小数，整体提升为小数运算。
- 整数值的小数打印不带小数点：`字(2.0)` 得 `"2"`。
