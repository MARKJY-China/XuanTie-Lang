

# 捕捉

**接住 `尝试` 块里的异常，可带错误变量。**

```text
尝试 {
    示("正在执行危险操作...")
} 捕捉 (错误) {
    示("捕获到异常")
}
```

## 你可以……

- **要错误信息就带变量**——括号写法和裸标识写法等价：

```text
} 捕捉 (错误) {
    示(错误)
}
```

```text
} 捕捉 错误 {
    示(错误)
}
```

- **无异常时整块跳过**——`尝试` 块正常跑完，`捕捉` 不执行：

```text
设 完成 = 假
尝试 {
    完成 = 真
} 捕捉 {
    完成 = 假
}
示(完成)
```

## 注意

- `捕捉` 不能单独出现，必须跟在 `尝试` 块后面。
- 错误变量是字典，目前只有 `消息` 一个字段（`错误["消息"]`)，勿依赖更多字段。
- 能进来的故障：除零/求模除零、整数溢出、注解参数类型错误、成员访问空值、未知成员、索引非对象、负索引、方法缺失。
  成员/索引/方法类硬错误只在**同一函数的 `尝试` 块内**可捕；跨函数（错误在被调函数里、`尝试` 在调用方）按硬退出处理。
  完整"可捕/硬退出"清单、位置格式与表达式形态见 [尝试](尝试.md)。
- 被接住的运行时错误，`错误["消息"]` 里带 `[文件:行:列] ` 定位前缀（issue #110）。
- 越界正向索引/字典缺键返 `空`、I/O API 返回 `结果` 容器——这类约定返回值不触发 `捕捉`。
