# 时

**时间命名空间。** 取时间戳、高精度计时与休眠。

## 函数

| 调用 | 返回 | 说明 |
|------|------|------|
| `时.现()` | 整 | 当前 Unix 时间戳（**秒**，如 `1790358274`） |
| `时.毫秒()` | 整 | 高精度**单调**计时（毫秒）——测量耗时用，不是 Unix 时间戳 |
| `时.微秒()` | 整 | 高精度**单调**计时（微秒）——同上 |
| `时.睡(毫秒)` | 空 | 休眠指定毫秒数 |

## 用法

```text
设 起 = 时.毫秒()
设 i = 0
当 i < 1000 { i = i + 1 }
示("耗时 " & 字(时.毫秒() - 起) & "ms")

时.睡(200)          // 暂停 200 毫秒
```

## 注意

*   `时.睡` 是**真正挂起当前执行体**的休眠：在 `异步 { }` 块（fiber）里它是切分点——调度器可在这段时间跑别的 fiber；在主线程里则阻塞当前线程。
*   `时.睡(1)` 的实际精度受系统定时器粒度影响（Windows 约 15ms 量级），需要精细计时请用 `时.毫秒/微秒` 做**差值**测量，而不是靠小睡眠累加。
*   循环里出现 `时.睡` 会让整个 `异步` 块编译为**线程池任务**（运行期间独占一个 worker），编译器会给出提示。
