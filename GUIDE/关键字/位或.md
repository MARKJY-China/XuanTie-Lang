

# 位或

**按位或：任一位为 1，结果即为 1。**

```text
示(5 位或 3)   // 7
```

## 你可以……

- **合并标志位**——把多个开关拼进一个整数：

```text
设 权限 = 可读 位或 可写
```

- **置位**——把某一位强制设为 1，其余位不动：

```text
标志 = 标志 位或 8
```

## 注意

- 没有 `|` 运算符，按位或只能写关键字 `位或`。
- `位或` 优先级低于 `位与`、`左移`、`右移`，混用时建议加括号。
