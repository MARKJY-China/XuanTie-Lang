
# 道

**带缓冲通道类型，并发任务之间传值的管道。**

```text
设 ch = 道(4)
ch.发("hello")
设 msg = ch.收()
```

## 你可以……

- **在 `异步` 块内阻塞收发**——编译器自动切换为阻塞版本，不占调度器：

```text
设 ch = 道(3)
设 工 = 异步 {
    示(ch.收() + ch.收())
}
ch.发(1)
ch.发(2)
等待(工)
```

- **用 `选` 等多通道**——第一个就绪的通道胜出，返回其下标：

```text
设 i = 选([ch1, ch2], 1000)
若 i >= 0 { 示("有通道就绪") }
```

- **带超时的收**——`收()` 无限等待；`收(0)` 非阻塞轮询（空则立即返 `空`）；`收(毫秒)` 限时等待，超时返 `空`：

```text
设 v = ch.收(0)        // 有则取，无则立即返空
设 w = ch.收(300)      // 最多等 300ms
```

## 注意

*   本词是**保留字**：不能用作变量名、函数名、参数名等标识符（完整规则与清单见 [词法与基础语法](../手册/01_词法与基础语法.md#保留字不可作标识符)）。
- 主线程/普通函数里的 `收()` 是**阻塞等待**（内部会泵送 fiber；后台常驻任务不会让它卡死，v1.0-rc.5/#142）；异步块内 `收()` 走调度器挂起。
- `收(0)` 是非阻塞轮询；旧版本忽略了超时参数（#143），v1.0-rc.5 起生效。
- `收` 最多接受一个超时参数；传多个参数会编译报错。
- `选` 超时返回 `-1`，使用前必须先判定，别拿去索引通道数组。
