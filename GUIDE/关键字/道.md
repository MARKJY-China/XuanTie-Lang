# 道

**带缓冲通道类型，并发任务之间传值的管道。**

```text
设 ch = 道(4)
ch.发("hello")
设 msg = ch.收()
```

## 你可以……

- **在 `异步` 块内阻塞收发**——编译器自动切换为阻塞版本，不占调度器：

```text
设 ch = 道(3)
设 工 = 异步 {
    示(ch.收() + ch.收())
}
ch.发(1)
ch.发(2)
等待(工)
```

- **用 `选` 等多通道**——第一个就绪的通道胜出，返回其下标：

```text
设 i = 选([ch1, ch2], 1000)
若 i >= 0 { 示("有通道就绪") }
```

## 注意

- 阻塞路径（非 `异步` 块）下收发是**非阻塞**的：`发` 满则丢弃，`收` 空则返回 `空`。要可靠收发，请在 `异步` 块内进行。
- `选` 超时返回 `-1`，使用前必须先判定，别拿去索引通道数组。
