# 若

**条件分支。条件为真就执行块，否则走下一分支。**

```text
若 分数 >= 60 {
    示("及格")
}
```

## 你可以……

- **串联多个条件**——第一个为真的分支执行，其余跳过；`否` 兜底：

```text
若 分数 >= 90 {
    示("优秀")
} 抑 分数 >= 60 {
    示("及格")
} 否 {
    示("重修")
}
```

- **条件里直接写表达式**——不需要括号：

```text
若 年龄 >= 18 且 已购票 {
    示("允许入场")
}
```

## 注意

- 条件是裸表达式，不套圆括号（玄铁不是 C 系语法）。
- 只有一条语句也要写花括号。
