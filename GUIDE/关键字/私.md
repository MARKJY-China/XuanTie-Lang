# 私

**私有可见性：成员仅能在定义它的型内部访问。**

```text
型 账户 {
    私 设 密码 = "SECRET"
    函 验证(输入): 布尔 { 返 此.密码 == 输入 }
}
```

## 你可以……

- **私有字段配公开访问器**——外部走方法，不碰字段：

```text
型 可见性测试类 {
    私 设 私有属性 = "SECRET"
    函 获取私有() { 返 此.私有属性 }
}
```

- **标记私有方法**——`私 函` 同样只能在型内调用：

```text
型 引擎 {
    私 函 点火() { 示("点火") }
    函 启动() { 此.点火() }   // 同型内部，允许
}
```

## 注意

- 在型外访问 `私` 成员是编译错误，不是运行时才炸。
- 子类也不能访问父类的 `私` 成员——只认定义它的那个型。
