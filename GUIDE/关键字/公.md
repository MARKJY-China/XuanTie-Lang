# 公

**公开可见性：成员对外自由访问，是默认级别。**

```text
型 配置 {
    公 设 端口 = 8080
    公 函 取端口(): 整 { 返 此.端口 }
}
```

## 你可以……

- **省略不写**——型成员不加修饰符时就是 `公`：

```text
型 配置 {
    设 端口 = 8080   // 等价于 公 设
}
```

- **标注模块顶层函数**——库文件里显式表明这是对外 API：

```text
公 函 初始化窗口(宽, 高, 标题) { ... }
```

## 注意

- 模块顶层符号目前默认全部导出，顶层的 `公` 是显式标注而非访问门禁；`公`/`私`/`护` 的强制检查作用于型成员。
