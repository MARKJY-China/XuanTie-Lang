# 听

**TCP 监听。新连接触发回调。**

```text
听(8000, 函(流) {
    流.写("欢迎!\n")
})
输("按回车停止...")
```

## 你可以……

- **回显服务器**——回调参数就是该连接的流：

```text
听(8000, 函(流) {
    循 {
        设 数据 = 流.读()
        若 数据 == 空 { 断 }
        流.写("回显: " & 数据)
    }
    流.关()
})
输("按回车停止...")
```

- **共享数据**——回调间是真多线程并发，用全局变量或通道汇总：

```text
设 在线 = 0
听(8000, 函(流) {
    在线 = 在线 + 1
    流.写("当前在线: " & 在线)
    在线 = 在线 - 1
    流.关()
})
输("按回车停止...")
```

## 注意

- `听` 立即返回、不挡退出：主线程跑到末尾进程就结束了，服务端末尾用 `输(...)` 或 `循 { 时.睡(1000) }` 留住主线程。
- 没有「停止监听」原语：一旦启动就活到进程结束。
- TCP 没有消息边界：一次 `读` 不等于「一条消息」（阻塞路径每次最多 4096 字节），要完整消息自己加分隔符循环拼。
