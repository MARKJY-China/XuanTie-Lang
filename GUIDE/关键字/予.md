 

# 予

**为引入的模块指定别名，作访问其成员的前缀。**

```text
引 "./库/文件.xt" 予 文件
```

## 你可以……

- **用短别名压住长名字**：

```text
引 "../lib/渲染/渲染.xt" 予 R
R.初始化窗口(800, 600, "示例")
```

- **隔离同名符号**——不同模块的同名函数靠前缀区分：

```text
引 "./lib/math.xt" 予 数学
引 "./lib/geo.xt"  予 几何

设 a = 数学.距离(1, 2)
设 b = 几何.距离(3, 4)
```

## 注意

- 不带 `予` 时，模块以文件名作为访问前缀。
- 同一模块一次编译只能用一个别名，多别名会报错。
- 模块内部的互调永远用裸名，别名只对引入方生效。
