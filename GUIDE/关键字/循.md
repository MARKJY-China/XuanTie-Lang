

# 循

**无限循环：无条件重复，直到 断。**

```text
循 {
    若 退出条件 { 断 }
}
```

## 你可以……

- **把出口写在中途**——先做事，再判退不退：

```text
设 n = 0
循 {
    n = n + 1
    若 n >= 10 { 断 }
}
示(n)  // 10
```

- **常驻等待**——服务、事件循环的常驻骨架：

```text
循 {
    设 指令 = 输("管理>")
    若 指令 == "退出" { 断 }
    示("执行: " & 指令)
}
```

## 注意

- 块内没有可达的 `断`（或 `返`/`终`），循环永远不结束。
