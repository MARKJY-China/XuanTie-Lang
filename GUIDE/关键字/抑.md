# 抑

**追加条件分支：前面不真就试我。**

```text
若 分数 >= 90 {
    示("优秀")
} 抑 分数 >= 60 {
    示("及格")
}
```

## 你可以……

- **连续串联多个条件**——自上而下，第一个为真的分支执行，其余跳过：

```text
若 分数 >= 90 {
    示("优")
} 抑 分数 >= 80 {
    示("良")
} 抑 分数 >= 60 {
    示("及格")
} 否 {
    示("重修")
}
```

- **在若表达式里分支出值**——配合 `否` 给出兜底值：

```text
设 级别 = 若 分数 >= 90 { "优" } 抑 分数 >= 60 { "良" } 否 { "差" }
```

## 注意

- `抑` 必须带条件且不能单独出现，只能跟在 `若` 块（或前一个 `抑` 块）之后。
