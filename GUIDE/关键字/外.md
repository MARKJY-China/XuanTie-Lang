# 外

**声明外部 C 函数（C-FFI），供玄铁直接调用。**

```text
外 函 XT_InitWindow(w: 整, h: 整, title: 字): 空
```

## 你可以……

- **声明后像普通函数一样调用**：

```text
外 函 XT_GetFPS(): 整
设 帧率 = XT_GetFPS()
```

- **包一层中文名再对外开放**——库的常见写法：

```text
外 函 XT_InitWindow(w: 整, h: 整, title: 字): 空

公 函 初始化窗口(宽, 高, 标题) {
    XT_InitWindow(宽, 高, 标题)
}
```

## 注意

- 参数与返回类型必须逐一标注；签名若与 C 侧实现不符，问题要到链接或运行期才暴露。
- 符号必须真实存在于所链接的 C 库或 runtime 中，否则链接失败。
