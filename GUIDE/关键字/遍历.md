# 遍历

**迭代循环：逐个取出集合中的元素。**

```text
遍历 项 于 [1, 2, 3] {
    示(项)
}
```

## 你可以……

- **遍历数组**——循环变量依次取到各元素：

```text
设 列表 = ["甲", "乙", "丙"]
遍历 名 于 列表 {
    示(名)
}
```

- **遍历字典**——循环变量依次取到各键，值用键再取：

```text
设 映射 = {"名": "玄铁", "地": "中国"}
遍历 键 于 映射 {
    示("#{键}: #{映射[键]}")
}
```

- **遍历字符串**——按逻辑字符逐个取出：

```text
遍历 c 于 "你好" {
    示(c)
}
```

## 注意

- 遍历字典拿到的是**键**不是值，值要再写 `映射[键]`。
