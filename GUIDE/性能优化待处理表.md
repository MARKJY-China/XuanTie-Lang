## 〇、对标格局(先说人话)

- **Python(解释型)**:除三个短板外已全面碾压(4~15×)。不值一提,不作宣传对象。
- **NodeJS(V8 JIT)/Java(HotSpot JIT)**:当前**全面落后 2~20×**(拼接最惨)。这是几十年 JIT 工程的功力,诚实面对。
- **Go(编译型)**:整数/递归强一个量级(本机 386 数据还打了折)。

**现实目标分档**:
- 近期(可宣传):**全面超过 Python**——修掉 P1/P2/P3 即达成。
- 中期(里程碑):整数/控制流进入 Node 的 1/2 射程内;fib 递归贴近 Node。
- 远期(不承诺):逼近 Go。**不承诺追平 V8/JIT**——那是 JIT 运行时优化的赛道,我们是 AOT 静态编译,赛道不同。

## 二、短板分析与优化项(按预期收益排序)

### P1 字符串拼接 —— ✅ 已根治(2026-08-15,10.5s → 3.5ms,3007×,比 Node 快 2.1×)

- **根因(已修)**:`xt_string_concat` O(n²) 全量复制 + 三重复制。
- **落地优化**:
  1. concat 去三重复制(单次拷贝)。
  2. **原地追加快路径**:`XTString` 加 `capacity` 字段;左串独占(引用计数阈值判定,区分 xt_add 路径 maxrc=2 / 自拼接路径 maxrc=1)时原地追加 + 容量倍增 realloc,摊销 O(1)。`s=s+s` 自重叠防护走慢路径。
  3. **自拼接专用编译落点**:`s = s + X`(语言类型"字")直发 `xt_string_append` IR,跳过重载分派/字典查找/冗余引用链;字面量直拼 `xt_string_append_lit` 零对象分配。启发误中(变量实际非字符串)由 runtime 回退 xt_add 兜底,正确性双向安全。
  4. 顺带根治:P-perf 接管块 merge 段漏放"结果产出引用"(每轮净漏 1 引用)。
- **实测**:1e5 次拼接 10 次平均 3,514μs(Node 7,436μs,Java 1,047,916μs)。
- **仍可选**:字符串构建器/rope(当前数据已无迫切性)。

### P2 字典插入 —— ✅ 已根治(2026-10-06,36,206 → 3,260 µs,11.1×,反超 Python/Node/Java)

- **根因(已修)**:`xt_dict_set`/`xt_dict_set_weak` 容量恒定 16 桶无扩容,1e4 插入坍缩成 ~625 深链 O(n²)。
- **落地优化**:负载因子 0.75 触发容量倍增重哈希(`xt_dict_grow`);遍历经 `xt_dict_keys` 快照,迭代期扩容安全。
- **实测**:3,260 µs(Python 5,328 / Node 4,154 / Java 4,638 / Go-386 1,627)。详见 `优化历史.md` 末节。

### P3 浮点装箱 —— ✅ 已根治(2026-10-06,205,810 → 5,720 µs,36.0×,反超 Python 14×)

- **根因(已修)**:`小数` 全程装箱——字面量即 `xt_float_new`,每次算术走运行时调用并再产堆对象,循环内 malloc/free 风暴。
- **落地优化**:编译器引入 `raw_f64`(槽位/寄存器以 i64 承载 double 裸位)。字面量产裸位;浮点槽位粘性 raw;数值标量间算术内联 `fadd/fsub/fmul/fdiv/frem/fcmp`;除零约定与装箱路径逐字对齐(0.0/可捕捉异常);边界(示/容器/实参/返回/捕获)统一装箱。运行时零改动。行为修正:浮点真值非零即真(旧装箱路径恒为假)。
- **实测**:5,720 µs(Python 82,150 / Node 1,618 / Java 1,672)。目标 ≤120ms 与冲刺 ≤10ms 双达成;对 Node 从 82× 收敛到 3.5×(剩余为槽位读写开销,P4 课题)。详见 `优化历史.md` 末节。

### P4 控制流与调用(分支慢 Node 19.5×、嵌套慢 10×、fib 慢 2.4×)

- **根因(待剖)**:boxed 值的比较/分支每轮脱壳;函数调用参数/返回装箱;循环变量覆盖写的 release 链。
- **优化项**:① 局部注解变量的读改写全 raw 化(与 P3 同源工程);② raw 签名函数(参数/返回皆 整)调用零装箱;③ 循环变量覆盖写的 release 消减(标量判定免释放)。
- **目标**:分支/嵌套 ≤2× Node;fib30 ≤12ms。
