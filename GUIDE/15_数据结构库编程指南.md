# 数据结构库编程指南

> **对标版本**：数据结构库 v1.0.1（`lib/结构/`）。安装：`tiepm az 结构`；仓库内开发可直接 `引 "../lib/结构/结构.xt" 予 S`。
> API 速查：[数据结构 API 参考](API/结构) ｜ 例程：[词频统计](例程/词频统计)

---

## 概览

`结构` 提供 8 个容器：栈、队列、双端队列、链表、二叉堆、二叉搜索树、集合、LRU 缓存。全部用 `型` 实现，纯玄铁，无 C 桥依赖。

| 容器 | 构造 | 主要操作 | 复杂度 |
|------|------|----------|--------|
| 栈 | `造 S.栈()` | `压入` `取出` `查看` | O(1) |
| 队列 | `造 S.队列()` | `入队` `出队` `查看头` | 入队 O(1)，出队摊还 O(1) |
| 双端队列 | `造 S.双端队列()` | `头入` `尾入` `头出` `尾出` | 尾端 O(1)，头端 O(n) |
| 链表 | `造 S.链表()` | `头插` `尾插` `移出` `查找` `反转` | 头尾插 O(1)，查找/移出 O(n) |
| 二叉堆 | `造 S.二叉堆(比较函)` | `压入` `取出` `查看顶` | O(log n) |
| 二叉搜索树 | `造 S.二叉搜索树(比较函)` | `加入` `查找` `有?` `中序` | 平均 O(log n)，最坏 O(n) |
| 集合 | `造 S.集合()` | `加入` `移出` `有?` `并` `交` `差` | 摊还 O(1) |
| LRU 缓存 | `造 S.LRU缓存(容量)` | `放` `取` `移出` `有?` `键列表` | O(n)（键序数组重排） |

所有容器都有 `大小`、`空?`、`清空`；栈/队列/双端队列/链表/堆/树还有 `到数组`（返回副本，改它不影响容器）。

## 安装与引入

```text
引 "结构" 予 S
```

## 空容器：返回 `结果`，不返回空值

栈/队列/双端队列/堆/树在空容器上的 `取出`/`出队`/`头出`/`尾出`/`查看`/`最小`/`最大` 一律返回 `结果` 容器：

```text
设 栈 = 造 S.栈()
设 弹 = 栈.取出()
若 弹.成功 {
    示("弹出: " & 字(弹.值))
} 否 {
    示("没东西可弹: " & 弹.错误)   // 栈为空: 取出
}
```

这样调用方必须显式处理空容器，不会拿到一个静默的 `空` 继续往下算。

## 栈

```text
设 栈 = 造 S.栈()
栈.压入("a")
栈.压入("b")
示(栈.查看().值)      // b
示(栈.取出().值)      // b
示(栈.取出().值)      // a
示(栈.空?())          // 真
```

`到数组` 按**栈底 → 栈顶**顺序返回。

## 队列

```text
设 队 = 造 S.队列()
队.入队(1)
队.入队(2)
示(队.出队().值)      // 1
示(队.大小())         // 1
```

底层是数组 + 头下标：出队只移动下标，积累到一定量后自动压缩，因此大量进出不会无限占内存，出队摊还 O(1)。

## 双端队列

```text
设 双 = 造 S.双端队列()
双.尾入(1)
双.头入(0)
双.尾入(2)
示(化(双.到数组()))    // [0, 1, 2]
示(双.头出().值)       // 0
示(双.尾出().值)       // 2
```

头端插入/删除需要搬移数组，是 O(n)；只在头端少量操作时用它，否则换链表。

## 链表

```text
设 链 = 造 S.链表()
链.尾插("x")
链.头插("y")
链.尾插("z")
示(化(链.到数组()))    // ["y", "x", "z"]
示(链.移出("x"))       // 真
链.反转()
示(化(链.到数组()))    // ["z", "y"]
```

节点用字典表示，不额外引入节点类型；`移出` 按 `==` 判等，删除第一个命中的节点。

## 二叉堆

比较函返回**负数表示第一个更优先**：

```text
// 最小堆
设 小堆 = 造 S.二叉堆(函(a, b) { 返 a - b })
// 最大堆
设 大堆 = 造 S.二叉堆(函(a, b) { 返 b - a })

小堆.压入(5)
小堆.压入(1)
小堆.压入(3)
示(小堆.查看顶().值)   // 1
示(小堆.取出().值)     // 1
示(小堆.取出().值)     // 3
```

`到数组` 返回的是**堆序数组**，不是有序数组；要得到完整有序序列，连续 `取出` 直到 `空?` 为真。

## 二叉搜索树

```text
设 树 = 造 S.二叉搜索树(函(a, b) { 返 a - b })
树.加入(5)
树.加入(3)
树.加入(8)
树.加入(3)             // 重复键不重复插入
示(化(树.中序()))       // [3, 5, 8]
示(树.大小())           // 3
示(树.高度())           // 2
示(树.最小().值)        // 3
示(树.最大().值)        // 8
```

- 不支持删除节点；
- 插入顺序有序时退化成链表，查找 O(n)；需要稳定性能请用平衡结构（本库未提供）；
- 比较函应满足全序（自反、传递）。

## 集合

```text
设 甲 = 造 S.集合()
甲.加入(1)
甲.加入(2)
设 乙 = 造 S.集合()
乙.加入(2)
乙.加入(3)
示(甲.有?(2))            // 真
示(化(甲.并(乙)))        // 元素数组，顺序不保证
示(化(甲.交(乙)))        // [2]
示(甲.子集?(乙))          // 假
```

要点：

- 元素必须是**可作字典键**的值（整/字/布尔）；数组、字典作元素会在运行时报错。
- `并`/`交`/`差` 返回**数组**（去重、顺序不保证），需要集合结果时自己 `加入` 到新集合。
- `子集?` 的参数必须是集合，不能传 `并`/`交`/`差` 的数组结果。

## LRU 缓存

```text
设 缓存 = 造 S.LRU缓存(2)
缓存.放("a", 1)
缓存.放("b", 2)
示(缓存.取("a").值)      // 1（命中后 a 变为最近使用）
缓存.放("c", 3)           // 淘汰最久未使用的 b
示(缓存.有?("b"))         // 假
示(化(缓存.键列表()))     // ["a", "c"]
```

- `取` 未命中返回 `失败("LRU 缓存未命中")`；
- 容量小于等于 0 时按 1 处理；
- 底层是键序数组，命中后要重排，单次操作 O(n)；容量别开太大（几千级以内）。
