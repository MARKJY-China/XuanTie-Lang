# 例程：词频统计（文本库 + 数据结构库）

> **对标版本**：文本库 v1.0.1、数据结构库 v1.0.1、XTC v1.0-rc.3。

统计文本中的词频并取前 3 名：字典计数 → 二叉堆排序 → 弹出；最后用 LRU 缓存记录“最近查询”。

## 源代码

```xuantie
引 "文本" 予 T   // 仓库内开发时改为: 引 "../lib/文本/文本.xt" 予 T
引 "结构" 予 S   // 仓库内开发时改为: 引 "../lib/结构/结构.xt" 予 S

设 原文 = "玄铁 是 一门 中文 关键字 编程 语言 玄铁 编译器 由 玄铁 写成 静态 类型 ARC 内存 管理"

// 把标点与换行折叠成空格，再按空白分词
设 净文 = 原文.替换("\n", " ").替换("，", " ").替换("。", " ")
设 词们 = 净文.分割(" ")
设 词数 = {}
遍历 词 于 词们 {
    设 词条 = 词.去首尾空格()
    若 词条 == "" { 续 }
    设 旧 = 0
    若 词数.含?(词条) { 旧 = 词数[词条] }
    词数[词条] = 旧 + 1
}

// 最大堆：计数大者优先
设 堆 = 造 S.二叉堆(函(a, b) { 返 b["数"] - a["数"] })
遍历 词条 于 词数.键集 {
    堆.压入({"词": 词条, "数": 词数[词条]})
}

示("词种数: " & 字(词数.长度))
示("前 3 名:")
设 序 = 0
当 序 < 3 且 非 堆.空?() {
    设 顶 = 堆.取出().值
    序 = 序 + 1
    示(T.填充右(字(序) & ".", 4, " ") & T.填充右(顶["词"], 14, " ") & 字(顶["数"]))
}

// 用 LRU 缓存保留最近查询的词条
设 最近 = 造 S.LRU缓存(3)
最近.放("玄铁", 1)
最近.放("编译器", 2)
最近.放("语言", 3)
最近.放("自举", 4)
示("最近使用的 3 个词: " & 化(最近.键列表()))
```

## 实际输出

```text
词种数: 15
前 3 名:
1.  玄铁            3
2.  内存            1
3.  由             1
最近使用的 3 个词: ["编译器", "语言", "自举"]
```

## 说明

- 中文没有空格分词，本示例把文本预处理成空格分隔；真实中文分词需要词典，不在本库范围。
- 堆的比较函返回负数表示“更优先”；这里用 `b["数"] - a["数"]` 得到最大堆。
- 堆里元素是字典，比较函按 `["数"]` 取值比较；元素类型由你自己保证一致。
- 计数相同时堆序不保证字典序，所以第 2、3 名的具体顺序可能随堆实现变化；要稳定排序请在弹出后再用数组库 `排序` 做一次全序排序。
- LRU 容量为 3，放入第 4 个键时淘汰最久未使用的 `玄铁`。
