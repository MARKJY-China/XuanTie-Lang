# 例程：文件清单（路径库）

> **对标版本**：路径库 v1.0.1、文本库 v1.0.1、XTC v1.0-rc.3。

把一批路径拆成“目录 / 主名 / 扩展名”三列，并演示规范化、换扩展名、相对路径与文件名合法性检查。

## 源代码

```xuantie
引 "路径" 予 P   // 仓库内开发时改为: 引 "../lib/路径/路径.xt" 予 P
引 "文本" 予 T

设 清单 = "src/主.xt
src/工具/文本.xt
src/工具/路径.xt
docs/README.md
根目录文件.txt"

示(T.填充右("目录", 16, " ") & T.填充右("主名", 12, " ") & "扩展名")
遍历 行 于 T.取行(清单) {
    设 件 = P.拆分(P.规范化分隔符(行))
    设 目 = 件["目录"]
    若 目 == "" { 目 = "." }
    示(T.填充右(目, 16, " ") & T.填充右(件["主名"], 12, " ") & 件["扩展名"])
}

示("--- 规范化 ---")
示(P.规范化("src/./工具/../工具/文本.xt"))
示(P.规范化("a//b/../../c"))
示("--- 换扩展名 ---")
示(P.换扩展名("src/工具/文本.xt", "md"))
示("--- 相对 ---")
示(P.相对("C:/项目/src/工具/文本.xt", "C:/项目/docs"))
示("--- 合法文件名 ---")
示(化(P.非法字符("报告:2026?.txt")))
```

## 实际输出

```text
目录              主名          扩展名
src             主           .xt
src\工具          文本          .xt
src\工具          路径          .xt
docs            README      .md
.               根目录文件       .txt
--- 规范化 ---
src\工具\文本.xt
c
--- 换扩展名 ---
src/工具/文本.md
--- 相对 ---
..\src\工具\文本.xt
--- 合法文件名 ---
[":", "?"]
```

## 说明

- `拆分` 的 `目录` 保留输入串的分隔符，因此先 `规范化分隔符` 再拆，列里不会出现 `/` 与 `\` 混排。
- `换扩展名` 只截取末尾，目录部分原样保留——它不会顺手把 `/` 改成 `\`；要统一分隔符就先 `规范化`。
- `相对` 的第二个参数是**目录**；不同盘符时退回规范化后的绝对目标，不会返回无意义的 `..\..\...`。
- 需要真实遍历目录时，语言目前没有列目录内建，可用 `系统.运行` / `执` 调外部命令，或写项目级原生桥。
