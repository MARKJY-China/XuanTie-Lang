# 玄铁 (XuanTie) v1.0-rc.2

第二个候选正式版。本版变更全部集中在 XTC(自举编译器)与其运行时。

**下载**

- `xuantie_v1.0-rc.2_setup.exe` — Windows 安装程序(自带 clang/MinGW,装完即可用 `xtc`)
- `xuantie_v1.0-rc.2_windows_amd64.zip` — 绿色包,解压即用

## 语言与编译期

- **保留字不得作标识符**:变量名、常量名、函数名、参数名、迭代变量名、型名、接口名等 **14 个标识符定义入口**全部拦截。清单:`结果 任务 道 测试 字符串 整 小数 布尔 数组 字典 字节`,另按名补判 `此`。
- **成员调用静态校验**:内置属性被当方法调用(`列表.长度()`)编译期报错并给出改写建议;静态可知的类型上"方法不存在"编译期报错(连目标型的全部派生型一起查,不误伤多态)。
- **实参个数校验补全**:方法调用与 `造` 构造调用少传实参,此前会读到未初始化的形参槽并按 ARC 释放垃圾对象导致堆损坏;现编译期拦下。
- **`终 <表达式>`**:终止码此前只认数字字面量,变量/算术/调用被静默丢弃退成 exit 0;现接受任意整数表达式,字符串/数组/字典当终止码改为编译期报错。
- **`-jc` 只检查模式崩溃修复**:检查模式的作用域退出例程会读已解约页的对象头(0xC0000005)。
- **嵌套异步块非法 IR 修复**:异步块内再起纯计算块并等待它时,内层函数体曾继承外层 fiber 状态机上下文,生成未定长类型的 `getelementptr`。
- **`等待(t).成员` 取空值修复**:方法分派前置段曾把接收者求值两次,`等待` 的一次性句柄被提前消费,结果静默变 `空`。
- **编译期自检硬失败**:IR 完整性自查发现非法标记时打印诊断并以非零退出码终止,不产出坏产物。
- **浮点运算落地**:运行时算术(`+ - * / %`)浮点分派与混合提升、编译器装箱安全路由、前缀负号与注解小数参数的段错误修复。
- **关键字名变量读取纪律统一**:抽出唯一入口 `读符号槽`,修复引用计数下溢导致的悬垂读(实测段错误)。
- **遮蔽修复(P0)**:函数内 `设`/`遍历` 变量遇同名全局一律新建遮蔽局部,杜绝模块函数静默污染调用方全局。
- **异常与错误处理**:捕捉机制死代码根治(除零、参数类型错误现可捕捉)、`是` 中缀双形态(类型判断/值等价)、除模运算全走运行时。
- **文件 API 铁律硬化**:`文件.写` 校验写入字节数与 `fflush`/`fclose`(磁盘满、短写不再静默成功);新增 `文件.删`(带重试,失败必报错)。
- **数组/字节方法接收者守卫**:错类型对象误用方法(如 `s.找(...)`)不再越界踩内存,改为明确报错退出。
- **性能与其他**:1e5 次字符串拼接 10.5s → 4.6ms;数学常量命名统一为 `圆周率`/`自然常数`;修常量裸访问把函数地址当数据读的既有缺陷。

## 工具链

- **`xtc pao` / `xtc 跑`**:编译后立即运行,临时产物落缓存目录、跑完清理,参数与退出码透传。
- **项目根模式**:含 `玄铁.配置.toml` 的项目内可裸跑 `xtc 铁`,按 `[项目] 入口` 编译。
- **`--检查`**:一次报出整个文件的语义错误。

## 运行时

- **异步路由**:含阻塞核心原语(`求`/`执`/`输`)的异步块整块路由线程池,不再饿死同进程其他 fiber。
- **等待线程池任务**:修复任务析构连带释放结果造成的堆结果悬垂,以及作用域退出的二次释放;核心原语实参捕获补扫。
- **HTTP 单参 `求`**:重定向跟随、连接与收发超时、多 A 记录容错;补 chunked 传输解码(此前响应超 2KB 会卡死或段错误)。
- **调度器**:`xt_scheduler_step` 非阻塞单步泵(主线程进 UI 主循环后 fiber 不再整体饿死);按需重绘,空闲 CPU 实测 0.000s。
- **跨平台**:macOS/arm64 与 Windows ARM64 自举打通,Linux ARM64 有验证记录;运行时 C 文件平台隔离、GNU/Linux 非渲染编译补 `-lm`、darwin `执()` 退出码归一化。
