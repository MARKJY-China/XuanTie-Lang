# 玄铁 (XuanTie) v1.0-rc.3

第三个候选正式版。本版变更覆盖 XTC(自举编译器)、工具链、发行设施与配套 IDE(铸造厂)。

**下载**(由 GitHub Actions 多平台流水线自动构建;安装包/压缩包同时在对象存储提供国内直链)

- `xuantie_v1.0-rc.3_setup.exe` — Windows 安装程序(自带 clang/MinGW,装完即可用 `xtc`)
- `xuantie_v1.0-rc.3_windows_amd64.zip` — Windows 绿色包,解压即用
- `xuantie_v1.0-rc.3_linux_x86_64.tar.gz` — Linux 绿色包(需系统 clang;见包内 README)
- `xuantie_v1.0-rc.3_darwin_arm64.tar.gz` — macOS(Apple Silicon)绿色包

## 语言与编译期

- **内置错写方法编译期拦截(报错增强)**:`列表.添加(2)` 这类"写错方法名"此前编译期放行、
  运行期才报「对象不存在的方法」;现对静态推断为内置类型(数组/字典/字符串)的接收者,
  错写词(添加/推入/append/push→追加、删除/移除/remove→删、插入→插、包含→包含?、
  合并/串联→连接)编译期直接报错并给出正确写法、常见内置方法清单与文档锚。
  豁免:该成员被动态挂载过(先挂后调是合法写法)、接收者非简单标识符、用户自定义型;
  判据走独立记录表,不参与内存释放/标量判定。
- **「不支持的前缀类型」提示**:类型词(数组/字典)被直接作表达式前缀时,报错附
  "内置方法请写在变量上"示例与文档锚(此前零信息)。
- **未知标识符同义错写专表**:在相近关键字提示之外补语义等价专表(打印→示、输出→示、
  返回→返、函数→函、循环→当、否则→否、跳出→断、引入/导入→引,以及
  return/print/function/class/while/import/null 等英文关键字)。
- **项目模式三处缺陷修复 + 运行时内建 `xt_cwd`**:修复项目根定位相关问题与错误退出路径崩溃。
- **性能:除/模恢复内联**(控制流守卫)——修复取模慢 7.1×、分支慢 5.2× 的回归。

## 工具链与发行设施

- **构建清单 MANIFEST.txt + `xtc -h` 自证**:发行包记录编译器与自举链各级 md5、对应提交
  哈希、包内全部文件 md5;「编译器自述」段由 `xtc -h` 原样打印,裸 exe 也能自证。
- **多平台发布流水线(GitHub Actions)**:打 tag 或手动触发即构建 Windows / Linux x86_64 /
  macOS arm64 三平台语言包与铸造厂 IDE;发布前自动硬校验指纹(包内提交 == tag 指向提交、
  版本行 == tag 名,不通过拒绝发布)。
- **打包脚本平台自适应**:`release/make_pkg.sh` 支持 Windows(Git Bash,内嵌工具链)与
  Linux/macOS(系统 clang)三条打包路径;编译器链顶动态取自举链最高级并校验相邻两级
  逐字节一致。

## 已知限制

- **Linux 版网络**:当前无系统 TLS 通道,`求()` 仅支持 http,https 会明确失败(不崩溃)。
- **Linux 版渲染**:发行包未内置 raylib 库产物,渲染功能需自行构建 raylib。
- **Windows ARM64**:自举与门禁已打通,发行包暂未提供(欢迎有 ARM64 设备的贡献者验证)。
