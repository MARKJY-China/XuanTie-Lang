# 句读 · AI 协作规约

## ① 项目一句话

句读是玄铁之妹:一门以句读符号为语法本体、十五文言虚字为关键字、珠算口诀为一等值的实验性中文语言。主力实现是用**玄铁**书写的"句读→玄铁"转译器;Python 参考解释器充当可执行规范;20 条黄金测试双实现同跑、输出逐字节比对,互为信任锚,不立新运行时。

## ② 目录结构

```
句读/
├── 规范.md            语言权威定义(权威顺序第一位)
├── CLAUDE.md          本文件
├── README.md
├── src/               转译器(玄铁写)
│   ├── 主.xt            入口:参数→读文件→词法→语法→语义→生成→写文件
│   ├── 词法.xt          归一化→切词→句终/续行判定→批注丢弃
│   ├── 抽象树.xt        AST 节点构造辅助(扁平字典节点)
│   ├── 语法.xt          递归下降出 AST(两枢机,无前瞻回溯)
│   ├── 语义.xt          名表解析+三静态检查(虚指/故曰越诀/不然末位警告)
│   ├── 生成.xt          AST→玄铁源码(模板拼接)
│   └── 词数.xt          数词解析(直书/命位/负),转译器与运行时共用
├── runtime/
│   └── jd_runtime.xt  动态值运行时(盒/受三解/运算分派/书形/错误四字段/文最左置换)
├── ref/
│   └── 解释器.py      Python 参考解释器(词法+语法+tree-walk,可执行规范)
├── tests/
│   ├── 黄金.jd        20 条黄金测试(期望内嵌:【句读】/【期出】/【期失】)
│   └── run.py         harness:双实现三方言 diff,一条命令跑完
├── examples/          五则示例(问候世界/账本/猜数字/纷咇/二一添作五)
└── build/             产物(gitignore:转译器 exe、生成 .xt、测试临时件)
```

## ③ 权威顺序

规范文档 > 黄金测试 > 参考解释器 > 转译器。改语义先改规范;改规范必同步黄金测试;两实现输出分歧本身即失败——分歧即规范歧义,先改规范再改实现。

## ④ 构建与测试命令

一切命令以仓库根为当前目录:

```
python 句读/tests/run.py                  # 跑全部 20 条(自动重建过期的转译器)
python 句读/tests/run.py --only 3         # 只跑试〇三(编号参数支持 3 / 03 / 试〇三)
python 句读/tests/run.py --overwrite      # 一键重录期望(diff 必须人工 review 后方可提交)
python 句读/tests/run.py --keep           # 保留 build/ 下的中间产物供排查
```

编译转译器(手动):`build/xtc_s4.exe 铁 句读/src/主.xt -sc 句读/build/jdt.exe`
黄金测试文件格式:`—— 试〇N·名 ———` 起,`【句读】` 源码块,`【期出】` 期望 stdout(空行止),出错类测试以 `【期失】` 给出期望首行(【类目】…行)。

## ⑤ 禁止事项

1. 不引第三方依赖(转译器、运行时、解释器、harness 皆然)。
2. 不改 `句读/` 之外的玄铁主编译器文件;宿主修复必须独立 commit 并注明"句读负载暴露"。
3. 不造超 800 行单文件;巨型重构一律拒绝,宁可结构平庸而步步绿。
4. 错误必须全中文四字段(【类目】卷「名」第N行:消息。/原文行/下划线),新增错误类目先登记规范 §七。
5. 明确的编程错误,宁可报错退出也不静默跳过(玄铁家法,句读一体遵行)。
6. 生成物恒居 `句读/build/`(生成码首行 `引 "../runtime/jd_runtime.xt"`,动此路径即破坏契约)。
7. 范围锁(规范既定,任何"顺手做"皆范围蔓延):不做方阵/OOP/并发/模块/底层漂移;漂移语义 v0.1 完全不实现。
8. **宿主(玄铁)两条铁律**(句读负载实测暴露,编码前必读):
   - 全局函数名会**遮蔽同名函数参数**(如构造器 `条件节` 曾吃掉 `循环节` 的同名参数)——任何 函/参数/局部 之名不得与任何全局 函 之名相撞;新名先 `grep "^函 名\|函 名(" src/ runtime/` 查重。
   - `遍历` 循环变量被编译器落入**全局槽**——同一遍历变量在嵌套或递归(直接或经调用链)中会互相覆写;凡递归/可嵌套函数内的列队行走,一律用索引式 `当` 循环(局部计数器按帧隔离,已证安全)。

## ⑥ 代码风格

多文件小步提交;每 commit 附根因与回归结果;标识符可用中文;转译器与解释器同构异码,**语义细则以规范.md 为唯一事实源**,两码互抄时必须回查规范。
