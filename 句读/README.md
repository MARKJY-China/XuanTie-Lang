# 句读(judou)

> 玄铁之妹。一门回答"若计算机生于中土,程序员当如何作文"的实验性中文语言:以句读符号(「」《》。、)为语法本体,十五文言虚字为全部关键字,珠算口诀(有序"模式→动作"规则,Markov 算法之裔)为一等值与差异化之魂。

```text
「纷咇」者,诀也。
    见「甲」当「甲」余十五等于零,则「「FizzBuzz」」止。
    见「甲」当「甲」余三等于零,则「「Fizz」」止。
    见「甲」当「甲」余五等于零,则「「Buzz」」止。
    不然则「甲」止。
也
```

## 双实现,一主一锚

- **转译器**(`src/`,用玄铁写):句读 → 玄铁源码 → `xtc` → 原生二进制。不立新运行时,受、运算、口诀皆译为玄铁的函数与循环。
- **参考解释器**(`ref/解释器.py`):Python tree-walk,充当可执行规范。
- **黄金测试**(`tests/`):20 条测试双实现同跑,stdout 逐字节 diff,互为信任锚。两实现分歧即规范歧义,先改规范再改实现。

## 一分钟上手

```bash
# 在仓库根目录
python 句读/tests/run.py            # 20/20 全绿(转译器源变动时自动重建)

# 跑一个句读程序
cd 句读/build
./jdt.exe ../examples/账本.jd -o 账本.xt     # 转译
"仓库根/build/xtc_s4.exe" 铁 账本.xt -sc 账本.exe   # 玄铁编译
./账本.exe                                      # 出:结余430

# 或直接用参考解释器(无编译)
python ref/解释器.py examples/账本.jd
```

语法速览见 [规范.md](规范.md);AI 协作规约见 [CLAUDE.md](CLAUDE.md);示例五则见 [examples/](examples/)(问候世界 / 账本 / 纷咇 / 二一添作五 / 猜数字)。

## 与 wenyan 的关系

wenyan 是必须致敬的先例:最长匹配析词、「」/「「」」之辨俱自 wenyan 来。句读的差异不在词汇替换,而在连标点系统一起换掉的世界线推演:「」《》。、是语法本体而非装饰;口诀体(图灵完备的规则式编程)为所有中文先例所未有;句读转译为玄铁而非 JS。

## 已知边界(v0.1 范围锁)

不做方阵 / OOP / 并发 / 模块系统 / 底层漂移;《问》对非数词输入得文,与数比较将按【异类之失】明确报错(宁可报错,不静默)。参考解释器按规范 §七不做静态预检,静态/运行时在个别动态错型边界的报错类目可能与转译器不同(黄金测试未触及该类边界)。
