## 一、符号系统

词法器在扫描时做**全半角归一**:凡全角符号皆折为规范形(下表第一列);唯「」《》括号之内的文字原样保留(串中原样保留)。三列写法完全等价,可混用。

| 列「…」 | `[ ]` | 列字面量 / 列模式之括 |
| 《名》 | `< >` | 尊名:v0.1 仅《问》《签》《度》 |

## 二、词法

1. **括内之字**:「」《》配对而食、可相嵌;括内一切皆文字,不析虚字。
2. **文字面量之界**:「「 开,遇**配对平衡后首个独立的 」」**而阖。即:串内可含成对的「」;单个 」 后不紧跟 」 者,若当前无未阖之内层「,为文法之失。ASCII 形 `[[…]]` 同理(阖于平衡后首个 `]]`);开阖形制不得混用(「「…]] 为文法之失)。串内一切字符原样保留,不归一、不转义(句读无转义序列;换行不可入串,行内未阖之串为文法之失)。〔补〕
3. **括外之字**:逐字成词,复合词依**最长匹配**析之(此法自 wenyan 来)。
4. **数词两体,不可混书**:直书体每字一码(`一〇〇`=100,`〇`=0);命位体以十百千为位词(`一百二十三`=123,`十`=10,`二十`=20,`二百零三`=203),上限九千九百九十九,逾者为文法之失。`负` 前缀表负数。直书与命位之辨:词中有十/百/千者为命位体,否则为直书体。〔补〕直书体诸位之间不得有位词,命位体诸位之后不得再续直书数字串(如 `一〇百` 为文法之失)。
5. **饰号**:读号(,)、冒号(:)、问号(?)在**列字面量与列模式之外**一律忽略(可带语气而语义不变);在列内,ASCII 逗号 `,` 兼作顿号(全半角等价的必然结果)。〔补〕
6. **句终三形**:换行、。、;皆终一句。行末为运算符、未阖开括、顿号或续行号(……/`..`)者,次行续之。缩进不涉语法。
7. **批注**:自「批」(或 `//`、行首 `pi`)至行末皆注,词法器丢弃。
8. **名之合规**:〔补〕「」内之名限汉字、ASCII 字母数字与下划线,非空;违者文法之失。名内之字原样作标识(全半角字母不归一,即「Ａ」与「A」为两名)。〔补〕

## 三、类型与值

七枚类型词:**数**(i64 整数,默认零)、**文**(字串,默认空文)、**列**(一基有序表,默认空列)、**册**(键文值任意之簿,默认空册)、**然否**(然/否,默认否)、**空**(唯空值)、**诀**(口诀/函数,一等值,不可空立——以「名」者,诀也。声明诀型为文法之失)。

字面量:数→数词/阿拉伯数字;文→「「…」」;列→列「e1、e2、…」(元素为任意表达式,可嵌套、可空:列「」);然→然;否→否;空→空。册无字面量。

〔补〕**单元素之列**:`列「三」` 之「三」按数解;`列「甲」` 之「甲」按名解(变量引用);唯 `列「「x」」` 读作含文 x 之列(词法先试串面而得)。故「单名单元素之列」v0.1 不可书,欲书者改用他形。

### 运算语义(〔补〕处为两实现共同锁定之细则)

- **加**:数+数=数;文+任意=文(他值先化为书形,见 §六);列+列=列(相接,生新列);**其余组合一律异类之失**(含 册+任何、任何+册、数+列)。
- **减乘除余**:唯数可施,否则异类之失。除为整除,**向零取整**(C 语义:`负七除二` 得 `负三`);余之号随被除数(`负七余二` 得 `负一`)。〔补·锁语义〕除零、余零报【零除之失】(宿主玄铁除零返零,故运行时必须先守卫)。
- **等于**:同类比值;异类恒否,不报错。诀之等:同一诀体方等(名等价),不同诀体恒否。〔补〕列等:长度等且逐项等(递归);册等:键集等且逐键等。〔补〕
- **大小比较(大于/小于/不大于/不小于/不等于)**:数与数比数值;文与文比字序(按 Unicode 码位);异类相报【异类之失】。与列、册、诀比较亦异类之失。〔补〕
- **且/或/非**:唯施于然否,否则异类之失。v0.1 **两边皆求值(不短路)**。〔补〕
- **受**:甲受乙,视甲之型三解——诀→调用(乙为实参);册→查簿(乙须为文,即键;无此键得**空**,不报错〔补〕);列→索引(乙须为数;一基,越界报【逾界之失】);甲为其他型报【异类之失】。乙为册键时须为数?不——册键必文,乙非文报【异类之失】〔补〕。
- **受必取原子**:受后恒为一原子(名、字面量、尊名、列字面量);原子之后的运算符皆属外层。受之左亦为原子级(后缀链):「甲」受「乙」受「丙」读作(甲受乙)受丙。〔补〕
- **无括号之约**:句读无任何表达式成组符。优先级七级,自高至低:受应用 → 非/负 → 乘除余 → 加减 → 比较 → 且 → 或。同级左结合。欲越优先级者先纳后算。
- **负**:一元负号,施于数,否则异类之失。〔补〕语法形:`负` 后接一个乘除余级表达式(如 负「甲」乘二 读作 负(甲乘二))。〔补〕

### 内建三尊

- **《问》**:读一行于标准输入(无提示、不回显);其文合数词之则为数(阿拉伯数字串视同直书体),否则为文;输入已尽(EOF)得空文。〔补〕
- **《签》受〈数〉**:得一至该数间随机整数(闭区间)。实参非数报异类之失;小于一报【逾界之失】。〔补〕
- **《度》受〈文|列|册〉**:文得**字符数**(非字节数),列得元数,册得键数;其他型报异类之失。〔补〕

## 四、语句

语句七种。句读无 switch;模式匹配是诀之事。

1. **声明**:`「名」者,表达式也。` 或 `「名」者,型词也。`(型词:数/文/列/册/然否/空;诀不在此列)。同块重立同名者,文法之失;块内重立外名者,遮蔽外者,块终即灭。
2. **赋值**:`纳 表达式 于 目标。` 目标为「名」或应用式(`「册」受「键」` 簿位、`「列」受指` 列位)。纳于未立之名者**立之**(块内新名;计划书试一五所本);读未立之名方为虚指之失。〔补·裁定〕
3. **输出**:`书 表达式。`
4. **条件**:`若 条件 则 块`(可接若干 `不然若 条件 则 块`,可接 `不然 块`),以 `也` 阖。同行小块:`若「甲」大于三则书「「大」」也。` 块阖之词(也/不然/不然若)兼有句终之效。
5. **循环**:`循 条件 块也`(当型)/ `循「名」于 表达式 块也`(遍历,名缚逐元;表达式须为列,否则异类之失)。二形之辨在「于」字之有无。`止` 独成一句,止于最近之循(诀体内之止属规则,见 §五)。
6. **诀定义**:`「名」者,诀也。` 换行后接诀体,以语句首之 `也` 阖。v0.1 诀只立 于卷之顶层(诀体内再立诀,文法之失)〔补〕。诀名全程可见(先呼后立亦可)〔补〕。
7. **表达式语句**:一表达式独成一句(其值弃之)。

## 五、诀:二体

同以 `「名」者,诀也。` 立、同以受呼、同为一等值(可赋于名、可递于诀、可自呼递归)。二体之辨视诀体首词:**首词为见者,口诀体;余皆直述体**。

### 直述体

顺序语句。首句可 `受「甲」。` 引入唯一之参(v0.1 一诀一参,多参以列或册为之;受句不得为首句之外出现,第二受句文法之失〔补〕)。`故曰 表达式。` 断其归——返回值而诀终;无故曰者归空。诀体内赋值立**局部之名**(不写全局);读取可见卷之名。〔补〕

### 口诀体(MVP 差异化之魂)

口诀者,有序"模式→动作"规则之列表也。语义取 Markov 算法之"有序重写、递归触发"。

规则形:`见 模式 (当 条件)? , 则 动作 (止)? 。` 与末位兜底 `不然 (则)? 动作 (止)? 。`

模式四形:
- **名模式**「甲」:恒中,缚甲为入值;
- **数模式**(数词/数字):值为数且全等则中;
- **文模式**「「x」」:值为文且含 x 则中(最左);无未阖内层之单「」不得入模式〔补〕;
- **列模式**列「…」:值为列、元数相等且逐项配之则中;项为名(恒中而缚其元)或字面量(数/文,全等则中)〔补〕。

执行语义(一页纸):以「名」受〈值〉呼诀,入值为 v。
① 自上而下逐条试配;带**当**者配中后求其条件,须为**然**,不然此规则不中、续试下条;
② 首中规则之动作求值得 v′——规则带**止**者 v′ 即为诀之出(终止规则);不带止者:名/数/列模式**更新** v(整值代之),文模式**置换** v(以 v′ 化书形,置入最左命中处)〔补〕,然后**复自第一条试配**(递归触发);
③ 无规则可配,v 即为出;
④ 递归触发逾一万次报【循环之失】(报于口诀**定义**之行)——算盘有档,口诀有穷。规则缚名为逐呼一域、跨规则共享(后规则重缚同名即改其值,兜底规则得见先生之缚)。〔补〕
不然规则恒中、必居末位;不然之后再有规则,或不然缺席且诸规则皆可能不中,皆合法(③ 兜底)。〔补〕不然带「当」者为文法之失。

**两枢机不变**:受必取原子;也字两处不相混(声明句内之也随声明而阖,块终之也独居语句之首,也永不作表达式首词)。

## 六、书形化与输出

`书 表达式` 打印其值之书形,后随换行。书形〔补·锁格式〕:
- 数:十进制,负数冠 `-`(如 `42`、`-7`);
- 文:原样;
- 然否:`然` / `否`;
- 空:`空`;
- 列:`列「` + 各元书形以 `、` 相连 + `」`,空列为 `列「」`;
- 册:`册(〈键数〉键)`(如 `册(2键)`;v0.1 不展开键值,避遍历序之争);
- 诀:`诀「名」`(匿名诀无此形,v0.1 诀皆有名)。

## 七、错误诊断

诊断全中文且结构化,每条含**类目/卷名/行号/原文**四字段,机器易解析:

```
【类目】卷「卷名」第N行:消息。
　原文行
　～～…(每字一～)　提示(可选)
```

行号 N 用汉字数词(第十二行);消息内之数字用阿拉伯数字〔补〕。错误经标准输出打印,进程以退出码一终(参考解释器同)。类目六枚:
`文法之失`(语法/词法错)、`虚指之失`(用未立之名)、`异类之失`(型不合)、`零除之失`、`循环之失`(口诀逾万)、`逾界之失`(列越界/签无域)。

卷名 = 源文件名去扩展名。〔补〕编译期(转译器)与运行期错误同格式;运行期错误之原文行 = 违错语句所在源行(诀体内者即诀体行)。

〔补〕**静态检查三事**(转译器为之,参考解释器不预检、运行时逢错方报):虚指预检、故曰越诀(文法之失)、不然不在末位(仅警告,入标准错误流,不入比对)。受之实参位的裸名解析见 §八.3。

## 八、转译契约

1. 生成玄铁源码,首行 `引 "../runtime/jd_runtime.xt"`,故**生成物恒居 `句读/build/`**。
2. 句读名映射玄铁标识符:一律加前缀 `jd_`(避关键字与内建撞名;「jd_甲」之名映射 jd_jd_甲,仍唯一)。
3. **受之实参位的裸名**(「甲」受「乙」之乙):收者静态已知为册→键文直书(不查虚指);名已立→双态盒(收者运行时为册则作键,否则作变量值);名未立且收者非册→虚指之失。收者静态型取声明初型(声明时所书型词或初值之显然型),赋值不改其标。〔补〕
4. 每一可错之运行时调用,皆以字面行号为参(不设全局行号)。卷名由生成物顶层一次性赋入运行时全局。
5. 宿主缺陷规避:凡调字段所存之诀,必先存局部变量再呼(玄铁 `对象.字段(实参)` 直呼有误,见仓库报告)。
