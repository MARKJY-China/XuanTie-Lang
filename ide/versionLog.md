# 玄铁铸造厂版本史(versionLog)

玄铁铸造厂 SemVer 框架:`主版本.次版本.修订号`。

- 主版本:产品里程碑(如"用玄铁 UI 库重构铸造厂"即为 v1 的门槛)。
- 次版本:功能集更新(v0.1 基础壳 → v0.2 → v0.3 控件设计器 …)。
- 修订号:向后兼容缺陷修复/小更新。

对标关系:铸造厂版本独立演进,不随玄铁语言版本号走;每个版本条目注明当轮实测对标的玄铁工具链状态。

## v0.2.0 (2026-09-30)

界面工程化版本。在 v0.1 壳的基础上完成:全面中文本地化、codicon 图标体系、文件树三态显示、
自绘一体化标题栏、完整菜单栏(文件/编辑/查看/编译/终端/帮助)、编译产物管理。
本轮对标玄铁 v1.0.0 工具链(编译器:自举链 s3;xt_lsp:s3 构建,md5 655343d4)。

#### 本地化与图标

- **Monaco 内置 UI 中文化**:vite 插件把 monaco 内部对 `vs/nls.js` 的全部解析重定向到自有 shim
  (`src/monaco/nls-zh.ts` + 映射表 `nls-zh-table.ts`),同签名实现 localize/localize2,
  英文默认值精确查表、查不到回落英文(monaco 升级不会崩,只缺翻译)。覆盖查找替换/补全/悬停/
  快速修复/右键菜单/F1 命令面板/问题导航/折叠/注释/多光标/重命名/格式化/缩进/颜色选择器/
  Unicode 对话框/粘滞滚动等全部可见面;键名经校验脚本逐一回查 monaco 语料,错字为零。
- **全面去 Emoji**:图标一律 `@vscode/codicons`(MIT);`.xt` 文件用 VSIX 同款玄铁图标;
  `玄铁.配置.toml` 用橙色齿轮,普通 toml 灰齿轮;新增图标一律先核实类名存在。
- **WebView2 原生右键菜单**(英文)在非编辑器/非输入框区域禁用。

#### 文件树

- **眼睛三态显示**(持久化):完全显示 → 半显示(仅认准类型原位,其余淡化并整组折叠到树尾,
  组内显示相对路径)→ 不显示(仅认准类型)。修复根层文件绕过过滤的缺陷(此前只有目录子项被滤)。
- **build 目录豁免**:工程 `build\` 内的构建产物在任何模式下都原位正常显示,不隐藏不折叠。
- **编译完成自动刷新文件树**:编译进程退出(含失败)即重载,新产物立即可见。
- 右键新增复制相对路径/复制完整路径;空白区域右键新建文件/文件夹/刷新。

#### 壳与菜单

- **自绘一体化标题栏**:`decorations:false`,工具栏与窗口控制(最小化/最大化还原/关闭)合一,
  拖拽与双击最大化走 drag-region;权限在 capabilities 显式声明;左上角仅一枚玄铁图标。
- **菜单栏六项**:文件(打开/新建工程/保存/全部保存/刷新)、编辑(撤销/重做/查找/替换/行注释)、
  查看(切换终端面板 Ctrl+`、切换文件树侧栏)、编译(当前文件 Ctrl+Shift+B / 整个项目,产物统一
  入 工程build 目录,位置可在设置自定义)、终端(新建 Ctrl+Shift+` / 清空 / 关闭会话)、
  帮助(官方文档 xt.markjy.com / 关于:版本·版权·开源仓库·当前 XTC 版本)。
- **设置弹窗**:主标题 + 小字副标题(工具链路径留空则按 PATH 自动探测),编译产物目录可配;
  全 UI 去除"——"拼接式标题。

#### 编辑器能力

- **大纲静态兜底**:documentSymbol 在 LSP 失败/超时/离线时回落逐行静态提取(函/型/口/设/常,
  含异步标记),大纲不再依赖 LSP 存活;completion/hover/documentSymbol 失败改 console.error
  留痕(此前静默吞错);release 启用 devtools(Ctrl+Shift+I)便于现场排障。

#### 修复(实测踩到,详见 NOTES.md)

- **握手自锁**:request 守卫早于 connected 置位 → LSP 秒失败 + xt_lsp 僵尸进程。
- **GUI 弹常驻 CMD 窗**:CREATE_NO_WINDOW 压掉(xt_lsp / xtc 探测)。
- **发行构建产出开发壳**:custom-protocol feature 固化,裸 cargo release 禁止分发。

## v0.1 (2026-09-30)

首个原型版。定位:玄铁自研 UI 库成熟之前,用成熟技术栈给现有玄铁工具链(xt_lsp / xtc / tiepm)
做一个"极致轻量+顺滑"的原生壳 —— Tauri 2 + Monaco + xterm.js,零前端框架。
本轮对标玄铁 v1.0.0 工具链(编译器:自举链 s3;xt_lsp:s3 构建,md5 655343d4)。

#### 功能范围(与 ide/AGENTS.md 的 v0.1 纪律一致)

- **文件树**:目录全量加载(限深限量),右键新建文件/文件夹、重命名、删除(回收站);`.xt` 高亮标识。
- **Monaco 编辑器**:Monarch 玄铁语法(关键字/类型/内置空间/字符串插值 `#{}`/三引号)与暗色主题;
  LSP 全家桶 —— 补全(拼音筛选,含多音字)、悬停、跳定义(Ctrl+点击 / F12)、大纲、
  实时诊断(解析级)+ 保存级语义诊断(xt_lsp 调 `xtc 铁 --检查`)。
- **一键运行**:先探测 `xtc -h` 是否支持 `pao`,支持则一步式;否则自动回退
  `tie -sc <应用缓存目录> → 运行产物`(PowerShell 串联,退出码判断);运行走独立终端会话,可交互、可停止。
- **内嵌终端**:ConPTY + xterm.js 多会话;运行/铁铺会话**直连程序不经 shell**(绕开 PowerShell 引号语义)。
- **铁铺入口**:安装(az)/搜索(ss)/列出(lc)/清理(ql),进终端会话执行。
- **新建工程模板**:控制台示例 / 空白工程;生成 `玄铁.配置.toml`(`[项目] 入口`)+ `主.xt`。
- **设置**:xt_lsp / xtc / tiepm 三件套路径;解析链 = 设置 → PATH → 工作区 `lsp\` → xtc 同目录
  → xtc 上 1-2 级 `lsp\`(自建工程靠 xtc 锚定兜底);LSP 连接/重连后对已打开文档补发 didOpen。

#### 后端(Rust / Tauri 2)

- 文件系统命令:树限深 24 层限量 2 万条、删除走回收站(trash crate)、非 UTF-8 拒读、重命名/创建前冲突检查。
- xt_lsp 进程桥:stdio Content-Length 分帧双向转发(对齐 lsp/xt_lsp.xt 帧协议),stderr 转日志事件。
- PTY 会话管理:portable-pty(ConPTY),读线程/等待线程分离,kill 走 ChildKiller 克隆。
- 工具定位:PATH 纯扫描(不经 where.exe,免 GBK 乱码);pao 能力探测;设置持久化(应用配置目录)。
- 工程脚手架:非法名/已存在硬报错,模板名未知即回滚半成品目录。

#### 本轮修复(实测踩到)

- **握手自锁**:`request()` 守卫要求已连接,而 `connected` 在 initialize 应答后才置位 →
  LSP 秒失败、xt_lsp 成常驻僵尸;现握手期放行 + 失败时清理进程与监听。
- **GUI 弹常驻 CMD 窗**:无控制台进程拉起控制台子系统子进程(xt_lsp / `xtc -h` 探测)未加
  `CREATE_NO_WINDOW`;现全部压掉。
- **发行构建产出开发壳**:裸 `cargo build --release` 不内嵌前端资源,WebView 连 localhost:5173 白屏;
  `custom-protocol` feature 已固化进 Cargo.toml 并写入 README/AGENTS 纪律。

#### 界面全面汉化(本轮)

- **Monaco 内置 UI 中文化**:vite 插件把 monaco 内部对 `vs/nls.js` 的全部解析重定向到自有 shim
  (`src/monaco/nls-zh.ts` + 480 键映射表 `nls-zh-table.ts`),同签名实现 localize/localize2,
  英文默认值精确查表、查不到回落英文(monaco 升级不会崩,只缺翻译)。
- 覆盖:查找替换、补全建议、悬停、快速修复、右键菜单、F1 命令面板、问题导航、折叠、注释、
  多光标、重命名、格式化、缩进、颜色选择器、Unicode 高亮对话框、粘滞滚动、行跳转等全部可见面;
  覆盖率校验脚本对表键逐一回查 monaco 语料(temp/check_nls_coverage.mjs),键名错字为零。
- 范围外(不翻,见表头声明):主题色描述、纯无障碍(screen reader)长文、上下文键调试描述。
- **WebView2 原生右键菜单**(英文)在非编辑器/非输入框区域一律禁用(编辑器自带中文菜单不受影响)。

#### 界面工程化(本轮)

- **全面去 Emoji**:图标一律 `@vscode/codicons`(MIT,与 Monaco 视觉同源);`.xt` 文件使用
  VSIX 同款玄铁图标(`extensions/xuantie-syntax/icon.ico`);写入 AGENTS.md 永久纪律。
- **文件树升级**:`.exe`/无后缀等二进制构建产物默认隐藏(设置可关,关闭后原位淡化显示);
  其他未知文本文件整组折叠为"其他文件 (N)"并淡化;md/txt/toml/json 等配专属图标。
- **文件树右键**:新增复制相对路径/复制完整路径;空白区域右键可新建文件/新建文件夹/刷新。
- **VSCode 式菜单栏**:「文件」(打开文件夹/新建工程/保存/全部保存/刷新文件树)与
  「编辑」(撤销/重做/查找/替换/切换行注释)只放铸造厂支持的功能,不做摆设项。
- **设置弹窗改版**:主标题 + 小字副标题(工具链路径留空则按 PATH 自动探测),新增
  "隐藏构建产物与二进制文件"开关;全 UI 去除"——"拼接式标题。

#### 标题栏与文件树三态(本轮)

- **自绘一体化标题栏**:窗口 `decorations:false`,工具栏与窗口控制按钮(最小化/最大化还原/关闭,
  VSCode 式悬停变红)合并为一栏;`data-tauri-drag-region` 支持拖拽与双击最大化;
  权限在 capabilities 显式声明。左上角仅保留一枚玄铁图标,无文字 Logo。
- **文件树眼睛按钮三态**(替代设置弹窗里的旧开关,状态持久化):
  完全显示(全部原位正常亮度)→ 半显示(仅认准类型原位,其余淡化并整组折叠到整个树末尾,
  组内显示相对路径)→ 不显示(仅渲染认准类型)。图标 eye/preview/eye-closed 随态切换。
  修复:根层文件此前绕过过滤(只有目录子项被滤),三态在根级不生效;已同规则过滤。
- **`玄铁.配置.toml` 专属图标**:同 toml 齿轮但橙色着色,与普通 toml 区分。
- **菜单栏扩至四个**:新增「终端」(新建终端 Ctrl+Shift+` / 清空当前终端 / 关闭当前会话)
  与「帮助」(官方文档 xt.markjy.com 经 opener 插件打开 / 关于铸造厂:版本·版权·开源仓库·
  当前 XTC 版本,读取 `xtc -h` 首行)。
- **大纲静态兜底与请求排障**:documentSymbol 在 LSP 失败/超时/离线时回落到逐行静态提取
  (函/型/口/设/常,含异步标记),大纲不再依赖 LSP 存活;completion/hover/documentSymbol
  失败改为 console.error 留痕(此前静默吞错,违反报错优于静默);release 启用 devtools
  (Ctrl+Shift+I)便于现场排障。
- **「编译」菜单**:编译当前文件(Ctrl+Shift+B)与编译整个项目(按 玄铁.配置.toml 的
  [项目] 入口);产物统一写入 工程文件夹\build(编译前自动建目录),目录可在设置里自定义
  (留空 = 默认位置);编译走 `xtc tie <源> -sc <build>\<名>.exe`,输出进独立终端会话。
- **「查看」菜单**:切换终端面板(Ctrl+`)与文件树侧栏的开/关。

#### 已知限制

- 字符串插值 `#{…}` 内的引用 hover/跳定义失效 —— xt_lsp 源码级限制(词法扫描不进插值体),与 IDE 无关。
- `xtc pao` 截至本轮不存在于任何已构建二进制(仅工作区源码),IDE 已内置探测+回退,将来自动切换。
- NSIS 安装包依赖 github 下载(当前网络不通);以 release exe 直发替代。
