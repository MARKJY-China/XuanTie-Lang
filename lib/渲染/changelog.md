# 渲染库 Changelog

## v1.1.0

**新增**

- **GDI 系统字体渲染**:`加载系统字体("微软雅黑", 字号)`——Windows 系统级光栅化(`GetGlyphOutlineW` 65 级灰阶),视觉效果与系统应用同级;**无需 ttf 文件**(直接用系统字体名),生僻字由系统字体引擎自动回落;按需栅格化 + 2048² 动态图集缓存(4px 间隔防双线性渗色),多字号独立缓存,启动零成本。句柄与 `绘字体文字`/`量字体文字`/`释字体` 完全通用(句柄 ≥100 自动分派)。
- **截图**:`截图("文件名.png")`——当前帧缓冲导出 PNG(须在 `结束绘图()` 之后调用;路径为相对路径,raylib 会拼到工作目录前)。渲染调试与自动化验收用。

**变更**

- 字体渲染回滚至原始位图管线(移除 v1.0.1 引入的 SDF 距离场与 .xtfc 磁盘缓存):无平滑预处理的原始光栅化,2 万全 CJK 字形构建成本大幅降低。需要系统级观感的中文界面请改用 `加载系统字体`。

**修复**

- GDI 灰阶模式常量误用(`GGO_GRAY8_BITMAP` 应为 6,曾误写 5=GRAY4 的 17 级粗量化)导致字形粗大、边缘台阶感。

## v1.0.1

**新增**

- 窗口三模式运行时切换:`设窗口可调整`/`设窗口无边框`/`设窗口全屏`/`窗口全屏?()`/`设窗口尺寸`——全部运行时可随时切,非初始化固定。可调整与无边框走 Win32 样式直改(GetWindowLongPtr/SetWindowLongPtr+FRAMECHANGED;raylib SetWindowState 对本后端运行时不生效),无边框还原时按当前可调整状态恢复厚边框。
- `设ESC关闭(真/假)`:ESC 退出键开关(默认开,raylib 惯例)。
- 补齐手册已列但缺失的封装:`窗口就绪?`/`设置目标帧率`/`取帧率`/`取帧时间`/`设置窗口标题`/`绘三角`/`绘多边形`/`绘纹理Ex`/`取鼠标滚轮`/`取运行时间`/`暂停` + 音频全套(`初始化音频`/`关闭音频`/`加载音效`/`播音效`/`释音效`/`加载音乐流`/`播音乐流`/`更新音乐流`/`停音乐流`/`释音乐流`);键字母常量补 `键B`/`键C`/`键E`。
- 改名对齐手册:`屏宽`→`取屏幕宽`、`屏高`→`取屏幕高`、`键刚按?`→`键刚按下?`、`获按键`→`取按键`、`鼠按下?`→`鼠标按下?`、`鼠刚按?`→`鼠标刚按下?`、`随机`→`取随机数`、常量 `键左移/键右移`→`键左Shift/键右Shift`;`等待` 是语言关键字,封装定名 `暂停`;`鼠X/鼠Y` 与 `鼠左键/鼠右键/鼠中键` 保留实际名(手册已改对齐)。
- 圆角矩形桥接：`绘圆角矩形(x,y,宽,高,圆角百分,...)`、`绘圆角矩形线(...,线宽,...)`(圆角百分 0-100,线宽像素)。
- Unicode 字符输入桥接：`获字符()`(文本输入框地基;中文 IME 上屏字符可收到,无候选框跟随)。
- 包内置 `libraylib.a` 与 `raylib.h`:经铁铺安装后任意目录可编译渲染程序,不再需要 `C:\raylib`。

**修复**

- 字体/纹理加载支持中文路径:宽字符读文件 + 内存加载(LoadFontFromMemory/LoadImageFromMemory),铁铺安装目录(含中文「已安装」)下不再 `Failed to open`。
- 字体加载字符集扩充:新增拉丁补充(含间隔号「·」)、通用标点(引号/破折号/省略号)、CJK 全角标点(U+3000-303F),常用符号不再显示为「?」。

## v1.0.0

- 首个铁铺发布版:窗口管理、图形绘制、文字、纹理、音频、输入处理等基础能力(基于 raylib)。
