# 渲染库 Changelog

## v1.0.1

**新增**

- 圆角矩形桥接：`绘圆角矩形(x,y,宽,高,圆角百分,...)`、`绘圆角矩形线(...,线宽,...)`(圆角百分 0-100,线宽像素)。
- Unicode 字符输入桥接：`获字符()`(文本输入框地基;中文 IME 上屏字符可收到,无候选框跟随)。
- 包内置 `libraylib.a` 与 `raylib.h`:经铁铺安装后任意目录可编译渲染程序,不再需要 `C:\raylib`。

**修复**

- 字体/纹理加载支持中文路径:宽字符读文件 + 内存加载(LoadFontFromMemory/LoadImageFromMemory),铁铺安装目录(含中文「已安装」)下不再 `Failed to open`。
- 字体加载字符集扩充:新增拉丁补充(含间隔号「·」)、通用标点(引号/破折号/省略号)、CJK 全角标点(U+3000-303F),常用符号不再显示为「?」。

## v1.0.0

- 首个铁铺发布版:窗口管理、图形绘制、文字、纹理、音频、输入处理等基础能力(基于 raylib)。
