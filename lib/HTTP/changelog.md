# HTTP 库 Changelog

## v1.0.1

- **安全默认:监听仅本机。** `服务(端口, 处理函)` 现在只绑 `127.0.0.1`。此前它经 `听` 绑 `INADDR_ANY`,等于随手一跑就对整个局域网开门——且默认值不可见,没人会去审计。**需要对外提供服务请改用新增的 `服务绑定`。**
- 新增 `服务绑定(端口, 处理函, 绑定地址)`:显式指定监听地址(`"0.0.0.0"` 对外、`"192.168.1.10"` 只绑某块网卡)。
- `服务` / `服务绑定` 现在**返回 `听` 的结果容器**:端口被占或地址非法时可用 `?` 或 `.成功` 检出,不再静默失败(此前 `服务` 丢弃返回值,起不来也没人说)。

## v1.0.0

- 首个版本:`服务(端口, 处理函)` 启动 HTTP/1.1 监听;处理函收请求字典 `{"方法","路径","查询","头","体"}`,返响应字典 `{"状态码","头","体"}`(均可缺省,默认 200)。
- 每连接一请求一响应(Connection: close,无 keep-alive);请求体按 Content-Length 收齐。
- 纯玄铁实现,基于 听/连 原语。
- 依赖 XTC 修复后的 分割(字面子串切分,保留空段);旧版 strtok 语义(丢空段、多字符分隔按字符集)下本库行为未验证。
