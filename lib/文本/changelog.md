# 文本库更新日志

- `tiepm.toml` 简介补充英文名 `XuanTieStrings`，供铁铺 `ss` 按简介检索
- 库 API、行为与 v1.0.0 完全一致

## v1.0.0 (2026-11-08)

首个版本。纯玄铁实现，按**字符**计数，不依赖 C 运行时新函数。

- 填充与对齐：`填充左`/`填充右`/`居中`（填充串可多字符）
- 截断：`截断`（含省略号宽度，超长才截）
- 统计：`计数`（不重叠）、`行数`、`取行`（兼容 CRLF）、`词数`
- 切分：`去前缀`/`去后缀`、`切分首`/`切分尾`（返回两段数组）
- 命名风格：`首字大写`/`首字小写`、`到驼峰`/`到蛇形`/`到中划线`/`到标题`
- 变换：`反转`、`字符数组`、`去全部空白`、`压缩空白`、`缩进`、`去缩进`
- 模板：`模板`（`{键}` 占位、`{{`/`}}` 转义、未知键原样保留）
- 判定：`空白?`、`数字?`、`回文?`、`包含任一?`
- 配套黄金测试：`Test/178_文本库.xt`
