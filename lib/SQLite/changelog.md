# SQLite 库更新日志

## v1.0.0 (2026-10-06)

首个版本。

- 连接：`打开`(支持 `:memory:` 内存库)/`关闭`(幂等)/`错误消息`；连接句柄 ARC 回收自动关闭（`sqlite3_close_v2`),busy 超时 5 秒
- 执行：`执行`/`执行带参`(`?` 位置参数绑定，防注入；参数类型 整/小数/字/字节/布尔/空）
- 查询：`查询`/`查询带参`，行集为 `数组<字典>`；列值映射 INTEGER→整 / FLOAT→小数 / TEXT→字 / BLOB→字节 / NULL→空
- 事务：`开始事务`(BEGIN IMMEDIATE)/`提交事务`/`回滚事务`
- 全部 API 返回 `结果` 容器，错误路径不炸程序
- 包内置 sqlite3.o(3.50.4 amalgamation）与 SQLite桥.o，经 tiepm.toml `[原生]` 对象机制链接——该机制的首个用例（渲染桥特判的通用化）
- 配套黄金测试：`Test/155_SQLite数据库.xt`(30 断言）
