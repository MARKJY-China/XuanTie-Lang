# UI 库 Changelog

## v1.7.0

**新增**

- **缺字监测**：新 API `缺字(文本)` 返回当前字体缺字形的字符；`缺字集()` 返回启动以来累计缺字；`设缺字检查(假)` 可关自动检查。渲染 `文本` / `按钮` / `输入栏` / `多行编辑` 前会自动逐字检查，缺字按（字体,码点）只报一次（stderr 打出字符与码点），并汇总进 `缺字集()`——不再像以前那样只看到方框却不知道为什么。依赖渲染库 v1.3.8（`字体有字形?` / `字符码点`）。
- **内置图标集**：内嵌 2359 个 Lucide 图标（v1.73.0，ISC 许可，数据在 `图标表.xt`，编译进程序、运行期不依赖外部文件）。新控件 `UI.图标(名字, 选项)`（默认 24×24、按 `图标色` 着色），`UI.图标按钮("search")` 也直接认图标名；`UI.图标名()` 列出全部名字。自定义图标仍可传 `.svg`/`.png` 路径。
  常用名：`search` / `menu` / `more-horizontal` / `settings` / `x` / `plus` / `trash-2` / `send` / `user` / `message-circle` / `arrow-left` / `chevron-down` / `check` / `copy` / `refresh-cw`。

```text
UI.图标("more-horizontal", {"图标色": UI.色彩["浅灰"], "图标尺寸": 20})
UI.图标按钮("search", {"点击": 函() { }})
```

**文档**

- 新增 `GUIDE/UI/图标.md`、`GUIDE/UI/缺字.md`；图标许可见 `lib/UI/assets/icons/LICENSE-lucide.txt`。

## v1.6.0

**修复**

- **容器子项被内边距偏移两次**：`布主轴` 初始化主轴位置时又加了内容区起点（`始X/始Y`），而 `计算布局` 调用时已经加过一次。结果：任何带 `内边距` 的行/列，子项都多缩进一个内边距，左侧列表项、标题栏对不齐。现在主轴位置从 0 起算，子项落在内容区左上角。
- **直角边框的 `边框宽` 不生效**：渲染用的 `R.绘矩形线` 是 raylib 固定 1px 的接口，`边框宽` >1 时画出来仍是细线。直角实线边框改由四条实心矩形按 `边框宽` 拼画。
- **三态色此前只对按钮/图标按钮生效**：`悬底色`/`按底色`/`悬字色`/`按字色`/`悬边色`/`按边色`/`禁底色`/`禁字色` 存在节点上，但渲染只有按钮分支读；行/列/文本/矩形等配了也没有任何效果。现在渲染统一走状态色解析（禁用 > 按下 > 悬浮 > 常态），所有节点都吃这些键；状态子字典里的 `圆角` 也参与渲染。

**新增**

- **三态色全节点可用**：列表项可写 `{"底色": 常态, "悬底色": 悬浮色, "按底色": 按下色, "点击": 函() {…}}`，不再需要用按钮模拟整行。
- **长名别名**：`悬浮底色` / `按下底色` / `悬浮字色` / `按下字色` / `禁用底色` / `禁用字色` 与短名等价（先吃长名，短名优先）。
- **文本换行/截断**：`换行`（需显式 `宽`）、`行数限制`（超出部分用 `…` 收尾）、`截断`（单行末尾省略号）；换行文本的固有高按行数计算，行/列容器能正确占位。
- **边框样式**：`边框样式: "实线"/"虚线"`（虚线仅直角矩形，6px 实 + 4px 空）。

**文档**

- 更新 `悬底色` / `按底色` / `悬字色` / `按字色` / `边框宽` / `点击`，新增 `换行` / `行数限制` / `截断` / `边框样式` 选项页。

## v1.5.7

**新增**

- **`字叉对齐`（文本控件垂直对齐）**：`字对齐` 只管水平，文字原先永远贴盒顶。新增 `字叉对齐`，取值 `UI.对齐始`（默认，贴顶）/ `UI.对齐中`（垂直居中）/ `UI.对齐末`（贴底），盒比文字高时才看得出效果。字形箱高按 `字号` 计（与按钮文字居中同一口径）。

```text
UI.文本("垂直居中", {"宽": 300, "高": 80, "字叉对齐": UI.对齐中})
```

**文档**

- 新增 `GUIDE/UI/选项键/字叉对齐.md`；`字对齐.md` 补「只管水平」的说明与相关链接。
## v1.5.6

**修复**

- **按钮文字垂直居中偏上**（issue #90）：居中用的字高原按 `字号×7/5` 经验估算，比真实字形箱高大 → `(内容高-字高)/2` 偏小 → 文字被推向顶部。现改用真实箱高（绘字体文字精 的 y 即字形箱左上角，箱高=字号）。
- **`字库字号` 不再要求应用层换算**（issue #91）：字形栅格化分辨率属渲染实现细节。默认值改为按屏幕 HiDPI 自动抬升（1x=32、2x=64、3x=96），`应用`/`设字体`/内置字体三处统一走 `默认字库字号()`；仍可显式指定（高级用法）。

**文档**

- `12_UI库编程指南.md`：`字库字号` 默认值与换算规则（`字库字号 ≥ 界面最大字号 × HiDPI 系数`）写清。

## v1.5.3

**修复**

- **布主轴不再覆盖锚点宽高**:行/列 尾部原先无条件用固有尺寸(子项之和)覆盖 `_布w/_布h`,双锚拉伸的容器宽度被「最宽子项」固有宽覆盖(实测面板 w=2186 远超窗口);现锚已定轴的尺寸保留,仅无锚轴取固有,显式 宽/高 仍最后兜底。
- **叉撑支持收缩**:`叉轴对齐 = 叉撑` 原实现只增不减,固有尺寸超宽的子孙仍撑破父容器;现双向对齐可用空间,并给子项打轴标记——该轴最终矩形服从槽位(叶节点固有尺寸与容器固有尾写均不再覆盖),实测面板内子行 w 从 2146 收敛到面板内容宽 843。子项显式设了叉轴尺寸(宽/高)则尊重之;锚定轴仍由锚定矩形决定。
- **带点击回调的节点命中即消费**:`点击`/`按住` 模式命中后原先仍返 空,命中判定继续下沉到兄弟节点——模态遮罩(矩形+空 `点击` 回调)盖住界面后点击仍穿透到下层按钮/输入栏。现指针在带 `点击` 回调(含空回调)的节点内即消费命中;禁用节点维持点击穿透旧语义。

**新增**

## v1.5.1

**新增**

**修复**

- **键盘事件大面积丢失**(按需重绘引入):帧首第二泵与 结束绘图 内泵形成双泵,raylib 每次 PollInputEvents 清空字符/键队列,上一泵注册的字符/键边沿在帧体读取前即被清掉——打字/退格/方向键/IME 上屏/Ctrl+V 约 99% 丢失。改为单泵纪律:脏帧只走 结束绘图 经典泵(与裸 60fps 循环同构),仅空闲周期帧首补泵。
- **不透明度内部键名与解析器推导不一致**(`_不透明` vs `_不透明度`)导致字典缺键静默返 空、整树 alpha 清零(全空白窗口)。内部键统一为 `_不透明度`,全部解析键已与 造节点 默认值逐一对账。

## v1.2.0

**新增**

- **输入栏控件**:`UI.输入栏(状态, 键, 选项)`——单行文本输入框,值双向绑定状态容器。占位文本、点击定位光标、左键拖动框选、退格/方向键按住连发、上/下跳到首/尾、Ctrl+A/C/V/X、回车提交回调、中文 IME 内联组合(拼音直接显示在栏内带下划线)+ 候选窗跟随光标(贴输入栏底边)、长文本横向滚动保持光标可见。
- **输入栏图标**:`左图标`/`右图标` 图片路径(png/jpg/bmp/gif,`.svg` 自动走 nanosvg 光栅化),`图标尺寸`(0=自动取栏内净高)/`图标距`/`图标色` tint,`右图标点击` 回调(一键清空等;命中不挪光标不进框选)。文本区自动内缩,长文本滚动被裁剪在文本区内、永不遮挡图标。
- **输入栏样式参数**:`占位色`/`焦框宽`/`字距`。
- **通用外观选项**(全控件可用):`底色2` + `渐变向`("横"/"竖")渐变背景、`羽化`(边缘柔边)、`阴影`({"颜色"/"模糊"/"x"/"y"})、`字距`。渐变/羽化由渲染库圆角渐变纹理生成器驱动。

**修复**

- `框色`(默认边框色)选项此前从未写入生效字段,非聚焦边框实际不绘制;现在聚焦画 焦框色/焦框宽、非聚焦画 框色/边框宽。
- 字距对 GDI 系统字体通路生效(渲染库 v1.2.0 联动:此前 spacing 仅 raylib 字体通路生效)。

## v1.1.0

**变更**

- **默认字体改 GDI 系统字体优先**(渲染库 v1.1.0 联动):`确保默认字体` 现在优先 `R.加载系统字体("微软雅黑", 32)`——Windows 系统级灰阶抗锯齿、按需栅格化、无需 ttf 文件;失败回退内置鸿蒙 ttf,再失败回退 raylib 默认字体。中文界面开箱即系统级观感。

**新增**

- 内置字体查找新增 `XUANTIE_HOME` 环境变量候选(安装器写入,指向安装目录):发行包用户的程序在任意目录运行都能定位 `lib\UI\assets` 资源。
