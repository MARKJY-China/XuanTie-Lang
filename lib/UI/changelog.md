# UI 库 Changelog

## v1.0.1

**新增**

- **默认鸿蒙字体零配置中文**:未显式指定字体时自动按候选路径加载内置 HarmonyOS Sans(铁铺包内 assets → 程序自身目录 assets → CWD assets),任意目录下中文即开即显;`设字体`/`应用` 选项显式指定优先。
- **按钮三态主题**:常态/悬浮/按下三态配色与圆角(默认圆角 8px、悬浮微亮、按下微暗)。
- 文字三态色:`悬字色`/`按字色` 选项(默认透明,沿用常态 `字色`)。
- **触发模式**:`触发` 选项三模式——`"点击"`(默认,按下并在按钮内松开才触发)、`"按下"`(按下即发)、`"按住"`(按住连发);`连发间隔`(默认 50ms,0=每帧)与 `首按延迟`(按住超时才开始连发;点击按钮设了它即成"单击+长按连发"两用钮)。
- **绝对布局容器** `UI.绝对(子列表, 选项)`:子项按 `x`/`y` 选项相对容器内容区左上角直摆,跳过 flex 计算;容器自身照常参与父级 flex、支持 `底色`/`圆角`/`内边距`。注意不裁剪(越界子项画出容器外)、无锚点(窗口缩放不重排)。
- **禁用态**:`禁用` 选项(真时不吃悬浮/点击),`禁底色`/`禁字色` 选项(默认灰)。
- `UI.色16("#RRGGBB")`:十六进制颜色,支持 8 位带透明度与省略 `#`;非法输入返品红示警。
- 新增 `assets/HarmonyOS_Sans_SC_Regular.ttf` 随包分发(华为公开发布,免费可商用)。

**改动**

- 背景色三态选项更名为 `底色`/`悬底色`/`按底色`(原 `景色`/`悬景色`/`按下色`),确立「X底色/X字色」状态命名约定,后续 `焦底色` 等照此扩展。
- 「点击」语义修正:由"按下即发"改为"按下且在按钮内松开才触发"(原行为由 `"按下"` 模式保留)。

**修复**

- 嵌套容器固有尺寸塌缩:`量固有` 对容器一律返回 [0,0],导致 行/列 嵌套时整行重叠;已改为递归测量(行=主轴求和+间距/叉轴取最大,列反之,叠=子项最大外包,绝对=坐标+尺寸外包)。
- 按下态曾不生效:鼠标桥接返回值归一化(`且` 对整数 1 判假);叠加解析器赋值优先级 bug(`X = A 且 B` 错解析,XTC 侧已修)。
- 启动体验:环境变量探测改走免子进程 API(消除黑色终端窗口闪烁);窗口首帧先出背景(消除白窗无响应感)。
- 修复帧循环内 `_渲染栈` 赋值泄漏的暴露路径(根治在 XTC 编译器侧:赋值语句表达式引用释放)。

## v1.0.0

- 首个铁铺发布版:FlexBox 布局引擎(行/列/叠/弹性)+ 文本/按钮/矩形基础控件 + 响应式状态管理(造状态/态取/态设/态观等)+ 应用/刷新双模式。
