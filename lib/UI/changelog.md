# UI 库 Changelog

## v1.5.3

**修复**

- **布主轴不再覆盖锚点宽高**:行/列 尾部原先无条件用固有尺寸(子项之和)覆盖 `_布w/_布h`,双锚拉伸的容器宽度被「最宽子项」固有宽覆盖(实测面板 w=2186 远超窗口);现锚已定轴的尺寸保留,仅无锚轴取固有,显式 宽/高 仍最后兜底。
- **叉撑支持收缩**:`叉轴对齐 = 叉撑` 原实现只增不减,固有尺寸超宽的子孙仍撑破父容器;现双向对齐可用空间,并给子项打轴标记——该轴最终矩形服从槽位(叶节点固有尺寸与容器固有尾写均不再覆盖),实测面板内子行 w 从 2146 收敛到面板内容宽 843。子项显式设了叉轴尺寸(宽/高)则尊重之;锚定轴仍由锚定矩形决定。
- **带点击回调的节点命中即消费**:`点击`/`按住` 模式命中后原先仍返 空,命中判定继续下沉到兄弟节点——模态遮罩(矩形+空 `点击` 回调)盖住界面后点击仍穿透到下层按钮/输入栏。现指针在带 `点击` 回调(含空回调)的节点内即消费命中;禁用节点维持点击穿透旧语义。

## v1.5.2

**新增**

- **多行编辑**:`UI.多行编辑(状态, 键, 选项)`——多行文本编辑器控件(铸造厂 CodeEdit 地基)。值绑 `状态[键]` 整段字符串(`\n` 分行);行号(默认真,`行号: 假` 可关)、点击定位光标、拖动框选、字符输入(含 IME 内联组合)、退格/方向键(按住连发)、回车换行、Tab 插 4 空格、Home/End 行首行尾、Ctrl+A/C/X/V(保留换行)、滚轮与滚动条拖拽、ESC/点外失焦;选项:占位/占位色/字号/字距/宽/高/底色/框色/边框宽/焦框色/焦框宽/圆角/内边距/只读/行号 + 通用键。
- **语法高亮**(多行编辑选项):`"高亮": "玄铁"` 开启玄铁分词着色——关键字/字符串/注释/数字四类(VSCode Dark+ 风配色),三引号多行串跨行状态正确推进,转义引号/行尾注释/未闭合串均妥善处理;`"高亮色": {"关键字": 色(...), ...}` 可按类覆写调色板。分词缓存驻编辑器状态,值变才重分词,渲染期零分词开销;IME 组合行暂走纯文本通路,上屏即恢复。
- **锚点系统**(Godot 风,全控件通用):`"锚": {"左": 比, "上": 比, "右": 比, "下": 比}`(0~1,可缺省)+ `"偏": {"左": px, ...}` 像素偏移。逐轴规则:双锚=按比例拉伸(宽随父变);单锚=定点+固有/选项尺寸(比值 <0.5 前向长、>0.5 后向长、=0.5 居中);无锚=维持现有 Flex 排布。叠容器内锚定子给满内容区槽位(IDE 壳:顶栏/侧栏/主区/状态栏一次写清,拖拽调窗口自动跟随);主轴容器内锚定子在弹性格内对齐。外边距不适用,`平移x/平移y` 仍叠加(动值 可驱动面板滑入滑出)。35 项矩形断言全绿。
- **图标按钮**:`UI.图标按钮(源, 选项)`——纯图标按钮(无文本标签),png/jpg/bmp/gif/svg 居中,默认 28×28 透明底,悬浮淡亮、按下加亮,禁用图标降透 40%;`宽/高/图标尺寸(0=自动)/图标色(tint)/悬按禁底色/圆角/内边距/禁用` 可配,交互与按钮同套。无边框自绘标题栏三件套(最小化/最大化/关闭)的官配控件。
- **按压源竞争修复**:深层节点(含默认"点击"模式)按下沿登记按压源后,祖先层/同帧下层不再竞争——此前行级 `触发:"按下"` 会把按压源抢写成行身份,松开时子按钮身份比对不符被压死(无边框标题栏三钮全失灵的实测案例)。新增帧级 `_本帧按压登记` 标记,深层先登记者胜。

**修复**

- **多行编辑聚焦不进脏源**:按需重绘的脏源清单只查了输入栏焦点(`_焦点栏`),漏了多行编辑焦点(`_焦点编`)——聚焦编辑器后鼠标静止即无脏源,帧体(含键盘处理)永不执行:打字/退格/方向键/回车/IME 全被吞,光标闪烁节拍也不走。现文本类焦点(输入栏·多行编辑)统一算脏,聚焦即持续重绘。
- **多行编辑占位文本显示 `???`**:占位渲染裸调 `绘文字`(raylib 内置默认字体,无中文字形),正文与输入栏占位均走 `_字体` 通路唯独此处漏接。已改为与正文一致的 `_字体` 分支。

## v1.5.1

**新增**

- **裁剪**(容器选项):子树超出节点边界即裁,视口外不响应交互——可收起侧栏/面板的宽高等收起动画不再溢出。
- **平移x/平移y**(像素,可负):渲染与命中间步偏移、不影响兄弟布局(CSS transform 语义),`动值` 驱动即抽屉/面板滑入滑出。
- **窗口选项**:`应用` 第三参新增 `背景`(整窗清底色,默认深灰 40,40,50)、`可调整`(允许拖拽调大小)、`全屏`(进入全屏并自动按真实屏幕尺寸布局)、`无边框`(去标题栏与边框)——此前背景写死深灰、窗口形态只能绕手动循环。
- **尺寸变化即脏源**:拖拽调大小期间逐帧按当前尺寸重排重绘(按需与纯循环双路径);此前调节过程画面冻结直到其他交互触发重绘。

**修复**

- **键盘事件大面积丢失**(按需重绘引入):帧首第二泵与 结束绘图 内泵形成双泵,raylib 每次 PollInputEvents 清空字符/键队列,上一泵注册的字符/键边沿在帧体读取前即被清掉——打字/退格/方向键/IME 上屏/Ctrl+V 约 99% 丢失。改为单泵纪律:脏帧只走 结束绘图 经典泵(与裸 60fps 循环同构),仅空闲周期帧首补泵。
- **不透明度内部键名与解析器推导不一致**(`_不透明` vs `_不透明度`)导致字典缺键静默返 空、整树 alpha 清零(全空白窗口)。内部键统一为 `_不透明度`,全部解析键已与 造节点 默认值逐一对账。

## v1.5.0

**新增**

- **图片控件**:`UI.图片(源, 选项)`——png/jpg/bmp/gif/svg(自动光栅化);固有尺寸取纹理原尺寸,`宽`/`高` 可指定缩放,`图标色` tint,配 `点击` 即成图片按钮。
- **通用状态覆写**:`悬浮`/`按下`/`禁用` 子字典升级为**任意选项键可覆写**(源/宽高/不透明度/图标色/平移……),解析顺序 禁用 > 按下 > 悬浮 > 常态;颜色三态继续兼容平面键。宽/高经上一帧悬浮/按压身份在布局期解析(一帧滞后,无感)。
- **不透明度**(0~100):渲染期整棵子树连乘,`动值` 直接驱动浮现/淡出;0 = 不可见且**不响应命中**(点击穿透)。渐变背景经绘制 tint 折算,不重建纹理。

**修复**

- `禁用: 真`(布尔形态)此前会对布尔调 `含?` 段错误——现在仅字典形态进入禁用覆写展开,布尔形态纯开关(顺带:`UI功能总览.xt` 示例此前启动即崩)。

## v1.4.3

**新增**

- **IME 失焦自动禁用**:无输入栏焦点时断开窗口 IME 上下文——组合与候选窗整体不产生(此前失焦打字候选窗失去定位点,落在屏幕右下角),获焦恢复(渲染 v1.2.3 `设输入法启用` 联动,逐帧幂等)。
- **悬浮输入栏变 I 形光标**:鼠标悬在输入栏上自动切文本编辑光标,移开恢复箭头;禁用栏不变(渲染 v1.2.3 `设鼠标样式` 联动)。

## v1.4.2

**修复**

- **主线程进 UI 主循环后 fiber 整体饿死**(纯 60fps 循环同病):`应用`/`刷新` 每个循环周期调用运行时新增 `xt_scheduler_step` 非阻塞单步泵——fiber 与线程池任务在 UI 主循环期间持续推进,无需手动 `等待` 泵送;其他线程 `态设` 在下一个轮询周期(≤8ms)唤醒重绘。

## v1.4.1

**新增**

- **按需重绘**(默认开):无脏源(状态标脏/鼠标位移/左键按住/滚轮/动画活跃/输入栏聚焦)时只泵事件空转不画帧,空闲 CPU 实测近零;持续动画界面每帧都脏,行为与全速一致。`{"按需重绘": 假}` 回纯 60fps 循环作对照。滚轮改 `_轮增量` 累计,防跨周期丢滚轮。

## v1.4.0

**新增**

- **滚动容器**:`UI.滚动容器(子列表, 选项)`——子项按列排布,滚轮丝滑补间滚动,可视区裁剪(滚出视口的子项不响应悬浮/点击),滚动条仅按住拇指可拖拽;`滚动条` 默认真,**内容不溢出/空容器自动隐藏且不占位**;`条宽`/`轨道色`/`拇指色`/`拇指拖色` 样式自定义。

**修复**

- 内容高前置测量:修掉尾随间距虚增导致的临界假溢出;目标滚动量按本帧内容高夹取。
- 按下态跟随按压源:只有按压起始在本控件才显示按下态,按住左键扫过按钮不再误亮(`触发: "按下"` 模式补登记/出清)。
- **双挂守卫**:同一节点实例一帧内被布局两次即明确报错退出——此前坐标被后挂载点覆盖,先挂载点内控件全部不可见(灵异现象:空容器却有滚动条)。

## v1.3.0

**新增**

- **组件动画系统**:`UI.造动画(键, {"时长", "曲线"})` + `UI.动值(键, 目标值)`——声明式补间动画,目标值变化当帧起从当前显示值平滑起播(中途变向续播顺滑);数值与颜色(r/g/b/a)皆可动画。曲线预设:线性/丝滑(默认)/缓入/缓出/回弹(过冲)。定点整数实现(×10000 比例尺 + 二分求参),零堆分配、全程确定性。
- **内建缓动**(免配置):按钮悬浮/按下/禁用的底色与字色、输入栏聚焦边框色,状态切换自动丝滑过渡(120~150ms)。组件身份按帧遍历序编号(树形稳定即稳定),输入栏用栏键(天然稳定)。
- **按钮微交互**(默认开,可调可关):悬浮上浮 2px 并丝滑渐增阴影(立体感);按住缩小至 95%(90ms 缓出快收)、松开回弹曲线复原(220ms 过冲,灵动摁感);文字随按钮同步缩放。`悬浮上浮`(像素,0=关)/`按下缩放`(百分,100=关)调节。
- **状态边色**:`悬边色`/`按边色`/`禁边色`(配 边框色/边框宽 使用),状态切换丝滑过渡。
- **状态子字典**(CSS 伪类风):`悬浮`/`按下`/`禁用` 一键装一个状态的覆写,子键 `底色`/`字色`/`边色`;与平面键可混用。

**修复**

- 矩形设了 `底色` 仍被 `字色` 覆盖绘制(白块)——现在仅底色透明时才用字色填充(历史行为兼容)。

## v1.2.0

**新增**

- **输入栏控件**:`UI.输入栏(状态, 键, 选项)`——单行文本输入框,值双向绑定状态容器。占位文本、点击定位光标、左键拖动框选、退格/方向键按住连发、上/下跳到首/尾、Ctrl+A/C/V/X、回车提交回调、中文 IME 内联组合(拼音直接显示在栏内带下划线)+ 候选窗跟随光标(贴输入栏底边)、长文本横向滚动保持光标可见。
- **输入栏图标**:`左图标`/`右图标` 图片路径(png/jpg/bmp/gif,`.svg` 自动走 nanosvg 光栅化),`图标尺寸`(0=自动取栏内净高)/`图标距`/`图标色` tint,`右图标点击` 回调(一键清空等;命中不挪光标不进框选)。文本区自动内缩,长文本滚动被裁剪在文本区内、永不遮挡图标。
- **输入栏样式参数**:`占位色`/`焦框宽`/`字距`。
- **通用外观选项**(全控件可用):`底色2` + `渐变向`("横"/"竖")渐变背景、`羽化`(边缘柔边)、`阴影`({"颜色"/"模糊"/"x"/"y"})、`字距`。渐变/羽化由渲染库圆角渐变纹理生成器驱动。

**修复**

- `框色`(默认边框色)选项此前从未写入生效字段,非聚焦边框实际不绘制;现在聚焦画 焦框色/焦框宽、非聚焦画 框色/边框宽。
- 字距对 GDI 系统字体通路生效(渲染库 v1.2.0 联动:此前 spacing 仅 raylib 字体通路生效)。

## v1.1.0

**变更**

- **默认字体改 GDI 系统字体优先**(渲染库 v1.1.0 联动):`确保默认字体` 现在优先 `R.加载系统字体("微软雅黑", 32)`——Windows 系统级灰阶抗锯齿、按需栅格化、无需 ttf 文件;失败回退内置鸿蒙 ttf,再失败回退 raylib 默认字体。中文界面开箱即系统级观感。

**新增**

- 内置字体查找新增 `XUANTIE_HOME` 环境变量候选(安装器写入,指向安装目录):发行包用户的程序在任意目录运行都能定位 `lib\UI\assets` 资源。
