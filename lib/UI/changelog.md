# UI 库 Changelog

## v1.4.3

**新增**

- **IME 失焦自动禁用**:无输入栏焦点时断开窗口 IME 上下文——组合与候选窗整体不产生(此前失焦打字候选窗失去定位点,落在屏幕右下角),获焦恢复(渲染 v1.2.3 `设输入法启用` 联动,逐帧幂等)。
- **悬浮输入栏变 I 形光标**:鼠标悬在输入栏上自动切文本编辑光标,移开恢复箭头;禁用栏不变(渲染 v1.2.3 `设鼠标样式` 联动)。

## v1.4.2

**修复**

- **主线程进 UI 主循环后 fiber 整体饿死**(纯 60fps 循环同病):`应用`/`刷新` 每个循环周期调用运行时新增 `xt_scheduler_step` 非阻塞单步泵——fiber 与线程池任务在 UI 主循环期间持续推进,无需手动 `等待` 泵送;其他线程 `态设` 在下一个轮询周期(≤8ms)唤醒重绘。

## v1.4.1

**新增**

- **按需重绘**(默认开):无脏源(状态标脏/鼠标位移/左键按住/滚轮/动画活跃/输入栏聚焦)时只泵事件空转不画帧,空闲 CPU 实测近零;持续动画界面每帧都脏,行为与全速一致。`{"按需重绘": 假}` 回纯 60fps 循环作对照。滚轮改 `_轮增量` 累计,防跨周期丢滚轮。

## v1.4.0

**新增**

- **滚动容器**:`UI.滚动容器(子列表, 选项)`——子项按列排布,滚轮丝滑补间滚动,可视区裁剪(滚出视口的子项不响应悬浮/点击),滚动条仅按住拇指可拖拽;`滚动条` 默认真,**内容不溢出/空容器自动隐藏且不占位**;`条宽`/`轨道色`/`拇指色`/`拇指拖色` 样式自定义。

**修复**

- 内容高前置测量:修掉尾随间距虚增导致的临界假溢出;目标滚动量按本帧内容高夹取。
- 按下态跟随按压源:只有按压起始在本控件才显示按下态,按住左键扫过按钮不再误亮(`触发: "按下"` 模式补登记/出清)。
- **双挂守卫**:同一节点实例一帧内被布局两次即明确报错退出——此前坐标被后挂载点覆盖,先挂载点内控件全部不可见(灵异现象:空容器却有滚动条)。

## v1.3.0

**新增**

- **组件动画系统**:`UI.造动画(键, {"时长", "曲线"})` + `UI.动值(键, 目标值)`——声明式补间动画,目标值变化当帧起从当前显示值平滑起播(中途变向续播顺滑);数值与颜色(r/g/b/a)皆可动画。曲线预设:线性/丝滑(默认)/缓入/缓出/回弹(过冲)。定点整数实现(×10000 比例尺 + 二分求参),零堆分配、全程确定性。
- **内建缓动**(免配置):按钮悬浮/按下/禁用的底色与字色、输入栏聚焦边框色,状态切换自动丝滑过渡(120~150ms)。组件身份按帧遍历序编号(树形稳定即稳定),输入栏用栏键(天然稳定)。
- **按钮微交互**(默认开,可调可关):悬浮上浮 2px 并丝滑渐增阴影(立体感);按住缩小至 95%(90ms 缓出快收)、松开回弹曲线复原(220ms 过冲,灵动摁感);文字随按钮同步缩放。`悬浮上浮`(像素,0=关)/`按下缩放`(百分,100=关)调节。
- **状态边色**:`悬边色`/`按边色`/`禁边色`(配 边框色/边框宽 使用),状态切换丝滑过渡。
- **状态子字典**(CSS 伪类风):`悬浮`/`按下`/`禁用` 一键装一个状态的覆写,子键 `底色`/`字色`/`边色`;与平面键可混用。

**修复**

- 矩形设了 `底色` 仍被 `字色` 覆盖绘制(白块)——现在仅底色透明时才用字色填充(历史行为兼容)。

## v1.2.0

**新增**

- **输入栏控件**:`UI.输入栏(状态, 键, 选项)`——单行文本输入框,值双向绑定状态容器。占位文本、点击定位光标、左键拖动框选、退格/方向键按住连发、上/下跳到首/尾、Ctrl+A/C/V/X、回车提交回调、中文 IME 内联组合(拼音直接显示在栏内带下划线)+ 候选窗跟随光标(贴输入栏底边)、长文本横向滚动保持光标可见。
- **输入栏图标**:`左图标`/`右图标` 图片路径(png/jpg/bmp/gif,`.svg` 自动走 nanosvg 光栅化),`图标尺寸`(0=自动取栏内净高)/`图标距`/`图标色` tint,`右图标点击` 回调(一键清空等;命中不挪光标不进框选)。文本区自动内缩,长文本滚动被裁剪在文本区内、永不遮挡图标。
- **输入栏样式参数**:`占位色`/`焦框宽`/`字距`。
- **通用外观选项**(全控件可用):`底色2` + `渐变向`("横"/"竖")渐变背景、`羽化`(边缘柔边)、`阴影`({"颜色"/"模糊"/"x"/"y"})、`字距`。渐变/羽化由渲染库圆角渐变纹理生成器驱动。

**修复**

- `框色`(默认边框色)选项此前从未写入生效字段,非聚焦边框实际不绘制;现在聚焦画 焦框色/焦框宽、非聚焦画 框色/边框宽。
- 字距对 GDI 系统字体通路生效(渲染库 v1.2.0 联动:此前 spacing 仅 raylib 字体通路生效)。

## v1.1.0

**变更**

- **默认字体改 GDI 系统字体优先**(渲染库 v1.1.0 联动):`确保默认字体` 现在优先 `R.加载系统字体("微软雅黑", 32)`——Windows 系统级灰阶抗锯齿、按需栅格化、无需 ttf 文件;失败回退内置鸿蒙 ttf,再失败回退 raylib 默认字体。中文界面开箱即系统级观感。

**新增**

- 内置字体查找新增 `XUANTIE_HOME` 环境变量候选(安装器写入,指向安装目录):发行包用户的程序在任意目录运行都能定位 `lib\UI\assets` 资源。
