第一步：将 xuantie-syntax 文件夹复制到 IDE 的用户扩展目录：
  Windows VSCode：%USERPROFILE%\.vscode\extensions
  macOS / Linux VSCode：~/.vscode/extensions
  Trae：把上述路径中的 .vscode 改为 .trae
  JoyCode：~/.joycode-editor/extensions
第二步：重启 VSCode（或其他基于 VSCode 内核的 IDE，如 Trae、JoyCode）；
最后：重启后扩展管理器无报错、并看到新扩展"XuanTie Syntax Highlighting"即安装成功。恭喜！

高亮、代码片段、拼音补全开箱即用；LSP 实时诊断需 LSP 服务器——
Windows 安装包自带 xt_lsp.exe，macOS/Linux 需自行构建 xt_lsp 放入 PATH
或在设置项 xuantie.lspServerPath 指定路径。
完整跨平台安装说明见仓库 docs/VSCode编辑器插件安装.md。
