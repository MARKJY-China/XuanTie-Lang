# 波形带限与听感验收记录（渲染库合成器扩展，issue #94）

> 记录锯齿/方波从「非带限直出（混叠抖动）」到「polyBLEP 带限」的修复过程，以及与 FL Studio 3xOsc 的听感对比结论。
> **结论先行：保持现状。当前方波 ≈ FL 3xOsc 方波套 5735Hz 61% 低通（柔和但干净），这是 22050 采样率下的合理状态。**

## 最终形态（推荐基线）

- `xt_poly_blep(t, dt)`：标准二阶 polyBLEP 修正窗
- `xt_osc_sample(wave, ph, dt)`：锯齿/方波跳变处做带限修正，dt = w/(2π)（C5 下约 1 采样宽）
- **无输出低通**：polyBLEP 本身已消除混叠，输出低通只会让波形变钝（曾试 8k/12k 二阶，均因此弃用）
- 瞬时音头：调用方显式传 `{ 包络: { 释音: 1 } }`（1ms 释音使 ADSR 不退化，起音 0ms）

## 问题与根因

用户裸波形对比（waveform.xt，C5 500ms）反馈：**3 锯齿 / 4 方波有短周期高频抖动，不像 FL 3xOsc 干净**。

根因（两重）：
1. **非带限直出**：朴素方波/锯齿在 22050 采样率下，Nyquist（11025Hz）之上的谐波折叠回低频，形成非谐波混叠乱音。C5 的 43 次谐波（22499Hz）折叠到 **450Hz**——这正是听感「抖动」的主要来源。
2. **polyBLEP 曾丢失**：修改过程中分发包的渲染桥.c 一度被覆盖回朴素版（无 xt_poly_blep），抖动即复现。排查时先确认「当前文件里到底有没有 polyBLEP」再动手。

## 修复与数值验证

| 阶段 | 450Hz 杂散 | 9-11kHz 峰值 | 说明 |
|---|---|---|---|
| 朴素直出（无 BLEP） | 161.8 | 280.1 | 混叠折叠明显 |
| polyBLEP 首版 | 81.2 | 325.8 | 主体干净，近 Nyquist 仍强 |
| +输出 9kHz 一阶低通 | - | 280.1（-14%） | 一阶太弱，弃用 |
| BLEP 窗×4 | 161.8（反升） | 280.1 | 窗过宽引入新伪影，弃用 |
| +输出二阶 8k/12k 低通 | 2.5 | 109.8/144.5 | 低通压近 Nyquist，但波形变钝 |
| **polyBLEP（无低通）最终版** | **2.5** | **164.2** | 混叠归零，高频保留，用户验收 |

最终结论：**450Hz 混叠杂散靠 polyBLEP 独立消除（161.8→2.5，-36dB），输出低通对 450Hz 无贡献且只会钝化音色，故移除**。

## FL Studio 听感对比（诚实记录）

用户用 FL Studio 3xOsc（单振荡器、HQ、无 ADSR、C5）逐项对比：

- **音头**：FL 无 ADSR → 音头突兀；我们默认 10ms 淡入淡出 → 柔。显式传 `{ 包络: { 释音: 1 } }` 后音头瞬时，与 FL 一致。
- **方波亮度**：FL 方波更刺耳响亮。用户实测：**FL 3xOsc 方波套 EQ 低通 5735Hz 61%（FL EQ2）后与我们程序「极其相似」**——即我们程序 ≈ FL 方波套约 5.7kHz 低通。
- **原因**：① 22050 Nyquist 上限（FL 48000，方波谐波 FL 到 24kHz、我们只能到 11kHz）；② polyBLEP 滚降曲线等效一条约 5.7kHz 起压的低通。
- **决策（用户拍板）**：保持现状。「FL 方波 + 5735Hz 低通」的柔和音色作为已知特征接受；22050 下已干净无抖动，属合理状态。
- **可选但未采纳**：更高阶 BLEP / 过采样可让方波更刺耳（高频保留更多），但改动面大且 11kHz 上限物理不可突破。

## 附带踩坑：ADSR 必须走「包络」子选项

渲染.xt 合成器只解析 `选项["包络"]["起音|衰减|延持电平|释音"]`，**顶层 `{ 释音: 1 }` 会被静默忽略**（释音保持 0 → ADSR 退化 10ms 淡入淡出）。正确写法：

```text
{ 包络: { 释音: 1 } }        # 1ms 释音,起音 0ms 瞬时,尾部 1ms 淡出防爆
{ 包络: { 起音: 20, 衰减: 50, 延持电平: 0.8, 释音: 100 } }
```

注释里的 `包络 { 起音, 衰减, 延持电平, 释音 }` 容易误读成顶层字段，属文档表达问题，后续可改进注释措辞。
