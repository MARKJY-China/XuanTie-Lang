# 混响实现踩坑记录（渲染库合成器扩展，issue #94）

> 记录渲染桥.c 混响从 freeverb 演进到 FDN 反馈延迟网络的全过程与每个坑。
> **结论先行：不要回退到 freeverb，不要改坏 allpass 的全通结构，否则重新踩坑。**

## 最终形态（推荐基线）

FDN 16 线反馈延迟网络 + 线内 allpass 扩散 + 慢速 LFO + 干音/尾音分离增益。

## 坑位详述

### 坑 1：freeverb 的金属薄钢板感

- 症状：尾音像 0.5m 见方的薄铁板被绿豆击中后的震荡回声。
- 根因：comb 反馈环的离散模态共振——频率接近输入谐波的延迟线共振突出，形成金属板材模态。
- 结论：**不要回退到 comb 型 freeverb**；金属感是结构问题，参数调不掉。

### 坑 2：FDN 线长拍频

- 症状：8 线 FDN 尾音出现「一对对曲线」的周期性涨落（振幅起伏）。
- 根因：线长比例接近简单比（如 401/449、631/701、761/829 ≈ 1.1），回声周期性对齐/错开。
- 结论：**FDN 线长必须质数且两两互质**；16 线密度翻倍后拍频被淹没。

### 坑 3（最关键）：allpass 缺失全通系数 → 变成放大器

- 症状：尾音能量**持续增长**到 tanh 饱和 → 输出完美方块波 → 「手甩水滴到铁板」的金属敲击声。8 轮参数调整听感完全不变。
- 根因：`out = -x + buf[idx]` 分子缺 `fb` 系数，传递函数 H(z) = (-1 + z⁻ᴺ)/(1 - fb·z⁻ᴺ) 不是全通，高频增益 >1（可达 1/(1-fb) = 2.86 倍）。FDN 反馈环每圈都被放大，尾音涨到饱和。
- 排查过程：听感不变 → 导出 PCM 做时域分析，发现尾音 RMS 从 0.16 一路涨到 1.0（不衰减）→ 波形抽样显示完美方块波 → 打印参数确认 fg=0.931 正常 → 逐环节验增益，锁定 allpass。
- 修复：`out = -a->fb * x + a->buf[a->idx];`（分子带 fb，真全通）。
- 教训：**全通滤波器实现必须分子分母系数对称；反馈网络里任何增益 >1 的环节都会逐圈累积成饱和**。数值分析（导出 PCM 看时域/波形）是这类「听感不变」疑案的唯一可靠手段。

### 坑 4：湿音增益与 tanh 饱和

- 症状：为提升湿音响度提高注入增益，尾音过载饱和。
- 处理：注入保持 1.0（控制 FDN 存储能量），湿音响度从**输出侧**补；干音期/尾音期分离增益（尾音期是混响主体，增益更高）。

## 最终参数

- FDN 线长 fdn_t[16] = {349, 367, 389, 409, 431, 457, 479, 499, 521, 547, 571, 599, 619, 647, 683, 733}（全质数，15.8-33.2ms，房间空间感）
- 每条线内嵌 60 采样 allpass 扩散器（打散梳状模态）；总扩散 16 级 allpass，fb 0.65
- 线内反馈低通 damp 0.35（共振钝化）；FDN 反馈 fg = 0.28 + 房间大小×0.7（钳 0.95）
- 干音注入 1.0；干音期湿音 ×3.0（混合比 ×0.5）；尾音期湿音 ×10.0
- 动态尾长（衰减到 -66dB）+ 末尾 0.3s 淡出；湿音 40ms 渐入（消除起始瞬态敲击）

## 遗留限制

- FDN 尾音仍有轻微「多正弦叠加」的模态感（无金属、无饱和，但不如 FL 卷积混响完全自然）
- 22050 采样率谐波截断影响锯齿波尖锐度（与 FL 内部 96kHz 对比）

## 防回退警告（置顶）

1. 不回退到 freeverb——comb 模态 = 金属钢板。
2. FDN 线长保持质数互质，否则拍频起伏。
3. **allpass 必须全通（分子带 fb）——这是放大器 bug 的根源，动手前先读「坑 3」。**
4. 湿音增益从输出侧补，不要靠注入增益硬顶（tanh 饱和 = 方块波 = 甩水）。
