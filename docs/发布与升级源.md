# 发布与升级源（雨云 ROS）

> 目标：`xtc 升级` 在中国大陆不走 GitHub，而是查文档站的 `latest.json`，下载链接指向雨云对象存储（ROS）。

## 数据流

```
release.yml(tag) ──上传──▶ 雨云 ROS(S3)
        │                     │
        └── 生成 latest.json ──┘
                    │
                    ▼
   https://xuantie.markjy.com/api/latest.json   ← 文档站 nginx 反代/重定向到 ROS
                    │
                    ▼
             xtc 升级 --国内
```

## latest.json 结构

```json
{
  "version": "v1.0-rc.4",
  "published_at": "2026-11-13T00:00:00Z",
  "platforms": {
    "windows_amd64": {
      "url": "https://download.xt.markjy.com/releases/v1.0-rc.4/xuantie_v1.0-rc.4_windows_amd64.tar.gz",
      "sha256": "…",
      "size": 63252890
    }
  }
}
```

平台键：`windows_amd64` / `windows_arm64` / `linux_x86_64` / `linux_arm64` / `darwin_arm64`。

## 一次性配置

1. 雨云 ROS 建桶（建议公开读）；记下 endpoint（如 `https://cn-sy1.rains3.com`）、桶名、AccessKey/SecretKey。
2. 绑定公开域名（如 `download.xt.markjy.com`），或直接用 `https://<桶名>.cn-sy1.rains3.com`。
3. 在 GitHub 仓库 Secrets 里加：

| Secret | 说明 |
|---|---|
| `ROS_ENDPOINT` | 例如 `https://cn-sy1.rains3.com` |
| `ROS_BUCKET` | 桶名 |
| `ROS_ACCESS_KEY` | 雨云 AccessKey |
| `ROS_SECRET_KEY` | 雨云 SecretKey |
| `ROS_PUBLIC_BASE` | 公网前缀，例如 `https://download.xt.markjy.com` |

4. 文档站 nginx 加一条（二选一）：

```nginx
# A. 重定向到 ROS 上的 latest.json（最简单）
location = /api/latest.json {
    return 302 https://download.xt.markjy.com/latest.json;
}

# B. 反代（隐藏 ROS 域名）
location = /api/latest.json {
    proxy_pass https://download.xt.markjy.com/latest.json;
    proxy_set_header Host download.xt.markjy.com;
}
```

## 发版时

CI 在 tag 触发的 `publish` job 里自动执行（已接入）：

```bash
node tools/publish-ros.mjs --dir artifacts --version "$GITHUB_REF_NAME"
```

本地手动发：

```bash
ROS_ENDPOINT=... ROS_BUCKET=... ROS_ACCESS_KEY=... ROS_SECRET_KEY=... \
ROS_PUBLIC_BASE=https://download.xt.markjy.com \
node tools/publish-ros.mjs --dir release --version v1.0-rc.4
```

只演练不上传：

```bash
node tools/publish-ros.mjs --dir release --version v1.0-rc.4 --dry-run
```

脚本行为：上传 `releases/<tag>/xuantie_<tag>_<平台>.tar.gz` 与 `MANIFEST_*.txt`，生成并上传根目录 `latest.json`（含每个平台的 URL/SHA256/大小）。

## xtc 侧

```bash
xtc 升级 --检查            # 查 GitHub API（海外/能直连时）
xtc 升级 --检查 --国内     # 查文档站 latest.json → ROS 链接
xtc 升级 --国内            # 下载并原地覆盖（--强制 重装同版本）
```

`--国内` 读取 `https://xuantie.markjy.com/api/latest.json`；下载完成后先运行解压出的 `xtc -V` 校验版本，再覆盖安装目录（当前二进制先改名为 `.old`，失败不改动原目录）。
