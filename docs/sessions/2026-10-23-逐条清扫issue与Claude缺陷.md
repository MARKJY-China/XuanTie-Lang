## 踩了什么坑

- **PowerShell 引号**：多次用双引号拼含中文引号/`\"` 的替换脚本，把整段脚本解析坏（未执行，安全）；改用 edit 工具才稳。
- **`玄铁.xt` 被脚本截断到 478 行**：`$out += 数组区间` 失败导致丢尾部；靠 `git checkout --` 恢复后重做。教训：改大文件用 edit 工具，别用脚本拼数组。
- **GSC 与新内建**：驱动用新内建时，GSC 必须先注册符号 + declare，否则 s1 编不过（已两次踩到）。
- **golden 含绝对路径**：重录基线后才发现换机器必失效；给 regress.py 加 `<ROOT>` 归一化并全部重录。
- **`.gitignore` 自排除**：它把自己忽略掉，所以从未入库；`/Test/*.xt` 规则还会吃掉辅助模块。
